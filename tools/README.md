# tools（本仓自带的离线工具）

| 工具 | 做什么 |
|---|---|
| `取数/llm_client.py` | 模型调用客户端（凭证在 `.local/接入凭证.env`，⛔ 不进版本控制） |
| `材料/取材料.py` | 从语料里取一段材料（按字数挑，可指名第几条；`list` 看各语料能取多少） |
| `材料/fetch_text.py` | 从 URL 取正文 |
| `对照/真值密度.py` | 量 LongMemEval 的真值密度（只读本地副本；缺数据会自己说去哪取） |
| `转换/语料转原文.py` | 把语料转成"原文"（`docs/记忆层.md` 里的原料形态） |
| `转换/小说切章.py` | 把一本小说切成章节（取材用） |
| `标注/看标注.py` | 看一份标注输出的节点 / 组 / 边（只读） |
| `记忆/标记集.py` | 标记集的规格测试（实现已经在 `memory/` 里） |
| `文档/check_docs.py` | 文档结构与规范自查：编号顺序 / 重复 / 冲突标记 / 相对链接（**改完必跑**） |

⚠️ **数据与凭证不进版本控制**：语料在 `docs/语料/`（见 [`../docs/语料评估.md`](../docs/语料评估.md)），
凭证在 `.local/`。脚本只读本机副本，缺了会报错并说去哪取。

标注**跑批**那一套（`批量标注.py` / `重复性.py`）**不在本仓**：它们依赖 `annotate`（标注提示词的实现），
而那套提示词已经归档。相关读数留在 `docs/参数账.md` 与 `docs/语料评估.md` 里，标注为历史记录。
