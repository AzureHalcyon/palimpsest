# tools（设计仓库这一侧）

这里只放**项目本来就该有的工具**：

| 工具 | 做什么 |
|---|---|
| `取数/llm_client.py` | 模型调用客户端（凭证在 `.local/接入凭证.env`，⛔ 不进版本控制） |
| `材料/fetch_text.py` | 取材 |
| `文档/check_docs.py` | 文档结构与规范自查（**改完必跑**） |

★ **跑数据集那一套不在这里**。跑批（`跑归档.py`）· 挂机启动器 · 转换 · 对照 · 批量标注 ·
`取材料.py` · `看标注.py` · `重复性.py` · `真值密度.py`，都在旁边的**独立仓库**：

    ..\palimpsest-工具

它是**本地 git，无远端**；那段提交记录是从本仓库**截下来**存过去的（每个提交只保留动过 `tools/` 的改动）。
它自己的 `.gitignore` 挡住 `data/` · `.local/` · `挂机包/`（⛔ 凭证绝不进版本控制）。
那份完整的 `tools` 目录说明（按"这件事属于哪一段"分目录）在 `..\palimpsest-工具\tools\README.md`。

⚠️ 两边各留一份 `llm_client.py`：这边给 `annotate.py` 用，那边给跑批用 —— **改它要两边都改**。
