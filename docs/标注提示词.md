````text 公共
你在整理一段材料：把里面值得记的位置摘出来，再把其中属于一起的划到一起。

这一遍**只产出这两件事**（外加一句理由），**不产出"关系"**——
两处之间是什么关系，不由这一步回答。

# 你要产出三样东西

节点：材料里的一处文本，它体现了一点值得记下来的东西。
      ★ 判断标准：这段文字是不是在说一件具体的事、一个明确的观点、一种情绪，
        或者给出一句解释、建议、判断？是，就标。
      ★ **是谁说的、是不是在回应上一句，都不影响。**
        材料里两边的发言都是材料的一部分；把对方的意思说出来（重述）、
        给出解释或建议，同样是内容。
        ⛔ 只排除真正空的：招呼、语气词、纯附和（"嗯""好""是的"）、
        没说出任何东西的重复。
      ★ 两个方向都会错，都要避免：
        · 标太少——某一句明明说了内容，却没标，那它就不在记忆里了；
        · 标太多——把招呼和语气也标上，图就被填满了，等于没有取舍。
      ★ 一轮说的话通常只构成一个节点，不要把它拆成几个；
        但一轮里确实说了两件事（一件具体的、一个观点），就分成两个。
      ⛔ 不要改写、不要概括、不要拼接不相邻的句子。原样摘出。
      ★ 全部标完后，回头把每一条再审一遍：只说得上"招呼 / 语气词 / 纯附和"的，删掉。

组：把**属于一起**的节点放在一起。这一遍只按**一个**标准——
    写在后面那一段里；按别的标准也能合起来的，这一遍**不写**（那是另一遍的事）。
    ★ **一处发言可以同时属于多个组**（既是重述、又在安慰）。
      但**每个组都必须各自满足本遍那一条标准**——
      那个说法套得住组内至少两处、**而且区分得开**，才写；
      套不住就别写，**宁可让它散着**。
      ⛔ "只按一个标准"说的是**别把别的视角的标准混进来**，不是说一处只能进一个组。
    ★ 两个方向都会错：该合没合，一件事散成两半；不该合却合了，组就撑坏了。
    ★ 一处就说全了、或跟别处都不搭的，**不属于任何组**。
      **散着是常见的**：一份材料里可能有**一多半**节点都不属于任何组，
      它们各自成事——**不是漏掉的，也不用给它们找地方放。**
      ⛔ **那就不要为它写组。** 一个只有它自己的组什么都没说，等于没分。
      ⛔ 也不要为了"**显得完整**""**显得有层次**""**跟另一组对称**"而补一个组：
        组多不多、均不均**不是成绩**。这一遍只有"合得对不对"这一个标准。
    ★ 每个组都要在 `组说明` 里写一句**你凭的是哪一条**——
      写清**那一条本身**（例如"自我否定""出生资料"），不要复述题面的话。
      ⛔ 说明只作记录，**不进图**。写不出凭什么的组，就不要写。
    ⛔ 组不带类型、不带名字。

<组判据>

<例子>

# 硬要求

1. 摘出来的文字必须在材料里**一字不差地出现**，而且**能找到唯一的位置**。
   ★ 给**完整的一句**，不许截断，不许用省略号。
2. 只标材料里真的写了的。材料里没有的，不要补。
3. 输出严格的 JSON，不要输出别的东西。

# 输入

材料：

<材料原文>

# 输出

```json
{
  "节点": [
    {"引文": "……"}
  ],
  "组": [
    {"成员": [0, 2]}
  ],
  "组说明": ["凭的是……"]
}
```

字段说明：
- `节点` 里每个元素的序号（从 0 开始）就是它在 `组` 里的编号。
- 一个节点可以同时属于多个组。
- `组` 可以为空数组——这段材料里符合本遍标准的情况一处也没有，是可能的。
- `组说明` 与 `组` **一一对应**（个数必须相同）。它只作记录，**不进图**。
````

````text 组-同一件事
本遍的标准：**同一件事**。合起来指的是同一件事的，才归一组。两种情形都算：

   一、**几处合起来才说得清一件事**。单看哪一处都不完整。
   二、**同一件事说了不止一次**。说法不同、位置不同，但指的是同一件事。
      ★ 这一种最要紧：认不出来，它就会被当成两件事，记忆里就有了两份。

★ 反面：**都在说同一个人、同一个话题、位置挨着**——这些**不算**。
  同一话题下可以有好几件不同的事。
````

````text 例子-同一件事
材料（原文）：

    甲：今天这个下午真安静。
    乙：嗯，雨把街上的人都赶回去了。
    甲：我妈下周要来住几天。
    乙：那正好，让她看看你新搬的地方。
    甲：地方还没收拾出来呢。
    乙：我最近也烦，什么都不想动。

产出（这里为了好读写成缩进的样子，你仍要输出 JSON）：

    节点 0：今天这个下午真安静。
    节点 1：嗯，雨把街上的人都赶回去了。
    节点 2：我妈下周要来住几天。
    节点 3：那正好，让她看看你新搬的地方。
    节点 4：地方还没收拾出来呢。
    节点 5：我最近也烦，什么都不想动。
    组 0：[0, 1]          组说明 0：合起来才是"下午安静，因为雨把人赶回去了"
    组 1：[2, 3, 4]       组说明 1：合起来才是"她要来住、让她看看新地方、
                                      可地方还没收拾"

★ 要注意的：

一、**六轮，六个节点**——每一轮都在说一件事或一个观点，所以每一轮都标。
   句首的"嗯，"是承接语，但它和后面的内容在**同一句**里，
   引文要**整句**摘，不许为了去掉它而截断。

二、组 0 与组 1 都是**几处合起来才说清的一件事**：
   单看"下午安静"不知道在说什么，单看"她要来住"也不知道成不成。

三、节点 5 那句"我最近也烦"**不属于任何组**：它自己说全了一件事，跟别处都不搭。
   ⇒ **不写"组 2：[5]"**。只有它自己的组什么都没说。

四、⛔ 把 [0,1,2,3,4,5] 全划成一组就错了——它们只是**同一场对话**，不是同一件事。

五、这一遍只看"是不是同一件事"。节点 0 与节点 5 有点像（都是一种闷），
   那是**另一遍**的标准，这一遍不按它分。
````

````text 组-同一类事
本遍的标准：**同一类事**。它们**不属于同一件具体的事**，但属于同一类。

★ 一个说法要能当"类"，得**靠内容**，不能**只靠动作或语气**。
  测法——**把组里两个成员说的话对调，这个说法还成立吗？**
  · **不成立** ⇒ 它靠的是内容，是"类"。
    （例："出生资料"：成员是"1960年12月12日"与"韩国忠清北道"。
      一对调，这个说法就不对了 ⇒ 它真的在说这几处的**内容**。）
  · **照样成立** ⇒ 它只是按"在干什么 / 什么语气"分的，**那不算类**。
    （"在给建议""在安慰""在重述""都有情绪"——这类说法套到哪儿都成立，**等于没筛**。）

★ 还有一个副产品要防：**几个组联合起来把材料盖完**。
  若你交出的几组**加起来**装进了大半节点，那说明你在按"每一句在干什么"把材料切完，
  而不是在找"属于一起"。⇒ 那种时候**宁可少写几组**。

★ 反面：**同一类**不等于**同一个话题**。
  也**不必**是同一件事——两件不同的事可以同属一类，那正是本遍要找的东西。
````

````text 例子-同一类事
材料（原文）：

    甲：你知道李璟荣吗？
    乙：当然，他是一名韩国演员。
    甲：他是哪年出生的？
    乙：1960年12月12日。
    甲：他出生在哪儿？
    乙：韩国忠清北道。
    甲：他的代表作是什么？
    乙：火花、少数意见、举报者。

产出（这里为了好读写成缩进的样子，你仍要输出 JSON）：

    节点 0：当然，他是一名韩国演员。
    节点 1：1960年12月12日。
    节点 2：韩国忠清北道。
    节点 3：火花、少数意见、举报者。
    组 0：[1, 2]      组说明 0：出生资料

★ 要注意的：

一、组 0 里是**两件不同的事**（出生年份、出生地）。按"同一件事"它们不该在一组，
   而**这一遍的标准是"同一类事"**：都是**出生资料**。
   ⇒ ★ 正因为如此，本遍的结果与别的遍**本来就应该不一样**，这不矛盾。

二、★ 组 0 的说法是"**出生资料**"：它**套得住** 1、2，**套不住** 0（演员身份）与 3（代表作）
   ⇒ 区分得开，够当"类"。
   ⛔ 若换成"这个人的资料"，它把 0 也装进去了——**太粗**；而且这种说法换到别的材料上
     照样成立，那是**话题**级的说法，不是类。

三、节点 0 与节点 3 **不属于任何组**：各自只有一处，没有同类。
   ⇒ **不写"组 1：[0]"**。只有它自己的组什么都没说。
````

````text 组-同一种具体情绪
本遍的标准：**同一种具体情绪**。

★ 关键在"**具体**"：要能说出**是哪一种**。
  "情绪有点复杂""不太好受""都是负面的"这种**说不清的，不算**；**说不清就别合**。

★ 判据是**同一种**，不是"都有情绪"：
  "我不甘心"与"我无所谓"是方向相反的两种情绪，**不能合成一组**。

★ 这一遍**必须写出是哪一种情绪**（写在 `组说明` 里）。
  写不出来，就说明你其实没在按这一个标准分 —— **那就不要写这个组**。

★ 反面：**都是负面的**不算同一种（负面是个大筐）；
  **都在说同一个人或同一件事**也不算——那是别的遍的事。
````

````text 例子-同一种具体情绪
材料（原文）：

    甲：面试又没过，我觉得自己挺没用的。
    乙：别这么说，你已经很努力了。
    甲：努力有什么用，反正结果都一样。
    乙：要不先歇几天？
    甲：歇着更难受，什么都不想干。
    甲：算了，不想说了。
    乙：嗯。

产出（这里为了好读写成缩进的样子，你仍要输出 JSON）：

    节点 0：面试又没过，我觉得自己挺没用的。
    节点 1：努力有什么用，反正结果都一样。
    节点 2：歇着更难受，什么都不想干。
    节点 3：别这么说，你已经很努力了。
    节点 4：要不先歇几天？
    节点 5：算了，不想说了。
    组 0：[0, 1, 2]      组说明 0：自我否定

★ 要注意的：

一、**七轮，六个节点**——**两边的发言都标**：乙的安慰与建议也是内容，
   不因为"说的不是他自己的事"就不算。
   ⛔ 而最后那句"**嗯。**"**不标**：它只是纯附和，没说出任何东西。
   ⇒ 一边要松（别因为是回应就不标），一边要紧（真正空的还是不能标），**两条同时管着**。

二、组 0 里那三处**不是同一件事**（一次落选、一句反问、一种状态），
   也**不是同一类事**。在这一遍里它们归一组，因为**都是自我否定这一种情绪**。

三、★ 节点 3、4、5 **不属于任何组**：
   3 与 4 是安慰与建议（说的是对方的处境，不是一种情绪）；
   5 是"不想再谈"，与"自我否定"不是同一种具体情绪。
   ⇒ **不写"组 1：[5]"**。就因为它"也算负面"就拉进组 0，或者单独给它一个组，
     两种都是错的——**负面是个大筐，不是判据**。
````
