# 文档地图

> 这个仓库的文档比代码多，先看这里，别从目录里随便点。
> 写着「历史」的那几份**保留原样**，用来追溯当时的判断，别当成现在的规格。

## 先读这四份

| 文档 | 它回答什么 | 状态 |
|---|---|---|
| [`../README.md`](../README.md) | 这是什么、两条路线、现在到哪了 | 现行 |
| [`设计.md`](设计.md) | 完整的系统设计（为什么这么设计） | 现行（长） |
| [`流程框架.md`](流程框架.md) | **现在真的怎么跑**：一场从开场到归档的每一步、读到的每个参数 | 现行 |
| [`记忆层.md`](记忆层.md) | 记忆层展开篇：归档、读取、件与组、常驻、势 | 现行（长） |

> ★ **冲突时以谁为准**（2026-10-19 定）：
> **现状 / 行为**看 [`流程框架.md`](流程框架.md)；**设计意图**看 [`设计.md`](设计.md)；
> [`记忆层.md`](记忆层.md) 是展开篇，只作解释与背景，⛔ 不单独裁决。
> 三份里任何一份与代码冲突，以**代码 + 测试**为准，并回来改文档。

## 按问题找

| 问题 | 去哪 |
|---|---|
| 有哪些参数、每个什么意思、能不能改 | [`参数账.md`](参数账.md) |
| 哪些还没定、为什么没定 | [`待决.md`](待决.md) |
| 改过哪些方向、否掉过什么 | [`决策记录.md`](决策记录.md) |
| 常驻记忆（开场那一段）怎么设计的 | [`常驻记忆.md`](常驻记忆.md) |
| 代码和设计现在差在哪 | [`实现与框架对照.md`](实现与框架对照.md) |
| 名词（格 / 件 / 组 / 势 / 场） | [`术语表.md`](术语表.md) |
| 写文档的规矩（编号、链接、留痕） | [`文档规范.md`](文档规范.md) |
