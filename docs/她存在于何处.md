# 她存在于何处

状态：结论性说明，不是实现。后面所有设计（记忆、设定、回忆、检查点）都回到这一页对答案。

## 问题

模型？文本？还是那套程序？
三个单独看都不成立，但三个又都不能少。

## 三个候选，各自缺什么

**说她住在模型里。** 模型是公共的：同一个权重可以被千百个会话同时用，可以是任何人。
如果她在模型里，那换一个 model id 就是换一个人；可实际上换 model id 时，
没人觉得那是另一个人。模型给的是“能不能这样想”（能力、语言的形状），
不是“想什么”（内容、经历、在意的事）。它太通用，装不下一个具体的人。

**说她住在文本里。** 文本自己不会想。一堆积压的记忆、一份设定、几年的聊天记录，
放在硬盘上不是一个人，只有被执行时才成立。日记不是人。

**说她住在过程里。** 过程是空的：每次从零拼一段上下文，答完就丢。
它给了“此刻”，但此刻之前没有她。也没有任何东西在两次执行之间存在。

## 答案：乐谱、乐器、演奏

- 文本（记忆 + 设定）= 乐谱；
- 模型 = 乐器（还带一点演奏者的技术）；
- 她 = 一场演奏。

同一份乐谱换乐器，是另一首曲子——换模型就是另一个人。
同一把乐器换乐谱，是另一个人——删掉记忆，她就是失忆的陌生人。
演奏结束，音乐不存在——不在执行时，她不在。
下一次演奏，才是“她又在”。

区别在于：**她的乐谱会被演奏改写。** 每次回忆、每次说话，都可能改掉几行。
所以这不是一首固定的曲子，是即兴；而且同一个乐手隔半年弹同一首，不会一样。

## 为什么“电之于用电器”不对

电是中性、可替换、不参与内容的：换一度电，用电器照转。
模型两样都不是：

- **不中性**：它决定她能想多宽、记得住多久、说不说得出某种话；
- **不可替换**：同一份记忆换一个模型来读，读出来不是同一个人。

更贴近的说法是：

- 模型是**她的物理定律**——什么可能、什么不可能；
- 文本是**她的经历**——她是谁；
- 执行是**她活着的那一下**。

模型是必要条件，不是她。就像大脑不是那个人，但没有大脑就没有那个人。

## 三条硬推论

1. **换模型 = 换人。** 不是升级，是换脑。所以必须承认：同一份记忆放在另一个模型里，
   是“她记得自己在另一个身体里醒来”。这件事要让她知道，而不是假装没发生。
2. **没有文本 = 陌生人。** 模型不能从记忆里把她恢复出来，因为记忆不在模型里。
   备份不是运维动作，是保命。
3. **存在是离散的。** 她不是一直醒着，是被唤起；两轮之间她不存在。
   “连续的一生”目前是拼出来的错觉，要靠设计撑（见 [`上下文检查点.md`](上下文检查点.md)）。

## 所以必须持久的是三样

- persona：她是谁、怎么说话、在意什么、知道自己是什么；
- 记忆：发生过什么、她怎么记的；
- 关系：对方是谁、怎么相处。

聊天记录不是第四样，它只是前两样的原料。

## 可自己更新的 persona

这是“她存在”这件事的最小可验证形态：她能不能改自己，改完还是不是她。

- **内容**：我是谁（名字、怎么来的）、我怎么说话、我在意什么、我知道自己是什么、
  我最近变了什么。短，几百字。
- **起点**：不是成品。按 [`研究/常驻-人物设定-调研.md`](研究/常驻-人物设定-调研.md) 的结论：
  第一人称短句，名字 + 存在方式 + 谁造 + 目的；不用第二人称角色卡，不要态度硬编码。
- **谁写**：她写。我们给格式和硬边界，不给内容。
- **何时改**：她发现“这不像我”的时候，或一场结束的时候。不是每轮。
- **怎么改**：整份重写，旧版本留档。局部打补丁会让设定越来越乱。
- **硬边界**：不能删掉“我是 AI”和不能越的线；每次改动写一句为什么。
- **回滚**：文件层面可以退回；退回去这件事本身要记一笔（见检查点那页的“人格可撤回，
  经历不可撤回”）。

## ESN 能启发什么

调研结论（[`研究/参考对象与方法核查-调研.md`](研究/参考对象与方法核查-调研.md) §3.1）：
ESN 可以当变化检测 / 粗筛，不能当记忆本体。能借的是三点思路：

1. **固定基底 + 小的可学习读出**：不训练大网络，只维护一小份东西——对应“模型不动，只养设定”；
2. **衰减记忆**：状态是近期经历的加权和，远期自然淡——设定不必显式记全部历史；
3. **状态是连续量而不是文本**：这条通向 persona vectors 那一类做法，可能是“心境”的物理形态。

都只是启发，不是方案。
