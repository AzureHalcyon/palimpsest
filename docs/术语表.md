# 术语表

本表只收**需要消歧**的词。正文一律用中文叙述；英文只在需要精确检索或对照文献时使用。

| 中文 | 英文 | 定义 | 说明 |
|---|---|---|---|
| 原文 | raw text | 系统与外部交互中实际发生过的文本，逐字保存 | 指一份一份的材料 |
| 语料 | corpus | 全部原文的总体 | 容纳原文的那个整体 |
| 关系图 | relational graph | 从原文标注出来的结构 | 节点锚在原文区间上，节点被划成组，边是它们之间的关系 |
| 节点 · 组 · 边 | node · group · edge | 图的构成 | 节点身份是原文区间，不是分段编号，也不是哈希；**组**是节点的集合、不带类型；**边**是带类型的关系、元数不限（不限两个） |
| 激活 | activation | 给定情境，图上被激活的部分 | 稀疏：一次只涉及少量单元 |
| 注意力 | attention | 激活的机制：情境与图上单元直接相比，由权重决定取用谁 | 无层级的先后规定；"看哪里"是判断，不是流程 |
| 多尺度 | multi-scale | 图上同时存在不同粒度的组织 | 是图的性质，不是展开的顺序；粗与细都可能先亮 |
| 粗筛 | coarse filtering | 先缩小候选范围，再在其中比较 | 可以漏，不可以丢：漏是这次没取用，丢是在图上没有了位置 |
| 浮现 | evocation | 编码器的输出，一轮里的一串 | 中文里最准的就是"浮现"，不再另取英文名 |
| 编码器 | encoder | 读图并输出激活的映射 | 同一映射，两种输出形态（文字 / 激活） |
| 读取函数 | reading function | 读法在实现层的名称 | 随经历生长，是这份语料上的函数 |
| 输出 | output | 编码器产生的、交给模型看的东西 | 一轮里是一串；不进库 |
| 检验 | test | 有确定答案的问题，用于判断读取有没有被带偏 | 不用于训练；做法见设计 10.1 |
| 探针集 | probe set | 用于检验的一批题 | 每个版本内固定；跨版本比较时按同一版本取 |
| 裁决者 | adjudicator | 判两处是否同一件事的角色 | 并行取一致；结论不直接落库 |
| 逐轮记录 | turn record | 每一轮记下的一行：刺激、图、期望、激活、参数、成本 | 用于训练、检验与统计；不进读取路径 |
| 约束 | invariant | 违反即缺陷的条件 | 见 README「约束」 |

## 约定

- 正文用中文术语；**英文只在确实没有合适中文表达时出现**。
- 不使用比喻命名。名字要么是机制名，要么是它在文献里的标准名。
- 「浮现」保留中文，不另造英文名。
