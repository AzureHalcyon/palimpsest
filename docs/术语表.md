# 术语表

本表只收**需要消歧**的词。正文一律用中文叙述；英文只在需要精确检索或对照文献时使用。

## v2（当前链路）

| 中文 | 定义 | 说明 |
|---|---|---|
| **事件** | 对话中由 `event` 工具维护的一段状态；名字是那件事的短标题 | 单位是事件，不是轮 |
| **属于 / 相关** | 事件的两种边：包含、关联 | 一个子可以挂多个父，也可以连别的根 |
| **栈** | 当前事件的路径 | 只是光标，不是数据 |
| **seq** | 事件的单调序号 | 和 `created` 一起决定先后；id 是随机串，不带顺序 |
| **种子 / 赢家** | 读取的入口 / 竞争的结果 | 种子不一定是赢家；网络里被多处点亮的也能赢 |
| **重放** | 归档时的 REM-SWS：不均匀激活、加强、全局衰减、剪 | 不是模型判断 |

## v1（历史）

| 中文 | 英文 | 定义 | 说明 |
|---|---|---|---|
| 原文 | raw text | 系统与外部交互中实际发生过的文本，逐字保存 | 指一份一份的材料 |
| 语料 | corpus | 全部原文的总体 | 容纳原文的那个整体 |
| ★ **AI** | base LLM | 租来的**基座模型**：冻结、不训 | 只在**会与"读取模型"混淆**的地方才必须写 AI；上下文已经明确的（如"模型原有层""既有模型"）**不必改** |
| ★ **读取模型** | the reading model | ★ **要训练的这一层**（＝旧称 编码器 / 读取函数） | ⛔ 单说"**模型**"有歧义（会被读成基座 AI）⇒ 正文一律用这个**带限定**的名字。它干的事叫**读法** |
| 关系图 | relational graph | 从原文算出来的结构 | cell 锚在原文区间上；cell 聚成**组**，⑤ 判出**件**；**边落库**（pairwise：a、b、关系、说法）。★ 模型读到的只有「格 / 件 / 组」，⛔ 边不作为输入喂给它 |
| ★ **节点与组** | nodes & groups | ★ **模型实际读到的那一侧**：节点（＝留下来的 cell，锚点区间）＋ 组（＝依赖簇） | ⛔ **不叫"图"**（模型读到的那一侧没有边）。★ 边**只存档**（跨材料关联，读的时候现算），**不作为输入喂给它** |
| 节点 · 组 · 边 | node · group · edge | 图的构成 | 节点身份是原文区间，不是分段编号，也不是哈希；**组**是节点的集合、不带类型；**边**是带类型的关系、元数不限（不限两个） |
| 激活 | activation | 给定情境，**节点与组**里被激活的部分 | 稀疏：一次只涉及少量单元 |
| 注意力 | attention | 激活的机制：情境与**节点与组**里的单元直接相比，由权重决定取用谁 | 无层级的先后规定；"看哪里"是判断，不是流程 |
| 多尺度 | multi-scale | **节点与组**里同时存在不同粒度的组织 | 是**节点与组**的性质，不是展开的顺序；粗与细都可能先亮 |
| 粗筛 | coarse filtering | 先缩小候选范围，再在其中比较 | 可以漏，不可以丢：漏是这次没取用，丢是在**节点与组**里没有了位置 |
| 浮现 | evocation | 编码器的输出，一轮里的一串 | 中文里最准的就是"浮现"，不再另取英文名 |
| 编码器 | encoder | 读**节点与组**、输出激活的映射 | 同一映射，两种输出形态（文字 / 激活）；★ ＝**读取模型**（这是它的机制名） |
| 读取函数 | reading function | 读法在实现层的名称 | ★ ＝**读取模型**（这是它在实现层的名字）；随经历生长，是这份语料上的函数 |
| **读法版本** | reading version | 读取模型在一个周期上的版本标识 | 与**图版本**正交（两者都可能单独变） |
| 输出 | output | 读取模型产生的、交给 **AI** 看的东西 | 一轮里是一串；不进库 |
| 检验 | test | 有确定答案的问题，用于判断读取有没有被带偏 | 不用于训练；做法见设计 10.1 |
| 探针集 | probe set | 用于检验的一批题 | 每个版本内固定；跨版本比较时按同一版本取。★ 只作消歧：**正文已改用「卷子」** |
| 裁决者 | adjudicator | 判两处是否同一件事的角色 | 并行取一致；结论不直接落库 |
| 逐轮记录 | turn record | 每一轮记下的一行：刺激、**节点与组的版本 / 视角**、期望、激活、参数、成本 | 用于训练、检验与统计；不进读取路径 |
| ★ **组** | group | **一批 cell 属于一起**；不带类型 | 代码里就是 `图.组`。两种来源：**依赖簇**（按场算，主力）与**相似聚类**（可跨场）。⛔ 与 `件` 不是同一个东西 |
| ★ **件** | piece | ⑤ 判出来的**一处落点**（跨场的"一件事"） | 代码里是 `图.件`。它跟组是两套对象：件管"这是不是同一件事"，组管"哪些位置一起传播" |
| ★ **超边 / 块** | hyperedge / block | 「块」＝某关系名下的**连通块**，是**派生视图**，⛔ 不是存储对象 | 存的是**边**（pairwise）；块要的时候从边现算。⛔ 别再把它当第三种对象 |
| **标记集** | markset | 件 id → 置信度：这件"有多该被记住" | 只在归档里改（归进 / 新建 / 层1 / 层2）；读的时候不用它做准入 |
| **版本对** | version pair | 每次归档落一对（**记忆版本 × 读法版本**） | 任何读数都要标这一对，否则说不清是谁变了 |
| **场** | session | 一次对话（`YYYY-MM-DD-NN`） | 归档的单位；底片一场一条 |
| **势** | momentum | 读取路径的 EMA：走过很多次的格更容易被传播带到 | 只乘传播系数，⛔ 不进起点、⛔ 不做准入 |
| 约束 | invariant | 违反即缺陷的条件 | 见 `docs/设计.md` 第 11 节与约束摘要 |

## 约定

- 正文用中文术语；**英文只在确实没有合适中文表达时出现**。
- 不使用比喻命名。名字要么是机制名，要么是它在文献里的标准名。
- 「浮现」保留中文，不另造英文名。
