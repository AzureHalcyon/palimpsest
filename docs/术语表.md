# 术语表

本表只收**需要消歧**的词。正文一律用中文叙述；英文只在需要精确检索或对照文献时使用。

| 中文 | 英文 | 定义 | 说明 |
|---|---|---|---|
| 语料 · 原文 | corpus · raw transcript | 逐字保存、永不改写的原文 | 单份叫原文，整体叫语料 |
| 关系图 | relational graph | 从语料标注出来的结构 | 节点锚在原文区间上，边是关系 |
| 节点 · 边 | node · edge | 图的构成 | 节点身份是原文区间，不是切片编号，也不是哈希 |
| 激活 | activation | 给定情境，图上被点亮的部分 | 稀疏：一次只涉及少量单元 |
| 多尺度稀疏激活 | multi-scale sparse activation | 在多个尺度上稀疏激活 | 先整体，再一段，再到句或片 |
| 浮现 | evocation | 编码器的输出，一轮里的一串 | 中文里最准的就是"浮现"，不再另取英文名 |
| 编码器 | encoder | 读图并输出激活的映射 | 同一映射，两种输出形态（文字 / 激活） |
| 读取函数 | reading function | 读法在实现层的名称 | 随经历生长，是这份语料上的函数 |
| 输出 | output | 编码器交给 AI 看的东西 | 不进库 |
| 探针集 | probe set | 固定的一批探针 | 固定才能跨版本比较 |
| 裁决者 | adjudicator | 判两处是否同一件事的角色 | 并行取一致；结论不直接落库 |
| 约束 | invariant | 违反即缺陷的条件 | 见 README「约束」 |

## 约定

- 正文用中文术语；**英文只在确实没有合适中文表达时出现**。
- 不使用比喻命名。名字要么是机制名，要么是它在文献里的标准名。
- 「浮现」保留中文，不另造英文名。
