# 术语表

只收当前链路要消歧的词。v1（格 / 件 / 组 / 势）的术语在
[`99_归档/v1/术语表.md`](99_归档/v1/术语表.md)。

| 中文 | 定义 | 说明 |
|---|---|---|
| 事件 | 由 `event`（旧入口）或 `remember`（`loop/`）维护的一件状态；名字是那件事的短标题 | 单位是事件，不是轮 |
| 属于 / 相关 | 事件的两种边：包含、关联 | 现在只由 `links` 建「关联」；旧数据里的「属于」按关联读 |
| seq | 事件的单调序号 | 和 `created` 一起决定先后；id 是随机串，不带顺序 |
| 种子 | 线索直接点亮的事件 | 种子不一定是赢家 |
| 赢家 | 竞争排第一的事件 | 网络里被多处点亮的也可以赢 |
| 重建 | 把选定的那件事的材料按时间顺序放回去 | 选哪件在上游；材料见「材料」行 |
| 编写 | 把重建的内容写成一段第一人称回忆 | 只有这段进上下文 |
| 材料 | 重建与编写读到的东西 | `loop/` 是 `remember` 写的 note；旧入口是场次记录里的对话原文 |
| 说法 | 每次编写落下的追加日志 | 不是可编辑的当前说法层 |
| 重放 | 归档时的 REM-SWS：不均匀激活、加强、衰减、剪 | 不是模型判断 |
| 归档 | 每轮落状态加一场结束跑重放 | 手动开关；成功后封口 |
| 封口 | `状态/<场>.jsonl.archived` 标记；这一场只读 | 不是删除，图仍可查/重建 |
| 冻结副本（已废弃） | 早期版本在本场开场时复制到 `状态/<场>.frozen/` 的 graph + vectors | recall 现在直读 live 图；旧目录里的副本不再被读取，见 `事件状态与读取.md` 的沿革 |
| 全局冻结 | `冻结/` 下的最新 graph + vectors | 归档后由 live 图生成；只作下一版起点，不参与本场回忆 |
| messages 日志 | `状态/<场>.jsonl.messages.json` | 完整对话消息，含 tool calls / tool 结果；续聊原样恢复 |
| 向量指纹 | `(model, dim)` | 缓存不符就作废重建，不能混维 |
| 整体重建 | `ingest --rebuild`：备份旧图后从状态记录重画 | 重放边、强度、奖励不恢复 |
| 步 | 循环里的一次完整往返：读进件、拼上下文、模型、执行 | 不是“轮”；一轮里可能走好几步 |
| 块 | 原文按块存：当前块（在写）、上一块（刚结束） | 块满了才升、才压；上下文里最多两块原文 |
| 段 | 块压出来的摘要，最多四段，越旧越短 | 段在上下文里，不是记忆；记忆只由模型写 |
| 进件 | `inbox` 里的一行：`user` 或提醒 | 网页、标准输入、以后的任务结果都从这进来 |
| 未来件 | `future` 里的一行：`note` ＋ `due_at` ＋ 谁放的 ＋ 回给谁 | 还没到的"将来的事"；到点落成一条进件（`kind=due`）。见 [`未来任务.md`](未来任务.md) |
| 设置 | `<data>/settings.json`，只记**改过**的键 | 没改的跟着代码默认，升级跟得上 |
| 提示词覆盖 | `<data>/prompts.json`，空 = 用仓库里的默认 | 每步现读，改完不用重启 |
