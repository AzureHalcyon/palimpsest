# 决策记录

只记当前链路（`memory_v2`）定下来的事。上一代（v1）的完整决策记录在
[`99_归档/v1/决策记录.md`](99_归档/v1/决策记录.md)。

## 2026-10-19 事件是单位，状态在对话里维护

**决定**：记忆的单位是事件；模型每轮用 `event` 工具写下正在说哪件事；归档不再判“并进/新建”。

**理由**：按轮切，轮的长短和信息密度不定；归档时事后判，等于把运行态判决冻成库里的属性。
切点在经历时就定了，是对话里的状态给出的。

**被否掉的**：按轮切；事后用模型判“是不是同一件事”；给每个节点标标签。

## 2026-10-19 事件之间是网，不是树

**决定**：边只有 `属于` / `相关`；一个父可以挂很多子，一个子可以有多个父，也可以连别的根；
栈只是光标。

**理由**：跨主题的关联直接连边，不硬塞成父子；树能表达的网都能表达。

**被否掉的**：树状路径；只做一层事件；给边加因果/人物等更多类型（先用内容重合和时间顶着）。

## 2026-10-19 状态工具与读取

**决定**：`继续` / `子事` / `回` / `换事` / `接旧` / `关联` 六种模式；每次调用返回状态快照；
系统不替模型连边。读取是“线索 → 种子 → 沿网和内容扩散 → 竞争 → 重建 → 编写”。
网络里被至少两个种子汇聚、且和线索余弦不低于 0.5 的事件也能当赢家。

**理由**：工具可校验、可回话；网络不能只排序备选，要能决定答案。

**被否掉的**：CoT 首行当状态；静默替模型加边；只让种子当赢家。

## 2026-10-19 归档只剩落盘与重放

**决定**：每轮状态落盘；归档是手动开关，跑一次重放（REM-SWS）：不均匀激活、按起点数加强、
全局衰减、剪弱边；`属于` 保底不剪；候选对攒够门槛才成新边；图可从状态记录 `ingest` 重建。

**理由**：归档不再需要模型判断；主干靠反复“镀一层、削一层”长出来。

## 2026-10-19 事件 id 用随机串，顺序另存

**决定**：id 用 `e-` 加 12 位随机十六进制，查重；事件另存 `created` 和单调的 `seq`；
同名解析、父件平局按 `(created, seq)`，不按 id 字符串。

**理由**：`e-0001` 把身份和顺序混在一起，到 9999 之后字符串排序会取错“最新”；
随机串长度稳定，不会用完。

## 2026-10-19 再巩固：原文只读，不做说法层

**决定**：原文只读；每次回想从原文重写；`说法/` 只做追加日志，不是可编辑的当前说法层；
编写只读按线索选出的片段加最近一段。

**理由**：说法层多一层要维护，且会漂；保留原文、重复编写，改口本身是一条可看的路径。

## 2026-10-19 验证与归档

**验证**：两场实聊（38 轮装修、32 轮工作/生活），跨会话各 10 题，都是 10/10，没有编造；
假前提、未定项、具体日期都守住了。

**归档**：v1 的文档整体在 `docs/99_归档/v1/`，可运行代码在 `archive/v1/`；
归档前的树由 `v0.2` tag 保存。

## 2026-10-22 记忆机制到此为止，下一步只做“自我”

**决定**：记忆层保持现状——标节点 + 回忆编写，不再扩展机制（不追参数化回想、不加检查点分支、
不改读取）。下一步只做“自我”这一层：一份她自己能改、且知道自己是一张卡的人格文本。

**理由**：前面几轮把“更精细的记录”错当成核心；检索与重建已经够用，缺的是承载判断和
“她是谁”的那一层。自改文本卡是现在唯一能立刻做、又不撒谎的形态。

**被否掉的**：结论层 + 置信度 + 版本重算（臃肿，仍是记录）；把空闲、主动、检查点一起铺开；
为“像人”先加一堆机制。

## 2026-10-22 她存在于文本与执行，模型是载体

**决定**：她的身份由持久文本（persona + 记忆）承载，只在执行时存在；模型是可执行基质，
不是个体。换模型按“换脑”处理：算她延续，但必须记进她的记忆，让她知道换过。

**理由**：模型是公共的，决定“怎么想”却装不下“想什么”；文本不被执行就不是人；
两轮之间她不存在。

**被否掉的**：说她在模型里；说她是那套程序；“电之于用电器”（电中性可替换，模型不中性）。
