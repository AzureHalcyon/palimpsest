# 参数化记忆

## 需求

- 原文能不能换成一组码，编写模型不读文本、只读码，直接写出那段；
- 糊就是丢信息，也就是丢事实。丢掉的那部分不能靠编补上，得能标出“这里不确定”；
- 交付的是“一段回忆 + 哪里不确定”；追问怎么接、话怎么说，不归它管；
- 如果做不到，就把编造率与置信度校准量出来，再谈优化；
- 如果这组码经过了量化，那么量化后还能读出什么；
- 体积不能成为长期积累的障碍；
- 编码得有一定的效率。

## 未定

- 解码器是不是她专属；
- 置信度怎么来：码里带着，还是解码时估；
- 码能不能一条一条加，不必整批重训；
- 多段拼在一起写，会不会互相污染；
- 码如果大到几十 KB 一条，还叫不叫“参数化”。
