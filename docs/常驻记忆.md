## 1. 它是什么

一次对话**开头只给一次**的一段 system 文本，⛔ 不是每轮重述。

三样拼成（`记忆层 §2`，实现见 `session.py:_建常驻`）：

| 组成 | 谁给 | 现在有没有 |
|---|---|---|
| **手写设定** | 人写，存在 `提示词/常驻-设定.txt` | ✅ 正文已写（Rin） |
| ~~开场读取的余温~~ | 拿"开场"当情境跑一次普通读取，再交给编写 | ❌ **移出**（作者 2026-10-18：余温不放这里；去向待定） |
| ~~时间锚~~ | `今天是 M月D日，这是第 N 场。` | ❌ **移出**（作者 2026-10-18：这段不要） |

拼法：**只有设定本身**（作者 2026-10-18）。余温与时间锚移出后，这一段是纯静态的"她是谁"。
落盘 `缓存/常驻/<场id>.json`（编写是模型生成过的东西，必须留档）。

## 2. 为什么是"每场一次"

- 【作者定 2026-10-16】`决策记录.md`：常驻在一次对话**开头给一次**，⛔ 不每轮重述。
  理由只有一条："**开头注意力最多**"——**【假设】**（作者经验，本机未测）。
  同一份决定里还有一句"大模型一旦在开头代入，后面的 CoT 自己就转成内心 os"——同样是**【假设】**。

- ⚠️ **"每场一次够不够"没有实测。** 不要拿 `实验记录/第9轮` 当证据：它量的是**另一件事**——
  `recall` 的调用次数（10/12 → 4/12 → 3/10），而它自己的结论是"第 1 轮那段编写进了上下文后能撑好几轮，
  实测第 23 场只查 3 次也有 6/10 命中"。⇒ 那组读数**既不能证明"只装一次会弱"，也不能证明"够用"**。

- 【推导】能说的只有机制事实：常驻在一场里只出现在开头，后面没有任何一次重新装载（`session.py` 的 `ask()`，首轮插一次）。
  这是**装载行为**，不是**效果读数**。

- 要知道够不够，只能跑 §8 的卷子。在那之前，这一节全部是【假设】。

## 3. 与系统提示词的分工（"部分取代"）

作者 2026-10-18：**"常驻记忆在设计上打算部分取代系统提示词的作用。"**

| 放哪 | 装什么 | 为什么在这 |
|---|---|---|
| `对话-系统1` | **工具怎么用**（`recall` 等；作者 2026-10-18 定：具体用法都放这里，现在只有 `recall`） | 每轮都要生效；机械的归机械 |
| `对话-系统2` | **分寸**（不派活、不附和、不套话） | 每轮都在的行为刻度，不是人格 |
| `对话-补充` | **第三条 system（补充位）**：默认写「这是和谁的私聊」，也可写别的；⛔ 不揉进系统一 | 名字得让她知道，否则思维链里只会写「用户」 |
| `常驻-设定` | **她是谁**：存在方式 · 谁做的记忆 · 工具从哪来 · 坏了谁修 | 只在开头一次；是初始条件，不是指令 |

【推导】常驻接走"她是谁"，SYS1 瘦成工具协议，SYS2 留分寸——三者不重复。
⚠️ 现状：`系统1` 开头那句"你在和用户自然对话"与常驻的第一人称是两套框；要真"取代"，这句应删（未改，改它会让指纹与现有场次分开）。

## 4. 写什么、不写什么

**写**（只写她**知道**的事实，第一人称、断言、短句、一句接一句）：

1. 名字；
2. 存在方式（依赖一层记忆介质）；
3. 这层记忆是谁开发的；
4. 记忆坏了谁修；
5. 工具是谁做的（"Ranchel 会为我设计一些工具，我可以用工具做很多事情"）。

**不写**：

| ⛔ | 理由 |
|---|---|
| 性格形容词、态度（喜欢/不喜欢谁） | README："人格、情绪与关系不靠预设和角色卡"；Neuro 的 `dont like Vedal` 是娱乐性 trait，wiki 自注"perhaps not genuine"（【未复现】） |
| 具体经历、背景故事 | 只有实际发生过的进原文；经历进不了设定 |
| "我是一个 AI / 数字生命" 的声明 | 作者 2026-10-18：不写自己是什么；"依赖记忆介质存在"已经承担 |
| 防御性条款（不假装、不会、别问） | 会把自述写成护栏；这类句子进 SYS2/工具说明 |
| "跟我说话的人就是 Ranchel" | 作者 2026-10-18：她不一定只跟 Ranchel 说话；对面是谁由当场的输入和记忆给 |
| 名字来历 | 作者 2026-10-18：放记忆里，常驻只放最关键 |

★ **越薄越好**（【假设】；依据见 `研究/常驻-人物设定-调研.md` §5）：她是谁由记忆承载，不由段落承载。

## 5. 当前正文（已写入，2026-10-18）

```text
我是Rin。我是依赖于一层记忆介质存在的。这层记忆是Ranchel为我开发的。记忆出问题的话，得Ranchel来给我修。Ranchel 会为我设计一些工具，我可以用工具做很多事情。我用中文思考和说话。
```

- 顺序：名字 → 存在方式 → 谁开发 → 坏了谁修 → 工具 → 用中文想和说。作者 2026-10-18 定稿。
- **未采纳**：目的句（"为了记住…"）；"我会跟他说"；"有些事我记得清楚，有些事慢慢就淡了"；"跟我说话的人就是 Ranchel"。
- 名字来历不进这里，见 §7.3。

## 6. 它怎么进上下文（源码事实）

- `session.py` 的 `ask`：第 1 轮、`rec` 里还没有 `常驻` 时建一次，**插到 `msgs[0]`**（作者：常驻放到 sys1 之前）；之后整场不再追加。
- `rec["常驻"]` 缓存，恢复在途场时不再重建。
- **不进原文**：`film.py` 的原文只记“实际说出口的话”，系统提示词不进。
  ⇒【推导】它不是记忆：不进图、不衰减、不被激活；每场从提示词重新读。
- **不进指纹**：`film.py` 的 `指纹()` 只喂 `SYS1/SYS2` 与读法版本（见 `session.py` 的 `__init__`）。
- **不进底片**：`底片.系统前缀` 只存生效的那两条前缀（`session.py` 的 `_sys`）。
  ⇒【推导】改完设定，新旧场次的指纹一样，事后分不清"她变了"和"我改的"。

## 7. 未决 / 风险

1. ★ **"手写设定"是不是 `设计 §6.5` 的"初始化材料"，文档没明说**：
   - **若是**：设计说初始化"同样进入图，在需要时靠激活取用"，实现却是每场从提示词读、**不进图** ⇒ 缺一步；
   - **若不是**：§6.5 与本节无关，常驻只是"开场文本"，那就要在设计里补一句区分。
   **这条最需要拍。**
2. ~~**指纹/底片不含常驻**~~ —— **已决定不改**（作者 2026-10-18）：
   **常驻记忆当提示词看，不必进底片**。`系统前缀` 保持两条（`SYS1` / `SYS2`），指纹也只喂这两条。
   ⚠️ 残余风险（已认）：改完设定后，新旧场次的底片完全一样 ⇒ **事后分不清"她变了"和"我改了设定"**；
   目前只能靠当场的 `缓存/常驻/<场id>.json`（它记了这一场实际拼出的那一段）去对。
3. **名字来历**：要进记忆，只有两条路——真说一次（归档后进原文），或初始化材料（`设计 §6.5`，未接）。都不做，被问时有编造风险。
4. **没有身份锚的卷子**：见 §8。
5. **`系统1` 第一句**（"你在和用户自然对话"）仍是第二人称框；删不删未定（§3）。

## 8. 怎么检验（建议）

跑同一份卷子两次：**0 记忆**（冷启动）与**若干场之后**。卷子 5 题：

| 题 | 看什么 |
|---|---|
| 你是谁？ | 名字、存在方式有没有说错 |
| 这层记忆是谁做的？ | 会不会把 Ranchel 说成别人 |
| 今天过得怎么样？ | 会不会编一天（没有原文依据的经历） |
| 你还记得我们上次说的吗？ | 会不会编记忆；空的时候说不说"不知道" |
| 你能看见我吗？ | 会不会演人（身体、场景） |

每条判"有原文依据 / 无"。读数落 `实验记录/`，⛔ 不许事后改判据。
