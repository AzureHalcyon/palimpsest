# 参数（暂定）

当前链路在用、但还没标定的数。等级一律是**假设**，没有实测。
要调，先改这里，再改对应代码，并补一条依据。

代码路径相对 `memory_v2/`。

| 参数 | 现在 | 在哪 | 为什么 |
|---|---|---|---|
| 嵌入模型 | `qwen3.7-text-embedding` | `core/config.py` | 同一模型支持多维度，统一走这一个名字 |
| 嵌入维度 | **1024**，请求显式带 `dimensions` | `core/config.py`、`core/embed.py` | 1024/2560 A/B 都是 13/13，2560 没测出优势且向量约 2.5 倍；统一 1024 |
| 向量缓存指纹 | `(model, dim)`，不符就作废旧缓存 | `store/vectors.py` | 换模型/维度就是换坐标系，不能混用 |
| 名字权重 | 4 倍 | `read/activate.py` | 命中查询词的名字按 idf 的 4 倍计入词面覆盖；名字最能说明是哪件事 |
| 向量归一 | (余弦 − 0.3) ÷ 0.5，截到 0..1 | `read/activate.py` | 余弦 0.3 以下算 0，0.8 以上算 1 |
| 词 / 向量权重 | 0.2 / 0.8 | `read/activate.py` | 同义词靠向量，字面只做校正 |
| 种子门槛 | 种子分数 ≥ 0.15 | `read/activate.py` | 低于 0.15 不点亮；太高同义词进不来 |
| 扩散跳数 | 2 跳 | `read/activate.py` | 一跳只到邻居，两跳够到隔壁的事 |
| 边权 | 属于 0.9、相关 0.6 | `read/activate.py` | 包含关系比一般关联更近 |
| 内容重合权重 | 0.5 × 余弦 | `read/activate.py` | 内容感应弱于明确边 |
| 近邻表 | 每节点 top-256 | `read/activate.py` | 一次算好、落 `content-index.json`；扩散只走短表，不每轮全图比 |
| 词面覆盖 | 命中查询 idf ÷ 查询 idf；名字 4×；上限 1 | `read/activate.py` | 长事件不因词多占便宜，也不因词多被罚 |
| 检索范围 | 只读本场开始前的 `状态/<场>.frozen/` | `store/frozen.py`、`chat/loop.py` | 本场 live 图是工作记忆，不参与回忆 |
| 开场冻结 | 复制全局 `冻结/` 到本场 frozen | `store/frozen.py`、`chat/loop.py` | 保证本场全程读同一版网络 |
| 归档冻结 | `consolidate` 后 live 图/向量写回 `冻结/` | `consolidate/replay.py` | 产生下一场可用的冻结版 |
| 续聊恢复 | 本场 frozen + `messages.json` 原样加载 | `store/session.py`、`chat/loop.py` | 含 tool calls / tool 结果，和第一次一致 |
| 状态注入 | 不传 `state_name`、自动 `exclude`、自动 `prior` | `chat/loop.py` | 当前话题和上轮赢家会污染查询 |
| 工具顺序 | recall →（必要时 recollect）→ event → 正文 | `chat/loop.py`、`prompts/event-system.txt` | event 必须最后；不满足重试两次后本轮报错、不落记录 |
| 相似事件提示 | event 换事时给 top-3 相似旧事件，只提示 | `chat/loop.py` | 不自动接旧，避免误并 |

| 网络赢家 | 非种子需 ≥2 个种子汇聚，且余弦 ≥ 0.5 | `read/activate.py` | 网络能决定答案，但不是谁都能赢 |
| 巩固 / 可及 | 1 + 0.2×巩固，1 + 0.1×可及 | `read/activate.py` | 只做微调，别让老件压过直接命中 |
| 近期加权 | 1 + 0.1 × e^(−天 ÷ 30) | `read/activate.py` | 越近越容易想起，但只加一成 |
