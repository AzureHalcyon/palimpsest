# 参数（暂定）

这条链路上现在在用的数。没实测的按**假设**处理，标了实测的会写日期。
要调，先改这里，再改对应代码，并补一条依据。

代码路径相对 `memory_v2/`；下面“循环（`loop/`）”一节另行说明，路径相对仓库根。
`rin:` 开头的路径在另一个仓（落地侧：工具、网关、设置、记忆工具面），本仓里没有。

| 参数 | 现在 | 在哪 | 为什么 |
|---|---|---|---|
| 嵌入模型 | `qwen3.7-text-embedding` | `core/config.py` | 同一模型支持多维度，统一走这一个名字 |
| 嵌入维度 | **1024**，请求显式带 `dimensions` | `core/config.py`、`core/embed.py` | 1024/2560 A/B 都是 13/13，2560 没测出优势且向量约 2.5 倍；统一 1024 |
| 向量缓存指纹 | `(model, dim)`，不符就作废旧缓存 | `store/vectors.py` | 换模型/维度就是换坐标系，不能混用 |
| 嵌入批次 | 20 条；空文本不送，位置留空 | `core/embed.py` | 上游收到一个空串就忽略 `dimensions`、整批按原生 2560 维返回 |
| 思考字段 | 优先 `reasoning_content`；正文里的 `<think>` 拆到 reasoning | `core/think.py`、`core/llm.py` | 有的网关把思考内联进正文，不拆就会当正文存下来 |
| 推理强度 | `reasoning_effort` 透传，空或 auto 不发 | `core/config.py`、`core/llm.py` | 端点支持才有效，默认不干预 |
| 挂起上限 | 6 轮 | `chat/tools.py`、`chat/loop.py` | 攒够才落成一件；不留缓冲会退回一句话一个节点，留太多就成了永远不落 |
| 名字长度 | 6–24 字 | `prompts/event-system.txt` | 太短搜不准、太长像一句话；检索建在名字和 note 上，名字必须单独读得懂 |
| 名字禁写 | 问句/空词/“谁说了什么” | `chat/tools.py`（`_check_name`） | 记内容不记说话动作；这类名字以后点不到那件事 |
| 名字权重 | 4 倍 | `read/activate.py` | 命中查询词的名字按 idf 的 4 倍计入词面覆盖；名字最能说明是哪件事 |
| 向量归一 | (余弦 − 0.3) ÷ 0.5，截到 0..1 | `read/activate.py` | 余弦 0.3 以下算 0，0.8 以上算 1 |
| 词 / 向量权重 | 0.2 / 0.8 | `read/activate.py` | 同义词靠向量，字面只做校正 |
| 种子门槛 | 种子分数 ≥ 0.15 | `read/activate.py` | 低于 0.15 不点亮；太高同义词进不来 |
| 扩散跳数 | 2 跳 | `read/activate.py` | 一跳只到邻居，两跳够到隔壁的事 |
| 边权 | 模型连的 0.85、replay 连的 0.6 | `read/activate.py` | 明确连的比离线攒出来的更近 |
| 内容重合权重 | 0.5 × 余弦 | `read/activate.py` | 内容感应弱于明确边 |
| 近邻表 | 每节点 top-256 | `read/activate.py` | 一次算好、落 `content-index.json`；扩散只走短表，不每轮全图比 |
| 词面覆盖 | 命中查询 idf ÷ 查询 idf；名字 4×；上限 1 | `read/activate.py` | 长事件不因词多占便宜，也不因词多被罚 |
| 检索范围 | live 图（本场 + 旧场） | `read/activate.py`、`chat/loop.py` | 不复制本场副本；本场刚发生的事也能回忆到 |
| 归档冻结 | `consolidate` 后 live 图/向量写回 `冻结/` | `consolidate/replay.py` | 全局版，只作下一版起点，不参与本场回忆 |
| 续聊恢复 | `messages.json` 原样加载 | `store/session.py`、`chat/loop.py` | 含 tool calls / tool 结果，和第一次一致 |
| 工具顺序 | recall →（必要时 recollect）→ event → 正文 | `chat/loop.py`、`prompts/event-system.txt` | event 必须最后；不满足重试两次后本轮报错、不落记录 |
| 相似抑制 | 1 − 0.5 × 余弦 | `read/activate.py` | 和赢家很像的备选把分数让掉一半 |
| 网络赢家 | 非种子需 ≥2 个种子汇聚，且余弦 ≥ 0.5 | `read/activate.py` | 网络能决定答案，但不是谁都能赢 |
| 巩固 / 可及 | 1 + 0.2×巩固，1 + 0.1×可及 | `read/activate.py` | 只做微调，别让老件压过直接命中 |
| 近期加权 | 1 + 0.1 × e^(−天 ÷ 30) | `read/activate.py` | 越近越容易想起，但只加一成 |
| 可及更新 | 取回 +0.1，按天 × 0.9 | `read/activate.py`、`chat/loop.py` | 真的取用才变强，衰减快 |
| 时间过滤 | 模型把相对时间换成 YYYY-MM-DD，传 after / before | `chat/tools.py` | 相对时间不进关键词，只做范围过滤 |
| 重放旧抽样 | 5 件 | `consolidate/replay.py` | 防旧主干饿死 |
| 重放遍数 | 3 遍，每遍重抽 | `consolidate/replay.py` | 一遍里被同一批起点照亮不算共现 |
| 旧事件证据 | 每场最多 +1，上限 8，每场 ×0.95 | `consolidate/replay.py` | 跨归档反复点亮才攒得起来 |
| 建 replay 边门槛 | 证据 ≥ 4.0 | `consolidate/replay.py` | 约四场才长一条；一次性共现不建边 |
| 连接底 | 0.02 × 支撑，上限 0.35 | `consolidate/replay.py` | 反复被支撑的连接衰减不掉 |
| 支撑衰减 | ×0.98 / 场 | `consolidate/replay.py` | 不用的支撑慢慢掉，边跟着回落 |
| 重放加强 | +0.02 × 不同起点数（≥2 起点） | `consolidate/replay.py` | 主干每轮镀一层 |
| 全局衰减 | ×0.87 | `consolidate/replay.py` | 主干也削，靠镀活下来 |
| 剪边 | <0.12 且底 <0.08；模型连接保底 0.15 | `consolidate/replay.py` | 结构不剪，关联可剪 |
| 内容感应 | 每点 top-1 | `consolidate/replay.py` | 旧事件被带亮 |
| 编写片段（旧入口） | 不超过 8 段全用；超过时取重叠最高的 8 段加最近一段，2000 字上限（首段总会保留） | `chat/loop.py` | 原文再长，输入不膨胀 |

## 循环（`loop/`）

代码路径相对仓库根 `palimpsest/`。这一层是持续在场用的，参数和 memory_v2 分开看。

| 参数 | 现在 | 在哪 | 为什么 |
|---|---|---|---|
| 块大小 | 50k token（真数） | `loop/config.py`（`block_tokens`） | 两块原文最多 100k；块小压得勤，块大旧事忘得慢 |
| 上下文预算 | 200k（官方 V4.1 有 1M，先吃 200k） | `loop/config.py`（`context_budget`） | 两块 100k + 四档 30k + sink；按真数判超 |
| 四档长度 | 1200 / 2400 / 4800 / 9600 字符 | `loop/config.py`（`band_chars`） | 越旧越短；由新到老每档不超过前一档 0.8（`band_decay`） |
| 旧段预算 | 30k | `loop/config.py`（`band_budget`） | 超了从最旧丢 |
| 工具结果保留 | 每块最近 2 条 | `loop/config.py`（`tool_fold_keep`） | 工具一直在调；只折能重取的（`recall`），`recollect` 不折 |
| 墙钟 | 每步末尾一行：日期 + 星期 + 时分，距上次对方说话、距我上次开口 | `loop/context.py`（`clock_text`）、`loop/store.py`（`last_incoming`） | 现拼、不落库；进 sink 会毁前缀缓存，写进记录会被压进摘要；「对方说话」取记录里的 `user` 行和进件里最新那条 `from_user` 的较晚者——通道来信在记录里只是一声铃，只看记录会把刚聊过说成一天前；`from_user` 由通道那侧按白名单标（群里别人、岛上的陌生人不算），`mute` 的不算 |
| 对方的名字 | `Ranchel`（设置里可改） | `loop/config.py`（`user_name`）、`loop/prompts/sink.txt`（`$user`） | 压缩文本里用「名字：」代替「对方：」，sink 第一句也用它；改完重启生效 |
| 我消息前的标记 | 空 = 用「对方的名字」 | `loop/config.py`（`owner_mark`）、`loop/context.py`（`owner_mark_of`） | 她读到的每一条你发的消息（哪个通道都一样）前面都拼【这个】：名字会改、会重名，方括号才是「这句是我的人说的」的凭据；末尾那帧环境、别人的话都不挂 |
| 我的账号 | 空 = 用通道自己报的（QQ 桥按白名单标） | `rin:settings.py`（`owner_ids`）、`rin:gateway.py` | 这些号或昵称发来的话标成 `from_user`：墙钟按它算「距上次对方说话」；填了就以它为准，群里别人、岛上的回帖不算 |
| 接口地址/密钥 | 空 = 用凭证文件（/etc/palimpsest/credentials.yaml） | `rin:settings.py`（chat_url / chat_key / embed_url / embed_key） | 网页里能直接换渠道：对话与嵌入分开填（常常不是一家）；密钥留空 = 不改，只显示「已设置 + 后四位」；改完立刻重建对话/摘要/嵌入三处客户端，不用重启 |
| 整理用的模型 | 空 = 跟主模型走 | `loop/config.py`（`persona_model`）、`loop/compress.py`（`make_client`） | 写自我描述那次整理单独用一个模型；填便宜的就省主模型额度，端点跟摘要一样是对话那一家 |
| 自我描述 | 开；描述上限 1200 字；每 24 小时且新材料 ≥20000 字才重写；整理时最多喂 30000 字（含旧段摘要）| `loop/config.py`（`persona_enabled` / `persona_chars` / `persona_hours`）、`loop/persona.py` | 内容归她、时机归定时：这段挂在 system 上，每次改写会作废一次前缀缓存，所以不在每一步让她改；新材料不够就跳过（聊得不够多先不写） |
| 墙钟刷新 | 120 秒；有人说话、刚醒来一定给 | `loop/config.py`（`clock_refresh`）、`loop/driver.py` | 时间挂在末尾那一帧上，不碰前缀缓存；这条限的是"别每步都念一遍"，纯工具链里只放一句边界 |
| 心跳步数 | 6 | `loop/config.py`（`watchdog_idle`） | 联网/查资料也会触发，所以只问一句、不硬停 |
| 重试退避 | 5 秒起、翻倍、封顶 300 秒 | `loop/config.py`（`retry_delay`） | 长跑一次抖动不该把循环打死 |
| 每天上限 / 提醒线 | 0 / 0（不限） | `loop/config.py`（`daily_token_cap` / `daily_token_warn`） | 按天真数；到上限等到第二天，消息照收 |
| 估算常数 | 汉字 0.76 token/字，其余 4.11 字符/token | `loop/context.py` | 2026-10-25 实测（中文 528 字 = 402 token，英文 1212 字符 = 295）；只在没有真数时兜底 |
| 提示词 | `loop/prompts/*.txt`（工具说明在 `rin:prompts/tools/`，一个工具一份），覆盖放 `<data>/prompts.json` | `loop/prompt_files.py`（`META` 注册表） | 提示词是数据；注册表说明每份是什么、改坏了会怎样 |
| 短期记忆 TTL | 3 天 | `rin:memory_bridge.py` | 到期压一行搬进 `archive.jsonl`，图里删掉 |
| 编写材料（loop） | 该事件那一条笔记，不挑选、不截断 | `memory_v2/api.py`（`recollect` 动词） | 一件事一条笔记（再记就是改），所以材料就是那句话本身 |
| 工具提示语保留 | 最新 2 条 | `loop/context.py`（`_HINT_LINES` 等） | 提示语只对当下那一步有用，历史里是噪声 |
| 网页绑定 | 默认不开；`--http 127.0.0.1:8080` 才开 | `rin:cli.py` / `rin:gateway.py` | 只绑本机，对外走隧道；开了就意味着有输入通道 |
| 网页令牌 | 首次生成 `web-token`（600 字节权限 600） | `rin:gateway.py`（`make_token`） | 接口和界面同一道门；不给令牌一律 401 |
| 增量游标 | `feed` 每次最多 300 条 | `rin:gateway.py`（`feed`） | 断线重连按 `(block_id, seq)` 补齐，不重不漏 |
| 可在线改的旋钮 | 存 `<data>/settings.json`，只记改过的键 | `rin:settings.py` | 改参数不用登服务器；没改的跟着代码默认，升级不会被旧值钉死 |
| 主 / 摘要 / 嵌入模型 | 都能在网页里改，也都能从 `/models` 端点清单里挑 | `rin:settings.py`（`picker`）、`rin:gateway.py` | 换嵌入模型会当场重建嵌入器、换摘要模型重建摘要客户端，不用重启 |
| 流式输出 | 开 | `loop/config.py`（`stream`）、`loop/driver.py`（`_on_delta`） | 走 SSE，增量先攒成草稿给网页看（边想边说）；记录只认最后那条完整消息；网关不兼容时关掉 |
| 嵌入模型 / 维度（loop 侧） | `qwen3.7-text-embedding` / 1024，与 memory_v2 同一对 | `loop/config.py`（`embed_model` / `embed_dim`） | 换模型必须连维度一起换；向量缓存按 (model, dim) 认，否则召回静默变差 |
| 摘要端点 | 跟对话那一家（换端点 = 改「对话地址」，不再单独选） | `loop/config.py`（`summary_model`）、`rin:settings.py`（`chat_url`） | 早期那套 auto/deepseek/bailian 的两家分流已去掉：模型名里带 qwen 也不会改投百炼 |
| 网页主题 | 跟随系统 / 浅色 / 深色，存浏览器 localStorage | `rin:web/index.html` | 白天要看得清；色值仍是 DSH 的两套语义变量 |
| 命令工具 | 默认关；开着就关进 Landlock「只有工作区能写」 | `loop/config.py`（`run_enabled` / `run_sandbox`） | 不维护白名单：边界交给内核，整机可读可执行、写只在 workspace；装不上就 fail-closed |
| 命令单文件上限 | 64 MB（`RLIMIT_FSIZE`） | `loop/config.py`（`run_file_mb`） | 防止往工作区里灌满盘 |
| 命令超时 | 20 秒，超了连进程组一起杀 | `rin:tools/shell.py`（`execute`） | 命令挂住不能把一整步拖死；孤儿进程会留在机器上 |
| 命令输出 | 4000 字，留头 60% 和尾 40% | `rin:tools/shell.py`（`_clip`） | 全量进上下文会把块塞满，把对白挤出去 |
| 拒读敏感文件 | `/etc/palimpsest`、`credentials.yaml`、`web-token`、`*.pem`、`.ssh` | `rin:tools/shell.py`（`_sensitive`） | 内核沙箱管不了"别念出来"，这条规则管的就是它；源码、数据、日志照读 |
| 工作区写入 | 只写 `<data>/workspace`，单次 10 万字；绝对路径与 `..` 拒 | `rin:tools/workspace.py`（`write`） | 想留东西用专用工具，不改 shell 白名单（`<data>/` 可写，放写命令等于把改库权限交出去） |
