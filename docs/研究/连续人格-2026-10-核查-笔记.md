# 连续人格（2026-10 那批材料）：核查笔记

> **这是核查笔记，不是调研记录**：只回答"哪些对象真、哪些数字要改、哪几样能借"，
> 不涉及本项目的设计（三时钟、关系账那套还没定稿，暂不落盘）。
>
> 进这份笔记的材料来自一份二手综述（StableMind / BRIDGE / Emergi-PersonaOS /
> `llm-personality-design-patterns` / OpenPersona / Tur / SPASM / BFI-Adapt / ContextEcho …）。

## 0 一句话

这批材料对我们的净收益不是架构，是**三个检查项 + 一个时机**；
而它自己那条最硬的实验结果（BFI-Adapt）说明：**照现在的做法，我们能做到"不乱变"，做不到"像人那样变"**。

## 2 四处必须改口

### 2.1 BFI-Adapt：不是"方向对、幅度不够"，是"哪儿都变"

原文（摘要）：*"PC-Agents exhibit measurable trait shifts at similar rates for event-trait pairs
with and without documented human change directions."* 再加上：
"Even when shifts follow the expected direction, their magnitudes usually fall below human
effect-size ranges"、"persona-level dispersion is compressed three- to four-fold"。

⇒ 模型在**人根本不会变**的事件上也照样变，速率还差不多。合起来是"**均匀地变**"，
不是"变得不够"。这条比转述严重一个量级，也是我们唯一能直接拿来当护栏的实验结论。

### 2.2 ContextEcho：轮数是 3,746–9,716、模型 23 个

转述写的 2,525–3,746 对不上（可能取自旧版）。其余三条结论都对：漂移跨机构普遍、
**会话内压缩不能可靠重置漂移**、**单次锚点重注入能在被测目标上恢复训练时的 register**。

### 2.3 SPASM：仓库只有数据

`lhannnn/SPASM` 的文件是 `data/spasm_deepseek_v4_flash_500x10.jsonl`、`DATASET_CARD.md`、
`metadata/`、`SHA256SUMS.txt`——**零个代码文件**（`language` 为 null）。论文说 "code and data
are available"，仓库只兑现了数据。所以"代码在论文里直接给出"这句要划掉。

### 2.4 `llm-personality-design-patterns`：最想要的那个模式还没跑过

它的证据表给每个模式标状态（`operational` / `staged`），并在脚注里写：
"Micro-drift and the suppression gate operate in the source system.
**The durable-commit event has not fired in operation.**"

⇒ "漂移结晶化"（阻止临时波动变成即时身份）目前是**设计 + 单测**，不是运行过的机制。
它另外有一条值得抄的措辞：*"guards against quoted or claimed speech becoming its own
remembered past"*——正是我们"转述夺最后发言权"那个已知后果。

## 3 能借 / 不能借

| 能借 | 落点 | 成本 | 出处 |
|---|---|---|---|
| **锚点单次重注入**（醒来、长块压缩后各一次） | `loop/driver.py`，走墙钟那种"末尾一帧"的注入方式，不碰前缀缓存 | 极低，只加时机 | ContextEcho |
| **表外事件不动任何维度**：倾向更新前查一张显式事件类型表，表里没有 ⇒ 默认不动 | 倾向更新处（未实现）；先手写 6–8 类 | 低，一个 dict | BFI-Adapt 的教训（推断） |
| **引用 / 转述带来源标记**：note 里分清"她说的""我听说的""我自己想的" | `store/graph.py` 的 note 字段 + 提示词 | 低 | patterns 那条措辞 |
| **运行时的门**：探针越界 ⇒ 冻结该维度，等人读 | 自检 / 探针 | 中（前置是要先有确定性探针） | OpenPersona 的三道门 + Emergi 的治理流程 |
| **治理流程的字段名**（候选 / 证据 / 审查 / 版本 / 否决） | 就是 `决策记录.md` 那套 | 零 | Emergi-PersonaOS |

| 不能借 | 为什么 |
|---|---|
| 0.85% 可训练参数 / LoRA 身份 | 违反"读法暂不训练"；参数牢但读不出来、改不动，与"可核验"冲突（见 [`自我的载体-调研.md`](自我的载体-调研.md) §2） |
| Lyapunov 式的漂移界 | API 下没有潜在状态，界只能落在探针分数上——那是代理指标，不是人格 |
| Tur 的 Merkle 迁移 | 换基座时才需要；现在解决的是"变什么"，不是"怎么搬" |
| OpenPersona 整套框架 | 30 MB、Jupyter、绑定 OpenClaw；我们要的是它的门，不是它的壳 |
| SPASM 的 ECP | 多智能体才需要；我们是单用户全局图 |
| StableMind / BRIDGE / ppol / SoulForge | 查不到对应物 |

## 4 下次照这个手法核

1. **论文**：`http://export.arxiv.org/api/query?search_query=all:"名字"` 或 `id_list=…`（本机直连可用）；
   要点是看 `<arxiv:comment>`——接收声明在那里，摘要里没有。
2. **仓库**：`gh api repos/<owner>/<repo>`；再 `git/trees/HEAD?recursive=1`，
   **按扩展名筛一遍**（这一轮就是靠这个发现 SPASM 没有代码）。
3. **包**：`https://pypi.org/pypi/<包名>/json`。
4. **三条判据分开**：论文有 ≠ 仓库有代码 ≠ 跑过。这一轮三个反例都齐了
   （BRIDGE 连论文都没有；SPASM 有论文没代码；patterns 有代码但关键事件没触发）。
