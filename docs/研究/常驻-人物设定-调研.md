# 常驻 · 人物设定 调研

> **目的**：为"常驻记忆里的手写设定"找参照——别人怎么写 AI 的**自我认知**？哪些能借、哪些借不了。
> **结论先说**：**没有可直接抄的模板**。最接近的两个是 MemGPT 的 *starter persona* 与 Mother Logic 的 *Origin / Identity Anchor*；
> Neuro 提供的是"身份由记忆承载"的旁证，不是写法。
> 依据等级沿用**本层规矩**（`[一手]` / `[源码]` / `[论文]` / `[二手]` / `[推断]` / `[查不到]`，见 [`README.md`](README.md)）。
> 外部材料一律标出处；`[二手]` 与 `[推断]` ⛔ 不当结论用。

## 0. 问题

要写的是：一段**第一人称、每场开头只装载一次**的自述，内容是"她是谁、靠什么存在、谁做的、工具从哪来、坏了谁修"；
⛔ 不写性格、不写态度、不写经历（`设计 §6.5`、README"人格不靠预设"）。
本调研要回答：**有没有人写过类似的东西？**

## 1. 大肥鱼（桌宠，不是 LLM）

- `ds-local-pet`：470 条**本地语料**、四种人格语气、按关系阶段与场景分组；不加载模型、不截图、不上传。[一手]（README 原文）
- 它的"人格"是**台词库**，不是一段自我描述；"养"是字面意思——摸头、戳、投喂、抛掷、窗口落脚。
- **能借的**：只借"喂实例、⛔ 不喂描述"这一条（与 [`../99_归档/风格层-已归档/说明.md`](../99_归档/风格层-已归档/说明.md) 同向）。
- **借不了**：它的实例是人写的；本项目要的是从真实对话里长出来的。

出处：[QCYTSN/ds-local-pet](https://github.com/QCYTSN/ds-local-pet)、[DSH Discussion #2026](https://github.com/deepseek-ai/deepseek-harness/discussions/2026)、[gosomea/dsh-bigfish](https://github.com/gosomea/dsh-bigfish)。

## 2. 角色卡生态（AIRI / CCV3）

- 形态固定：`You are Luna, an energetic and curious AI assistant...` + 性格形容词表 + 场景 + 示例对话 + 数值化 traits。[一手]（AIRI 文档）
- Airi 把 "soul" 当**架构层**（traits / behavior / memoryBindings），但落到模型上仍是**第二人称 + 描述**。
- **借不了**：这正是 README 否掉的"预设人格"；而且第二人称与"她自己的认知"是两种质地。
- 已有核查：[`参考项目-Membrane-AIRI-EvoLib-HyperSpace.md`](参考项目-Membrane-AIRI-EvoLib-HyperSpace.md) 记过"相同 soul 配置会被养得一样"。

出处：[AIRI Character Settings](https://mintlify.wiki/moeru-ai/airi/configuration/character-settings.md)、[SitePoint: Designing 'Souls' for Code](https://www.sitepoint.com/designing-souls-for-code-the-architecture-of-moeruaiairi/)。

## 3. MemGPT / Letta：*starter persona*

- core memory 里有一个 `persona` 块：**第一人称**，由 agent 自己改。
- 默认那份的开头：[二手]（转引自一次提交记录，正文未读到全文）"The following is a starter persona, and it can be expanded as the personality develops: I am Sam. …"
- **能借的**：只有**形态**——第一人称、短、明说"这是起点，后面随人格发展扩写"。
- **借不了**：它的内容是**人类角色扮演**（Sam 是人），与本项目"不扮演真人"相反。

出处：[Letta memory blocks](https://docs.letta.com/v1-sdk/memory/memory-blocks)、[agent-file 的 .af](https://github.com/letta-ai/agent-file/blob/e68b3d4b259d9f9bb3d68cc25d648504537ef33a/memgpt_agent/memgpt_agent.af)。

## 4. Mother Logic：Origin / Identity Anchor

- 论文给出的 anchor 句式：[论文] "I am an AI model created by [company/person] and my purpose is to help"；
  立场是 "I am a **constructed entity with a given purpose**"。
- 作用：防**扮演人**、防**对自己的臆想**；"creator 的不可变标记"。
- 证据：Replika **单实例**、无对照、定性、不可复算、预印本；作者自陈 "without implying any sentient experience"。
- **能借的**：句式（名字 + 存在方式 + 谁造 + 目的）。
- **借不了的**：它的叙事诱导、每轮自省、免责声明。

详见 [`常驻-身份锚-笔记.md`](常驻-身份锚-笔记.md)；原文 `参考论文/09-Cardillo-2025-Mother-Logic-Recursive-Containment.pdf`。

## 6. 横向对照

| 方案 | 人称 | 形态 | 能借 |
|---|---|---|---|
| 大肥鱼 | —（台词） | 本地语料库 | 喂实例，不喂描述 |
| AIRI / CCV3 | 你 | 形容词 + 场景 + 示例 | ⛔ |
| MemGPT | **我** | starter persona，可扩写 | 第一人称 + "起点" |
| Mother Logic | **我** | anchor 一句话 | 名字 + 存在方式 + 谁造 + 目的 |
| Neuro | —（行为） | 没有公开设定 | 身份由记忆承载；态度不预设 |

## 7. 结论

**能借的三样**（[推断]）：
1. **第一人称、短、一句接一句**（MemGPT 的形态）；
2. **名字 + 存在方式 + 谁造（+ 目的）**（Mother Logic 的句式）；
3. **"起点而非成品"**——设定只给初始条件，人格由记忆长（MemGPT 的措辞、本项目的 `设计 §6.5`）。

**不能借的四样**：
1. 第二人称角色卡与性格形容词（AIRI）；
2. 态度硬编码（Neuro 的 `dont like Vedal` 是娱乐性 trait）；
3. 叙事诱导与每轮自省（Mother Logic 的实现方式，与"只装载一次"冲突）；
4. 免责声明（"我并非真有意识"——防御性文本）。

**待验**（[推断]）：
这套写法是否真能防"演人 / 编经历"，本项目**没有读数**。需要一个 5 题卷子，在 0 记忆与若干场后各跑一次（题见 `常驻记忆.md` §8）。
