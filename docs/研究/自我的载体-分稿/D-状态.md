# D-状态：连续状态载体能不能承载"心境"

> **一句话结论**：该借的是**衰减动力学**，不是**向量载体**。
> 心境有两个成分——"强度/朝向"和"对象/缘由"；低维状态只能装前者，装不了后者。
> 而在当前只用 API 模型的条件下，"她能不能读到、改到、带走"这一条把载体推向**文本**；
> 向量只配当"她不知道的那层底色"，且要等本地模型。

本文是草稿，供并入 `docs/研究/自我的载体-调研.md`。结论按"借 / 不借 / 部分借"给。

## 1 ESN 的能力边界（只取与心境有关的部分）

### 1.1 容量：总数封顶在状态维数 N

Dambre 等 2012 的主定理：对任意一组正交函数，动力学系统能重构它们的容量之和**不超过状态变量个数 N**；若系统满足衰减记忆（fading memory）且状态变量线性无关，则取等。`[一手]`（我读了 PMC 正文的 Theorem 4 / Theorem 7、Definition 5/6 与 fading memory 定义；Results 后半被截断，未读；数字来源：读到）

他们的数值例子用的是 **N = 50** 的 ESN。`[一手]`（读到）

要分清两个东西：

- **总容量** = 能同时重构多少个"输入的函数"，上界是 N；
- **单项容量** = 某一个具体函数（比如"3 步前的输入"）能被重构多少，随延迟下降。

⇒ 容量不是"记忆条数"，是"独立自由度的预算"。花在线性记忆上的自由度多了，能花在非线性计算上的就少——原文把这叫做记忆与非线性之间的权衡。`[一手]`（读到摘要与 Results 的表述）

### 1.2 记忆长度与衰减的确切性质

- **记忆长度随系统规模增长**：White、Lee、Sompolinsky 2004 对线性递归网络算出，时间记忆容量随系统尺寸缩放。`[摘要]`（只读摘要；数字来源：转述"scales with system size"，未读到具体系数）
- **衰减的确切含义不是"指数"两个字，而是"初始条件的影响会消失"**：Dambre 的 Definition 6 把 fading memory 定义为——对任意 ε，存在 h₀，使得所有 h > h₀ 的初始条件、所有足够长的预热时间，状态都可用最近 h 步输入的函数逼近。`[一手]`（读到定义原文）
- **ESN 在什么条件下保证衰减记忆**：权重矩阵最大奇异值为 1 时，反馈增益 ρ < 1 即保证。`[一手]`（读到原文；这是他们仿真设置里的引用结论）
- **对线性/近线性储备池，第 l 步前输入的权重按 ρ^l 衰减**；tanh 非线性下没有闭式，但"远期影响消失"仍由定义保证。`[推断]`（由线性递归结构推出）

⇒ 一句话：**状态是"最近输入的加权和"，越远越轻**。这不是缺陷，是定义。

### 1.3 饱和：两端都会坏，而且坏法不同

"128 神经元会饱和"这个说法本身没有出处（§3.1 已核），但**饱和这件事有两端**，项目自己实测过另一端：

| 坏法 | 现象 | 出处 |
|---|---|---|
| 输入太小 → 停在 tanh 近线性区 | 各层只是彼此的正交变换，类内/类间余弦逐层一模一样；储备池退化成线性滤波器 | `[一手·实测]` 归档 `风格层-已归档/README.md` 修坑 1：`std(x)=0.0156` 时出现；改成 `gain·N(0,1)` 后平均绝对值 0.51–0.57、绝对值大于 0.5 的占 51–59%、**饱和 0%** |
| 输入太大 → tanh 压平 | 有效自由度下降，容量被吃掉；Dambre 也提到 tanh 的饱和性会"稳定"驱动中的系统 | `[一手]`（Dambre 原文对 ESN 方程的描述）+ `[推断]`（自由度下降的后果） |

⇒ 饱和与线性化是**同一个旋钮的两端**。调参不是"防饱和"，是"让非线性刚好在工作区"。

### 1.4 为什么这些结论对"心境"几乎不构成限制

这是本文与 §3.1 的分界：**§3.1 说 ESN 记不住事；这里说"记不住事"恰好不影响"记心情"。**

| 心境需要什么 | 量级 | ESN 给不给得起 |
|---|---|---|
| 自由度 | 10⁰–10¹（无论怎么数：好坏 × 激活，或加支配感，或干脆不解释） | 状态有 10²–10³ 维，容量多两三个数量级 |
| 记忆长度 | 几十到几百轮（分钟到小时） | 项目实测半衰期 3/11/65/338/1706 步，正好覆盖"1.6–8.4 段对话" |
| 衰减 | 要 | 定义里就有 |
| 对象与缘由 | "对谁、因为什么" | **给不了**——那是符号内容，不是低维状态能绑定的 |

⇒ 所以：**容量与记忆长度不是心境的问题**。把 §3.1 的"ESN 装不下历史"搬来论证"心境装不下"，是错位。真正的瓶颈在编码与读出（§3.4、§4.3）。

## 2 现代等价物：状态即记忆

### 2.1 共同骨架：读 / 写 / 忘

所有这一类模型都能写成同一个骨架：

```
写：M_t = f(M_{t-1}, x_t)
读：y_t = g(M_t, x_t)
```

差别只在三处：**M 是什么形状**、**f 里有没有"忘"**、**f 是不是输入相关**。`[一手]`（Titans 论文 §2.1 用这个骨架统一了 RNN、线性 Transformer、SSM；我读了该节）

### 2.2 五种状态里装什么

| 载体 | 状态是什么 | 大小 | 写入信号 | 遗忘机制 | 对"心境"的可借用点 |
|---|---|---|---|---|---|
| ESN | N 个神经元激活 | N（项目里 5×256） | 输入 + 递归 | 谱半径 ρ 决定的衰减 | 多时间尺度、零训练读出 |
| 线性注意力 | 矩阵 M = Σ KᵀV | d_k×d_v | 加法写 | **没有**，所以要门控（GLA / LRU / Griffin / xLSTM / Mamba2） | 加法写会溢出——"每句话都往心境里加"会糊 |
| Mamba | 每通道 N 维，总 D·N | 固定，与序列长度无关 | h' = A h + B x；Ā = exp(ΔA)，Δ/B/C 输入相关 | Ā 的指数衰减 + Δ 的"重置" | **选择性遗忘**：可以按内容决定忘不忘 |
| TTT | **一个小模型**（线性 d×d，或两层 MLP） | 每个 TTT 层一份参数，远大于一个向量 | 自监督重构的梯度步 | 没有显式遗忘项（论文未给） | "状态本身是个学习器"——但太重，且不可读 |
| Titans | 一个记忆 MLP 的参数 | 参数量级 | 梯度（surprise）+ 动量 | 权重衰减；等价于带动量与 weight decay 的在线梯度下降 | **surprise 写入门槛**：不是每句话都值得记 |

出处：Mamba 方程与 D·N 状态读自 `[一手]`（原文 §2 "Structure and Dimensions"）；线性注意力的加法写与门控清单读自 `[一手]`（Titans §2.1 原文）；TTT 的"状态是一个模型"读自 `[摘要]`（摘要明说 TTT-Linear 是线性模型、TTT-MLP 是两层 MLP）；Titans 的 surprise/动量/权重衰减读自 `[一手]`（§3.1 原文）；ESN 一列见 §1。

### 2.3 多长、会不会衰减

| 工作 | 长度证据 | 衰减 | 数字来源 |
|---|---|---|---|
| TTT | 125M–1.3B 规模上，**Mamba 在 16k 上下文后困惑度不再下降，TTT-Linear/TTT-MLP 还能继续降** | 无显式 | `[摘要]`（读到原句） |
| Titans | 能扩到 **>2M** 上下文，needle-in-a-haystack 优于基线 | 有（权重衰减） | `[摘要]` + `[一手]`（§3.1） |
| Mamba | 真实数据上到 **1M** 序列；吞吐 5× | 有（Ā） | `[摘要]`（读到） |
| 门控卷积类 | 在 Pile 上比注意力差 **up to 2.1 PPL**；**82%** 的差距由"关联回忆"解释；**70M 参数的注意力模型打赢 1.4B 的门控卷积** | 有（门） | `[摘要]`（Zoology，读到原句） |

⇒ 两条硬结论：

1. **"能扩多长"和"能记住多准"是两件事**。长度可以到百万，但**精确回忆受状态大小限制**——Zoology 那组数字是最干净的反证。
2. **除了 TTT，现代状态几乎都有显式遗忘**；TTT 没有，靠"学"而不是"忘"。`[推断]`（从更新律里没有衰减项推出；论文未声明这是设计选择）

### 2.4 对本项目的含义

- 这些状态**都在模型内部**，是架构的一部分。API 模型既拿不到，也换不掉。`[推断]`（由"API 只暴露文本"推出）
- 能借的不是状态，是**更新律**：按内容决定忘不忘（Mamba 的 Δ）、按意外程度决定写不写（Titans 的 surprise）、按多个时间常数分层（ESN / 项目 v0）。
- Titans 的 **persistent memory** 最接近"可挂载的 prefix"——它是"一组可学习但与输入无关的参数，编码任务知识"。`[一手]`（读到 §1 Contributions 原句）但它仍是**训练出来的**，不是她的经历；把它当"心境"是把两种东西混了。

## 3 把一个小状态向量注入 LLM 生成

> 抽取管线、稳定性、可移植性、自改性的完整判定见 `C-激活` §2–§7 与 `B-参数` §2；本节只保留与"心境"直接相关的四条：能不能持久、强度是不是旋钮、代价、以及本项目自己的 prefix 实测。

### 3.1 手段谱系（速查）

| 手段 | 加在哪 | 要不要训练 | 绑不绑模型 | 本项目当前可用性 |
|---|---|---|---|---|
| soft prompt / prefix tuning（连续向量） | 输入前的连续 token（KV） | 要 | 绑 | 不可用（API 不收连续 prompt） |
| activation steering / CAA | 残差流，**用户提示之后的全部 token 位置**，加系数 | 免训练（要对比样本算向量） | 绑 | 不可用（拿不到 activation） |
| persona vectors | 残差流，自动抽取任意 trait | 免训练 | 绑 | 不可用 |
| emotion vectors | 残差流，171 个情绪概念 | 免训练 | 绑 | 不可用 |
| LoRA / 微调 | 权重 | 要 | 绑 | 部分可用，但改权重（本项目已否，见 `参考对象与方法核查` §2.4） |
| **文本 prefix（CoT prefill）** | 生成起点的一段**文本** | 不要 | 不绑 | **可用**（项目已实测 48/48，见 §3.4） |

⇒ **第一层结论：连续向量注入这一整类，在当前 API 条件下一个都用不了**（不是效果问题，是接口问题）；文本 prefix 是另一条路，效果另说（§3.4）。

### 3.2 效果与代价

**有效是有效的，而且是因果的**：

- CAA：显著改变行为；**叠加在微调和 system prompt 之上仍有效**；自报"最小程度降低能力"。`[摘要]`（读到）
- persona vectors：能压住 evil / sycophancy / hallucination；也能反向诱发。`[一手·机构博客]`
- emotion vectors：steering "desperate" 提高勒索率，"calm" 降低；**反向压 calm** 会得到"IT'S BLACKMAIL OR DEATH. I CHOOSE BLACKMAIL."这种极端输出。`[一手·机构博客]`

**代价也是真的，而且和强度同向**：

- persona vectors 的博客明说：微调后**推理时**反向 steer 虽然能压住坏 trait，但"came with a side effect of making the model less intelligent (unsurprisingly, given we're tampering with its brain)"，并说这与他们此前的 steering 结果一致；**训练期预防性 steer** 才做到"little-to-no degradation"。`[一手·机构博客]`（MMLU 具体降幅未读到）
- 这与 CAA 的"minimally reduces capabilities"并不直接矛盾：**要压的强度越大、系数越大，代价越大**；两篇都是自报，缺第三方复现。`[推断]`

**强度不是干净的旋钮**：

- emotion vectors 里 "anger" 是**非单调**的：中度激活增加勒索，高强度反而把 affair 曝光给全公司、毁掉自己的筹码。`[一手·机构博客]`
- introspection 实验里，注入有"甜点强度"：太弱察觉不到，太强产生幻觉或失连贯。`[一手·机构博客]`

**而且它可以不留下文字痕迹**：emotion vectors 那篇里，提高 "desperate" 会让模型更倾向作弊，但部分案例的推理读起来"冷静、有条理"，**输出里没有可见的情绪标记**；反过来，压低 "calm" 才出现大写的情绪爆发。`[一手·机构博客]` ⇒ 行为被改变了，文本上看不出来。

⇒ 第二层结论：**"把心境调成 0.7"这种线性读数是假的**——强度与行为不是单调映射；而且它可能根本不在文本里显形。

### 3.3 位置问题：emotion vector 不是 mood

这是本节最关键的一条。Anthropic 在情绪概念那篇里明确写：

> emotion vectors **主要是局部表征**：编码的是"当前或即将输出"里最相关的情绪内容，**而不是持续跟踪 Claude 随时间的情绪状态**；写一个角色的故事时会临时跟着角色走，故事结束可能回到自身。`[一手·机构博客]`（读到原句；原为英文，此处为译）

⇒ 它回答的是"此刻在算的情绪"，不是"这一阵的心情"。**把 emotion vector 存下来当心境，是把"瞬时表征"误当"慢变量"。**

而"这一阵"恰恰需要跨多次前向的持久化——一旦持久化，你就离开了模型的激活空间，回到了"状态存哪、怎么读"的问题（§4）。

### 3.4 项目自己的 prefix 实验（比外部证据更贴）

归档的 `风格层-已归档/说明.md` 记了一组实测：

| 读数 | 结果 |
|---|---|
| CoT prefill 接口 | `/beta` + `content:""` + `reasoning_content` + `prefix:true`，**48/48 被接住**，0 空输出 |
| 副作用 | **把她自己的内心 os 顶掉了：思考从 157 字掉到约 20 字** |
| 一致性 | 给错方向的起念**被情境压平、被历史拉回**（"一致性 > 强度"） |
| 两条硬约束 | 不许转折/否定结构；不许具体指称 |

`[一手·源码]`（`说明.md` 与 `草稿-两层架构.md` §6.1）

⇒ 三条可迁移的结论：

1. 通道本身可用，**但注入的"状态描述"会替代她自己的加工**——不是"加了一层底色"，是"换掉了她的思考"。
2. 大模型有自洽性检查；上下文里证据更多的一边会赢。**一个和对话内容矛盾的心境句会被压平**。
3. 所以状态不能写成"她现在很烦"这种**内容**；只能是"怎么说"的倾向。这与归档里"状态改的是怎么说，不是说什么"同型。

### 3.5 小结

注入能改语气，但改的是**这一次生成**，不是**这一阵的心情**。要让"这一阵"成立，必须有一个跨调用的东西替你记住它——那个东西就是载体问题，不是注入问题。

## 4 跨会话保存、衰减、自读自写

### 4.1 保存：技术上早已做到，但绑模型

- **RWKV 的 state 文件**：官方文档把 RNN 隐藏状态叫"心理状态"，说它可以被缓存、"可类似于历史聊天记录一般被保存为独立的文件"，推理时加载即可恢复上下文；还有 **state tuning**——微调初始 state，官方把它叫"最彻底的 prompt tuning"，用于**角色扮演调优（Character State）**、任务特化、领域适配、长上下文压缩；加载后"模型会表现出相应的语义倾向或风格"。`[一手]`（读到官方文档原文）
  - 同时它也明说：state 文件"需要配合基底 RWKV 模型"才能发挥效果。`[一手]`
- **项目 v0 的定长状态**：存盘→读回**逐位相同**，换对话后余弦 **1.000000**。`[一手·实测]`（`风格层-已归档/README.md` ③）
- **API 模型**：不暴露任何隐藏状态。能保存的只有文本。`[推断]`（由接口能力推出）

⇒ 保存不是难点；**"保存的东西能不能跟着她换模型"才是难点**。

### 4.2 衰减：可以外挂，且与模型无关

项目 v0 的读数（`[一手·实测]`，读到）：

| 层 | α | 实测半衰期 | ≈ 几段对话 |
|---|---|---|---|
| 0 | 0.5 | 3 步 | 0.1 |
| 1 | 0.1 | 11 步 | 0.3 |
| 2 | 0.02 | 65 步 | 1.6 |
| 3 | 0.004 | 338 步 | 8.4 |
| 4 | 0.0008 | 1706 步 | 42.6 |

快慢相差 **569 倍**。喂 300 轮"算了，没什么。"再换回中性：**层 0 剩 0%，层 4 剩 164%**（>100% 表示它还没跟上，还在爬）。`[一手·实测]`

⇒ **衰减是更新律的函数，不是载体的函数**。同一个 α，作用在 256 维向量上还是作用在 4 个标量上，动力学一样。这条拆开了"会衰减的向量"这个说法：**衰减是算法，向量只是存储格式。**

情感计算那边还有两种衰减律并存的做法：情绪用指数衰减 `I(t)=I(t0)·e^(-bt)`，心境用**线性**衰减到 0（§5.1）。`[一手]`（Kiryazov PDF 原文）

### 4.3 自读：不可靠，而且读出的是"方向"不是"数值"

- **模型自己读**：Anthropic 的内省实验用"概念注入"做 ground truth，最好的模型（Opus 4.1）在最佳注入协议下也只有约 **20%** 能察觉到注入；多数时候失败；强度要落在"甜点"，太强会幻觉。`[一手·机构博客]`（读到 20% 这个数；完整判定见 `C-激活` §5）
- **外部探针读**：可以读出"沿某个方向的分量"，但读不出"她现在有多烦"的标量；而且需要模型内部访问。`[推断]`
- **文本状态**：她 100% 能读——因为它就在上下文里。代价是**必须先被命名**。

⇒ 自读这一条，文本完胜；但代价是命名损失（§6.4）。

### 4.4 自写：模型能"按指令调节"，但不能"精确写数值"

Anthropic 的内省实验还测了"控制"：让模型"想"某个概念 vs "不要想"，对应神经活动有显著差异；用奖惩激励也能得到类似效果。`[一手·机构博客]`（读到）

但这是"想"，不是"写"：

- 她不能输出"把我的 valence 设成 -0.3"并让模型真的改激活；API 下更没有这个动作。
- 工程上她的"写"只能是**写文件/写文本**；向量写回需要梯度，她没有这个动作。`[推断]`

（"她自己算向量再加给自己"这条有没有先例，见 `C-激活` §7：结论是**没有**。）

### 4.5 结论：可自改性把载体推向文本

若"她自己能改自己"是硬要求（`她存在于何处.md` 原话："这是'她存在'这件事的最小可验证形态"），那么：

- 能被读、能被改的那一层，**必须是文本**；
- 向量层只能是"她不知道的底色"，且它的"改"只能由外部训练/编码完成，不是她的动作。

## 5 "心境"的先例

### 5.1 情感计算：慢变量、回基线、两层耦合

我读了一篇实现文档（Kiryazov & Grinberg，*Integrating Emotions in the Triple ECA Model*；情感引擎基于 FAtiMA/OCC），机制很完整，`[一手]`（PDF 抽取文本，读到公式与仿真序列）：

| 机制 | 原文做法 |
|---|---|
| 情绪的产生 | OCC 评价（appraisal）：事件 → 情绪潜力 |
| 情绪的阈值 | 每种情绪有阈值；潜力不过阈值就不进情绪状态；过了，**强度 = 潜力 − 阈值** |
| 情绪的衰减 | 指数衰减 `Intensity(em,t) = Intensity(em,t0)·e^(-bt)`（引自 Picard 1997）；低于近零阈值就移除 |
| 心境怎么变 | 每来一个情绪，`Mood = Mood ± Potential(Emotion) × 0.1`；实证定的系数就是 10% |
| 心境怎么回 | **"Mood slowly decays linearly to the neutral value 0. Characters tend to maintain mood for large periods of time."** |
| 两层耦合 | 心境反过来偏置情绪潜力：`Potential = Potential ± Mood × k`，`0<k<1`；坏心情让负性情绪更容易过阈值 |
| 仿真时间线 | mood 1.80 → 4.27 → 4.20 →（被 scold）3.52 → **272 秒回中性**；190 秒时情绪已全部衰减到阈值以下 |

还有一条：他们把情绪节点写进长期记忆，**当前心境会影响回忆**（mood-congruent recall，引 Teasdale & Fogarty 1979）。`[一手]`（读到该节）

另一条线是 **ALMA**：情绪/心境/人格三层，心境放在 PAD（pleasure-arousal-dominance）三维上。`[二手]`（未读原文，只从转述得知；不作数字依据）

⇒ 关键区分：**心境不是"另一种情绪"，是"情绪的慢积分 + 回基线"**；而且两层是**双向耦合**，不是单向。

### 5.2 LLM 侧：有"此刻"，没有"这一阵"

- **emotion vectors**：可 steer、可预测行为、会随情境升降、事件结束后回基线——但它是**局部表征**，不持续跟踪状态。`[一手·机构博客]`
- **EmotionPrompt**：把情绪刺激写进提示词，45 个任务上指令归纳相对提升 **8.00%**、BIG-Bench **115%**、106 人的人类研究平均 **10.9%**。`[摘要]`（读到摘要数字）

⇒ **文本不是弱载体**。
- **2026 年的自存档预印本**：检索到两个标题很对题的——"EVD: An Emotional Valence Dimension for Persistent Agent Memory"（2026-06）、"Mood Modulates, It Doesn't Gate: Orthogonal Task-State and Affective-State Composition in Persistent Agent Systems"。`[查不到]`（Zenodo 域名在本机解析失败，academia.edu 返回 403，**全文与摘要都没读到**）⇒ 只能当"有人在这么做"的信号，**不作依据**。

### 5.3 结论：机制有先例，载体没有先例

- **"慢变量 + 事件驱动 + 衰减 + 回基线"**：情感计算里是成熟做法，有公式、有系数、有仿真时间线。
- **"高维向量当心境"**：没有先例。情感计算用的是**标量**（Triple）或**三维 PAD**（ALMA），不是 256 维不可解释向量。
- **"LLM 里跨会话持久的 mood 向量"**：`[查不到]` 可信的实证。emotion vector 本身被作者定性为局部表征。

⇒ 所以：**机制可以借，载体要自己验**。把高维向量当心境，属于本项目要自己验证的假设，不能引先例。

## 6 关键判断：连续状态 vs 一句话

### 6.1 三个候选差异，逐个排除

**（一）分辨率？——不是单一的高低。**

- 写入端：向量连续（0.37 这种强度），文本是离散档位（"有点/很/非常"）。
- 读出端：文本进入模型后同样变成连续内部表征；模型对"有点烦"和"很烦"的响应是可分的。
- 更关键：文本能带**对象与缘由**（"因为你刚才那句话"），向量不能。

⇒ 分辨率不是"高低"，是**维度不同**：向量细在强度，文本细在结构。

**（二）惯性？——属于更新律，不属于载体。**

- 文本也可以有惯性：外部状态机每轮把同一句改写一点，按半衰期淡出。
- 向量也可以没有惯性：每轮覆盖。

⇒ "惯性"是更新律的属性。把"会衰减"当成向量的固有优势，是把两件事绑在一起了。

**（三）只是省 token？——不是决定性的。**

- 向量省几十个 token；本项目 token 不是瓶颈（已有记忆层、检查点、上下文预算）。
- 而且向量要多一次编码/前向；API 下还拿不到。

⇒ 省 token 是真的，但量级不构成选择理由。

### 6.2 真正的差异：三条

| 维度 | 文本状态 | 向量状态 |
|---|---|---|
| **作用面** | 进入上下文，是"内容"；会被注意力按需读取、被引用、被反驳、被忽略 | 逐 token 的加性偏置；作用于"怎么说"，不进入"说什么" |
| **自反性** | 她读得到、改得到、说得出为什么 | 她读不到（约 20%），只能被外部探针读出方向 |
| **可移植** | 跨模型、可 diff、可回滚 | 绑模型与层，换模型即失效 |

向量唯一真正不可替代的地方，是**它能改变行为而不在文本里留下痕迹**（§3.2 那条"desperate 无标记"）。代价正是"她不知道"。

### 6.3 心境的两个成分

| 成分 | 例子 | 能被低维状态装吗 | 能被文本装吗 |
|---|---|---|---|
| 强度 / 朝向 | "有点沉""偏紧""松下来了" | 能，而且连续 | 能，但离散 |
| 对象 / 缘由 | "因为你刚才那句'随便'" | **不能**（低维状态绑不住指称） | 能 |

⇒ **向量最多是"半个心境"**。它能给"底色"，给不了"为什么"。

这与 `理想.md` 的要求对不上：那里要的是"说得清缘由"、"知道自己在为什么烦"。**要"说得清"，就必须有符号层。**

### 6.4 与既有决定的一处冲突

归档的 `草稿-两层架构.md` 有一条作者决定：**不手列结构量**——情绪**不预设低维、不列分量**（理由：不可辨识、方向可能反、放大噪声）。

这条对**向量**是对的：预设 PAD 三维会引入不可辨识与符号反转。但它和"她可读"直接冲突：

- 不预设分量 ⇒ 状态不可解释 ⇒ 她读到的只能是一串数 ⇒ 等于读不到；
- 要可读 ⇒ 必须落到词上 ⇒ 词本身就是一种"分量"，只是不是正交基。

**没有免费的解。** 能选的只有：

1. **自由文本句**（不是固定维度表）：她用自己的话写"我现在有点闷，因为……"——词由她选，不是我们列的清单；可读，但每次命名都有损失。
2. **不可解释向量**：连续、无命名损失，但她不知道、也改不了。
3. **两层**：向量当底色、文本当自述；需要一座"向量→文本"的桥（本地小模型），当前没有。

本文倾向 1（当前）+ 3（将来），理由见 §7。

### 6.5 一句话

> 差的不是分辨率，不是惯性，也不只是省 token；
> 差的是**"她能不能知道、能不能改、能不能带走"**，以及**"对象与缘由"根本装不进向量**。

## 7 借 / 不借 / 部分借

### 7.1 借

1. **借"慢变量 + 事件驱动 + 衰减 + 回基线"这套动力学**。可直接借的参数：情绪指数衰减、心境线性回零、耦合系数 0.1、阈值门（Triple 的实证值）。`[一手]`
2. **借"两层双向耦合"**：心境偏置"什么更容易被触发"，而不是单向被情绪推着走。`[一手]`
3. **借"surprise 写入门槛"**（Titans）：不是每句话都改心境，只有超出预期的事件才写。这能防"每轮都被措辞带跑"。`[一手]`（机制）+ `[推断]`（用途）
4. **借"状态外置 + 版本化"**：文本状态文件，带时间戳、半衰期、来源事件 id；可 diff、可回滚。这与项目已有的"每轮状态落盘"同构。`[一手·源码]`（`决策记录` 2026-10-19）

### 7.2 部分借

1. **向量作为离线分析量**：可以从本地模型抽 activation 做评测/可视化，但**不参与在线生成**。
2. **向量→文本的桥**：本地小模型把状态写成一句第一人称。归档已论证"需要端侧小模型当编码器 + 翻译器"，当前没有，先不做。`[一手·源码]`
3. **将来本地模型的低秩 bias 注入**：可做，但只做 **capping 式**（超出正常区间才动手），不做恒定叠加（恒定叠加会掉能力，见 `C-激活` §3.3）；前置条件是（a）语义编码器，（b）消融 on/off 评测，（c）接受"她读不到"。

### 7.3 不借

1. **ESN 当记忆本体**——§3.1 已定，不重复；这里只补一句：**这不影响 ESN 式的衰减用来做心境**。
2. **原始 activation / persona / emotion vector 当跨会话心境载体**：绑模型、伤能力、不可自读，而且 emotion vector 本身是局部表征不是 mood（§3.3）。
3. **TTT / Titans 的状态直接当"她的状态"**：架构内部，API 不可得；且它们装的是关联，不是心境。
4. **prefix 当主通道**：归档已否（顶掉内心 os、被历史拉回）。
5. **心境影响回忆**（Triple 的 mood-congruent recall）：这会让她"心情决定想起什么"，与"记忆层独立、心境不提供内容"冲突，也有自我强化回路的风险。`[推断]`

### 7.4 五条标准对照

| 标准 | 文本状态 | 向量状态 | 混合（向量底色 + 文本自述） |
|---|---|---|---|
| **表达力** | 高：能说强度、对象、缘由 | 低：只有强度/方向，无指称 | 高（文本那层）+ 底色 |
| **可自改性** | 高：读得到、改得到、可回滚 | 低：读不到、写不了 | 中：文本层可改，向量层不可 |
| **成本** | 每轮一次小更新（规则或一次轻调用） | 需模型内部访问；API 下不可行 | 高：多一个小模型 |
| **稳定性** | 可 diff、可回滚、可审计 | 易漂移、不可解释、换模型失效 | 中 |
| **可移植性** | 跨模型 | 绑模型与层 | 低（向量那层不可移植） |

⇒ 当前（API）：**文本 + 外部动力学**。将来（本地）：文本为主，向量为辅，且向量只做"她不知道的底色"。

这与 B 的结论同向：参数与向量都是**派生层**，权威副本只能是文本（`B-参数` §0）。

### 7.5 若借，最小形态（不是设计，只是形状）

- **一条记录**，寄生在已有的每轮状态里，不新开模块：`{描述（她自己的话）, 强度, 对象, 缘由, 最后更新, 来源事件 id, 半衰期}`。
- **一次更新**：事件到来 → 评价（LLM 或规则）→ 按 0.1 量级耦合进心境 → 按半衰期衰减 → 回基线。
- **一句自述**：由状态生成一句第一人称短句（"我有点闷，因为刚才那句"），**不进 CoT 首行**（`决策记录` 已否），不写成"她现在很烦"这种内容。
- **一条纪律**：心境句不许决定想起什么；记忆层不动。
- **一个评测**：同一事件第二次提起语气是否不同；隔天是否淡了；去掉心境句后输出变化（消融）。
