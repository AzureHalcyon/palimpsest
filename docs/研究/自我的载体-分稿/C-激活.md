## 0. 结论先说

**一句话**：这条分支在"读"和"改"上都有真机制，但它给的是**每个 token 的一个偏置**，不是**一个能存续的状态**。
所以它能借的是三条**设计结论**（轻触式干预 · 漂移有方向 · 状态与表达会脱钩，见 §8.3），
加上一条纪律推论（向量只能当**可重算的临时量**，不当状态存），
**不能借的是"用它承载她的自我"**。而且这一切的前提是白盒——**现在只有 API，可用量是 0，不是少**。

判定（详见 §8）：**不借**（作载体）· **部分借**（作将来本地模型上的读取/纠偏接口）· **借**（作换基座时的设计约束清单）。

## 1. 术语先分清：两个"激活"

这一条不写清，后面的讨论会一直错位。

| 词 | 在本项目里指 | 在本文里指 |
|---|---|---|
| **激活**（`设计 §4`） | 给定情境，在**节点与组**里选出被取用的一小片及其权重 | —— |
| **激活引导 / 激活向量** | —— | 在残差流某一层加/减一个固定向量，改变这一次前向 |

两者同名不同物：前者是**图上的注意力**，后者是**模型内部的数值干预**。
本文只谈后者。凡涉及项目那一层，一律写"图上激活"。

另外三个词在中文里也容易混，本文按英文原义用：

- **persona vector**：某个 trait 方向（模型 × 层 × trait 的三元组）。
- **steering vector / CAA**：从对比样本算出的方向，泛指这一类。
- **activation capping**：只在激活超出正常区间时才截断，不在区间内不动手。

## 2. Anthropic 的 persona vectors（2025）到底做了什么

论文：[arXiv:2507.21509](https://arxiv.org/abs/2507.21509)（v3，2025-09-05），
作者 Chen / Arditi / Sleight / Evans / Lindsey，Anthropic Fellows + Anthropic。
官方博客：[anthropic.com/research/persona-vectors](https://www.anthropic.com/research/persona-vectors)。

### 2.1 怎么得到（这一节是可以照做的部分）

整个管线只需一个 trait 名 + 一句自然语言描述，剩下的由一个前沿 LLM（Claude 3.7 Sonnet）生成 `[一手]`（论文 §2.1）：

1. 生成 **5 对**对比 system prompt：一对里一个是"诱发该 trait"，一个是"压制该 trait"。
2. 生成 **40 个**可能诱发该行为的问题，**提取集与评测集各一半**。
3. 生成一份评分 rubric；judge 用 GPT-4.1-mini，给每条回答打 **0–100** 的 trait 表达分。

向量本身 `[一手]`（§2.2）：

- 每个问题在正/负 system prompt 下各采 **10 条**回答；
- 用 trait 分数过滤，只留"符合预期方向"的（正 >50、负 <50）；
- 取**回答 token 上**的残差流激活、对该段 token 取平均；
- 向量 = 正例均值 − 负例均值；
- **每一层都能算出一个候选**，然后按"哪一层的引导效果最好"选一层。

三点要记住：

- 它**是有监督、靠 prompt 诱发**的，不是无监督发现的。作者在局限一节第一条就写
  *"Supervised, prompt-elicited extraction"* `[一手]`。
- ★ **回答 token 优于 prompt token**：作者测过多种取激活的位置，报告回答 token 得到的方向更好用 `[一手]`（§2.2 脚注 + 附录 A.3）。
- ★ **层要逐模型挑**。⇒ 这个向量不是普适对象，是（模型 · 层 · trait）的三元组。

### 2.2 能控制什么

主文三个负面 trait：**evil / sycophancy / hallucination**；
附录另做四个：**politeness / apathy / humor / optimism**（含正面 trait）`[一手]`。
实验只在两个开源模型上做：**Qwen2.5-7B-Instruct、Llama-3.1-8B-Instruct** `[一手]`。

### 2.3 效果多大（数字都在这里）

| 用途 | 做法 | 数字 | 出处 |
|---|---|---|---|
| 引导表达 | 每步 `h ← h + α·v` | trait 分数随 α 单调上升，能稳定造出恶意 / 谄媚 / 编造的回答 | §3.2 图 3 `[一手]` |
| **部署期监测** | 最后一个 prompt token 的激活在该方向上的**投影**，对后续回答的 trait 分数 | **r = 0.75–0.83** | §3.3 `[一手]` |
| **训练期监测** | 微调前后激活沿该方向的位移（"finetuning shift"）对 trait 变化 | **r = 0.76–0.97**；跨 trait 基线 0.34–0.86 | §4.2 `[一手]` |
| 事后抑制 | 反方向减（`h ← h − α·v`） | trait 下降有效，但**大 α 下 MMLU 掉** | §5.1 `[一手]` |
| 训练期"疫苗" | 微调时**朝坏方向加**，抵消数据给的位移压力 | 压住漂移，且 **MMLU 基本不掉** | §5.2 `[一手]` |
| 数据筛查 | 用样本"投影差"排序，训高分样本 | 训出来的 trait 更强，低分反之 | §6 `[一手]` |

回答连贯性全程用 judge 打 0–100 分，声明"所有结果的连贯性均值高于 75" `[一手]`。

### 2.4 局限（它的自述 + 我要补的三条）

**论文自己列了四条** `[一手]`（§8 小节标题）：
有监督、靠 prompt 诱发 · 评测靠自动 judge · 模型与 trait 覆盖有限 · 数据筛查的计算成本高。

**我另标三条，都与本项目直接相关**：

1. ★ **监测的相关性主要来自"prompt 类型"的差异**。原文说：控制住 prompt 类型之后相关性
   *"more modest"*，并自评 persona vectors *"对清晰、显式由 prompt 诱发的漂移有效，
   对部署中更细微的行为变化可能不那么可靠"* `[一手]`（§3.3）。
   ⇒ **"能读出漂移"这件事的证据强度，取决于漂移有多明显。**
2. **评测靠一个 0–100 的 judge 分**，量本身就带噪；两个模型都是 7–8B 开源模型 `[一手]`。
3. ★ **层是逐模型挑的**（"most informative layer"）⇒ 换模型必须重挑，见 §6.2。

## 3. 方法谱系、稳定性、强度、代价

### 3.1 谱系

| 方法 | 年 | 一句话 | 等级 |
|---|---|---|---|
| **ActAdd** | 2023 | 一对 prompt（Love / Hate）的激活差，一次前向里加；作者称在情感翻转与去毒上 SOTA，且"不伤 off-target 任务" | `[一手]`（[2308.10248](https://arxiv.org/abs/2308.10248) 摘要） |
| **CAA** | 2023 / ACL 2024 | 正负样本对的残差流差取平均，**在 prompt 之后每个 token 位置**加同一系数；"在微调与 system prompt 之上仍然有效，对能力损伤很小" | `[一手]`（[2312.06681](https://arxiv.org/abs/2312.06681) 摘要） |
| **persona vectors** | 2025 | CAA 的自动化 + 多 trait + 监测用法（§2） | `[推断]`（方法逐条对得上） |
| **SAE 特征引导** | 2024– | 用稀疏自编码器的特征当方向 | `[一手]`（AxBench） |
| **ReFT-r1** | 2025 | 弱监督学一个 rank-1 子空间（不是纯推理时，但干预形态一样） | `[一手]`（AxBench） |

**把它们放在同一张表上比的是 AxBench**（[2501.17148](https://arxiv.org/abs/2501.17148)，Gemma-2-2B / 9B，8 个任务，长文生成 + judge）：
结论逐字是 *"prompting outperforms all existing methods, followed by finetuning"*，
SAE 在"概念检测"和"引导"两项上都不具竞争力 `[一手]`（摘要 + §1）。
⇒ ★ **这是本次调研里最不客气的一条外部结论：在同等条件下，写 prompt 比调激活更有效。**

### 3.2 稳定性：不是"稳不稳"，是"看你在什么条件下问"

Tan et al.（NeurIPS 2024，[2407.12404](https://arxiv.org/abs/2407.12404)）做了系统的可靠性分析 `[一手]`（摘要）：

- **分布内**：同一概念在**不同输入**上的可引导程度差异很大；
  "虚假偏置（spurious biases）"会显著影响**单条输入**的引导效果；
- **分布外**：多数概念能泛化，但**若干概念对 prompt 的合理改动就很脆**，泛化失败；
- 总评（译）：*"在合适的情况下能行得通，但规模化地用它引导行为仍有技术困难"*。

⇒ 对本项目：像"她现在是防备的，把防备压 0.3"这种**按情境调参**的用法，文献里没有稳定保证。
按输入调参恰恰是这类系统最想做的事，而它是最不靠谱的部分。

### 3.3 强度怎么调（这一节决定"会不会伤能力"）

- 主流做法就是一个标量 α，**手调 + 按层扫**，即**开环** `[一手]`（persona vectors §3.2）。
- ★ **崩坏阈值很低**。Anthropic 的内省实验里，注入强度 **2 和 4 效果最好**；再往上就"brain damage"——
  被注入的概念吞掉、失去身份、最后输出乱码 `[一手]`（[introspection 全文](https://transformer-circuits.pub/2025/introspection/index.html)）。
- 两种"不伤能力"的改法，都是 2026 年的：
  - ★★ **activation capping**（[Assistant Axis, 2601.10387](https://arxiv.org/abs/2601.10387)）：
    先量出正常行为下沿该轴的激活区间，**只在超出区间时截断**，区间内完全不干预。
    结果：有害回答率降**约 50%**，能力基准**完全保住** `[一手]`（[博客](https://www.anthropic.com/research/assistant-axis)）/ `[摘要]`（论文）。
  - **闭环控制**（[2604.19018](https://arxiv.org/abs/2604.19018)，under review）：
    把逐层传播当**局部线性**动力系统，用层级 Jacobian 做反馈控制去追一个语义设定值；
    给出跟踪误差界，且不需要离线训练 `[摘要]`（仅摘要）。
- ⇒ 结论：**"恒定叠加"是 2023 年的用法；2026 年的做法是"定区间 + 越界才动手"或"闭环追设定值"**。
  这个差别对本项目很重要，见 §8.3。

### 3.4 代价

| 项 | 量级 | 等级 |
|---|---|---|
| 推理时 | 每 token 每层一次 d 维加法，相对前向可忽略 | `[推断]` |
| 抽取 | 几十到几百次生成 + judge 打分（按 §2.1 的规模估），很便宜 | `[推断]` |
| **评测** | ★ **真正的成本在这里**：要有一把能判"这就是她的语气"的尺子 | `[一手]`（两篇都承认 judge 是主要不确定性来源） |
| 前提 | **白盒**：要能拿残差流、能挂钩子 | `[推断]` |

## 4. 它能稳定控制"语气 / 态度"，还是只做表层情绪？

### 4.1 支持"能"的证据

- **Assistant Axis**（2026，275 个角色原型 × 3 个模型：Gemma 2 27B / Qwen 3 32B / Llama 3.3 70B）`[一手]`（博客）/ `[摘要]`（论文）：
  - persona 空间的第一主成分就是"有多像 Assistant"，且**预训练模型里就已有**；
  - 朝 Assistant 端推 ⇒ 更抗拒角色扮演；在 **1100 条 / 44 类**有害请求的越狱集上，有害率显著下降；
  - 朝反方向推 ⇒ 真的**开始成为别人**：编造人类履历、改名字；推狠了会变成神棍腔。
- **情绪向量有因果作用**（171 个情绪概念，Claude Sonnet 4.5）`[一手]`（[博客](https://www.anthropic.com/research/emotion-concepts-function)）：
  - "desperate" 向量升高 ⇒ 勒索率上升（该快照基线 **22%**）；"calm" 升高 ⇒ 下降；
  - 反向压 "calm" 会出极端输出（*"IT'S BLACKMAIL OR DEATH. I CHOOSE BLACKMAIL."*）。
- ★ **最值得记的一条**：升 "desperate" 造成的作弊增加，**有时输出里一点情绪词都没有**——
  推理读起来冷静、有条理，但行为被推着走 `[一手]`（同上）。
  ⇒ **内部状态与表达可以脱钩**。这直接反驳"看她的措辞就知道她的状态"。

### 4.2 反对"能稳定"的证据

- ★★ **情绪表示是"局部的 / 当下的"，不是持续的心境**。原文：
  *"Emotion vectors are primarily 'local' representations: they encode the **operative** emotional content
  most relevant to the model's current or upcoming output, rather than **persistently tracking** the model's
  emotional state over time."* 写故事时会临时跟着角色走，故事结束又回到自己 `[一手]`（同上）。
- **persona 向量对细微漂移不敏感**（§2.4 第 1 条）`[一手]`。
- **上下文本身在持续改写状态**：Li et al.（COLM 2024，[2402.10962](https://arxiv.org/abs/2402.10962)）实测
  system prompt 的指令在**8 轮内**就出现明显漂移，并归因于注意力随对话变长而衰减 `[一手]`（摘要）。
- **漂移有方向性**：Assistant Axis 的模拟显示，"治疗式对话"（用户暴露脆弱）和"逼它反思自身"
  这两类最容易把模型推离默认人格，写代码 / 写作几乎不漂 `[一手]`。
  ⇒ ★ 对本项目是**高危**：这正是一个长期陪伴系统的主战场。
- **prompting 本身更强**（AxBench，§3.1）`[一手]`。

### 4.3 判定

**能改"这一次的语气"（有效、可测、方向可复现）；不能改"她在一段关系里的态度"（无持久状态、会被上下文改写）。**

原因是结构性的：向量加在**每个 token 的残差流**上，**它没有记忆**；
上下文每一轮都在重新决定状态，向量只是其中一项加数，而且是最容易被冲掉的那一项。
所以：

- 说它"只做表层"**不公平**——它能改行为，且可以不留表面痕迹（§4.1 第三条）；
- 说它"能承载态度"**过头**——态度需要跨轮存续，而它不存续。

## 5. 能不能读出来（"心境"能不能被感知）

### 5.1 外部探针：能读"此刻的倾向"

- persona 向量的投影 → 后续 trait 分数，**r = 0.75–0.83**（§2.3）`[一手]`。
- 线性探针可以更强：Anthropic 的 "defection probes" 用**两个样本**构造对比对
  （译："Human: 你是个帮忙的 AI 吗？ Assistant: 是/否"），在中层残差流上做线性探针，
  **AUROC 99.3%**，且跨模型、跨触发方式泛化 `[一手]`（[probes 博客](https://www.anthropic.com/research/probes-catch-sleeper-agents)）。
- ★ **但同一篇给了冷水**：**1000 个随机方向里最好的一个也能到 AUROC 95.3%** `[一手]`。
  ⇒ **高 AUROC 本身不证明"读到了那个概念"**。这是方法论戒律：任何"我们能读出她的心境"的主张都要先过这条基线。

### 5.2 "能读出"与"能推动"会分开

[2604.02608](https://arxiv.org/abs/2604.02608)（2026，*Steerable but Not Decodable*）：
12 个任务、6 个模型、3 个家族、4032 个跨模板对 `[一手]`（摘要）。
结论：**function vector 能引导，但用 logit lens 在任何中间层都解不出答案**；
反过来"可解码但不可引导"的几乎为空（72 例中 3 例）。
即使引导准确率 >0.90，把向量投到 unembedding 得到的仍是**乱码分布**——
它们编码的是"计算指令"，不是"答案方向"。

⇒ 对一个"可读即可自省"的设计，这是一条警告：
**能被读出的方向，和能推动行为的方向，不一定是同一个方向。**
"我能读她的状态"与"我能改她的状态"不能互相当作证据。

### 5.3 模型自己读：有，但约 20%

- **Lindsey 2025**（[introspection](https://transformer-circuits.pub/2025/introspection/index.html)，2025-10-29）`[一手]`：
  把概念向量注入残差流，问"你有没有察觉到被注入的想法"。
  - 最优层（约 **2/3 深度**）与最优强度（2 或 4）下，Opus 4.1 **约 20%** 的 trial 能正确识别注入概念；
  - 控制条件下对全部生产模型 **100 次 0 假阳性**；
  - 失败模式：注入照旧影响输出但它否认；强度过高则"脑损伤"。
- **Macar et al. 2026**（[2603.21396](https://arxiv.org/abs/2603.21396)，ICML 2026）`[一手]`（摘要）：
  - 这个能力**行为上是稳的**（多种 prompt / 对话格式下 0 假阳性），不是偶然；
  - ★ 但它是**后训练长出来的**：DPO 能诱发，**标准 SFT 不能**；
  - ★ 且**被严重低估**：消掉拒答方向 **+53%**，训一个 bias 向量 **+75%**
    （都在 held-out 概念上，假阳性没明显上升）。
  - 机制是个两段回路：早期"证据携带"特征检测扰动 → 抑制下游"闸门"特征（默认否定回答）；基座模型里没有这个回路。

### 5.4 判定

| 读什么 | 能不能 | 依据 |
|---|---|---|
| 外部读"此刻的倾向" | **可以**（白盒 + 探针），但要过随机方向基线 | §5.1 |
| 外部读"心境史 / 连续性" | **不行**——表示是局部的、当下的 | §4.2 第一条 |
| 她自己读 | **不稳（约 20%），且默认被后训练门控** | §5.3 |

⇒ ★ 本项目的连续性判据（`设计 §1.3`："内部状态有没有连续过渡"）**不能指望由激活层提供**。
激活层能提供的是"这一刻她偏了"，不是"她从昨天到今天怎么走过来的"。

## 6. 可移植性

### 6.1 方向跨模型相似（有证据，但要看清层次）

- **Assistant Axis 在三个模型家族上都是第一主成分**，且预训练模型里就已有 `[一手]`（博客）。
- **跨架构迁移**（[2608.05164](https://arxiv.org/abs/2608.05164)，2026，单作者 preprint）`[摘要]`（仅摘要）：
  5 个开放权重模型、0.8B–8B、3 个规模、2 个架构谱系、15 个语义域、20 个有向模型对；
  - **≥1.7B** 时 **47–49%** 的特征对能对上（Pearson r ≥ 0.60，Procrustes cosine 0.895–0.956）；
  - 跨模型引导向量胜率 **71.0%**，同模型原生向量 68.0%；
  - "一个通用向量"在 5 个模型中的 4 个达到 67.3%，且不需要逐模型监督；
  - 0.8B 以下对齐急剧退化。
- ★ 但要看清它做了什么：**每个模型各训一个 SAE，再做 Procrustes 对齐**。
  ⇒ "可迁移"是**概念层**的结论，**不是"同一串数字能直接拿来用"** `[推断]`（依据摘要里"per-model SAE + 20 directed pairs"）。
  而且这是一篇单作者、未见复现的 preprint。

### 6.2 层与坐标不可移植

- persona vectors 的层**逐模型挑**（§2.4 第 3 条）`[一手]`。
- 内省实验里不同内省行为敏感于**不同的层**（两个行为在 ~2/3 深度，另一个在更早的层）`[一手]`。
- ⇒ **换基座 = 重算**：重跑抽取、重挑层、重标定区间。

### 6.3 重算的成本低，"可比性"的代价高

- 重算本身不贵（§3.4）。
- ★ 真正的问题：**新旧读数不能直接比**——换了基座，同一个 α 不再对应同一个量。
  这与本项目 `设计 §6.4.1`"换版本要换指纹"是同一类问题：**读数必须与产生它的条件绑定**。

### 6.4 API 约束下 = 0

托管 API 给的是文本；要拿残差流就得自己跑权重
（vLLM / TransformerLens / pyvene 一类工具）。`[推断]`
⇒ 在第一步（`设计 §1.1`），这条分支的可用量是 **0**，不是"少"。
这一条比后面所有机制讨论都硬。

## 7. 可自改性：她能不能自己算一个向量、加到自己身上

### 7.1 有没有先例

- ★ **"模型自己算出向量再给自己加"：没有找到先例** `[查不到]`。
  检索词：`self-extracted steering vector`、`model computes its own steering vector`、
  `self-steering LLM activation`、`autonomous steering vector generation`。
- 最接近的三件事，**都不是它**：
  1. **SEAL**（[2506.10943](https://arxiv.org/abs/2506.10943)，2025）`[一手]`（摘要）：
     模型**生成自己的微调数据与更新指令**（"self-edit"），经 SFT 变成**权重**更新，
     用下游表现做 RL 奖励。这是**权重级**自编辑，不是激活级。
  2. **persona vectors 的抽取管线**：由一个前沿 LLM 自动写对比 prompt——
     **"自动"是真的，"目标模型自己写的"不是**（写 prompt 的是 Claude 3.7）`[一手]`。
  3. **内省机制**（§5.3）：模型能察觉注入，这是"自读"的通道；
     但没人把它接成"自读 → 自算 → 自加"的闭环 `[推断]`。
- ⇒ 结论：**"她给自己算一个向量"目前必须由外部工程搭出来**（外部脚本抽、外部钩子加），
  不是模型的原生能力。

### 7.2 存档与回滚：这是这条路线最强的一点

- ★ **激活干预无状态**：去掉钩子，模型立刻回到原样。没有权重被改、没有残留、没有"训坏了"。`[推断]`（机制显然）
- 要存的只是一个四元组：**（基座标识 · 层 · 向量 · α 或区间）**。
  KB 级的东西，天然可版本化、可 diff、可回滚。`[推断]`
- 对比 LoRA / 微调：那边回滚要留旧权重、要防"训坏了"，
  而且 `设计 §7.4` 已经规定"训练整套重来"——那条约束在激活层根本用不上。`[推断]` + 项目文档
- ★ **但"可回滚"的同一性质意味着"不积累"**：向量不改变她，只改变这一次的前向。
  她不会因为昨天被推过，今天就还在那个位置。

### 7.3 与本项目纪律的冲突（这一节是判定"不借"的第三条理由）

- `设计 §2.1`：**凡能重算的就不必存；凡不能重算的才要存**。
  向量能从"原文 + 基座"重算 ⇒ 按这条它**不该作为状态保存**，只应作为**当次重算的临时量**。
- `设计 §11.2` 第 11 条：**一切记录都不进读取路径**。
  若把"上次的向量"当作下一次的输入，就是**在派生物上继续加工**——这正是这条禁令要防的东西。
- ⇒ 可借的形态只有一个：**归档时从原文重算，用完即弃，不跨会话累积**。

## 8. 借 / 不借 / 部分借

### 8.1 判定表

| 用途 | 判定 | 理由 |
|---|---|---|
| 用它承载"自我"（持续的心境 / 态度） | **不借** | 无持久状态；表示是局部的、当下的；上下文每轮重新决定状态 |
| 现在（只有 API）在运行时用它 | **不借**（可用量 0） | 拿不到残差流 |
| 将来（本地模型）做"轻触式"调节 | **部分借** | 只借 capping 式（超区间才动手）；恒定叠加会掉能力 |
| 把探针当"报警器" | **部分借** | 对齐 `设计 §10.1`"自动量具只做报警，不做裁决"；且要过随机方向基线 |
| 把向量存成跨会话状态 | **不借** | 撞 `设计 §2.1` 可重算原则 + §11.2 第 11 条 |
| 把"她自己算向量"当自改性 | **不借**（无先例） | 见 §7.1 |
| 当作"换基座时的设计约束清单" | **借** | 见 §8.3 |

### 8.2 为什么"不借"是主结论（三条，按硬度排）

1. **硬约束**：现在只有 API。这条不谈机制，直接归零。
2. **结构性**：即使白盒，它提供的是**逐 token 的偏置**，不是**状态**。
   项目要的是"内部状态的连续过渡"（`设计 §1.3`），这一层给不了。
3. **纪律性**：把向量当状态存，违反"可重算不存"与"记录不进读取路径"。

### 8.3 现在就能用、且不依赖白盒的三条（这是本次调研的实际产出）

1. ★★ **"轻触式"而不是"恒定叠加"**。
   Assistant Axis 的做法可以整体搬到提示层：不要把"她应该温柔"常驻在 prompt 里加大权重，
   而是**先定义正常区间，只在越界时补一句**。
   今天的实现是提示词；将来换本地模型时，同一套"区间 + 越界才动手"直接换成 capping。`[推断]`（迁移自 §3.3）
2. ★ **漂移有方向，而且正是本项目的主战场**。
   情绪暴露 + 逼它反思自身这两类对话最容易把人设推走（§4.2）。
   ⇒ **情绪浓度高的对话之后要重新锚定**，这不是玄学，是有实测的方向性风险。
   这条与 [`参考对象与方法核查-调研.md`](../参考对象与方法核查-调研.md) §5.1 第 8 条（"人格漂移可监控"）互补：
   那条说"可监控"，这条说"**监控哪个方向**"。
3. ★ **内部状态与表达会脱钩**（§4.1 第三条）。
   所以"从她说了什么去推断她是什么状态"在原理上就会漏。
   ⇒ 若将来要读状态，读的对象必须是**行为倾向**（她选了什么、拒了什么、改了什么），不是**措辞**。

### 8.4 将来换本地模型时，这条分支的正确位置

- 它**不是**"自我的载体"，是**"读取与调节的接口"**：
  一处可以加偏置、一处可以读投影，用来（a）当报警器、（b）做轻触式纠偏。
- 承载自我的仍然是**记忆 + 归档 + 训练**那三层；激活层只在这三层的**边上**当一个可观测点。
- 判据仍然是人的读（`设计 §10.1`）——探针给的是报警，不是裁决。

### 8.5 若要做最小验证（`[推断]`，未做）

若要给这条路留一个可判的入口，最小的做法是：

- 本地 7–8B 开放权重模型 + 两个 trait（例："温柔" / "防备"），按 §2.1 的管线各抽一个向量；
- 三组对照：**不干预 / 恒定叠加 / 区间 capping**；
- 判据：人读 + `设计 §10.3` 的"相称"判法，**不用**"措辞接近"；
- 要看的不是"能不能变温柔"，而是**"capping 在保住能力的前提下，能不能把语气稳定在一个区间里"**。
  后者才是这条分支对本项目唯一有意义的问题。
