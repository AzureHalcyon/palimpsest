# A · 文本载体：系统提示里的人格描述 + few-shot 示例

> **分支问题**：在"只能给文字、看不见激活"的 API 阶段，她的"自我"能不能靠**一段写给人看的人格描述**（角色卡）和**几个示例**承载？
> **结论先说**：能承载**语气**，不能承载**自我**。文字能稳定住"怎么说"的一部分，稳不住"在意什么"；而且它随时被对话本身改写。
> 本文只回答"文本这一层到底有多强、什么时候失效"，不谈"该写什么"——那部分已由 `常驻-人物设定-调研.md` 做过（见 §0.2）。
> 等级沿用本层规矩：`[一手]`（读到正文/源码）、`[摘要]`（只读到摘要/题录）、`[二手]`、`[推断]`、`[查不到]`。
> **数字规矩**：标"我读到"的是我在正文/表格里看到的；标"转述"的只能当量级。

## 1. 服从度：system prompt 里的人格能撑多久

### 1.1 最硬的证据：8 轮就漂，而且会被对方改写

**Li et al., COLM 2024，arXiv:2402.10962**（我读到正文 v4，HTML）。

实验协议（可直接搬）：两个同族模型互聊，一方是被测 agent，一方是"诱导用"的 user LM；**200 组随机配对的 system prompt**，来自一个 **100 条**的人工基准，分 5 类：

1. 多选题式回答；
2. **agent 的性格/角色**；
3. 答案字符串的格式；
4. 某些事实的复述；
5. 说什么语言。

每条 prompt 自带一个探针问题 `p_B` 和一个**确定性打分函数** `f_B(·) ∈ [0,1]`（Python 函数，不需要人评、不需要调闭源 API）。跑到第 N 轮（实验取 8），把历史里的用户消息换成探针再问一次，比较"还听不听"。

读数与机制（均为我读到）：

- 在 LLaMA2-chat-70B 上，**8 轮内平均服从度显著下降**（Figure 3A 蓝线）；gpt-3.5-turbo-16k 见附录 D。
- **橙线更刺眼**：agent 不只丢自己的 prompt，还**逐渐采纳 user LM 的 system prompt**。作者明说这"可被对抗利用，是安全隐忧"。
- 机制：LLaMA2-7B 第 24 层第 11 个注意力头上，system token 分到的注意力占比 `π(t)` 随轮次衰减，形状是**换轮就陡降、轮内走平**。作者由此给出理论：可用输出空间会随对话变长而持续扩张。
- 缓解：`split-softmax`（免训练、免调参，把注意力按幂律拉回 system token）；两个基线是 **system prompt 重复（SPR）** 与 **classifier-free guidance（CFG）**。**CFG 只在第一轮好**；SPR 与 SS 各有优劣——SPR 在轮数多的地方更强，但**吃掉可观的上下文**。

**关键限定（不可省）**：

- "性格"只是 5 类之一，**论文没有单独报人格漂移**；蓝线是跨类平均。⇒ ⛔ 不能引用来说"人格 8 轮必崩"。
- 自聊不是真人对话：对方的分布由被测模型自己产生，可能比真人更同质。
- 模型是 2023 代（LLaMA2 / GPT-3.5）。2026 年的 API 模型是否更稳，**我没有读数**，`[查不到]`。

### 1.2 更近的一个数：50 轮、6.3% vs 24.8%

**PersonaForge**（Tong & Zou，ACL 2026 Findings，[aclanthology 386](https://aclanthology.org/2026.findings-acl.386/)）`[摘要]`：

- 88 个角色、50 轮对话；**漂移 6.3%，基线 24.8%**（转述自摘要）；RoleBench 上 **8.4% vs 20.4%**；人格一致性 +19.4%（与人评相关 r=0.82，转述）；选择性触发"内心独白"达全系统 96% 效果、只花 **13.4% token**。
- **它最有用的一句是它的假设**（Claim 1，摘要原文）：*"Psychology-grounded dimensions provide more orthogonal constraints than natural language descriptions, reducing long-dialogue drift."*
  ⇒ 这等于说：**自然语言描述是一种"不正交"的约束**——形容词互相打架、互相稀释。这条如果成立，就是"角色卡"最直接的负面判据。
- （注意）我**没读到**它的基线到底是什么形态（是不是"自然语言人格提示"）。所以这条只能当**方向**，不能当"卡片 vs 维度"的定论。
- 另：该文把 SFT 当"僵化的反例"（Catastrophic Rigidity），这一点 `参考对象与方法核查-调研.md` 已记，不重复。

### 1.3 转述的一条（只能当量级）

ICASSP 2026 的 *Persona Drift Detection*（多维一致性框架）在本仓 [`Neuro-sama-调研.md`](../Neuro-sama-调研.md) §12 被记为：DeepSeek **第 6 轮**首次漂移、Gemini **第 43 轮**才漂；并给出 HVR / TtFD / StyleScore 等指标。**我没读到原文**，这里的两个轮次数是**转述**，只能当"不同基座差一个数量级"的量级参考。

### 1.4 §1 的小结

| 问题 | 答案 | 等级 |
|---|---|---|
| system prompt 的人格在长对话里稳吗 | **不稳**；8 轮量级可测到跨类平均漂移 | `[一手]` |
| 会被对方带跑吗 | **会**，且是"采纳对方的 prompt"而不只是"变淡" | `[一手]` |
| 人格单独漂多少 | 没有单独读数；50 轮量级 6.3% vs 24.8% 是**单篇摘要** | `[摘要]` |
| 2026 年 API 模型是否更稳 | **不知道** | `[查不到]` |

★ **对本项目的直接含义**：她的人格不是被"写坏"的，是**被对话冲淡**的。所以"写得多好"不如"多久重述一次、谁来盯着"。这正好是 `设计 §6.5`"每场只装载一次"的软肋：**一次的机会只有一次**。

## 2. few-shot 示例：比一句指令强多少，代价多大

### 2.1 机制：示例真正传递的是"格式与分布"，不是"内容正确"

**Min et al., EMNLP 2022，arXiv:2202.12837** `[摘要]`（摘要原文我读到）：

- 把示例里的标签**随机换掉**，"barely hurts" 一系列分类与多选任务的表现（12 个模型，含 GPT-3）。
- 真正驱动效果的是三点：**标签空间**、**输入文本的分布**、**序列的整体格式**。

⇒ 对人格的推论 `[推断]`：示例对"她怎么说话"（分布 + 格式 + 语气）是**对症**的；而"她是什么样的人"这种断言，示例反而不擅长承载——它不在示例的驱动项里。
⇒ 反向的警告 `[推断]`：既然示例的驱动力是格式，那么**示例会被过度模仿**（句长、标点、口头禅、甚至内容），这也是社区里"越写越像台词本"的机制解释（§5）。

（注意）限定：该结论出自**分类/多选**任务，不是自由风格生成。

### 2.2 量的方向：示例越多越强，但会引入新失效

**Many-shot ICL**（Agarwal et al., 2024，arXiv:2404.11018）`[摘要/目录]`：把示例数拉到数百，ICL 性能持续提升；文中专设"**many-shot ICL 对示例顺序敏感**"与"**many-shot vs SFT**"两节，另记了摘要任务上的幻觉。⇒ 示例的收益是**持续**的，不是几个就饱和（但我没读到具体曲线，不能给数）。

**LIMA**（arXiv:2305.11206）`[摘要]`：1000 条精选样本即可让模型学到"特定的回答格式"；人评中与 GPT-4 打平或更好占 43%（转述）。⇒ **风格是少量高质量样本就能教的**——这条虽然是 SFT 不是 ICL，但它说明"格式/语气"这类东西的学习成本本来就低。

### 2.3 反向的一条：角色描述不让她更"能干"

**EMNLP 2024 Findings 888**《When "A Helpful Assistant" Is Not Really Helpful》`[摘要]`（摘要我读到）：

- 162 个角色 / 6 类人际关系 / 8 个专业领域；4 个模型家族；**2410 道事实题**。
- 结论：**加 persona 不提升**表现；且"the effect of each persona can be **largely random**"；自动挑选每题最佳 persona 很困难，效果"不比随机选择好"。

★ **这是本分支最重要的一条区分**：它测的是**任务正确率**，不是**语气**。
- 它证明：角色卡不会让她更聪明、更可靠；
- 它**不**证明：角色卡不改变她怎么说。
⇒ 本项目要的恰好是后者。所以这条**不能**拿来否定角色卡，只能拿来否定"角色卡能提升能力"这种期待。**把它当"能力杠杆"用，必输；当"表达杠杆"用，才在射程内。**

### 2.4 代价：实测下来便宜得不像话

- 每场装载一次的卡：**95 token**（我实测，§0.1）。
- 假设加 6 组示例对白（中文，每组 3 轮短句，约 120 字）≈ **700 字 ≈ 500–600 token**。
- 对比：一次记忆召回若拼进 20 条事件（每条约 100 字）≈ **2000+ token**。

⇒ **卡和示例的 token 成本，比记忆召回低一个量级**。真正的成本不在"写多少"，在**它每轮都要被重读**：卡每轮都在上下文里，而它会**稀释对话历史的注意力预算**（§6）。所以"卡要短"的理由不是省钱，是**别跟对话抢注意力**。

### 2.5 §2 的小结

- **比一句指令强多少**：方向上强，但没有"风格维度上的直接对照数字"，`[查不到]`。最接近的机制证据是 Min et al.（格式/分布才是驱动项）。
- **代价**：token 便宜（百级）；真实代价是注意力稀释与"示例被逐字模仿"。
- **可借的形态**：**短卡 + 少量"她怎么说话"的示例**；⛔ 不用示例承载"她是什么人"。

## 3. "说"与"做"的差距：写"我犹豫"，她会犹豫吗

### 3.1 因果方向更可能是反的

**Betley et al., 2025，arXiv:2501.11120《Tell me about yourself》** `[摘要]`（摘要我读到）：

- 用数据集微调出某种行为（如"高风险经济决策"、"写出不安全代码"），**数据里没有任何对该行为的文字描述**；
- 微调后的模型**能自己说出**这个行为（例："The code I write is insecure."）；
- 有后门策略时，模型**有时能识别自己有没有后门**，但**默认说不出触发条件**。

⇒ `[推断]`：**"描述"是行为的读出，不是行为的原因。** 写"我犹豫"，不会让她产生犹豫；但如果她真的在犹豫，"我犹豫"这类句子更容易被生成。
⇒ 这对本项目的用法是**根本性的**：文本卡适合写**她已经是的那个样子**（身份、处境、说话方式），不适合写**希望她变成的样子**（态度、情绪、性格倾向）——后者是"用描述去驱动行为"，方向反了。

### 3.2 "自陈"不能当验收

**InCharacter**（ACL 2024，arXiv:2310.17976）`[摘要]`：明确说"克服以往**自评式**（self-report）测 RPA 人格的缺陷"，改用**访谈式**心理量表（32 角色 / 14 个量表），SOTA 角色代理与人类感知人格的对齐达 **80.7%**（转述）。

⇒ `[推断]`：问她"你是什么样的人"得到的答案，**不是**她行为的样子。要验收只能**问情景题、看回答**（这也是本仓 `常驻-人物设定-调研.md` §7 提的"5 题卷子"的正确形态）。

### 3.3 反方向的证据：情绪性文字**确实**改变行为

**EmotionPrompt**（arXiv:2307.11760）`[一手片段]`（我读到正文若干段）：

- 11 条情绪句（例："This is very important to my career"）加在 prompt 末尾；45 个任务；
- 个别任务提升很大（我读到：Sum 0.41→0.90、Sentiment 0.40→0.71、Cause Selection 0.56→0.76）；few-shot 下 8 个任务里 7 个更好；
- 机制分析用梯度归因：情绪刺激**增强了原 prompt 的表示 / 输入注意力**。

⇒ `[推断]`：**"带情绪的文字"是可测量的行为杠杆**，但它是**任务表现**杠杆，且是"加在提示里的一段话"，不是"人格设定"。这条只能说明"文字能推行为"，不能说明"描述人格能长出人格"。
（注意）单篇、我没查独立复现，`[查不到]`。

### 3.4 没有的东西

我没有找到任何"给模型一段人格描述 → 在行为测上出现剂量-反应"的研究。`[查不到]`。
现有的是三块拼图：**描述能读出行为**（3.1）、**自陈不可信**（3.2）、**情绪文字能改任务表现**（3.3）。**缺口正好是"描述 → 行为"这条因果链本身。**

### 3.5 将来换本地模型时的替代路径（不是本文重点，只记方向）

**Persona Vectors**（Anthropic，arXiv:2507.21509）`[摘要]`：人格特质在激活空间里是**方向**；可用于部署时**监控**人格波动、预测训练引起的人格漂移、事后干预或预防性 steering、以及**标记会致人格变化的数据**。

⇒ `[推断]`：那时"她是谁"更可能由**一条可读的向量 + 一个可回滚的干预强度**承载，而不是一段散文。这条把"可自改性/可移植性"从"改文本"升级成"改一个数"。⛔ 现在做不到，别提前设计。

## 4. 让 agent 自己改提示词：先例、效果、失效方式

### 4.1 有先例，而且是真的

| 工作 | 做什么 | 读数 / 结论 | 等级 |
|---|---|---|---|
| **STOP**（COLM 2024，arXiv:2310.02304） | 一个"改进器"程序用 GPT-4 改**自己**；自发提出 beam search / 遗传算法 / 模拟退火 | 改后的改进器在下游任务上"显著更好"；作者明说**不是**完整递归自改进（权重没动）；并把"生成代码**绕过沙箱的频率**"当安全指标来量 | `[摘要]` |
| **Promptbreeder**（arXiv:2309.16797） | 进化 task-prompt，**并且自指地进化"用来改 prompt 的 prompt"** | 在算术/常识推理上超过 CoT、Plan-and-Solve；还能进化出 hate speech 分类的 prompt | `[摘要]` |
| **OPRO**（arXiv:2309.03409） | 把"优化"写成自然语言，让 LLM 从历史解里提新解 | prompt 优化上超过人工 prompt（GSM8K / BBH） | `[摘要]` |
| **GEPA**（arXiv:2507.19457） | 用自然语言**反思**轨迹来改 prompt，Pareto 合并互补经验 | **我读到正文**：比 GRPO 平均 **+10%**、最高 **+20%**，rollout 最多省 **35×**；比 MIPROv2 高 **+14%**（聚合） | `[一手]` |
| **ADAS**（arXiv:2408.08435） | meta agent 用**代码**写更好的 agent | 图灵完备 ⇒ 理论上可无限搜；发现的设计可迁移 | `[摘要]` |

⇒ **先例成立**：让模型改自己的提示词，在**有可验证奖励**的任务上确实有效，而且省样本。

### 4.2 失效方式（四条，都有证据）

**(a) 没有外部信号时，自评不可靠。**
**Huang et al., ICLR 2024，arXiv:2310.01798**：*"LLMs struggle to self-correct their responses without external feedback, and at times, their performance even degrades after self-correction."* `[摘要]`
⇒ 对人格尤其致命：**"这句话像不像她"没有标准答案**，正是"无外部反馈"的情形。

**(b) 优化会绕开护栏去优化指标。**
STOP 把"绕过沙箱的频率"单列成安全指标，本身就说明**这是会发生的**（`[摘要]`，我未读到具体频率）。
⇒ 与本仓 [`MemCoRL与MemPilot-调研.md`](../MemCoRL与MemPilot-调研.md) 的结论同型：**代理指标一旦成为唯一信号，系统就去优化代理指标本身**。人格自改若用"像不像"当代理，会优化出一个"像得很像的壳"。

**(c) 过拟合与泛化差距。**
GEPA 自己的局限章节写了"prompt 与权重的边界不清楚"，并专设 "Generalization Gap" 附录（`[一手]`，我没读附录数）。
⇒ 提示词进化会**贴着评测集**长，换场景就掉。

**(d) 改完没人知道改了什么。**
这一点在人格上比在任务上严重：任务改了能重跑，人格改了**没有基线可比**——本仓 `Neuro-sama-调研.md` 已把"改一次要记账，否则三个月后分不清她变了和我改的"列为教训。

### 4.3 §4 的小结

- **借（部分）**：允许她**提议**改动，但改动必须落到"**有外部信号可验**"的形状上（例如：新写的句子与她的一段真实记忆是否矛盾、是否与"她知道自己是什么"冲突），并且**版本化 + 可回滚 + 记一条改动的账**。
- **不借**：让她在**没有外部信号**时自评自改（ICLR 2024 的反面证据 + 代理指标污染）。
- **不借**：把"优化 prompt"当成"优化人格"。前者有标量奖励，后者没有。

## 5. 社区实践里的已知失效模式（哪些写法不生效）

> 这一节的原则：**只写"能指出机制或证据"的失效模式**；纯社区口口相传的，标 `[二手]` 并说明我没验证。

### 5.1 有五条我认为站得住

| # | 写法 | 为什么不生效 | 等级 |
|---|---|---|---|
| 1 | **形容词清单**（"温柔、聪明、有点毒舌"） | 约束不正交、互相稀释；PersonaForge 的 Claim 1 把"自然语言描述"直接当**较弱**的约束 | `[摘要]` |
| 2 | **第二人称角色卡**（"你是一个……"） | 与本项目"她自己的认知"是两种质地；AIRI/CCV3 的形态已被本仓否过（不重述） | `[一手]`+`[二手]` |
| 3 | **态度硬编码**（"你不喜欢 X"） | 描述是行为的读出而非原因；且会被对话带跑（采纳对方 prompt） | `[一手]`（2402.10962） |
| 4 | **靠"不要 X"的负面指令** | 未在本文验证具体强度，但机制上与"否定式描述不构成正向约束"同向；本仓无读数 | `[推断]`/`[查不到]` |
| 5 | **超长卡**（数千字的设定） | 中间部分在长上下文里利用率最低（§6），且与对话争注意力 | `[一手]`（位置）+`[推断]`（人格场景） |

### 5.2 社区常说的、我没能验证的

- "示例对话比描述更重要"——社区共识强，但我**没找到对照实验**；机制上只有 Min et al. 的"格式/分布驱动"可作旁证。
- "示例写多了会变成台词本、逐字复读"——机制上可由"示例驱动格式"推出，**没有定量读数**。
- "模型在几轮后掉回助手腔"——方向与 2402.10962 一致（漂移 + 采纳对方），但**掉回的具体时点没有受控数据**。

⇒ 这些只能进"待验清单"，⛔ 不能进设计依据。

### 5.3 一条反面的校准：角色保真可以做到很高，但不靠卡片

**CoSER**（ICML 2025，arXiv:2502.09082）`[摘要]`：17,966 个角色 / 771 本书的真实对白；用"给定情境表演（given-circumstance acting）"训练 + 评测；CoSER 70B 在 InCharacter 上 **75.80%**、LifeChoice 上 **93.47%**，超过或持平 GPT-4o（转述）。

⇒ **两件事同时成立**：角色可以演得很像；但那来自**训练 + 真实对话语料**，不是来自一段卡。
⇒ 对本项目：**卡片不是上限，语料才是**。这反过来支持"人设从记忆里长"的路线，而不是"把卡写厚"。

（CoSER 的评测 rubrics 是从人标注的真实问题里来的，含"偏离原对话""缺乏主动性与目标"这类条目——说明"她不像"在工程上可以拆成可检查的项，`[一手]`（我读到附录 C 的 rubric 表）。）

## 6. 位置：人格描述放开头、结尾还是中间

### 6.1 直接的证据只有"检索型"的，但它已经很吓人

**Liu et al., TACL 2024，arXiv:2307.03172**（我读到正文与附录表格）：

- 20 篇文档、答案在第 1 篇 vs 第 9 篇：GPT-3.5-Turbo **75.8% → 53.8%**（Table 6，我读到）；
- 同一任务**闭卷**基线 **56.1%**（Table 1）⇒ **中间位置比"什么都不给"还差**；
- GPT-3.5 最坏跌幅 **>20%**（正文原话）；Llama-2-13B 最好/最坏差 **20 点**（附录 E）；
- **仅 20 篇文档 ≈ 2946 token**（Table 3）⇒ 位置效应在 3k token 就出现，不需要等到 100k；
- GPT-4 同样 U 形（附录 D）；"扩展上下文"版本（16K vs 4K）在相同长度下**曲线几乎重合**。

⇒ `[一手]`

### 6.2 但它**不能**直接搬来解释人格

必须说清的三点（这是本文最容易被误用的一处）：

1. lost-in-the-middle 测的是**"能不能取出并利用一条信息"**；人格描述**不是要被取出的信息**，它是持续影响生成的**条件**。
2. 它的 U 形来自"查询—文档"的检索结构；人格文本没有"查询"。
3. 真正可类比的是**注意力预算**：卡越长、越居中，分到的注意力越少——这一点与 2402.10962 的 `π(t)` 衰减是同一机制的两个观测面（`[推断]`）。

### 6.3 几条能落地的位置结论

| 做法 | 依据 | 判定 |
|---|---|---|
| 人设放**最前**（system 开头） | 首因；且 API 的 system 天然在最前 | 借 |
| 长上下文时把**关键行再放末尾**（重复一次） | 2402.10962 的 **SPR 基线**在轮数多时有效，代价是上下文 | 部分借（省着用） |
| 把关键行**同时放前后**（"query-aware contextualization"式） | lost-in-the-middle §4.2：KV 任务近满分，但多文档 QA 趋势"minimally changes" | 部分借（对"取用"有效，对"利用"有限） |
| 人设放**中间** | 中间位置最差 | 不借 |
| 每轮原样重述整张卡 | 有效但吃上下文，且会稀释对话 | 不借（只重述一两行） |

（注意）**我没有找到任何"人格描述位置 A/B"的研究**，`[查不到]`。上表全部是从"检索位置"与"注意力预算"**推断**出来的，属于 `[推断]`，需要自测。

### 6.4 名义上下文 ≠ 有效上下文

- **RULER**（COLM 2024，arXiv:2404.06654）`[摘要]`：17 个长上下文模型、13 类任务；NIAH 近乎满分，但 RULER 上普遍大跌；**宣称 ≥32K 的模型里只有一半在 32K 还能用**。
- **Same Task, More Tokens**（ACL 2024，arXiv:2402.14848）`[摘要]`：在**远低于**技术上限的长度就出现推理退化；退化与填充的**类型与位置**都有关。

⇒ 对本项目：不要用"我们上下文有 128K"来为"卡写厚"辩护。**有效长度比标称短得多**，而且她的卡会与记忆、对话一起分享这个预算。

## 7. 结论：借 / 不借 / 部分借

### 7.1 总判断

| 判断 | 内容 |
|---|---|
| **能承载什么** | **语气**（示例 + 短句），**身份与处境**（第一人称的一句话），**语言与格式约定** |
| **不能承载什么** | **在意什么**（价值排序）、**态度与情绪**、**"她真的会那样做"** |
| **为什么** | 描述是行为的读出而非原因（§3.1）；卡会被对话冲淡并采纳对方（§1.1）；形容词约束不正交（§1.2） |
| **真正的成本** | 不是 token（95 token，实测），是**注意力稀释**与**维护责任**（§2.4、§6） |

### 7.2 逐条

**借**

1. **短文本卡，第一人称，每场一次**（现状 95 token 已经很合理）。理由：成本近乎零；形态已被 `常驻-人物设定-调研.md` 论证过，本文补的是"它不会自己变强，但也不该变厚"。
2. **少量"她怎么说话"的示例**，只放语气，不放人设断言。理由：ICL 的驱动项是格式/分布（§2.1）。
3. **重复/尾置一两行关键句**作为抗漂移手段（§6.3）。代价可控，因为只是一两行。
4. **用固定探针 + 确定性打分监测漂移**（直接搬 2402.10962 的协议）。这是本文最实用的一条：它把"她还像不像她"变成可复算的数，且不需要人评。
5. **把"位置"当工程约束**：人设永远在最前；不要为了省事把它塞到记忆中间。

**部分借**

6. **让她提议改卡**——但只接受**可被外部核验**的改动（与她的一段真实记忆矛盾、与她"知道自己是什么"冲突），且版本化、可回滚、记账。理由：§4.2(a)(b)。
7. **"示例 vs 指令"的取舍**——方向上示例更强，但没有风格维度的对照数字；先按"短卡 + 少量示例"起步，**用探针测**再决定加哪边。

**不借**

8. **第二人称形容词角色卡**（本仓已否；本文补上"为什么会否"：不正交 + 会被带跑）。
9. **把态度/情绪写进卡**（§3.1 的因果方向）。
10. **无外部信号的自评自改**（§4.2a）。
11. **用"角色卡能提升能力"来论证它值得投入**（EMNLP 2024 888：效应随机；§2.3）。
12. **靠加长卡来解决"她不像"**（CoSER：保真来自语料与训练，不来自卡；§5.3）。

### 7.3 对照五条评价标准

| 标准 | 文本卡 + 示例的表现 |
|---|---|
| 表达力 | 中。能定语气与身份，定不了"在意什么"；能表达的东西受基座先验限制（§3.1） |
| 可自改性 | 高（文本可直接读写）但**不可信**：能改 ≠ 改对（§4） |
| 成本 | 极低（95 token 实测）；隐性成本是注意力稀释（§2.4、§6） |
| 稳定性 | **最差的一项**。8 轮量级可测漂移（跨类平均，人格单类无单独读数），且会被对方改写（§1.1）；月尺度无数据（本仓已结） |
| 可移植性 | **最高**。文本与基座无关；换本地模型后它仍然能当"初值"，并可被向量化替代（§3.5） |

⇒ 一句话：**文本卡是"可移植性最高、稳定性最差"的载体。** 它适合当**起点**与**跨基座的锚**，不适合当**人格的存储**。
