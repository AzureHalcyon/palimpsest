## 0. 一句话

**palimpsest 的两条核心主张——"读法是这份语料上的函数"与"含义不进几何"——在 2026 年
各自找到了外部证据，但方向是分裂的：前者基本没有现成工作（是空白，也是机会），
后者有硬证据，而且证据说 palimpsest 的方向对、但强度不够。**

最要紧的三条，先摆在这里：

| # | 发现 | 出处 | 它动摇了什么 |
|---|---|---|---|
| **1** | **正交性约束**：语义嵌入不可能正交（训练会把相近概念聚到一起），于是把事实写进共享连续参数的系统，**在几十条语义相关事实内就崩到接近随机**；ρ>0.6 时 **N=5 条就崩** | [arXiv:2601.15313](https://arxiv.org/abs/2601.15313) `[预印本]` | ★★ **同时支持与修正 §3.3"含义只作标注"**：方向对，但纪律要加严成"**进地址，不进几何**" |
| **2** | **知识编辑规模化会崩**，且唯一能扩到 10 万条的方法是把记忆**挪回显式 KV 数据库** | [arXiv:2401.07453](https://arxiv.org/abs/2401.07453) `[论文]` · [arXiv:2507.18028](https://arxiv.org/abs/2507.18028) `[论文]` | ★★ **§1.1 第二步（记忆进参数）**：参数化阵营自己承认，大规模事实上参数打不过检索 |
| **3** | **"模型默认倾向"会淹没条件差异**：3/4 的决策点上，去掉人设的模型默认动作已落在可接受范围内 | [arXiv:2609.16667](https://arxiv.org/abs/2609.16667) `[预印本]` | ★★ **§10.3 最小闭环（k-sweep）**：曲线可能被地板效应压平，先要证明判据有判别力 |

| 路线 | 代表工作 | 机制（训什么 / 信号从哪来） | 与 palimpsest 的关系 |
|---|---|---|---|
| **可微检索索引** | DSI、DSI++ `[论文]` | 把整个语料编进参数，用同一模型直接答 query；DSI++ 把"语料增长"当持续学习问题 | **最像"读取函数"的东西**——但它编的是**文档**，不是**节点与组**；且实测**持续索引会遗忘** |

| **测试时训练 / 快权重** | TTT-Linear、**Titans** `[论文]`、qTTT `[论文]` | 推理时做梯度步，把经历压进一个记忆模块的参数 | ★★ **最接近第二步的形态**；但 Titans 要改架构重训骨干（见 §3.2） |

| **参数化记忆 / 知识编辑** | ROME、MEMIT、AlphaEdit、NeuralDB | 定位关键层 → 对权重做闭式/零空间扰动 | ⚠️ **第二步最主流的路线，但容量与副作用实测都在打脸**（§3.1） |

## 2. 已找到的"读取函数随经历生长"的先例

这一格是 palimpsest 的核心主张（§5.4"它是这份语料上的函数"），本次**分三档**给结论。

### 2.1 第一档：检索函数本身从经历中学（最接近）

- **HAGE** `[预印本]` — [ar5iv 2605.09942](https://ar5iv.labs.arxiv.org/html/2605.09942)、[代码](https://github.com/FredJiang0324/HAGE_MVPReview)
  记忆是**带可训练边特征的多重关系图**（temporal/semantic/causal/entity 四维）；
  `QueryRouter`（MLP）按关系意图**动态调制边特征**，`w_ij(q) = softplus(MLP([q; ẽ_ij]))`；
  边特征与 router 用 **REINFORCE 联合优化**，加 **anchor 正则**防漂移。
  ⇒ **训练期学的，不是在线学的**。这是目前找到的**最完整**的"读旧记忆的度量由经历学出来"。
- **AURORA** `[论文]` — [ACL 2026 Findings](https://aclanthology.org/2026.findings-acl.495/)
  "**索引拓扑冻结，度量表示持续学习**"，当成 few-shot 持续学习问题；外加贝叶斯路由在
  "自适应索引"与"静态 fallback"之间切换以平衡 stability/plasticity。
  ⇒ **"既要学、又别学坏"的现成答案**。
- **Cross-domain utility reversal** `[预印本]` — [arXiv:2608.22610](https://arxiv.org/abs/2608.22610)
  "技能库审计"发现两类可靠性失败：**coalition pollution**（库级收益掩盖组级负贡献）
  与 **cross-domain utility reversal**（对源域有益的技能，**迁移后效果反号**）。
  修法是**采样 Shapley 边际**做 coalition-aware 选择。
  ⇒ ★★ **这比"迁移得不好"强得多**：它说的是"**符号都反了**"。
  这是本次找到的**支持"读法是这份语料上的函数"的最硬证据**——通用件换语料不只是变差，是**有害**。
- **DSI++** `[论文]` — [arXiv:2212.09744](https://arxiv.org/abs/2212.09744)（EMNLP 2023）
  **直接冲着"整套重来、不做增量"来的**：把"语料增长后增量建索引"当持续学习问题，
  承认遗忘真实存在，然后用**更平坦的极小值**（+12% 稳定记忆）＋ **生成式记忆**采样伪 query 解决。
  净效果：NQ 上 Hits@10 **平均 +21.1%**，且**比顺序重训少 6 倍模型更新**。
  ⇒ ⚠️ **这是对 §7.4 最直接的挑战**——见 §5.1。

### ★ 2.4 明确"未找到"

- **没有找到**任何工作把"读取器"当作**绑在单份语料上、随经历持续生长**的函数。
  现有的全部落在两类：**通用编码器 + 索引**（DPR/RETRO/REPLUG 一路），
  或者**整个语料塞进参数**（DSI/DSI++ 一路）。**palimpsest 这一格是空白。**
- **没有找到**用**定长槽位**做"记忆浮现"的工作。
  Perceiver IO / Slot Attention / DETR 提供了机制，但它们**服务的是感知**；
  且 DETR 的 object queries **跨输入相同**——恰恰是 palimpsest 不要的那个性质。
  ⇒ ⚠️ 这一条要记牢：**palimpsest §5.2 的"k 个槽位"没有现成轮子。**
- **没找到**把"检索结果以**激活**形式注入"与"以**文字**形式注入"做**头对头质量比较**的实验。
  找到的都是**速度/成本**对比（PRECOG 的 4500×）。**"激活注入不比文字差"目前缺乏直接证据。**
- 检索词：`learned metric for memory retrieval agent`、`memory evolution graph neural network agent`、
  `continual learning dense retriever test-time adaptation`、`per-corpus learned retriever`、
  `differentiable search index incremental`、`fixed slots memory surfacing`、`set encoder memory retrieval`。

## 3. 把记忆写进参数（第二步）——可行性的硬数据

### 3.1 知识编辑：容量上限与失败模式

- **ROME / MEMIT 规模化会崩** `[论文]` — Gupta et al., ACL 2024 Findings,
  [arXiv:2401.07453](https://arxiv.org/abs/2401.07453)
  顺序编辑时遗忘分**两阶段**：先是**渐进遗忘**（已编辑事实 + 下游能力同步流失），
  随后**灾难性遗忘**（原文：一次更新就让模型"失能"）。**后者给这类方法封了扩容天花板。**
- ★ **但崩的原因被定位了，且可修** `[论文]` — [arXiv:2502.01636](https://arxiv.org/abs/2502.01636)
  根因是 (1) 内部激活被**过优化** (2) 被编辑矩阵**范数持续增长**；
  加 **MPES + Frobenius 范数约束**后**能扩到 10,000 次编辑**，耗时降 42–61%。
  ⇒ **"编辑多了必崩"不是原理性的，是正则缺失。** 单卡可复现。
- **副作用有理论级解法** `[论文]` — AlphaEdit, ICLR 2025 Oral,
  [arXiv:2410.02355](https://arxiv.org/abs/2410.02355) / [源码](https://github.com/jianghoucheng/AlphaEdit)
  把扰动**投影到"保留知识"的零空间**再施加，理论上保证保留知识的输出不变；
  平均提升 36.7%，**只要一行投影代码**。
- ★★ **最强反面证据** `[论文]` — NeuralDB, ICLR 2026,
  [arXiv:2507.18028](https://arxiv.org/abs/2507.18028)
  **唯一能扩到 100,000 条**的方法，做法是把被编辑事实**外化成显式神经 KV 数据库 + 门控检索**，
  参数侧只留一个开关。
  ⇒ **直说**：在"承载大规模事实"这个维度上，**参数化记忆输给了检索式记忆，而且是参数化阵营自己承认的**。
  palimpsest 第二步若以容量为目标，会被这条反复打脸。
- **编辑指标本身不可信** `[论文]` — ACL 2025,
  [aclanthology 2025.acl-long.868](https://aclanthology.org/2025.acl-long.868/)
  常规指标近满分，模型**依然吐原始知识**（superficial editing）；
  成因定位到后层注意力头的左奇异向量**封装着原始知识**。

### 3.2 测试时训练：Titans 及其实测反转

**Titans** `[论文]` — [arXiv:2501.00663](https://arxiv.org/abs/2501.00663)（Google）

- **训什么**：一个**深度神经长期记忆模块 M**（不是矩阵状态，是带 MLP 的网络）。
  M 是 **meta model**——学的是"如何记忆"这个函数，不是记住训练数据本身。
- **信号从哪来**：**惊讶度 = 损失对输入的梯度**。
  `ℓ(M_{t−1}; x_t) = ‖M_{t−1}(k_t) − v_t‖²`。梯度越大 = 输入越偏离过去 = **越该记**。
- **参数怎么变**：`M_t = M_{t−1} + S_t`，`S_t = η_t·S_{t−1} − θ_t·∇ℓ(M_{t−1}; x_t)`
  ——**past surprise（带衰减的动量）＋ momentary surprise（当前梯度）**。
  作者证明它**等价于带动量、权重衰减的小批量梯度下降**，据此做成可并行训练。
- **一个可直接借的设计判断**：论文原话指出，此前的快权重/delta 规则模型
  "**都是基于 momentary surprise，忽略了序列中的 token 流**"，且多数**缺遗忘门**。
  Titans 的 η_t、θ_t 都是**数据相关**的：η_t→0 表示"忽略上一次惊讶"（上下文切换），
  η_t→1 表示"全盘纳入"。

**★ 但有一条致命的错位**：Titans 的长期记忆是网络的**一个分支/一层**，训练时与注意力
**端到端联合优化**。要用它**必须改架构并（至少）重训骨干**——正好落在 §1.1
"没有资源训练大参数模型"这条约束之外。

**★ 复现门槛的真实证据** `[论文]` — [arXiv:2510.09551](https://arxiv.org/abs/2510.09551)
独立轻量复现的原话：Google 论文"**缺乏公开代码**且描述**存在歧义**，阻碍复现"。
结论：**Titans 并不总是超过已有基线**（归因于 chunking 的实现选择）；
**但它的 Neural Memory 组件相对纯注意力模型有一致的提升**。
⇒ **抄部件，别抄结论。** 这一条要写进任何引用 Titans 的地方。

### 3.3 不经文字接口的注入

- **PRECOG / SMC** `[预印本]` — [arXiv:2608.02560](https://arxiv.org/abs/2608.02560)
  利用 SSM 的固定大小、位置无关的循环隐状态是"读过的全部内容"的摘要：
  **离线**把语料预编码成隐状态，查询时**直接注入**。
  **1.2B gated-SSM，192 KB 隐状态**，prefill **~27 秒 → <6 毫秒（约 4500×）**。
  ⚠️ **适用边界（原文）**：该机制"**对 Transformer KV-cache 在架构上不可能**"
  （KV-cache 位置纠缠、且随长度线性增长）。
  ⇒ **这是"不经文字接口注入"目前唯一被实测跑通的形态**，且是**小模型 + 边缘硬件**案例；
  **代价是必须以 SSM 为骨干。**
- **Memorizing Transformers** `[论文]` — [arXiv:2203.08913](https://arxiv.org/abs/2203.08913)：
  指定层做 kNN 记忆增强，检索到的 KV **直接进注意力**而非拼进 prompt。
- **UniMem** `[论文]` — [arXiv:2402.03009](https://arxiv.org/abs/2402.03009)：
  把 16 种长上下文方法统一到 **Memory Management / Writing / Reading / Injection** 四维。
  ⇒ ★ **建议作为第一步编码器的设计语言**——它把"注入"单列为一维。
- **激活注入的可靠性**：见 §5.5（这是对"同一映射两副面孔"最直接的技术质疑）。

### 3.4 LoRA 作记忆载体（与约束最匹配）

- **PEFT Scaling** `[预印本]` — [arXiv:2606.02437](https://arxiv.org/abs/2606.02437)
  明确把 PEFT 从小"省钱替代"重新定位为：**小 adapter 作为强共享基座之上的持久本地状态**，
  承载"偏好、技能、工具习惯、**记忆类更新**"。三条规模化轴：Scale Up / Down / Out。
  ⇒ **不要求预训练**，且**天然兼容 §7.4"整套重来"**（重来的是 adapter，不是基座）。
- **PerLTQA** `[论文]` — [arXiv:2402.16288](https://arxiv.org/abs/2402.16288)：
  个人长期记忆的**评测集**（记忆分类 / 检索 / 融合）。
- **O-LoRA** `[预印本]` — [arXiv:2509.06100](https://arxiv.org/abs/2509.06100)：
  正交子空间让新任务的 LoRA 不侵占旧任务子空间。

### 3.5 MIRAS：把设计轴形式化（★ 与 §5.7 那条线几乎逐项对应）

**MIRAS** `[论文/预印本]` — [arXiv:2504.13173](https://arxiv.org/abs/2504.13173)（Google）

它把 Transformer、Titans、现代线性 RNN **统一重解释为联想记忆模块**，
即"用一个**内部目标**学习 key→value 映射"，并把这个目标命名为 **attentional bias**。
然后给出四轴设计空间：

| MIRAS 的四轴 | palimpsest 的对应 |
|---|---|
| **① 联想记忆结构** | 节点与组（点 ＋ 一组节点） |
| **② attentional bias 目标** | §4.2"情境与单元直接相比"的**比较函数**——★ 它指出绝大多数现有模型只用**点积相似**或 **L2 回归**两种，并给出**一整套替代目标及其稳定化近似** |
| **③ retention gate（遗忘门）** | §3.8 时间尺度 ＋ §8 失效——★ 它把**遗忘重新解释为"保留正则"**，并给出一组新的 forget gate |
| **④ memory learning algorithm** | §7"训练什么"——★ 它把这轴单列，正对应 §7.4 的"整套重来 vs 增量" |

派生出三个新模型 **Moneta / Yaad / Memora**，在 recall-heavy 任务上超过 Transformer 与线性 RNN。
⇒ ★★ **这是本次找到的与 palimpsest 设计语言同构度最高的形式化框架**：
它把 palimpsest 散在 §4/§5/§7/§8 的四件事，收成**一个四维设计空间**，
并且**每一维都给出现成候选**。
⇒ ⚠️ 但它**全部是架构级、要预训练**——是"第二步的设计语言"，**不是第一步能直接用的件**。

### 3.6 Engram：条件记忆与稀疏分配律

**Engram** `[预印本]` — [arXiv:2601.07372](https://arxiv.org/abs/2601.07372)（DeepSeek）

- 提出 **conditional memory** 作为**与 MoE 互补的第二条稀疏轴**：
  用现代化 N-gram embedding 做 **O(1) lookup**，让"知识查找"不再用算力去模拟。
- ★★ **核心发现：U 形 scaling law**。把问题形式化为 **Sparsity Allocation**——
  在**神经计算（MoE）**与**静态记忆（Engram）**之间分配容量，存在一个**最优配比**。
- 扩到 **27B**，在同参数同 FLOPs 下超过纯 MoE；且**收益不止在检索**
  （MMLU +3.4 之外，**BBH +5.0、ARC-Challenge +3.7、HumanEval +3.0**）。
- 机制分析：Engram **把骨干前几层从"静态重建"里解放出来**，等于**加深了网络**；
  并且**把局部依赖交给查表，腾出注意力容量给全局上下文**
  （Multi-Query NIAH：**84.2 → 97.0**）。
- ⇒ ★★ **对 palimpsest 的直接意义**：这为 §3.7"**规模由组织方式的参数量决定**"
  与 §5.7"**机械的归机械、模型的归模型**"提供了一个**可测量的形状**——
  "多少交给查表、多少交给计算"**存在最优配比，且可扫出来**。
  它同时给 §1.2"记忆不能只靠条目，而是类似权重的东西"一个现实注脚：
  **记忆放在"静态可查"那一侧，反而让计算侧更强。**

## 4. 联想记忆的数学（§3、§4 两节的理论对应物）

### 4.1 ★★ 正交性约束：本次最要紧的一条

**Attention Is Not Retention: The Orthogonality Constraint** `[预印本]` —
Zahn, Beton, Chana, 2026 · [arXiv:2601.15313](https://arxiv.org/abs/2601.15313)

它从 CLS 出发，指出：**可靠的记忆要求 key 正交，而语义嵌入不可能正交**
（训练就是把相近概念聚到一起）。后果是 **Semantic Interference**：

```
M·kⱼ = vⱼ(kⱼ·kⱼ) + Σ_{i≠j} vᵢ(kᵢ·kⱼ)      干扰量 O(N·ρ)
ρ = 语义密度（平均成对余弦相似度）
```

**实测崩塌点（这是硬数据）**：

| 条件 | 结果 |
|---|---|
| ρ > 0.6 | **N = 5 条事实就崩** |
| 中等 ρ | N ≈ 20–75 崩 |
| **16,309 条 Wikipedia 事实** | Modern Hopfield **97% → 0%**；离散存储 100% → 46% |
| 科学测量（ρ=0.96） | N=10,000 时 **0.02%** |
| 图像嵌入（ρ=0.82） | N=2,000 时 **0.05%** |

**原文判定**："**This failure is geometric, not architectural**"——
加容量、加注意力跨度、加训练数据**都救不了**。

**它的解法**：**Knowledge Objects (KOs)** —— 结构化事实 ＋ **hash 身份** ＋ 受控词表 ＋ 显式版本链。
在 Wikipedia 事实上，KO 检索 **45.7%**（Modern Hopfield 塌到近零），
**hash 寻址维持 100%**。它明确把 hash 寻址类比为**齿状回的模式分离**。

**另一条硬数据**：结构化 SPO 事实 **45.7%** vs 非结构化文本 **4.1%（11×）**；
因为实测前沿模型的**谓词一致性只有 40–70%**（schema drift）。

> ★★ **对 §3.3 的可操作修正**（这是本文最重要的一条建议）：
>
> palimpsest 现在的纪律是"**含义只作标注，不进几何**"。按这篇证据，**方向是对的**，
> 但**强度不够**——因为 palimpsest 的**相似度比较本身仍然发生在连续语义空间**
> （§4.2"情境与单元直接相比"）。Zahn 的结论要求的正是**把含义移出连续几何**。
>
> ⇒ 建议把纪律加严为：
> **"含义必须进地址（离散、正交、可哈希），不能进几何（连续、相似、会串扰）。"**
>
> 这不是推翻 §3.3，是**给它补上一个可证伪的强度**：
> 现在的说法禁的是"同类型节点互相靠近"，而证据说的是"**任何共享连续空间都会串扰**"。
> 二者差别在：前者只禁用"组"当向量维度，后者还追问
> **"情境与节点直接相比"这一步本身用什么空间**。
>
> ⚠️ **★ 范围限定（2026-10-11，据 `连接-工作记录.md` 收窄）**：
> 这条加严**只管事实侧**——即"**事实性内容的取回**"。
> ⛔ **它不管人格 / 倾向 / 联想那一侧**：那一侧**本来就该连续、该泛化、该"相近的靠近"**
> （`未验证 §13.1`：事实走地址，人格走几何）。
> ⇒ 所以正确的读法是：**事实进地址、不进几何；人格该进几何。**
> 把这条加到整个人格层上，会撞 `README` 与 `未验证 §13.4`。

### 4.2 现代 Hopfield

- **Hopfield Networks is All You Need** `[论文]` — [arXiv:2008.02217](https://arxiv.org/abs/2008.02217)
  `z = Wᵀ softmax(βWq)`；连续状态、**一次更新即收敛**、指数容量、指数小的检索误差；
  **更新规则与 Transformer 注意力等价**。
  三种能量极小：全局平均 / 亚稳（子集平均）/ 单模式定点。
- **Universal Hopfield Networks** `[论文]` — Millidge et al., ICML 2022,
  [PMLR 162:15561](https://proceedings.mlr.press/v162/millidge22a.html) · [全文 PMC7614148](https://pmc.ncbi.nlm.nih.gov/articles/PMC7614148/)
  统一为 `z = P·sep(sim(M,q))`；经典 Hopfield / SDM / DAM / MCHN 只是
  **similarity + separation 的不同取值**。多项式分离 `C ∝ N^{n−1}`，指数分离 → 指数容量。
  ⚠️ **关键警告**：指数容量的 MCHN **在含噪 query 上实际很差**——
  "**真正的瓶颈不是容量，是相似度函数的分辨力**"。实测 **Manhattan/Euclidean > 点积**。
- **Sparse Modern Hopfield** `[预印本]` — [arXiv:2309.12673](https://arxiv.org/abs/2309.12673)
  **稀疏的误差界可证明更紧**，且保持指数容量。
  ⇒ ★ **§4.3"粗筛可以漏，不可以丢"的理论对应物**：稀疏不是妥协，是**更紧的界**。
- **能否容纳"组"与多元关系**：组 ≈ 存储模式（可以），但**点与组共享同一相似度算子
  正是干扰最强的情形**（撞 §4.1）；**n 元关系 Hopfield 本身不表示**，
  必须走异联想（`z = Pσ(Mq)`，其形式恰是自注意力）或绑定算子。
- Krotov & Hopfield `[论文]` — [arXiv:2008.06996](https://arxiv.org/abs/2008.06996)：
  **隐藏神经元层是挂载 metadata 的现成接口**（对应"含义只作标注"）。
- **attention ≈ SDM** `[论文]` — Bricken & Pehlevan, NeurIPS 2021,
  [arXiv:2111.05498](https://arxiv.org/abs/2111.05498)：
  在特定数据条件下，Transformer 注意力可紧密联系到 Kanerva 的 SDM，且在 GPT-2 上验证条件成立。
  ⇒ **attention ↔ SDM ↔ 现代 Hopfield 三者同一**——
  §4.2"激活是一次注意力"因此有**三重独立的理论背书**。

### 4.3 VSA / HRR：与"几方就带几方"同构度最高

- **HRR 的绑定算子就是"含义不进几何"的实现**：循环卷积 `⊗` 的结果**与成分不相似**——
  `a⊗b` 不会因为 a、b 语义相近而靠近 `c⊗d`。n 元关系 = `a⊗b⊗c`，解绑 `⊛b⊛c ≈ a`。
  role-filler 结构**直接表达多元关系**。
  ⇒ ★★ **这正是 §3.6"一条关系连的是若干个已锚定的节点，不限定是两个"、
  "要建立关联就加一条边，不靠共享属性"的现成数学。**
  ⚠️ **必读的坑** `[预印本]` — [arXiv:2109.02157](https://arxiv.org/abs/2109.02157)：
  HRR 在可微架构中**因数值不稳定而失效**，加投影步后检索效果**提升 100× 以上**。
- ★ **谐振子网络** `[预印本]` — [arXiv:1906.11684](https://arxiv.org/abs/1906.11684)：
  **在 a、b 都未知时联合分解 `a⊙b`**——VSA 线里唯一能处理"**多方联合解码**"的算法。
  ⇒ 这一条直接对应 palimpsest"边的元数由内容决定，不预先规定"的**读取需求**。
- 综述：Kleyko et al. [arXiv:2111.06077](https://arxiv.org/abs/2111.06077) ·
  [arXiv:2112.15424](https://arxiv.org/abs/2112.15424)

### 4.4 多时间尺度：有反直觉的坏消息

Fusi 2005 原文正文未抓到（ScienceDirect 403 / Cell 超时），
**改用 Rubin & Fusi 2007 开放全文**（[PMC2525933](https://pmc.ncbi.nlm.nih.gov/articles/PMC2525933/)）取得完整数学：

- 级联 n 态，转移概率 `1/2^{k−1}`；**幂律衰减**（区间 ∝ 2ⁿ）；
  可存记忆数**随 n 指数增长**，代价仅初始 S/N 的 `1/n`。
- 可检索记忆数随突触数 C 呈**幂律**（非级联只有**对数**）。⇒ 这是"级联多尺度"的核心价值。
- **"遗忘是干扰不是被动衰减"坐实**：原文——
  "Old memories are forgotten because they are **overwritten by the new ones**"。

⚠️ **两条对 palimpsest 的警告（均为该文原文）**：

1. ★ **存在临界初始记忆痕迹**——低于阈值则"**it is as if the memory had never been created**"，
   **刚写下就取不出**。
   ⇒ **要检查的事**：palimpsest 的**长尺度条目在写入瞬间是否仍可被激活**？
   §3.8 把时间尺度做成"一条谱"，但没问"谱的最长端还取不取得到"。
2. ★ **复杂度↑ 与稀疏↑ 不能同时要**：长寿命要求"更复杂的突触 ＋ **更不稀疏**的表示"。
   ⇒ **这与 §4.3"稀疏有两条来源"存在潜在张力**，需要显式处理。

⚠️ **"多时间尺度在小模型上是否有用"——作者自己给了否定**：
C ≈ 10⁴ 时"**the best performance is obtained for the smallest n** …
any additional complexity would not help"。n 应随寿命**对数增长**。
⇒ ★ palimpsest 面对的是**个人项目规模**，这一条**必须当作反对证据读**。

## 5. 反面证据（明确反驳 palimpsest 某条设计）

按"打击强度"排序。**这一节比上面任何一节都重要。**

### 5.1 【反驳 §7.4 "整套重来、不做增量"】DSI++

`[论文]` [arXiv:2212.09744](https://arxiv.org/abs/2212.09744)

它正面处理"整套重来"的代价：承认持续索引会遗忘，然后**用平坦极小值 + 生成式记忆解决**，
拿到 **+21.1% Hits@10 且少 6 倍模型更新**。

**palimpsest 的可归因性论证在原理上站得住**（行为差异只能来自数据），
但**代价这一侧需要一个明确回答**：k 从 1 扫到 N、每次归档都可能触发重训时，
"整套重来"的开销是什么量级？DSI++ 说明这个代价**在工程上可以被大幅压掉**，
而压掉它**不必放弃正确性论证**——它用的是**训练动力学**（更平坦的极小值），不是增量继承。

⇒ ★ **建议**：把 §7.4 的理由（可归因）与手段（从头训）**拆开写**。
现在两者捆在一句里，导致任何"降低重训代价"的提议看起来都像在违反 §7.4。
按 2502.01636 与 DSI++ 的证据，**"从头训"可以有更便宜的做法**。

### 5.2 【反驳"记忆可以大量写进参数"】两条

- `[论文]` [arXiv:2401.07453](https://arxiv.org/abs/2401.07453)：ROME/MEMIT 两阶段遗忘，**封顶扩容**。
- ★★ `[论文]` [arXiv:2507.18028](https://arxiv.org/abs/2507.18028)（NeuralDB, ICLR 2026）：
  **唯一能扩到 10 万条的方法，是把记忆挪回显式 KV 数据库**。参数侧只留门控。
  ⇒ **在容量维度上，参数化记忆输给检索式记忆，且是参数化阵营自己承认的。**

### 5.3 【反驳"编辑成功 = 记忆写进去了"】

`[论文]` [aclanthology 2025.acl-long.868](https://aclanthology.org/2025.acl-long.868/)：
指标近满分，模型仍吐原始知识，且有因果机制。
⇒ 若第二步要自证，**不能只报编辑成功率，必须做因果级验证**。

### 5.4 ★★ 【反驳 §10.3 k-sweep 的判别力】ANIMASK

`[预印本]` [arXiv:2609.16667](https://arxiv.org/abs/2609.16667)（2026-09）

构造与 k-sweep **高度同源**：冻结故事世界、**把作者续写 hold out 作 human reference**、
**在每个决策点**比对角色动作 vs **去掉 persona 后**的模型产出。
40 个故事 / 6 个模型 / **3,846 个决策点**。

结论里最要命的一条：
- ★ **3/4 的决策点上，模型默认动作已经落在 persona 可接受范围内**；
- 分歧处**模型比 persona 更谨慎**；
- 原句：*"The persona guarantees who the character is, and the model sets how far the character will go."*

**推论**：若多数情境下"有没有记忆"产出都合格，
k-sweep 的三档判词"类似/说得通/说不通"会在多数 k 上**塌到"说得通"**，
曲线被**地板效应压平**，**区分不出 k=3 与 k=30**。

⚠️ **打击的限度**：ANIMASK 的对照是"删掉 persona"，palimpsest 的对照是"改变累积经历量"，
**两者不等价**；但"**模型默认倾向淹没条件差异**"这一机制可迁移。

⇒ ★ **可操作建议**：在正式 sweep 前，先用现成语料测一次"**不可接受率**"——
若不可接受率太低，**曲线是空的，扫了也白扫**。

### 5.5 ★★ 【反驳"激活注入"与"两副面孔"】转向向量的不可靠性

`[论文]` [arXiv:2505.22637](https://arxiv.org/abs/2505.22637)：
七种 prompt 类型**全部高方差**，且**经常产生与期望相反的效果**；
不同 prompt 类型导出的转向向量**方向互相不一致**。
原句："vector steering is unreliable when the target behavior is **not represented by a coherent direction**."

**推论**：§5.3"两种输出形态来自同一个映射"若要成立，
需要一个前提——**回忆内容在激活空间里必须是一个"连贯方向"**。
对"某段具体经历"这种高度复合、异质的内容，**这个前提很可能不成立**。

⇒ ⚠️ 这是对"第一步训练结果到第二步不作废"**最直接的技术质疑**。
建议：在第一步就把"**注入的是一个方向，还是一个子空间/一组向量**"这个问题显式写下，
不要默认它必然成立。

### 5.6 ★★ 【反驳"相关性是必要条件"就够】"人格"可能不是不变量

`[预印本]` [arXiv:2607.02368](https://arxiv.org/abs/2607.02368)

它定义 trait 为"**更换测量框架后仍存活、且属于单个 respondent 的内部结构**"，检验程序是：
把 response set 表示成 Item–Dimension 矩阵，其相关矩阵当作**对称正定矩阵流形上的一点**。
人类侧验证该量确实携带 trait 应有的东西：
**跨 test–retest（不共享条目、顺序、上下文）r = 0.77**；识别个体最高 76%（chance 0.4%）；
**预测 GPA R² = 0.281**，而同一批响应的 BigFive 聚合**什么都预测不了（R² = 0.018）**。

**在四个前沿 LLM 上，这个量返回空。** 进一步：
persona 分离度**只在每个实例共享同一题目顺序时才可读**（94.7%）；
**给各自顺序就掉到随机**；**重新对齐到任意一个共享随机顺序即恢复到 82–84%**。
逐条独立生成、无潜在结构的响应**能复现整个模式**。
结论原句：*"The cultural signal is a group template, not a property of any instance."*

**推论（这一条最难对付）**：
如果 LLM 上"人格"只是**共享上下文造成的组模板**，那么 palimpsest 测到的
"行为差异与累积经历相关"可能只是**共享上下文的相关**——
**"相关性"这个必要条件会被平凡地满足**（同一个 prompt 前缀当然产生相关输出），
从而**丧失判据力**。

⚠️ 注意这与 §1 的担心**方向相反**：不是"怕没有相关性"，
而是"**相关性太容易满足，不构成证据**"。

⇒ ★ **可操作建议**：需要一个"**换框架不变性**"检验
（改情境的呈现顺序/措辞/测量框架，看行为差异是否存活）。

### 5.7 【反驳"经历越多越好"是被默认的】两条独立证据

- `[论文]` ICML 2026 — [arXiv:2605.28705](https://arxiv.org/abs/2605.28705)：
  证明标准注意力**不可避免地**通过均匀/因果聚合历史上下文引入**任务间干扰**；
  给出 **bias–variance–interference 分解**，刻画历史 in-context 信息
  **何时正迁移、何时可证负迁移**；解释长 prompt 的顺序敏感性与退化。
  ⇒ **k-sweep 的曲线理论上不应被假定为单调上升。**
- `[预印本]` [arXiv:2608.01149](https://arxiv.org/abs/2608.01149)（PATH-Bench）：
  **后来的经验可以重塑早先获得的增益**（later experience can reshape gains acquired earlier）；
  **强 transfer 不保证 retention**。
  ⇒ 同样指向**非单调**。

### 5.8 【反驳"单次读数就够"】方差噪声

- `[预印本]` [arXiv:2601.21339](https://arxiv.org/abs/2601.21339)：
  12 模型 × 10 prompt × 100 采样。**within-LLM 方差 10–34%**；
  若读的是数量/流畅度类**表层指标**，**prompt 只解释 4.22%**，within-model 噪声解释 33.70%。
  原句：*"single-sample evaluations risk conflating sampling noise with genuine prompt or model effects."*
- `[预印本]` [arXiv:2512.06710](https://arxiv.org/abs/2512.06710)：
  把 **ICC（组内相关系数）** 引入 agent 评测，把方差分解为
  **between-query（任务难度）** 与 **within-query（agent 不一致）**；
  **ICC 在结构化任务上 n=8–16 次收敛，复杂推理需 n≥32**。

⇒ ★★ **这是 palimpsest 最该借的单件工具**：
它把"**差异 vs 漂移**"变成"between-condition 方差 vs within-condition 方差"，
并给出**每个条件要重采样多少次才有权说话**。
直接回答训练 §3.1"重复采样抖动基线"怎么建。

### 5.9 【反驳"人读裁决"在长程上可行】

- `[预印本]` [arXiv:2607.01254](https://arxiv.org/abs/2607.01254)（The Benchmark Ceiling）：
  benchmark 的有效性取决于嵌入其中的人类判断质量，而这个质量**结构性稀缺**；
  随模型逼近天花板，**判别信号集中到最难的条目**，恰是**最需要顶尖专家判断**的那些；
  替换成本随前沿能力**凸性上升**。
- `[预印本]` [arXiv:2605.23420](https://arxiv.org/abs/2605.23420)：
  社会规范对齐用**三名 panelist** 当参考解（而非一人），且**报告人-人一致性**。

**推论**：k-sweep 的判据是"人读三档"——**最贵的判断类型**，
而 k 从 1 扫到 N 意味着**判断量随 N 线性增长、难度不降**。
palimpsest 把"自动量具只做报警"设为纪律，等于**把成本集中在最稀缺的资源上**，
且**目前没有给出 N 的上界或抽样策略**。

### 5.10 【反驳"判官给不给原文"是可控变量】

- `[预印本]` [arXiv:2601.07506](https://arxiv.org/abs/2601.07506)：
  **当给定 reference 与判官参数知识冲突时，判官会无视 reference、转而依赖自身参数知识**，
  评分可靠性断崖下跌（"knowledge-driven failure"），**且常见 prompt 缓解手段无效**。
- `[论文]` G-Eval — [aclanthology 2023.emnlp-main.153](https://aclanthology.org/2023.emnlp-main.153/)：
  摘要任务上与人类 **Spearman 0.514**，作者自承"**低于中等规模神经评测器**"，
  并主动警示 LLM 判官**对 LLM 生成文本存在偏袒**。
- `[预印本]` JudgeSense — [arXiv:2604.23478](https://arxiv.org/abs/2604.23478)：
  **措辞改写就显著降低判官一致性**，且**序数任务既最不稳定、又是最少判官能判对的**。

⇒ ★★ **综合推论**：训练 §3.1 担心的"给原文 → 退化成像原文"，
与文献证明的"给原文 → 判官**不认**原文"，**是同一枚硬币的两面**。
两者都指向：**原文参考的存在与否是一个未受控的强变量**。
k-sweep 在不同 k 上给判官的原文量（或累积图的长度）不同，
**判官的行为漂移会与要测的"经历量效应"混在一起**。

⚠️ **而 palimpsest 担心的那个具体机制（"过度贴参考措辞"）——本次未找到任何论文量化过。**
最接近的两篇测的是**误读/不贴**，不是**过度贴**。这是**真实缺口**，
也是**可以做原创贡献的地方**。

### 6.2 借不了的（逐条写清为什么）

1. **Titans 架构本身** —— 它的长期记忆是网络的**一个分支/层**，与注意力**端到端联合优化**；
   要改架构并重训骨干。**落在 §1.1 资源约束之外。**
2. **Transformer 骨干上的 SSM 状态注入（PRECOG）** —— 原文明确"对 Transformer KV-cache
   架构上不可能"（位置纠缠 + 线性增长）。除非换 gated-SSM 骨干。
3. **现代 Hopfield 的"指数容量"当容量依据** —— 它假设**正交 key**；
   实测 ρ>0.6 时 **N=5 就崩**（§4.1）。
4. **线性注意力/SSM 把 KV 压成单一状态矩阵当底座** —— `[预印本]`
   [arXiv:2102.11174](https://arxiv.org/abs/2102.11174) 给出 `O(d)` 上限；
   "读取成本与规模无关"是靠"**容量与维度绑定**"换来的。
5. **"组不带类型"（§3.6）** —— **没有找到任何受控消融**。
   "既无支持也无反驳，**是一个未验证假设**"；而现有最强证据（§4.1）方向相反。
6. **"软加成 vs 硬补齐"（§4.2）** —— **没有找到直接对照**。
   Universal Hopfield 的 separation 理论**暗示存在容量-鲁棒性权衡**，
   **不能假定软一定好**。
7. **再巩固的"不完全提醒/预测误差"触发** —— REALM 用的是**检索反馈**，不是预测误差幅度。
   **若要后者，没有现成工作可抄。**
8. **"含义只作标注"作为完整方案** —— 不够，应"进**地址**，不进**几何**"（§4.1）。
9. **多时间尺度在小规模下可能有害** —— Rubin & Fusi 原文：
   小预算下**最优 n 最小**，"any additional complexity would not help"。
10. **k-sweep 式的 canon holdout 判据** —— ANIMASK 把"作者续写"当 human reference，
    读数是"是否收敛到 canon"。**palimpsest 明令禁止这个方向，不能进口。**
11. **一致性的任何总分**（CharacterEval / RoleEval 类）—— 都是"越不变越好"，
    **与 §1 判据反号**，进口即自相矛盾。
12. **PCC / PDS 这类自动评测器** —— 把裁决权交回 LLM，与 §10"量具只报警，不做裁决"冲突。
13. **HorizonBench 的 ground-truth provenance** —— 它依赖**从 mental state graph 生成对话**；
    palimpsest 用真实文本（章节），**没有这样的出处标注**，
    因此"差异与累积经历相关"里的"相关"**无法被机械核验，只能靠人读**。
    ⇒ **这是结构性的，不是工程量问题。**

### 6.3 ★ "不进口数据集"这条纪律的代价（直说）

**唯一不付代价的进口项是方法学**——预注册、诚实基线、ICC 重采样预算、
判官自一致性对照、非对称假阳性代价、换框架不变性检验。**这些是协议不是数据。**

代价在四处：

1. **失去唯一的外部可比性。** 所有能给出"跨系统可比数字"的东西
   （MINTEval 平均 27.9%、LME-V2 的 72.5%/48.5%、ZifaMem 的 +11.4% CI）
   **全部依赖共享数据集**。不进口 = palimpsest 的曲线**只能和自己比**，
   无法回答"这算好还是差"。
2. **失去噪声底的参照。** ICC 的 8–16/32 次预算、10–34% within-model 方差，
   都是**在具体任务分布上测出来的**，**必须在自己语料上重测一遍**——这是省不掉的人力。
3. **失去防"判官退化"的对照。** 判断"给原文会不会退化"需要一个**判官会在其上出错**的标注集；
   JudgeSense 提供了能力但**不含"相称"类目**。不进口就得自建。
4. **失去地板效应的先验。** ANIMASK 的"3/4 决策点已合格"是**只有拿到共享 canon 才能发现的**。
