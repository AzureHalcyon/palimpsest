# 研究

外部材料的调研记录与参考文献。**这里的文档是记录，不是设计**；
当前的说明见 [`../设计.md`](../99_归档/v1/设计.md)。

## 两类东西

**调研记录**（本层）：对有先例的系统做调研，写清**能借什么、为什么借不了什么**。
它们的证据等级沿用各自的标记（`[一手]` / `[源码]` / `[论文]` / `[二手]` / `[推断]` / `[查不到]`）。

**参考文献**（`参考论文/`）：**真的读过、并且被引用过**的第三方论文原文，
以及可检索的抽取文本（`.抽取/`，不入版本控制）。规矩见 [`参考论文/README.md`](参考论文/README.md)。

## 规矩

1. ★ **记录不改**。订正以引用块形式附在相应位置，正文按当时的标准保留。
2. ★ **旧结论不要直接当依据**：这里的文档写作时早于当前设计，
   文中对"本项目"的 `§N` 指的是**当时的项目文档**，作为出处标记原样保留。
3. ★ **借不了的地方要写清为什么借不了**，不许糊过去。
4. ★ **论文只放引用过的**；引用处要能指出"读它的地方"。
5. ★ **抓取与抽取的产物不入版本控制**（`.抽取/` `.抓取/`）：
   抽取文本可由 PDF 重建，抓取的网页是当时的快照。
