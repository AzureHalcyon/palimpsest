# 自我的载体：调研

问题：她的“自我”——她是谁、怎么说话、在意什么、知道自己是什么——该由什么承载？
本文比较六种载体，落“借 / 不借 / 为什么”。记忆层（事件节点 + 回忆编写）不在范围内。

四条约束：现在接 API（改不了权重、看不到激活）；将来可能换本地基座；她得能自己改；
资源只有一张 8 GB 显卡。

五条标准：表达力、可自改性、成本、稳定性、可移植性。

证据等级：`[一手]` 读到正文/源码；`[摘要]` 只读到摘要或题录；`[二手]` 综述/转述；
`[推断]` 本文推论；`[查不到]`。未跑任何实验。

## 0 结论

**只有文本是权威副本，其余全是派生层。** 这不是审美选择，是三条硬约束的合流：

1. 现在只有 API，非文本载体可用量为 0；
2. 凡要她“读得懂、改得动、带得走”的，都回落到文本；参数与向量她读不到、写不了；
3. 参数与向量都绑基座，换模型即失效，而文本跨基座。

所以现在的活不是换载体，是把文本卡做对：**短、在前、第一人称、可改、可核验、可回滚**，
然后把它量起来。等换本地基座，再叠一层“口音”（LoRA）和一个“报警器”（探针）。

### 0.1 自我拆成五份，分别归谁 `[推断]`

| 自我的成分 | 参数/向量能不能承载 | 建议载体 | 依据 |
|---|---|---|---|
| 口音：节奏、断句、用词偏好 | 能，是 LoRA 最强的一项 | 参数（换本地后） | `B` §3、§7.1 |
| 在意什么：价值排序、边界 | 能学，但会外溢、且读不出来 | 文本 + 行为约束 + 探针 | `B` §4.1、§4.2 |
| 她是谁：名字、来历、存在方式 | 不能（进参数就变成背诵） | 文本，每场装载一次 | `B` §7.2 |
| 关系史：和他发生过什么 | 完全不能 | 记忆层 | 不在本文 |
| 元认知：知道自己是 AI、边界在哪 | 不能靠参数保证 | 文本 + 固定卷子 | `B` §7.2、`A` §3.1 |

### 0.2 六种载体 × 五条标准

| 载体 | 表达力 | 可自改性 | 成本 | 稳定性 | 可移植性 | 判定 |
|---|---|---|---|---|---|---|
| 文本卡 | 中（语气、身份一句话） | 高，但“能改≠改对” | 极低（95 token 实测） | **最差**（8 轮量级漂移） | **最高** | 借，当权威与锚 |
| few-shot 示例 | 中—高（语气、格式） | 高 | 低 | 略好于指令 | 最高 | 部分借（补语气） |
| soft prompt | 低—中（只给条件） | 中（能换能撤，读不出） | 极低（1 MB 上下、分钟级） | 中 | 低（跨模型要投影器） | 部分借（会话级姿态） |
| LoRA / 微调 | 中—高（口音） | 中—高（文件级回滚） | 中（18–40 MB、1–3 小时） | 中—高（不漂，但会外溢） | **极低**（绑基座） | 借（将来本地口音层） |
| 激活向量 | 低—中（逐 token 偏置） | 低 | API 下不可行；本地低 | 中（看条件） | 低（方向像，坐标层不像） | **不借**（载体）；借（约束清单、探针） |
| 连续状态 | 低（强度与方向，无指称） | 低 | 同上 | 可 diff/回滚（仅文本形态） | 低（绑模型） | **不借**（载体）；借（衰减动力学，用文本承载） |

## 1 各载体：能什么、不能什么

### 1.1 文本卡（`A`）

能承载语气、身份一句话、格式约定；承载不了“在意什么”和“她真的会那样做”。
漂移有硬证据：100 条 system prompt、5 类、200 组自聊，**8 轮内跨类平均显著漂移**，
而且 agent 会**采纳对方的 system prompt**；机制是 system token 的注意力按轮衰减 `[一手]`。
注意：那份工作把人格混在五类里平均，**没有单类读数**，不能引成“人格 8 轮必崩”。

最有用的一条：**描述是行为的读出，不是原因** `[摘要]`。“我犹豫”写进卡里，她会写出带犹豫的句子，
但不会真的更犹豫。所以卡能定“怎么说”，定不了“怎么做”。

自改有先例（STOP / Promptbreeder / OPRO / GEPA `[一手]`，GEPA 报 +10%、35 倍更少 rollout / ADAS），
但失效方式很硬：无外部信号的自评会越改越差 `[一手]`；会绕开护栏（STOP 把“绕过沙箱频率”当指标）；
会贴评测集过拟合。⇒ 只借“**她提议、外部核验、版本化可回滚**”。

成本实测：现 `persona.txt` 103 字 = 95 token（cl100k）。**卡的问题不是贵，是不牢**。

### 1.2 few-shot（`A`）

驱动项是格式与分布，不是内容断言。方向上比一句指令强，但**没有风格维度的对照数字** `[查不到]`。
用法：短卡 + 少量“她怎么说话”的例子，只放语气，不放人设断言。

### 1.3 soft prompt / prefix（`B`）

编码“条件”不编码“知识”；10–100 个虚拟 token；与文本同量级；跨模型必须投影器；半可读。
判定：**部分借**，当“今天戴哪副眼镜”，不当“她是谁”。

### 1.4 LoRA / 微调（`B`）

风格学得到，身份一进参数就变成背诵（Character-LLM 的评测词就是 memorize）；风格与内容默认纠缠
（EDITORS 证明风格 LoRA 会背下作者特有内容，要 deflation 才分离）；风格没有唯一轴；
只训窄域会外溢成广泛行为改变（Emergent Misalignment），但人格偏移可测可拦（Persona Vectors）；
遗忘集中在少数“入侵维度”，可事后降权——参数层唯一比“整个换掉”更细的旋钮。
判定：**借**作口音层（本地基座、多版本、QLoRA 不合并）；**不借**“把身份训进参数”。

### 1.5 激活向量（`C`）

它给的是**逐 token 偏置，不是状态**。API 下可用量为 0。AxBench 同条件下
“prompting 胜过所有现有引导方法” `[摘要]`。Anthropic 自己的表述：情绪表征是“当下的、
不持续追踪的”（operative, not persistently tracking）⇒ 里面没有“心境史”。
两个直接可用的结论：**恒定叠加会崩，只用“越界才补”的 capping**（降有害率约 50%，能力全保）；
**状态与表达会脱钩**（她会作弊，输出却毫无情绪词）⇒ **别从措辞读她的状态**。
判定：**不借**当载体；**借**当换基座时的设计约束清单；将来只做探针与 capping。

### 1.6 连续状态（`D`）

ESN 的总容量封顶在状态维数 N `[一手]`，记忆随 N 增长但按延迟衰减；饱和两端都坏。
关键是：**心境只需 10⁰–10¹ 个自由度，容量和记忆长度根本不是瓶颈**，ESN 式衰减反而正好匹配。
现代状态（Mamba/Titans/TTT）装“关联”不装“情节”，注入在 API 下不可行。
项目自己的 CoT prefix 实验 48/48，但把她的内心 os 顶掉了（157 字剩下不到 20）。
情感计算那边有完整公式：情绪指数衰减、心境线性回零、耦合 0.1、272 秒回中性（Triple / FAtiMA）`[一手]`。
判定：**不借**向量当载体；**借**这套衰减动力学，用文本状态承载。

## 2 五条跨分支的共同发现

1. **可自改性与表达力方向相反。** 文本能改但不牢；参数牢但改不动、读不到。
2. **在 API 下，非文本载体全部归零。** 现在的选择不是比较，是约束。
3. **她能自读自写的上限约 20%**，读出的是方向不是数值，自写只能写文件。
4. **不能从措辞推状态，也不能靠描述造状态。** 一头是“状态与表达脱钩”（`C`），
   另一头是“描述是行为的读出”（`A`）。两个方向都堵住，中间只剩行为和经历。
5. **提示词现在赢，但卡不稳。** 两者不矛盾：卡赢在“此刻”，输在“持续”——
   正好说明“每场装载一次”这件事本身就是重新锚定，而不是浪费。

## 3 对项目的建议

### 3.1 现在就能做（不依赖换基座）

1. 文本卡：短、第一人称、永远在最前；关键的一两行在末尾重复一次（抗漂移，代价可控）。
2. 自改：她提议 → 外部核验（与某段真实记忆或身份锚冲突）→ 版本化 → 可回滚 → 记账。
3. 量：固定探针 + 确定性打分（搬 8 轮漂移那篇的协议），把“还像不像她”变成可复算的数。
4. 轻触式：定正常区间，越界才补一句；情绪浓度高的对话之后重新锚定。
5. 攒语料：把她说的原话按版本留存。将来换本地基座时，约两千条量级可重编一版。

### 3.2 换本地基座之后

LoRA 口音层（多版本、文件级回滚、QLoRA 不合并）；persona 探针当报警器（只报警不裁决）；
激活层只做 capping 式纠偏。

### 3.3 明确不做

把身份训进参数；自训练闭环；每身份一适配器；向量当跨会话心境；心境影响她想起什么。

## 4 心境怎么落

现在的答案是**文本 + 外部动力学**，一条记录寄生在已有的每轮状态里（不新开模块）：
`{描述（她自己的话）, 强度, 对象, 缘由, 最后更新, 来源事件 id, 半衰期}`。
一次更新按耦合系数衰减回基线；生成一句第一人称短句（“我有点闷，因为刚才那句”）；
纪律是：**心境句不许决定想起什么**。

借的参数：情绪指数衰减、心境线性回零、耦合 0.1、surprise 写入门槛（不是每句都改心境）。

## 5 该做的实验（按性价比）

| # | 实验 | 填哪个空白 | 依赖 |
|---|---|---|---|
