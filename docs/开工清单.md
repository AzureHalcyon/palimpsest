# 开工清单

动手之前要定的事，以及动手之后会反复撞到的规矩。

设计见 [`设计.md`](设计.md)。这里只写**做的时候怎么看、按什么顺序**。

---

## 1. 一次性的事（过了这个点就补不回来）

有些东西只在"还没有任何积累"的时候能采到。它们排在所有工作之前。

| # | 事项 | 为什么是一次性的 | 落地 |
|---|---|---|---|
| **T1** | **空白对照**：在一条材料都还没进来时，跑一遍检验，并**记下你自己的观察** | 结构可以从代码重算，**"当时它是什么样"不可复算** | 一份带日期的记录 |
| **T2** | **定目标值**：哪些量是"要达到多少"，不是"越小越好" | 事后只能记"变了"，不能记"变好还是变坏" | 写进 `参数账` |
| **T3** | **不可核的量**：模型给出的判断（打分、出题、裁决）必须当场落盘 | 事后无法重建 | 落进逐轮记录 |
| **T4** | **边界要人看过**：标注与切分的边界，人工看若干段真实材料 | 边界错是静默错，事后无法归因 | 一份人工记录 |

⇒ ★ **T1–T4 全都不依赖任何未决**。它们排在"写代码"之前，因为它们的成本只有一次机会。

## 2. 逐轮记录的字段（第 7.6 节）

**这是动手前唯一必须定死的东西**：它决定从第一天起手上有什么数据。
字段见设计 [`7.6`](设计.md)。落地时至少含：

```
刺激（原文区间） · 图（版本标识） · 期望（一组位置加关系类型）
· 激活（取用了哪些、各多少） · 参数（这一轮用的读取参数） · 成本
```

⇒ ★ **一条纪律**：**刺激记位置，不记它的表示**。
记了表示就无法在图上重放这一轮，而"同一情境、换一个读取版本、比较取用结果"
正是训练与检验共同依赖的操作。

## 3. 能立刻做（不依赖任何未决）

## 6. 环境（已定，2026-10-08 实测）

| 项 | 值 |
|---|---|
| 解释器 | **系统 Python 3.13.14**（`python`，Store 版） |
| 已装 | **numpy 2.2.6** · **PyYAML** · **requests** |
| 未装 | torch（现在用不到：训练要租卡，第一步只调 API） |
| pip 源 | 已配清华源（`%APPDATA%\pip\pip.ini`），**不用再配** |
| 编码 | 脚本里把 stdout 重设为 UTF-8，不依赖环境变量 |

★★ **本机的一条硬事实：网络与 pip 在沙箱下不可用，提权即通。**

沙箱下 `pip install` 会失败，而且**报错看不出是权限问题**——
它说"找不到任何版本"，日志里没有任何连接尝试；`import numpy` 也失败，
而 numpy 其实装着。提权后两者都正常。
⇒ 因此：**凡是要装包、要访问网络的操作，直接提权一次，不要反复试。**

⇒ **现在不需要装任何包**：第一步只用这三个，够。

## 7. 会反复撞到的几条

1. ★ **改文档用唯一锚点，改完必自查**（跑 `tools/check_docs.py`）。
2. ★★ **模型给出的判断，单遍不作数**：并行若干遍取一致，不一致的悬置。
3. ★★ **凡进入记录的量，必须跨进程可复现**；内置 `hash`、遍历序、时间戳都要显式验。
4. ★★ **要否掉一条路，先给出"实现没错"的证明**，否则否掉的可能是自己的实现。
5. ★ **跑之前先写复算**；能重跑一遍的数，才敢写进结论。
6. ★★ **下结论前问一句"我看到的是全部数据吗"**。
7. ★★ **改 git 的二进制或非 ASCII 路径，别用给人看的输出**：
   `git ls-files --cached` 会把中文目录名转义，脚本拿到的路径 `git rm` 认不出；
   用 `git ls-files -z`（NUL 分隔的原始路径）。这条已经骗过我一次。

## 8. 判据

**这一层该不该存？** 问一句：

> **它能从原文重新算出来吗？**
> **能** ⇒ 它不是源，不必长期保存（但可能要留痕供核验）。
> **不能** ⇒ 它是一次性的，必须留住。

**这条变了该怎么记？** 问一句：

> **它是"记录错了"还是"事实变了"？**
> **记录错了** ⇒ 走修订，只在建图之前，且留痕。
> **事实变了** ⇒ 走失效，绝不碰原文。
