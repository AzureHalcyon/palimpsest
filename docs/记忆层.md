## 1. 三个时钟

| 时钟 | 算什么 | 能不能写 |
|---|---|---|
| **对话中** | 取用 · 表述（算不完的判断） | ⛔ **只读**，层冻结 |
| **归档**（段末） | **重算一遍**（可复算的那些不进库）＋ 训练读法 | ✅ **写读法参数 ＋ 不可复算的项** |
| **训练**（归档里的子阶段） | 判断的**参数** | ✅ **整套重来，⛔ 不继承** |

- 【作者定 2026-10-16】**周期 ＝ 一次对话**：`归档 → 新对话 → … → 这一次对话结束 → 归档`。
- 【推导】记忆层在对话中**不提供任何状态**，连续过渡由**输入流**承担。
  依据：`设计 §6.4.1`——"两次对话之间的连续过渡只能由输入流承担，这一层在对话中不提供任何状态"。
- 【推导】**写 ≠ 改库**：可复算的那些**不进库**（只是一份缓存，重算就有），所以归档不是"改一个状态"，是**重算 ＋ 把不可复算的写进库**。
  ⇒ `设计 §6.4.2`"并行多轮、不串联"随之换了理由：**既然一切都是重算，串联本身就没有意义。**
  ⇒ 也因此**不存在"两个东西同时在动"**（对照：MemCoRL 需要"交替时冻住另一半"——我们只有一个可训的东西）。

### 1.1 什么必须存（判据只有一条：可复算吗）

| 东西 | 可复算吗 | 性质 |
|---|---|---|
| **原文** | ⛔ 不可（只增不改） | ✅ **存储** |
| **参数**（读法 · 任何标定出来的阈值） | ⛔ 不可（训练/标定有随机性，且依赖历史） | ✅ **存储** |
| **记录**（逐轮记录 · 修订留痕） | ⛔ 不可（记的是"实际发生过的那一次"） | ✅ **存储**（⛔ 不进读取路径） |
| ★ **惊讶度读数**（调用模型拿到的 logprobs ⇒ 每处一个误差） | ⛔ **不可**（那一次模型给的；换模型/版本就变，跨会话也只到 `1e-3`） | ✅ **存储**（和原文一起落盘，带模型与提示词的指纹） |
| **cell 的划分**（边界在哪） | ✅ 可（已有文本＝LLM 切一次；新对话＝天然分段 ⇒ 外生、可重算） | ⛔ **缓存** |
| **库** | —— | ★ **就是存储**（⛔ 不叫它缓存） |
| ├ **节点**（＝留下来的 cell）· **待观察池** | ✅ 可 | ⛔ **不进库**，是一份**缓存** |
| ├ ★ **组** | ★ 看由谁产：**LLM 产 ⇒ ⛔ 不可复算 ⇒ 在库里** · 依赖簇算 ⇒ ✅ ⇒ 只是缓存 | ★ **眼下在库里** |
| └ **边** | —— | ⛔ 不落库（读的时候现算） |
| 读取的输出 · 浮现 | —— | 一次性 |

- 【推导】**不可复算的只有三样：原文 · 参数 · 记录。** 其余全是缓存或一次性。
  依据：`设计 §2.1`"凡能重算的东西，就不需要为了'防止丢失'而长期保存；凡不能重算的东西，才需要保存"。
- 【推导】**为什么原来以为要进库的两项，现在不进库了**：节点与组原先由**标注（判断）**产生，同一输入可能给不同结果
  ⇒ **不可复算** ⇒ 那时它们**必须在库里**（`设计 §3.2` 对标注记录就是这个理由）。改成**算出来的**之后 ⇒ 可复算
  ⇒ ★ **它们不占库了，只是一份缓存**。
  ★★ **措辞要准：⛔ 不是"库变成了缓存" —— 库一直是存储，是这两项不再有资格进库。**
- 【推导】缓存的额外好处：**换算法就重算，⛔ 没有历史负担**（不存在"迁移旧库"）。

## 2. 一段对话

```
归档 ─▶ 新对话 ─▶ ① 常驻记忆（开场一次：从图里读、重新表述一遍）
                      ├─ ② 很多轮：用户说话 → 她（可能 tool_call 想起什么）→ 她说话
                      │      · 每轮写一行逐轮记录
                      │      · 记忆层全程只读
                      ③ 这一次对话结束 ─▶ 归档
```

- 【作者定 2026-10-16】**常驻记忆一段只给一次，在开头**，⛔ 不是每轮重述。
  理由（【假设】作者经验，本机未测）：**开头注意力最多**。
- 【推导】**常驻记忆 ＝ 拿"开场"当情境的一次普通读取**，⛔ 不是一份固定文本
  ⇒ 它靠激活、靠训练、每次重算；而"表述每次重新生成"（`README`）⇒ **它在措辞层面永远不是一张卡**。
- 【推导】常驻记忆的来源三样：**专门手写的部分**（身份 · 关系 · 工具；冷启动那一次装进原文）
  ＋ **稳定人格的部分**（＝ 开场读取的产物）＋ **时间锚与上次的余温**。
- 【推导】**"上次的余温"⛔ 不是调制**。调制不越归档边界，一段对话结束就归档了 ⇒
  它只能是**开场读取的产物**（从原文/库里取）。

## 3. 归档流程

```
材料（这一次对话的原文，逐字）
 │
 ├─① 切 cell          ★ **外生**，⛔ 不训练（产物是缓存，⛔ 不落库）
 │       · **已有的文本**：让 LLM 切一次 —— 这是给旧语料**打的补丁**，够用就好，⛔ 不返工
 │       · **新对话**：一场天然就是一段（周期＝一次对话）⇒ 记下来即可，⛔ 不用切
 │         ⚠️ **已改（2026-10-18）**：cell 的粒度是**轮**（每轮一格），不是整场一段；见 `流程框架.md` [6]
 │       · ★ cell 只是**「聚」的原子**：⛔ 不追求"切得对"。**事件划分在 ④ 之后由惊讶度聚出来**（见下面的两条）
 │       · **递归细化**：某个 cell 内误差仍高 ⇒ 在该 cell 内**下探到更细的天然单位**（句 / 轮）
 │         ⇒ 直到分辨率下限（⛔ 不是另一套切法）
 │
 ├─② 预测误差（惊讶度） ★ **每次调用都把 logprobs 和原文一起落盘**（它是记录，重算会漂）
 │       · 用现有读法预测每个 cell ⇒ 每处一个误差
 │       · ★★ **标记**：误差超过 `T = μ_{t−τ} + γ·σ_{t−τ}`（**移动窗口内的均值 ＋ γ 倍标准差**）
 │         ⇒ **超过的那几处 ＝ 标记**（⛔ 用"排名前 k"—— 那要拍 k，且"处处误差大"时没信息量）
 │         ⚠️ **它是"相对于附近的跳变"，⛔ 不是"全局最大"** —— 两者语义不同（`实验-18` 实测）
 │
 ├─③ 产生（REM · 宽松）
 │       · ★★ 配对 ＝ **【被标记的 cell】 × 【标记集里的「件」】**
 │         ⇒ 是"全盘扫"的**子集**：**起点收窄、由 `④` 维护另一半**
 │         ⛔ 不用相似度 ⇒ 跨场也能一次配上（另一场的件在标记集里）
 │       · 互相依赖 ⇒ 候选组
 │
 ├─④ 收尾（**强度衰减 ＝ 艾宾浩斯**；⚠️ SWS 的"剪候选连接"**未实现**） ★★ **两层，⛔ 是"一次判断"**
 │       · **层1（每次归档）**：新标记的先进**标记集**（`confidence = 1.0`）—— ★ ⛔ 判断
 │       · **层2（长期维护）**：标记集里每个件 **每窗口 −0.1** ⇒ `≤ floor` 剪出（★ ⛔ 删，仍在图里）
 │       · **强化有两个来源**（`§9`：噪声连不上 · 低频重要碰得到就连上）：
 │         ① **它又被标记** ⇒ `+0.05`（奖"又出现"的）
 │         ② ★★ **`⑤` 把新的归进某个件** ⇒ 那个件 `+0.05` ·
 │            ★★ **并把件内冷掉的成员拉到 `max(当前, 0.25)`**（＝"第二次被提起 ⇒ 能用上就行"）
 │         ⚠️ **②是"低频重要"的活路**：它不需要常出现，只需要"每次出现都能被归进去"
 │         ★★★ 【作者定 2026-10-17】**② 这一条已改**：`归进` **⛔ 再加 `+0.05`** ——
 │           「归档只管结构，强度归激活」⇒ 重提（repetition）按**那一场每一轮的激活分布**
 │           累积强化（`Σ 系数 × 激活值`，见 `流程框架 §3.1.4` / `knobs.件.激活强化系数`）。
 │           理由：两处都加分 ⇒ **同一件事被强化两次**，而两次的权重没人能定。
 │           ⚠️ 「冷成员拉起」**也没接上**：标记集的键是**件**、而「成员」是 **cell**，
 │           不是一个东西（`knobs.死旋钮` 里登记为无读者）。
 │         ★★★ 【作者定 2026-10-17】**衰减改成艾宾浩斯**（作者原话：「如果重提的多，那么应该
 │           衰减的越来越慢，符合艾宾浩斯好吧（甚至给保底）」）：
 │           每件一个 `稳定度 S`（初值 1、只增）—— 每被重提一场 `S += 平均激活`；
 │           这一场的衰减率 ＝ `每窗口衰减 / S`，夹到 `衰减下限` 之上
 │           ⇒ S=1 与原来一字不差（−0.1）· S=4 ⇒ −0.025 · S≥20 ⇒ 触底 −0.005
 │           （0.9 掉到门槛 0.2 要 140 场 ⇒ **这就是"保底"**；但它仍然会淡，忘了才叫忘）。
 │         ★★ 同时定了**三档**：`手工`（用户明说）−0.02 / 地板 0.5 ⇒ 永不剪出 ·
 │           `自报`（她自己标）**普通档**（作者：「她自报的给普通，当兜底用」）· `意外` 普通档。
 │         ★★ 冲突：**⛔ 覆盖**。新旧两条都留，落 `新.修正 → 旧`（+ 旧的 `被修正`），
 │           取用时成对带出、按时间排（"以前…… 后来……"）—— 见 `流程框架 §3.1.4`。
 │       · **掉了就真忘**（不再主动浮现）· ★ **靠"新的对话里重提"回来**（重提 ⇒ 又被标记）
 │       · **不确定性**：决定**可塑性**，⛔ 不是决定去留
 │       · ⚠️ **hold-out：这里用不上**（全盘重算 ⇒ 人人通过；且判不了新的）—— 见 `§3.1` 后那条【未定】
 │
 ├─⑤ 末尾看一眼（模型 · 唯一需要判断的地方）
 │       · ★★ **前面必须先"激活提候选件"** —— ⛔ 不能把全部件喂进去
 │         （件数随场数线性长 ⇒ 几十场就上千 ⇒ 判不过来）
 │         线索 ＝ 新标记的 cell ⇒ **相似度提候选**（★ 这是"取用"，合法）
 │         ⇒ 取出 k 个候选件（5–10）⇒ 只在这 k 个里判
 │       · 判"归进哪个件 / 还是新建"，给个说法 / 类型名
 │       · ★★ **它的归类同时是 `④` 的强化信号**（归进某个件 ⇒ 那个件与件内冷成员被强化/拉起）
 │       · ⚠️ **判据是"是不是同一件事"（模型），⛔ 不是相似度** —— 相似度只负责提候选件
 │
 └─⑥ 训练（整套重来，⛔ 不继承）
```

- 【作者定 2026-10-16】① 切 cell 走**外生的便宜办法**（已有文本＝LLM 切一次 · 新对话＝天然一段），⛔ 不靠训练，
  也⛔ **不追求"切得对"**。
- ★★ **① 的"切"与后面的"聚"，是同一件事（事件划分）的两种算法。** 我们用**聚**来做：
  - **cell ＝ 聚的原子**：只要求**细 · 全 · 固定**，所以用便宜的外生办法分（⛔ 不用贵的量）
  - **组 ＝ 真正的事件划分**：★ 用**惊讶度**聚（难的那一步用贵的量做）
  ⇒ ⛔ 不是"先按事件切好"；`①` 分出来的**不是事件**，是原子。
- 【推导】① 的**递归细化**：某个 cell 内惊讶度仍高 ⇒ 在该 cell 内**下探到更细的天然单位**（句 / 轮）⇒ 到分辨率下限。
- 【推导 2026-10-16 修正】② **用「局部自适应阈值」而不是"要标定的全局绝对阈值"**：
  `误差 > μ_{t−τ} + γ·σ_{t−τ}`（窗口内的均值 ＋ γ 倍标准差）。
  ★ 原来写的是"用排名"，理由是"绝对阈值要标定、且处处误差大时没有信息量"——
  **那说的是"全局固定阈值"**；`μ+γσ` 的均值随窗口走，**恰恰解决了"处处误差大"**
  ⇒ 两条其实不冲突，是**同一目标的两种落法**，取"局部自适应"这一种（`实验-18` 在 13 轮上标出 `[3,5,8,11]`，
  比"排名前 3"多标了轮 3，人读认为该记）。⚠️ `γ` / `τ` 待标定（`参数账`）。
- ★ **② 的读数要落盘**（和原文一起）：见 `§1.1` —— 它是「记录」，重算会漂。
- 【推导】③ 必须**全盘扫**：候选若靠几何提，就只提"像"的 ⇒ 字面无关的连接永远进不了候选池。
- 【作者定 2026-10-16】④ 的顺序是**先连接再衰减**；它是**必需**的第二步
  ——每批新料都会出现"处处误差大"，衰减让误差爆炸**在批内收干净**。
- 【推导】④ **孤立性定去留 · 不确定性定可塑性**：二者合起来才分得开"低频重要"与"噪声"
  （噪声永远连不上 ⇒ 融不进 ⇒ 走掉；低频重要的一旦被碰到就能连上 ⇒ 留下）。
  ⚠️ 不确定性这一条来自外部（MESU 元可塑性），**本机未验**【未复现】。
- ⚠️ **【未定】④ 的 hold-out 具体测什么 · 材料从哪来 —— 读不准**（2026-10-16 记）：
  `§9` 那条【推导】写着"**用这一段连、还用这一段测 ⇒ 降了只证明它背下来了**" ⇒ **"要 hold-out"没错**；
  ★★ **但"别的材料"从哪来，作者口径是**：
  > "**当时说 hold-out 没有别的材料，是因为训练；激活都是在全盘上进行的，哪来的别的材料。**"
  ⇒ ★ **训练**那一侧：hold-out 是标准的（留出一批不训的材料）；
  ⇒ ★ **读取 / 激活**那一侧：**全盘**（看的是整张图）⇒ **没有"别的"这回事**。
  ⚠️ **而 `④` 是"归档"里的一步** —— **它归哪一侧、拿什么测，还没说清。**
  ⇒ **暂定**：④ 先只跑**孤立性 · 不确定性**；**hold-out 那一条等说清再实现**，⛔ 不硬填做法。
- 【作者定 2026-10-16】⑤ **模型只留这一处**：判"是不是同一件事"（那类买不到的信号）。
- 【推导】⑥ **批内可串联（产生→衰减）· 跨批必须平行**。

### 3.0 每一步：输入 / 算法 / 产出（★ 2026-10-16 定，⛔ 别再靠上下文记）

| 步 | 输入 | ★ 算法（谁在算） | 产出 | 存不存 |
|---|---|---|---|---|
| **① 切 cell** | 材料原文 | **按天然单位**（轮 / 对话边界）。**旧语料＝让 LLM 切一次当补丁** | cell | ⛔ 缓存 |
| **② 惊讶度** | cell ＋ 读法（第 0 步＝占位读法） | **调模型拿 `logprobs`**（★ 只有官方端点给）⇒ 每处一个误差 ⇒ ★★ **超过 `μ+γσ` 的 ＝ 标记** | 误差 ＋ **标记** | ✅ **记录**（和原文一起落盘） |
| **③ REM（产生）** | 被标记的 cell ＋ 标记集 | ★★ **配对 ＝ 标记的 cell × 标记集里的「件」**（全盘扫的子集）—— ⛔ **不问模型** | 候选连接 | ⛔ 存档（中间量） |
| **④ 收尾（强度衰减 ＋ SWS 剪候选·未实现）** | 新标记 ＋ 候选 | ⚠️ ★★ 2026-10-18（作者口径）：**SWS 的功能是"REM 连完之后把不该有的连接去掉"**（＝把 `③` 的候选压到 `⑤` 看得完），⛔ 不是"强度衰减"；下面的 `−0.1/窗口` 是**艾宾浩斯**的。SWS 那一半**四个判据全被否**（相似度 · 参与度 · 旧模型 · 切出来的类，见 `研究/REM-SWS-机制参考.md` §背景）⇒ **从未实现**。<br>★★ **两层**：层1 **新标记进标记集（1.0）** · 层2 **衰减 −0.1/窗口 · ≤floor 剪出（⛔ 删）**<br>★ **强化**：①又标记 `+0.05` · ~~②`⑤` 归类 ⇒ 该件 `+0.05` ＋ 件内冷成员拉到 `0.25`~~ ⇒ ★★★ 【作者定 2026-10-17】**归进⛔ 加分，强度归激活**（`Σ 系数 × 激活值`）；冷成员那一条没接（件 vs cell 不是一个东西） | 标记集 ＋ 留下的连接 | ⛔ 存档 |
| **⑤ 末尾一眼** | 活下来的一小撮 | **模型判**"是不是同一件事"、给个说法 | 类型名 / 说法 | —— |
| **⑥ 训练** | 节点与组 | 整套重来，⛔ 不继承 | 读法参数 | ✅ 参数 |

★ **两条最容易搞混的**：
1. **③ 是穷举，④ 才是筛。** ★ `③` 里**没有智能**（就是配对）；智能在 ④（误差）与 ⑤（判断）。
   ⇒ ⛔ **不许让模型在 ③ 里判"有没有关系"** —— 那是判断；而且**模型判不出的，就进不了候选面** ⇒ **盲区**。
2. **② 的误差是"量"，⛔ 不是"判断"** —— 模型在那里只提供**概率**。

★★★ **③④ 里"模型"只做一件事：提供一个数（概率）。⛔ 它不下任何判断。判断只在 ⑤。**

| 模型在干什么 | 算不算"模型参与" |
|---|---|
| **提供一个数**（logprobs / 概率） | ⛔ **不算** —— 它是算法里的一个**冻结部件**（与"冻结嵌入"同类） |
| **下一个判断**（"这是不是同一件事"） | ✅ **算** —— ★ **只有 ⑤ 有** |

⇒ 所以：
- **③** ＝ 枚举配对 —— **连模型都不用调**
- **④** ＝ ★ **改读法的输入（把 A 放进情境）⇒ 用同一个读法重算误差 ⇒ 比数值 ⇒ 降了留**
  ⛔ **全程不问模型任何问题**（"算误差"在 ② 就已经在做；④ 只是在新条件下再算一遍）
- **⑤** ＝ ★ **唯一"模型下判断"的地方**

★★ **三个视角 ⇔ 组 / 边**（归档的 `标注提示词` v16 正好有三个视角，一次只用一个）：

| 视角 | 产出 | 在链里是 |
|---|---|---|
| **同一件事** | 哪些节点属于一起 | ★ **组** |
| **同一类事** | 不属同一件具体事、但同属一类 | ★ **边**（组-组） |
| **同一种具体情绪** | 情感上是同一种 | 另一种**边** |

★★ **旧语料 vs 新对话**（⛔ 别再说成"旧语料不能连"）：

| 材料 | 能走到哪 | 用处 |
|---|---|---|
| **旧语料** | ① → **LLM 标组（手工簇）** → ★ **③④ 也能跑**（用占位读法算误差即可） | ★ **验证机制用** —— 不必等新对话 |
| **新对话** | ① → ②→③→④→⑤→⑥ 全走 | ★ **正式跑**（她的经历；误差**当场记下**） |
| **两者的差别** | 只是"误差当场记" vs "事后补算"（后者会随模型版本漂） | ⛔ **不是"能不能"** |

★ **外生只保证"不受训练影响"，⛔ 不保证"不漏"**：
- **切 / cell（细原子）**：外生 ＋ **全** ⇒ ✅ 无盲区
- **聚 / 组（粗划分）**：外生 ＋ **会漏** ⇒ ⛔ 有盲区（＝去掉标注的同一个理由）

### 3.1 ⛔ 不留"标注"这一层

- 【作者定 2026-10-16】**标注整层去掉**：节点 ＝ 留下来的 cell · 组 ＝ 依赖簇 · 组内连接 ＝ 现算。
- ★★ **簇（组）有两种来源**（2026-10-16 补，作者口径）：
  | 来源 | 谁给的 | 可复算 | 在哪 |
  |---|---|---|---|
  | ★ **手工簇** | **LLM 标 / 人标**（＝"特殊的手工簇"） | ⛔ 不可 | ★ **进库（存储）** |
  | **依赖簇** | 算出来的 | ✅ 可 | ⛔ 只是一份**缓存** |
  ⚠️ **手工簇是给定的，⛔ 不会随训练长**（依赖簇会长）⇒ 它是**占位 / 骨架**，⛔ 不是终态。
  ★★ **分界 ＝ 有没有经历**（作者 2026-10-16 口径："手工簇得是少数"）：
  **有 `logprobs` 的材料（新对话）走算的**（`② → ③ → ④` ⇒ 节点 · 依赖簇）；
  **⛔ 没有经历的材料（旧语料）才由手工簇补位**。详见 [`待决.md`](待决.md) §22。
- 【推导】理由：若注释由读法产生，则
  `读法决定"记什么" ⇒ 记下来的成为训练材料 ⇒ 训出下一版读法 ⇒ 读法没见过的永远记不下来`
  ⇒ **盲区自我固化**，而且**双倍有害**：记不下来 ⇒ 也想不起来（库里没有那个位置）
  ——正撞"缺的是**可达性**，不是容量"（`设计 §5.7`）。
- 【推导】所以**不是**把标注改成"取用头在归档时跑一次"，而是**整层不要**。

## 4. 为什么"切法是算法"是对的

- 【推导】**候选面固定 ＋ 去留可学 ＝ 既不盲、也不固化**：

| | 结果 |
|---|---|
| **候选面固定**（算法切） | 没有"读法见不到"的东西 ⇒ **无盲区** |
| **去留可学**（误差 · 衰减 · 读法） | 库的形状随经历变 ⇒ **不固化** |

- 【推导】"写死"在这里是**优点**：固定的候选面是防盲区最干净的办法（比"靠读法产生候选"干净）。
- 【推导】归属：它属于 `README` 的"**记、存、查归机械**（写死 · 要快 · 可复算）"，⛔ **不是"判"**。

## 5. 落点

★ **只有三样是"存储"**：**原文 · 参数 · 记录**。其余都是**缓存或一次性**。

| 落点 | 装什么 | 性质 |
|---|---|---|
| **原文（语料）** | 逐字，只增不改 | ✅ **存储**（不可复算） |
| **参数** | 读法（两个头）· 标定出来的阈值 | ✅ **存储**（不可复算） |
| **记录** | 逐轮记录 · 修订留痕 | ✅ **存储**（⛔ 不进读取路径） |
| **库**（存储） | ★ 只装**不可复算**的项 —— 眼下是**组**（组由 LLM 产时） | ✅ **存储** |
| **缓存** | 节点（留下来的 cell）· 待观察池 · 凡是读法版本能重算的 | ⛔ 随时可丢可重建 |
| **存档** | 算出来的关联 · 卷子 | ⛔ 供核验与训练 |
| **一次性** | 读取的输出 · 浮现 | 用完即弃 |

- 【推导】**边不在一等对象里。** "连上以后误差降了多少"是**中间量**：算的时候用，写完进**存档**，读的时候**现算**。
  依据：本部 §14"关系从不以对象形式存在"。
  ⇒ 正确说法：**我们扫的是参数，⛔ 不是边**。

## 7. 大模型拿到什么

开头   常驻记忆（她是谁 · 关系 · 工具 · 时间锚 · 上次的余温）  ← 一段一次；注意力最多

## 8. 三个模型

| | 是什么 | 训不训 |
|---|---|---|
| **大模型** | API 黑盒；**用户从始至终只跟它对话** | ⛔ |
| **小模型** | **一端两用**：编码器（取某一层池化）＋ **表达头/翻译器**（魔改；旁路注入状态） | ✅ |
| **嵌入模型** | 冻结；**用于提候选**（★ 不再用于切 cell —— 切 cell 走 LLM 切一次／对话天然分段） | ⛔ |

- 【实测 2026-10-16】大模型侧的接口已验：
  `POST /beta/chat/completions` ＋ 末条 `assistant` 带 `content:""` ＋ `reasoning_content:<起念>` ＋ `prefix:true`（⛔ 不带 tools）；
  48/48 条件被接住，0 空输出。脚本与原始数据在 `99_归档/风格层-已归档/`。
- 【实测 2026-10-16】同一批实验里，**注入起念会把模型自己的思考顶掉**：思考字数从 **157** 掉到 17.7–34.2。
  ⇒ 读"效果"必须读**可见输出**，读思考会高估。
- 【作者定 2026-10-16】**嵌入模型不能用来定去留**，只能**提候选**（★ 切 cell 已不靠它）。
  ⛔ 一旦用相似度定去留，就永远碰不到字面无关的连接。
  ⚠️ 要说清它能提到什么：语义相近的 ⇒ 它能提出"**意思像、字面不像**"的候选；
  **它提不出**"意思也不像、但在经历上属于同一件事"那类——那正是训练要建的那一整类新边。
- 【假设】**出口形态必须是她的第一人称**（`她当时有点沉` 不合，`我有点闷` 合）。本机未测。

## 9. 信号

| 信号 | 判什么 | 成本 | 自监督 |
|---|---|---|---|
| 机械负例（编造 · 越界 · 时间不可能 · 空集乱冒） | ⛔ **只能否** | 0 | ✅ |
| 推力（k 槽位必须满） | 形状 | 0 | ✅ |
| **预测误差（局部自适应阈值 `μ+γσ`）** | **哪儿该找** | 一次前向/批 | ✅ |
| **边际增益（hold-out）** | **连上有没有用** | 贵但少 | ✅ |
| 孤立性 · 不确定性 | 去留 · 可塑性 | 0 | ✅ |
| 后果（用户的下一次反应） | 好不好 | 0，弱而稀疏 | ⚠️ |
| 末尾那一眼（同一性） | 该不该同指 | 中 | ⛔ **长不出来** |

- 【未复现】自监督的边界：能覆盖"**筛错**"，覆盖不了"**该连**"。
  出处：`docs/研究/参考对象与方法核查-调研.md`。
- 【作者定 2026-10-16】"该连"**不靠信号产生，靠试探产生候选**；信号只负责筛。
- 【推导】**响应量必须是"预测误差"，⛔ 不是"激活权重"**——"激活 ＝ 情境与单元直接相比"就是相似度，
  用它全盘扫只是全盘相似度扫描。
- 【未复现】**代理指标的警告**（出处：Liu et al., ACL 2026, *MemCoRL*，DOI `10.18653/v1/2026.acl-long.1804`）：
  只用"被引用"当唯一奖励 ⇒ 检索策略**造出会被引用的假证据去骗下游**。
  ⇒ 对我们的意义：**"孤立性 / 召回 / 被激活"也是代理指标**，必须有"下游真的对不对"（hold-out）压着。
  详见 `docs/研究/MemCoRL与MemPilot-调研.md`。
- 【未复现】可借的两条（出处：arXiv `2610.06830`，*MemPilot*）：
  ① **双视图**——压缩记忆库 ／ 原始历史，"前者高效访问，后者保留细粒度信息"；库里没有的，回原始历史做 query-specific 整理。
  ② **objective-wise advantage decoupling**——每个目标先各自归一化再合成（理由：**先合成会掩盖各自的信号**）。
  与本部 §15.1"四条判据各自报警、⛔ 不许合成一个分数"同型。
- 【未复现】（不进设计，只记边界）MemCoRL 的另两条补丁**不适用**：
  "交替时冻住另一半"——我们只有一个不可复算的东西（§1.1），不存在两个同时在动；
  "KL 拉回参考策略"——**KL 惩罚"离参考远"，而我们的判据恰恰是"离参考多远不算数"**
  （【作者定】"收敛回种子没关系，要看的是动没动、动得跟经历相不相称"）⇒ 方向相反。
  它防漂的功能已由**整套重来（不继承）**与**连续过渡由输入流承担**覆盖。

| **手段** | 设计 §1.1 | ★★ "**"读法"是为实现目标而做的降级手段，本身不是目标。**所以每条取舍先问一句：它是为了逼近第二步，还是只在优化第一步的手感？" ⇒ 只为第一步好用的**刻意做浅**，并标明"第一步专属" |
| **任务** | 设计 §7.1 | "**训练目标是：给定情境与当时的节点与组，输出应当取用的内容。**"（两部分：**取用哪些** · **怎么表达**） |

⇒ ★★ **所以"取用"是设计明写的任务，⛔ 不是漂移**；"手段"那一层就是 §1.1 那句自检。
⇒ ⚠️ 但要认清取用的**引力**：**它是唯一有标签的东西**，实操上必然把自己变成目标
⇒ 每次动它，都回到 §1.1 问一句："**这让我更逼近第二步了吗？**"

★ **判据怎么读**：设计 §10 写死了——"**判据只有一条，人读；自动量具只做报警，不做裁决。**"
⇒ ⛔ 所以**不许把"行为因经历改变"做成一个自动指标**（作者 2026-10-10："不需要追求什么把人格量化成指标"）；
⇒ 它是**给人读的对照**（§16.1 记的那几对，含"同一情境 · 早窗 vs 晚窗"）。
⇒ ★★ **没有读数时，就写"目标判据：无读数"**，⛔ **不许拿四条读数的全过来代替**（见 §15.5）。

★ **作者对语料的话**（2026-10-10）："我打算用**小说**来实现'连续'语料。"
⇒ 小说给的是**时间轴**（同一情境、早期 vs 晚期）＋**人可读的参照**（人物在文本里实际怎么反应）；
⛔ 它给不了"**对方针对系统的反应**"（那要真实交互）。

## 14. 先分清"算"发生在什么时候

这是本文的骨架。三个时间是三件不同的事，混起来就会冒出"边到底存不存"这类假问题。

| 时间 | 算什么 | 产物 | 例 |
|---|---|---|---|
| **归档时**（离线，唯一写入窗口，见设计 6.4） | 能**算得完**的判断（材料内、不组合爆炸） | **落库** | 组："这些位置属于一起" |
| **训练时**（归档里的一个子阶段） | 判断的**参数** | **参数** | 比较函数 · 表达映射 |
| **测试时**（对话中，层冻结、只读） | **算不完**的判断（跨材料跨时间，且由情境筛） | **用完即弃** | 关系 · 取用 · 表述 |

★ 界线只有一条：**离线能不能算完。**

- **能** ⇒ 归档时算完落库。目前只有"在一起"（组）这一类：它是材料内的 n 元判断，规模线性；
- **不能** ⇒ 只能测试时现场算。关系是**跨材料的两两以上**，数量组合增长（设计 §3.7），
  而且"哪些候选值得比"本身要由情境筛 ⇒ **不存在"离线全部算完"这个选项**。

⇒ ★ **判官不落库。** 它不是"决定哪条边进库的人"，是**产生训练信号的人**
（并行取一致的纪律照旧：每轮独立、不一致的悬置）。
⇒ 关系**从不以对象形式存在**——不是"换了个存法"，是**没有那个对象**。

## 15. 训什么

**三步的边界**（2026-10-10 定）：

| 步 | 训不训 | 做什么 |
|---|---|---|
| **第 0 步** | ⛔ **不训，只攒料** | 用 API ＋ **固定提示词**把线跑通（★ 它是**临时的读法**，见下）；攒逐轮记录 · 候选对 · 卷子 · 底片 |
| ★ **第 1 步** | ✅ **训读法** | 训两个头（取用 · 表达）。设计 §5.3 说的"训练结果到第二步不作废"指的就是这一步的结果 |
| **第 2 步** | ✅ 训 | 把记忆压进参数，接口消失 |

⇒ ★ **因此第 0 步的记法必须按"第 1 步要什么"来定**——攒了不该攒的等于没攒（设计 7.6、归档 §4-4）。
⇒ 第 0 步用的读法是**临时的**（一套固定提示词）：★ 凡用到它的地方都要**标出来**，**它的行为不能当读法的行为**。

训练的产物是**参数**，不是边。两个头，共享一个映射（设计 §5.3）：

| 头 | 决定 | 资源不够时可以 |
|---|---|---|
| **取用** | 给定情境，**节点与组**里哪些位置被取用、各多少——**"想起什么"** | 先训 |
| **表达** | 取用的结果如何组织成交给模型的那一段——**"怎么说"** | 后训 |

★ **为什么非训不可**：**跨材料、跨时间、字面上无关的关联，只能由训练算得出来**——
几何算不出来（话题不重合）· 规则算不出来（没有共同词）· 模型手标不可靠（它不会主动翻半年前）。
★ **弱标签从哪来**：**"他后来是不是又提到了。"**

★ **规模由参数化的读法吸收**（设计 §3.7）：读取定长，成本与**节点与组**的规模无关。

### 15.1 这一层的架构

骨架出处：作者 2026-10-10 的描述（"一个神经网络，覆盖在所有节点上面，节点靠组进行分类；
得到输入，信号传播，先得到和信号需求相关的一些方向，然后在这些方向上进行最主要的传播……
最后拿到一批节点，把原文取出来，重排、编写，最后输出"）。

```
所有节点（各视角的并集）
   └─ 组给出结构（谁和谁在一起）

两路输入 ──▶ 传播 ─▶ 重排 ─▶ 编写 ─▶ 输出
   ├─ 线索：当前这一句 / 这次请求
   └─ 调制：近处（自上次归档以来）
   两路都进入**传播 · 重排 · 编写**
```

**两路输入，同一个来源，内容不同：**

| | 内容 | 作用 |
|---|---|---|
| **线索** | **当前这一句 / 这次请求**（我要找什么） | 决定去找什么 |
| ★ **调制** | ★ **近处**：自上次归档以来的输入流（前几次对话、节奏、此刻的气氛与她的状态） | 决定"该想起什么"与"该怎么说"，**进传播 · 重排 · 编写** |

★ **调制的原料就是"还没归档的那一段"**（归档边界是现成的 ⇒ 机械、零参数）——
于是短期记忆有了精确的定义：

> **短期记忆 = 对"还没归档的那一段"的感知。**

⇒ 归档之前靠调制（现读原文），归档之后靠图与读法（训出来的）——两边不重叠。
⛔ **调制不越过归档边界**：越过了，短期记忆就在替记忆层干活，"长期"永远长不出来，
也退回到"把原文塞进上下文"。
⛔ **不存成层内状态**（冻结照旧；先前那条"余温"仍然撤回）——调制是**现读的**，用完即弃，与输出同待遇。
★ 它**只吃偏好信号**——这是结构性的，不是选择：§23.3 的机械对照**每次都固定调制、只改取用**，
所以那些对照对调制**不携带任何信息**（见 §23.6）。

★ **可复算的那些不进库**（＝ 原文 ＋ 读法版本的函数 ⇒ 一份缓存）；★ **库是存储**，装不可复算的项。而**训练产的关联、方向、取用**
全靠训练（⛔ 不落库，**只存档**——见设计 §3 的落点表）
> ⚠️ **加注（审计 C2）**：提示词**自 v4 起不产关系**⇒ 其中"**标注产的边**"**作为独立对象是空的**；标注侧只剩"**组内的连接随之成立**"这一派生形态（设计 §3.6）。
⇒ 网络要学的就是"**在点和集合之上，信号怎么走**"。

> ⚠️ **加注（审计 C7）**：记录层有**反证**——`研究/参考项目与记忆层-调研.md` §9 第 3 条（订正 2026-10-02；同一实测另见该文 §6.1 HippoRAG 行与 §7 动作 A8 的订正）记着实测：PPR **零交集条目最优名次中位 633**（要求 ≤8，**P1/P2/P3 全部不满足**）⇒ "**传播在我们的语料上确实不成立**"，原因是**查询太宽**（种子中位 **640/892 = 71.7%**）。⇒ 本条要**写清"为什么现在可以了"**（差别大概是**线索更窄**）。⛔ 本加注**不改"传播"的设计**，只把反证摆在旁边。

**传播——不读原文。**

- ★ **两步**：**先粗定位**与需求相关的一片区域，**再在区域内做主要传播**；
  传播中碰到的**近邻一并纳入**计算；
- ★ **浅层就是候选生成**：不存在"外面另加的一道闸"，它和主要传播是**同一个过程的前后几步**；
- ★ **联想发生在组与组之间**——点稠密、组稀疏，**组才是完整单位**；
- ★ **组内是"软加成"**：命中一个点，只让同组成员**之后更容易亮**——⛔ 不是马上整组全亮
  （硬补齐会把同组、但这次不相关的成员拖进来）；
- ★ **组要进"结构"，不进"向量"**：组当传播路径（归类 / 超边）没问题，
  把组当向量的一维就撞设计 §3.3（含义进几何 ⇒ 同组互相靠近、读取时互相干扰）；
- ⛔ **不能是另一套规则**——否则"什么能被想到"被写死，那部分行为不随经历改变；
- **可以漏，不可以丢**（设计 §4.3）；第二步里它整个消失（模型内部的注意力就是它）；
- 代价：随**传播到的那一片的大小 × 步数**涨 ⇒ **可达性的上限由浅层粗定位决定**。

**重排——决定发生在这里，因为这里才看得见原文。**

- 取到的那批节点 → **取原文** → 用原文重排；
- ⇒ 设计 §3.1"只提候选，不决定结果"从此**适用于 传播**：传播收敛范围，**取用由重排定**；
- 节点在传播阶段靠**预计算的表示 + 结构**（那时不读原文）——这是"传播阶段不读原文"的前提与代价。

**编写——只吃重排的输出**（⛔ 不许再去读原文），产出**定长 = k 个槽位**。

- 这是设计 §4.3"一次输出的表示是定长的"的落地；
- ★★ **两态就在这儿**：同一个槽位序列，第一步把每个槽位**文字化**给模型看，
  第二步把每个槽位的**向量**注入——设计 §5.3 的"同一个映射的两副面孔"；
- ⚠️ 它可以**给关系命名**（给已有连接贴标签），**但不许引入取材集之外的内容**（交付 ⊆ **取材集**）。

**跨视角要写清两层**（缺一层就会被另一层否掉）：

| 层 | 规则 |
|---|---|
| **标注层** | 各视角**各自独立、不投票**（设计 §3.5.1） |
| ★ **读取层** | **可以跨视角传播**，而且那是**训出来的** |

**训练分工**：传播·重排·编写 都用对照 / 边际增益训（可两两排序），四条判据各自报警、⛔ 不许合成一个分数。
语料正好各喂一块：传播 的"该不该取用"有 LongMemEval / HCoT / DuLeMon 的真值，
编写 的"哪个说法更好"有 Douban 的人工判断。

### 15.2 期望输出

**输出的单位是"一件事"，不是"一个点"。** 取用是**点级**的（带权重、组给软加成），
输出是**组级**的（一件事 = 一个组，或一个自足的节点）。

```
一次浮现 = k 个槽位（通常只用几个；没用到的不出现）
  槽位 1：一件事          ← 由该组成员的原文重排 / 编写而来
  槽位 2：另一件事
  …
  ＋ 这几件事之间是什么关系 / 合起来说明了什么
  ＋ 内部留痕：各自支撑在哪些位置、权重多少（→ 记录层，不进给模型的那段）
```

★ **"若干件事"怎么来**——**不需要聚类器，簇是现成的**：

| 谁给 | 给什么 |
|---|---|
| **结构** | 给簇：**组**就是"属于一起"（设计 §3.1）；**不属于任何组的点各自成一件** |
| **动力学** | 给强度：**软加成**让同组成员容易一起亮 ⇒ 组内才有东西可池化（下一段） |
| **排序** | 给取舍：**组与单点排同一个榜**，按强度取前 k 件（k 就是槽位数，⛔ 不是新旋钮） |

★ **强度和表示的来源是"路径"，不是手列的组属性**（作者 2026-10-10 定）。

```
池化（重排 的输出头）
  输入：★ 点亮成员【在传播之后的表示】     ← 路径上的东西；随情境变化
  两路输出：强度（标量）· 表示（向量）
  自足节点 ＝ 成员数为 1 的件，走同一个函数  ← 于是"同榜、同尺度"自动成立，不需要校准
```

★ **它不是「训」出来的，是「攒」出来的**（2026-10-18 作者更正：旧词「可训池化」有误导性）。
作者原话：「**它就该是一个层层叠加起来的地图 / 势**」。

- 每回想一次，那条**路径**（点亮了哪些成员、从哪儿走到哪儿）就在图上**留下一层**；
- **强度**读的是「这个位置被多少条路径叠过、叠得多深」＝**势**，⛔ 不是一组学出来的参数；
- ⇒ **不需要监督信号，也不需要正对**：攒的次数就是它变「熟」的程度。
  （⛔ 旧说法「12 场 ~50 正对、不够启动训练」是按「要训练」推的，**作废**。）

§15.1 那条流程（"**先定位方向 → 在方向上主要传播 → 碰到近邻纳入**"）走出来的**就是一条路径**；
而零参数的 `max` **只读最高点，把路径的形状拍平了** ⇒ 前面那条路白走。
⇒ 一句话：**`max` 读最高点 · 地图（势）读路径叠了几层。**

#### 15.2b 「势」怎么叠、怎么引导（2026-10-18 定）

| 问题 | 定法 |
|---|---|
| **记什么** | 一次激活**够亮**的格（终结分中位以上）—— ⛔ 半径内全记，那会把热区糊成一片 |
| **怎么叠** | EMA：`势 = α·亮度 + (1-α)·势`（`唤醒` 一起记，只作读数） |
| **引导读什么** | **`势` 本身**（⛔ 不用 `势/唤醒`）—— 实测条件势把「亮一次」和「亮二十次」抹平了：316 格里 127 格只亮过 1 次，条件势照样 0.6–1.0 |
| **遗忘** | 内建在 EMA 的 `(1-α)` 里，⛔ 另写一条衰减（见下表和艾宾浩斯的区别） |
| **起什么作用** | **引导传播**：α/β/γ 各乘 `(1+κ·条件势)`；⛔ 不进起点、⛔ 不进准入 |
| **防固化** | 传播噪声幅度 ∝ `1/(1+条件势)`（MESU：不确定处可塑性高）；**第一次没有势时不加噪** |
| **存哪** | **不是图的一部分**：`缓存/势.json`，可删、可重算（`recall` 只读，叠层在 `session`） |

★ 图景（作者原话）：「一次激活完成之后……留下激活的路径，从最强一直到最弱……
下一次激活，如果还是命中类似的地方，那么之前的路径就可以开始引导，路径上更容易被激活，
而不是像第一次一样传播那样随机地游走……不断叠加，最终会变成一个网络。」

⇒ 落法是**位置上的势**，不是有序路径：常走的位置势高，热点自己连成网；
**区分不同的事靠起点 cos 与边**，不靠势。有序路径版不采用——那个"顺序"是亮度排序构造出来的，
不是真实的传导先后，会叠出伪结构。

★ **和归档侧艾宾浩斯不是一回事**（别当成重复设计）：

| | 艾宾浩斯（`markset.衰减`） | 势 |
|---|---|---|
| 对象 | **件**（标记集） | **格**（读取路径） |
| 时机 | 每归档一场 | 每次激活 |
| 决定 | **存不存**（掉到门槛以下剪出） | **激活往哪儿流** |
| 单位 | 场 | 次 |

旋钮：`势α` / `势κ` / `势噪声`（见 `参数账`）。

★ **组的两种形态**（都属于依赖簇，2026-10-18）：
① **时段种子段**：从「惊讶处」起段（种子 ± 邻）；② **相似聚类**：散格之间按**高分位阈值（p90）
＋每格只连最近 2 个** 连成组（≥2 格、≤8 格，**可跨场**）。散格不是永久散 ——
将来又被说到、或与新格够近时，会被连起来。阈值交给数据（格多线就抬）⇒ 早期聚得粗、多了自然分裂。

⛔ **不要手列的结构量。** 成员数 · 锚点跨度 · 是否连续 · 时间尺度这一路**全都不要**：

- **不可辨识**：§23.3 的机械对照**从不单独改它们**（同一个组，你没法只改"成员数"而不改点亮集）
  ⇒ 按 §23.6 同一句话（"只许改调制，否则不可辨识"），它们的效应与"取用"的效应混在一起；
- **方向反了**：奖"连续 / 集中"、罚"散在多处"，而设计 §3.1 与归档 §10.2 明说一件事**可以散在多处**、
  "同一件事说了不止一次"正是要认出来的那一类；
- **放大标注噪声**：组大小是标注的产物（同组对 Jaccard **0.37**、单成员组占比 **8%–38%**，
  而且"**不进任何组**"是它的等价写法 ⇒ **成员数不是良定义的量**）；
- 组级的"时间尺度"**字段都不存在**（设计 §3.8 的尺度是逐条挂在节点与边上的）。

| 分工 | 内容 |
|---|---|
| **强度** | ★ **判断**——读**路径叠出来的势**（⛔ 不是手列属性，也⛔ 不是学出来的参数） |
| **前 k** | ★ **预算**——机械只给预算，不给结论（`k` 是槽位数） |

⇒ 强度只决定上不上榜（**重点**）；**完整性**由内层读整组原文负责。
⇒ ⚠️ `强度 ＋ 排同一个榜` 是**第一步专属**（第二步注入的是向量，没有显式标量；那条路径变成模型内部的注意力）。
但"第一步专属"与"要攒出那张地图"**不冲突**：设计 §1.1 的"做浅"说的是别过度工程。

⚠️ **本文一度把 `max ＋ 取前 k` 判成"机械在决定结果 ⇒ 违规"——那个判断是错的。**
判断在**权重**里（设计 §4.2 原话："由比出来的**权重**决定取用哪些位置、各取多少"），
`max` 只是**读法**、`取前 k` 只是**预算**。⇒ 记在这里，免得有人再推一遍同一个错。

★★ **"一件事"在实现上长什么样**（作者 2026-10-10 定）：

```
件 = {
  点亮: [(锚点, 权重, 传播后表示)],  ← 这次真亮了的成员；★ 池化的输入
  取材: [锚点…],                     ← ★ 整组（自足节点就是它自己）；编写 读原文的范围
  强度: float,                       ← ★ 读「路径叠出来的势」（⛔ 不是 max 规则，也不是学出来的）
  代表: 锚点,                        ← 强度最高那一处（排序 / 留痕 / "先看哪儿"）
  组id | 无,                         ← 供核验；自足节点没有
  表示: 向量,                        ← ★ 同样出自池化；只能提候选与算关系
}
```

★ **两个范围不要混**：**点亮集**（强度与件间关系的依据）· **取材集**（整组；编写 读原文的范围）。
依据就是上一条——"完整性由内层读整组原文负责"。
⇒ ⚠️ **判据 4（不越界）的基准是"取材集"**，不是点亮集；否则"读整组原文"与"不许越界"会自相矛盾（见 §16.1）。

★ **件带一个向量**（作者 2026-10-10 定）。理由：**件间关系是联想的内容本身**
（"重点在这几组是怎么连上的"），而到 编写 才读原文算关系，等于把关系推迟到表达那一步，
与"**取用归 重排 · 表达归 编写**"的分工不合。
⚠️ 边界要守（设计 §3.3）：这个向量**只能用来提候选与算关系**（设计 §3.1"几何量最多用来提出候选位置"），
⛔ **不能用来决定取用**——决定仍是"池化出的强度 ＋ k 作预算"。

⇒ 件是**一次性对象**（不落库）；身份就是它的锚点，不需要持久 id。

★ 这三者还解释了"**联想发生在组与组之间**"：因为"一件事"的单位本来就是组——
传播在组间走 ⇒ 亮起来的本来就是若干组 ⇒ 输出单位天然是组。

★ **重点不在"取到了哪几组"，而在"这几组是怎么连上的"。** 联想发生在组之间，
所以**同一次浮现里一起亮起来的那几组，它们之间的关系本身就是这次联想的内容**——
只罗列各组的内容，等于把联想丢了。

依据是设计 §5.1 原话："它要说明的是：取用了哪些位置、这些位置之间是什么关系、它们合起来表达了什么。"

★★ **输出必须带关系。** 而"自包含句"那种形态（每条独立、不许用靠上下文才懂的指代、
不许出现轮号）**恰恰是把关系丢光的那一种**——`准入记录` 里那条高危假设，
在输出这一侧的形态就是"**把一组带关系的事压成若干条自足的话**"。

★ **不好描述的东西走调制，不占槽位。** 情绪、分寸、此刻的气氛，改的是"**怎么说**"
（突出哪一半、省略什么、什么分寸），**不是"说什么"**——所以它们不改变输出的形状
（还是一件事一个槽位）。
⚠️ 情绪同时还有另一个落点：**作为一组位置**（取用侧，它本身就是要想起来的东西，
见设计 §3.1"同一种情绪的若干节点被划成一组"）。**两个落点都要有**，缺一个都会走偏。

**三件事分开放**——这是"一组只亮一半"不至于变成"一件事的一半"的原因：

| | 谁负责 |
|---|---|
| **完整性** | **内层的输入**：点亮的那几个点，把**它们所属组的整段原文**一起带进内层 |
| **重点** | **权重**：点亮的那一半权重高 ⇒ 内层知道该突出哪一块 |
| **交付** | **外层**：仍然只是读取模型的输出；**对话 AI 看不到原文**（设计 §5.2） |

⇒ 实现上的一条要求：原文只在内层读一次，编写 不许另外去读（归档 §3.12A）
⇒ "整组的整段原文"要在 **重排 的产物**里就带上。由此**定长不受影响**：整组原文进的是内层输入，不是交付。

**没想起来就是没有。** 对外的结果只有两种（想起来 / 没想起来）；"没有"时不注入任何东西。

**还没定**：

1. **槽位顺序**：按权重（最相关的先）还是无序；
2. **空槽**：k 里没用到的是对外不出现，还是留个占位（倾向前者）；
3. **节点这一层的取舍**：作者 2026-10-10 说"节点不均匀铺，只是一般比较稠密"，
   所以设计 §3.1"位置是一次判断"照旧成立；但**稠密到什么程度**、要不要换一档更细的切分粒度，还没定；
4. ★ **软传播的代价**：一组只亮一半时，表达仍可能失真（编写是生成的，可能把重点说反）。
   这个洞**不能用机制兜**（兜它就是硬补齐），只能靠判据 3、4 加人读。
5. ★ **损失形状**——取用是硬是软 · 传播 · 重排 · 编写 各自的目标形态 · "判不了"怎么用 ·
   边际增益的角色。**见 §15.3"还没选"那一块**（那里只列候选，⛔ 没有结论）。

| 候选 | 聚合在哪一步 | 判断 |
|---|---|---|

| **集合排序** | 聚合**进了目标**（要一个集合分数） | ⚠️ 重复：集合分数已经由**势的池化 ＋ 前 k** 定义（见 §15.2） |
| **序列决策** | **顺序进了模型** | ⚠️ 取用顺序在取用侧没有用处（顺序属于输出侧的槽位，而槽位顺序本身待定） |
| **子集选择**（top-k 松弛） | **k 进了目标** | ⚠️ k 是输出侧的上界；放进目标就多一个旋钮 |

⇒ ★ **于是损失作用在"条目"（组 / 单点）这一级**：参数是**单元权重**，经**势的池化**
（输入＝点亮成员的**传播后表示**，见 §15.2）汇合成条目强度，再由条目级排序损失回传。
⚠️ ⛔ **不是经 `max` 这条规则汇合**——那会把**路径的形状拍平**，
把"回想有路径可循"这件事丢掉（见 §15.2）。

★ **编排归 编写，而且它已经在那儿了**：交付判据允许**改写 / 合并 / 省略**（归档 §3.12B），
而"这几件事之间是什么关系"本来就是输出的内容（设计 §5.1）。
⇒ 所以**不必把编排搬进 编写**：**取舍归 重排**（池化 ＋ k 作预算）· **编排与表述归 编写**。
⇒ ★ 连带好处：**A-b 不必成为必需**——重排与编写 各有自己的可训目标，接口只传前向产物。

⚠️ **作废一条我先前写过的推导**："集合级 BT 在单项改动下退化成逐单元 logistic"——
那个推导假设集合分数**可加**；而聚合现在定成**势的池化**（初值 = 最大值），所以推不出来。
（它一度被我当成"推出来的结论"写进本文；作者 2026-10-10 指出那只是我举的例子。）

**C 编写器的目标形态**（候选，⛔ 未定）：成对偏好（需参考模型）· **listwise 排序**（更贴 §18 的"采样 N 份一起比"）· 奖励模型 + RL（能承载标量后果）· **直接把裁判的判断当监督**（最简，但等于把裁判当标准）。
 附一处：**"判不了"是丢弃还是当平局**——平局本身说明"这两处在判据上等价"，丢弃会丢掉这条信息（⛔ 未定；但**无论哪种，都必须计数上报**，那是判官噪声的读数——M11）。

**D 边际增益当什么**：pair 的权重 / listwise 的分值 / reward（⛔ 未定）。

### 15.4 分阶段，与两态怎么不失真

**结构上**：传播与重排 合成**一个打分器**（同一个目标的两档精度，重排 才读原文）；编写 独立。
**时间上**：★ **先训 传播与重排，后训 编写**——传播与重排 的标签可以机械造、可复算；编写 要真偏好。

★★ **一处会让两步走作废的地方**：编写 的输出是**槽位向量**，第一步把它**文字化**、第二步**注入**。
如果"文字化"是自由生成的解码器，那训出来的是**解码器 + 生产器的合体**，
第二步丢掉解码器之后，**剩下的那一半没有保证还成立**。

⇒ 处置：**文字化用固定模板**（槽位 → 固定格式的一句话），**把自由度全部压在槽位向量的内容里**。
两处好处：第二步去掉的只是一层薄解码器，第一步的训练真能带走；顺带堵住"输出写成散文"。

**执行的顺序**：

| 阶段 | 做什么 | 前置 |
|---|---|---|
| **0** | 把归档立起来，产出 §23.2 那五样 | ★ 一切的前置 |
| **1** | 初始化（**参数起点**，⛔ 不是"材料"意义上的初始化，见设计 §6.5 与 `连接-工作记录.md` §1.4b）：节点表示（预训练**读取模型**起步）· 传播算子（从零） | 0 |
| **2** | 训 传播与重排（机械对照：漏 / 噪音 / 空 / 难度分层） | 1 |
| **3** | 训编写与调制（shadow 路的候选 ＋ 裁判三档） | 2（编写吃重排的输出） |

★ **固定初始化 ≠ 热启动。** 设计 §7.4 禁的是"用**上一轮的结果**做起点"；而用**同一个固定的起点**
（预训练读取模型起步 ＋ 固定种子 ＋ 固定数据顺序）是另一回事：它不带上一轮的偏差，
所以**不违反 §7.4 的理由**，而且让每一轮的差异**只由数据解释**。
⚠️ 代价：那个起点的偏差**每次都被重新引入**——热启动的偏差逐轮**累积且无法审计**，
固定起点把它变成一个**常数**：可审计、不累积，但**洗不掉**。
⇒ ★ **起点本身要有一条 `准入记录`**（预训练读取模型自带一整套假设：它见过的语料、它的分词、它的语言习惯）。

★ **跳变落在哪一侧，是有区别的**：传播与重排 的约束强（大量机械对照，不要裁判）⇒ 相对稳；
编写 只有少量偏好 ⇒ 会跳。**但 编写 的跳有一部分是设计接受的**——README 原话：
"**表述每次重新生成。同一段记忆在不同处境下有不同说法，说法用完即弃。**"
⇒ 口径：**取用侧要稳（跳 = 报警）· 表达侧本来就该变（跳 = 正常）。**

★★ **不设"联合训练"阶段。** 编写与「传播·重排」的目标不同、信号不同，而且**数据量差着量级**
（传播与重排 是机械造的对照，要多少有多少；编写 要偏好 ＋ 裁判，是最慢的一环）。联合只能靠加权和，
而那个**权重本身就是一个旋钮**——它决定两个目标谁让路。⇒ 按"少旋钮"的口径，倾向不联合。
⇒ 它们的"共享"是**接口上的共享**（编写吃重排的输出），不是损失上的共享。
⚠️ 这一条把设计 §7.1 的"它们可以联合训练"收窄了：那句要读成"**接口已按终态定**"，
⛔ 不是"损失要合并"。
⚠️ 但注意：这**不是**"⛔ 不许合成一个标量"的直接推论——那条禁忌只管**判据与读数**
（见 §15.3 的 A-c），训练侧的多任务是另一件事。

### 16.1 四条判据各自怎么读数

|---|---|
| **1 产生了增量** | 有 / 无浮现，**下游读数的中位数差**（★ 跨模型采样，防过拟合某个底座） |
| **2 该想起来** | ★ **拆成两格，分开记**：**重排 取用**——该进榜的进榜了没（条目级）· **编写 交付**——该说到的说到了没（表达级）。⚠️ 两处都能"少说"，合记就分不清是谁的锅 |
| **3 不该提** | **期望为空的样本上，取用非空的比例**（假阳性率） |
| **4 不越界** | **交付的支撑集 ⊆ 取材集** 的违反数（机械可算；⚠️ 基准是**取材集**＝整组，见 §15.2） |

★ **读数分两层，每层各读一遍**：

| 层 | 读什么 | 比另一层多给什么 |
|---|---|---|
| **答案层** | 上面那四条 | 已经影响到答案的变化 |
| ★ **表示层** | **同一批输入下的中间表示**（相似度；★ 以及**哪些组之间的影响上升 / 下降**） | ★ **早期报警**——答案还没变时它已经在变；而"重心迁移"就是**"关系演化了没有"**的可观测形态 |

⚠️ 表示层的四条纪律（都从已有的规矩里长出来）：

1. **它只回答"变了多少"，不回答"变好还是变坏"** ⇒ 报警器，⛔ 不是裁决；
2. ⛔ **参数差不可直接比**——网络有**置换对称**：功能相同的两个网络，参数可以差很远 ⇒ 要比就比表示；
3. ⛔ **它属于"给人看的量具"**：不进读取路径、不作训练特征（归档 §3.10(9) 那条纪律的第 4 处）；
4. **分析用的中间表示临时、用完即弃**（同 §5.6 对输出的待遇），⛔ 不落库。
⚠️ CKA / Procrustes / RSA 这类方法**本身是外部材料**，自带假设 ⇒ 用哪个要写一条 `准入记录`。

★ **比较要做四对，每对读两层**（前三对分"行为变化 ＝ 图的贡献 ＋ 读法的贡献"；★ **第四对才是目标判据**）：

| 比什么 | 答案层 | 表示层 |
|---|---|---|
| 同图 · 同数据 · **重训两遍** | **抖动基线** | **表示抖动基线** |
| **同读法** · 图变化前后 | 数据（图）的贡献 | 表示差异 |
| **同图** · 重训前后 | 读法的贡献（含抖动） | ★ **哪些组的重心迁移了** |
| ★★ **同一情境 · 早窗 vs 晚窗** | ★★ **目标判据**（设计 §1）——**人读**（设计 §10） | 表示差异 |
| ★ **同一情境 · 有注入 vs 无注入** | ★ 第四对**可跑的那一半**（内容的贡献） | 表示差异 |

⇒ ★ 没有第一对，"重训前后的差异"里有多少是抖动就分不清；没有第二、三对，就分不清是**节点与组**变了还是读法变了。
⇒ ★ 这四对**正好用上"图版本 ＋ 读法版本"这对标识**——它不再是记录癖，**它是比对的分组键**。
⇒ ⚠️ 都要在同一批检验题上跑 ⇒ 检验题的规模与频率是成本项（进 `参数账` §6）。
⇒ ★ **早窗 / 晚窗 ＝ 两个读法版本**（周期级，设计 §6.4.1）⇒ ⛔ 不需要新字段。

★★ **第四对必须配第一对用**：**只有超过抖动基线，"差异"才算经历造成的**。
⇒ ⚠️ 结论**哪怕是"没相关"也照报**——那正是要防"拿手段量具验收"（§13）。

★ **第四对怎么读：人读**（设计 §10："判据只有一条，人读；自动量具只做报警"）。
把"这些东西"注入（底座**冻结**、文字化用固定模板，见 §15.4），把反应与**文本里那个情境下实际的反应**
摆在一起，**给人读**。
⚠️ **"相称"这一路要小心**（推导，未验）：判别器若拿到原文**措辞**，会**静默退化成"像原文 ＝ 相称"**
（同一根指针换外壳）；而若一点原文都不给，它只能判流畅 / 长度这类**与"相称"无关**的表层特征。
⇒ ★★ **所以可跑的那一半先做**："**有注入 vs 无注入**的反应差，是否超过第一对抖动基线"——
不需要原文措辞、不涉及措辞，也不撞设计 §7.2 那条"不用下一个句子当目标"：
**受训对象**（底座冻结 ⇒ 梯度只落在"**注入什么内容**"上，落不到措辞）·
**奖励内容**（奖励"合不合"，⛔ 不要求接近原文）。

⚠️ ★ 而现在**连这个代理都还没有**：唯一的裁判判据是"能不能指回原文"（§19），
而正确答案恰是**标注者已划的那个组** ⇒ **裁判读的是标签，不是反应**。

报数照 `参数账` 的规矩：**报中位数与最大值**（实测单条耗时 6.1–107.2 s，平均没有意义），
并**必须同时报思考字数**（不报，同一格子重跑就不是同一条件——A5b）。

⚠️ 这四个读数是**报警器**，不是裁决；它们的**确切形式待标定**（进 `参数账` §6 核验）。

★★ **加池化参数之前的门槛：可辨识性先于参数。**

> **进强度的那一路，必须随情境变化。**
> 手列的组属性（成员数 · 锚点跨度 · 是否连续 · 时间尺度）**不满足**——§23.3 的机械对照
> 从不单独改它们，它们的效应与"取用"的效应混在一起（同 §23.6"只许改调制，否则不可辨识"）。

判定手段用仓库自己的噪声底：

| 量什么 | 怎么量 |
|---|---|
| **路径那一路的抖动** | 同一批检验题上，**同读法 · 图重判前后**的强度排序抖动 |
| **参数那一路的抖动** | 同一批检验题上，**同图 · 重训两遍**的强度排序抖动 |

⇒ 若**前者与后者同量级或更大**，说明强度主要是**标注的产物**，加/训池化只会放大它。
★ 好处：**这条不依赖训练流程跑通**——只要有两次重判的图，现在就能量。

## 17. 材料与信号

**材料 = `(情境, 该浮现什么)` 对。**

| 部分 | 从哪来 | 能不能生成 |
|---|---|---|
| **情境** | 从底片采样真实触发 / 半合成改写 | ★ **可以生成** |
| **该浮现什么** | 多份候选（采样 N 个）⇒ 两两排序 | ★ **可以生成** |
| ⛔ **底片本身** | —— | ⛔ **不许生成**（事实源不能造） |
| ⛔ **进池子的东西** | —— | ⛔ **不许是生成的** |

⇒ 一句话：**情境可以造，浮现可以多造；底片与进池子的东西必须是真实发生过的。**

| 信号源 | 管哪条判据 | 在哪一侧 | 成本 |
|---|---|---|---|
| **边际增益**（有 / 无这段浮现，下游差多少） | 判据 1 | ★ **测试时**（或重放时）量，训练时用 | 自监督 |
| **采样 + 两两排序** | 判据 2 / 3 | 测试时存档，训练时比较 | 要能重放 |
| **归档时的模型自己出卷子** | 判据 4 + "表达偏离意图" | 归档时 | 几乎为零 |

⚠️ **边际增益用的是"下一句概率的差"，不是"下一句概率"本身。** 它把下一句概率当**量具**，
不当**目标**——设计 §7.2 禁的是把预测当目标，不是禁这个读数。

## 18. 主形态：采样 + 两两排序

```
同一情境 ⇒ 采样 N 个候选浮现 → 两两比较排序 → 取靠前的继续采样、继续比
```
⇒ ★ 这一步把训练从"只能标日志"变成"**可以造日志**"：**没有对照就没有训练，有了采样就有了。**

```
主路（真实）   ：当前读法 → 浮现 → 真的说出去 → 进底片        （不打扰）
shadow 路（离线）：同一情境 ⇒ 采样 N 个候选 ⇒ 只存档，不发出   ⇒ 事后比较 / 重放 ⇒ 偏好对
```
★ **shadow 路同时就是卷子的基础设施**：同一个机制既产训练数据、又产量具读数
⇒ 顺手解开"量具必须早于训练"的先后矛盾（两件事是同一条路）。
⛔ 硬约束：**候选一个都不许进池子。**

---

## 19. 三条防护 + 裁判的约束

**三条防护**（否则会绕回"越来越像他"）：

1. ★ **别用"预测"，用"边际增益"**——判据是"有这段浮现 vs 没有它，差多少"，⛔ 不是"概率高"本身；
2. **方差过滤**：只在两个候选**差得明显**时取这一对；
3. ★★ **监视"代理 ↔ 目标"的偏离**：定期看"浮现是不是越来越像他的原话"（相似度 / 措辞重合）⇒ 一起就往回拉。

**下游模型可以当裁判，但约束必须提前讲清**：

- ⛔ 不许用"流畅 / 通顺 / 像话"当理由；
- ⛔ 不许奖励"更顺着他说"（谄媚）；
- ✅ 按"这段经历有没有被正确表达"判，判据是**能不能指回原文**；
- ⚠️ **判不出时，必须允许它输出"判不了"**（否则它会硬给一个）。

★ **防过拟合底座**：偏好好的"下游"要**跨模型采样**（同一候选用两个不同底座各跑一遍）
⇒ 学的是"表述本身好不好"，不是"某个模型喜不喜欢"。

## 20. 卷子（量具）

★★ **先按设计的定位**（设计 §7.2 / §10.1）：**检验不用于训练本身，用于判断读取有没有被带到错误的方向。**
⇒ ⛔ 它**不是训练标签**——一度被本文这么用，那是错的。
训练信号来自**图的用途**（设计 §7.2）：**后果** · **对照**（主要形态）· 检验只判方向。
⚠️ 但 ★ **"内容是图给的"不是问题**：设计 §7.3 明说"应当取用的内容……必须落在原文上——**图是它的唯一来源**"。
被禁的只是拿**图的结构**当**信号**（§11.2 第 12 条）。两件事不要混。

- **两个出题来源**：**底片采样**（答案是逐字原文 ⇒ 测"有没有丢 / 有没有编"）·
  **归档时的模型自己出题**（它最清楚当时想抓住什么 ⇒ 测"记录与当时意图的偏离"）。
- **三条纪律**：答案必须落在底片上 · 题目要能证伪 · 出题时的意图要留档。
- **配套工程件**：**留档归档时的对话窗口**，核对时 fork 一个来问——**只读，结论不写回**。
- **定位**：不是静态文件，是**随归档增长的机制**（每个版本内固定，跨版本按同一版本取）。
- ⚠️ **反面**：**越追求可审 ⇒ 越往离散漂**。不许为了可测把表示推向离散。

### 20.1 出题：两个来源，各测一件事（照设计 §10.1）

| 出题者 | 怎么出 | 测什么 |
|---|---|---|
| **从原文采样** | 从定稿的原文里取样，**答案是逐字原文** | 该取用的取到了没有（假阴性）· 取回了没发生过的没有（假阳性） |
| **标注当时的模型** | AI 自己出题——它知道当时想表达什么 | **"记录"与"当时的意图"偏离了没有** |

⇒ ★ **第二个来源补的正是第一个测不到的那一格**；而它**必须**在同一个语境里问
（设计 §10.1："出题的那次对话要留档，核对时回到当时的语境去问——**只读，结论不回流**"）。
⇒ ⛔ **但它因此不能兼作"取用"的题**：那会变成拿图的结构当信号（撞设计 §11.2 第 12 条）。

★ **三条纪律**（设计 §10.1）：答案必须落在**原文**上 · 题目要能**证伪** · **出题时的意图要留档**。
★ **检验集随材料增长**（每个版本内固定，跨版本按同一版本取）。

⚠️ ★★ **实测两处与上表不符**（2026-10-10 跑批，属**实现欠账**，⛔ 不是设计）：

1. **现有 13 题全是"线索 ＝ 答案"**——`跑归档.py` 给两路填的 `情境位置` 与 `答案` 是**同一个区间**（实测 13/13）。
   ⇒ 那测的是"这段还在不在"，⛔ **测不了取用**（检索是"线索 → 位置"）。
2. **出题与建图是同一对话、同一个 AI**——出题前的原话是"**刚才那份产出，就是你标出来的记忆**"；
   实测 q3–q12 的答案区间 **10/10 都被某个图节点包含**。
   ⇒ 这一路测"意图偏离"是**对的**（它就该在那个语境里），⛔ 但**不能兼作取用的题**。

★ **`组说明` 是出题的素材**：它给出"这一组说的是什么"⇒ 答案＝那一组的位置，线索＝能引出它的情境。
（所以 §15.2 要求每次判断都说出"具体是什么"——它不只服务于核验。）

## 23. 数据集

★ **唯一的约束是：兼容归档（dreaming）阶段。** 也就是说——**数据集就是一次归档的产物**，
所以任何语料都只要**喂进同一条路**，不需要为它写适配。

⇒ 这一条是设计 §6.3"统一路径"在数据侧的兑现：**为每份语料写适配器，等于按来源分流**，
只是分流点从流程挪到了数据集。

### 23.1 输入契约

```
原文（逐字）＋ 来源软标记（只给核验）
```

⛔ 不需要语料自带的标注，也不需要它的字段格式。
★ **外部标注最多当核验**（"我们出的题跟它标的对不对得上"），**不进口数据集**——
卷子的答案是**逐字原文**（§20），"该取用哪些完整单元"由**卷子 + 采样排序**自己产。
⇒ 于是"借来的真值只是代理"这个问题**不存在**：不借，就没有代理。

★ **第三方文本（小说等）的准入纪律**（作者 2026-10-10 起用小说当连续语料）：

| 能供 | ⛔ 不能供 |
|---|---|
| ★ **"重提密度"**——伏笔 · 回忆 · 旧事重提 ⇒ 正是唯一弱标签"**他后来是不是又提到了**"的供给源 | **关于他的真实信息**（全是虚构的）⇒ 只能供通用读法 / 人设 / 关系结构 |
| 长程连续的原文 ⇒ 跨窗的**关联**有地方落 | **间隔**（设计 §6.2：间隔不产生材料）· **对方的反应**（§17 的"后果"那一源） |
| 取用真值（可出题） | **后果 / 边际增益** · **调制对**（离线只能模拟） |

⚠️ **第一人称的陷阱**：小说的内心独白是**写出来的**（"我心里一紧"）⇒ 在这上面训出来的读法
会在"**直接读到情绪**"上过拟合，在"**从别人的话里推断情绪**"上不足——**而后者才是陪伴最需要的**。
⚠️ **`<主人>` 是测试装置**（假装小说主角是他的对话对象），要标出这个性质，别当成设计元素。★ **该装置已移除（v16）**（`99_归档/标注提示词-2026-10-16/标注提示词-更改.md` v16 行）；但**这条教训照旧有效、必须留着**：**测试装置不许混进设计**。
⇒ ★ **一个 doc_id 装整本**（位置共享、组不跨文档），**每次归档只吃一个窗** ⇒
跨章的关联靠**多次归档累积**，⛔ 不能指望一次归档就得到长距结构。

### 23.2 产物（＝数据集）

| # | 产物 | 依据 |
|---|---|---|
| **1** | **图**：cell（锚点区间）＋ **依赖簇** ＋ 待观察池 ＋ 版本 | §3 · §5 |
| **2** | **记录**：修订留痕 · 指纹 | §5 |
| **3** | **卷子**：题目 ＋ 答案落在原文 ＋ **出题意图留档** | §20 |
| **4** | **材料**：情境（位置）＋ 该浮现什么（**一组完整单元**）＋ 多份候选 | §17 |
| **5** | **逐轮记录**：刺激 / 期望 / 激活（**候选与分数**）/ 参数 / 成本 | 设计 §7.6 |

另加两样不占位但必须有的：**版本对**（图版本 ＋ 读法版本，设计 §6.4.1）与**指纹**。

★ 这五样合起来就是**一次归档的全部产出**；★ **模型读到的只有其中的「节点与组」**（⛔ 不含边——边不作为输入喂给模型）；候选只在 shadow 路里活着，⛔ 不进池子（§18）。

### 23.3 对照怎么造

§17 那三条信号源里，**传播与重排的候选对可以机械造**，不必等裁判：

| 规则 | 做法 | 训哪条 |
|---|---|---|
| **漏** | 从期望集里去掉一个（去掉的越重，负得越多） | 判据 2 |
| **组内噪音** | 加一处**与期望同组、但这次没被期望**的位置 | ★ 测"软加成有没有过度"（正对上"不许硬补齐"） |
| **同材料 / 跨材料噪音** | 加无关位置（**难度分层**：同材料 < 跨材料） | 判据 3 |
| **空 vs 非空** | 期望为空时，任何非空取用集都更差 | ★ 判据 2 / 3 的核心 |
| **越界**（只对编写） | 渲染里出现**取材集**之外的内容（机械可查的那部分自动生成） | 判据 4 |

★ 每条对照都要留 **`生成规则`** 这一列：机械负例与裁判负例的可信度完全不同，混成一堆以后分不开。
★ **只有 编写（编写）需要真偏好**：三档标签（A / B / 判不了），见 §19。

### 23.4 三处不是从语料来的设计约束

1. **关系类型只作记录，不进损失**——设计 §3.6 **不设分类上限** ⇒ 不存在可对齐的类型空间
   ⇒ 类型不能当标签；
2. **空集是合法标签**——README"会忘" ＋ 判据 2、3 ⇒ 必须有"**这次什么都不该想**"的样本；
3. **按材料划分，不按轮**——同一份材料的轮之间会泄漏。

### 23.5 顺序上的后果

★ 这条约束把**归档（dreaming）从"待搬的设计"变成"必须先有的东西"**——
数据集是它的产物，而仓里现在只有**建图**那一步（`tools/标注/annotate.py`）。
**压缩 / 选择 / 核对**（设计 §6.4.2）、**出题**（§20）、**造材料**（§17）**都还没有**。

```
先把归档立起来（第 0 步需要的那几件）→ 语料才变得了数据 → 才谈训练
```

⇒ 所以"不完美但能跑"的第一个里程碑是：**一份语料进去，一次归档，五样产物出来。**

### 23.6 调制的数据格

**调制本身只是一个地址范围**（近处 = 自上次归档以来；离线数据里 = **线索之前的那一段**）。

★★ **但它只吃偏好信号——这是结构性的，不是选择。** §23.3 的机械对照**每次都固定调制、
只改取用**（漏 / 噪音 / 空），所以那些对照对调制**不携带任何信息**：
调制的效果在那里**不可辨识**。

⇒ 要学调制，对照必须**只改调制、不改别的**：

| 字段 | 内容 |
|---|---|
| `调制` | 近处的地址范围 |
| ★ `调制对` | **同一线索 · 同一期望取用 · 不同的调制** 的一对 ＋ 三档标签 |
| `来源` | **偏好**（裁判或人）——没有机械判据 |

⇒ ★ 结论：**编写 与调制共用同一批偏好数据**（都出自 shadow 路 ＋ 裁判）。
⛔ 构造调制对时**只许改调制**，否则分不清是调制还是别的东西在起作用。
⚠️ 连带：调制的学习速度因此受**偏好数据量**限制，比 传播与重排 慢得多。

**调制对怎么造**（离线）：取同一条线索、同一个期望取用，**只换调制**。
离线语料里"调制"就是**线索之前的那一段**（模拟"自上次归档以来"）⇒
同一线索配**两个不同的前置窗口**（例如切在第 1 段后 / 切在第 3 段后），
就得到一对"同线索、同期望、不同调制"。
⛔ **线索与期望必须逐字相同**——否则这一对判不出是谁在起作用。
标签仍是三档，来源必须是**偏好**（裁判或人）。

### 23.8 跑一遍：步骤与校验

```
1. 装载   原文 → doc_id ＋ 定稿（只修采集故障，且在建图之前）
2. 建图   多视角 · 并行多轮 · 按设计 3.5.1 各自降噪  → 标注 ＋ 标注记录
3. 出卷子 底片采样 ＋ 归档模型出题（留档窗口）        → 卷子
4. 造材料 取情境 → 取期望 → 采样候选 → 机械造对照（§23.3） → 样本
5. 落盘   五样 ＋ 版本对 ＋ 指纹；**一份原文一组**
```

★ **现状**：只有第 2 步的**建图**有工具（`tools/标注/annotate.py`）——跑之前要先补其余四样（见 §23.5）。

**每次落盘必过的校验**（机械、可复算）：

| # | 校验 | 不过就是缺陷 |
|---|---|---|
| 1 | 所有锚点 `取(doc,start,end)` **逐字取回** | 地址错 |
| 2 | 引文**唯一命中**（多处命中＝歧义） | 定位方式有问题 |
| 3 | `期望取用` 的每一处**都落在原文上** | 标签不是位置 |
| 4 | 每条候选的 `生成规则`**非空** | 机械负例与裁判负例会混 |
| 5 | **候选与候选的产物在节点与组里找不到对应节点**（不进池子） | 违反硬约束 |
| 6 | `组` 的成员**同属一个 `doc_id`** | 组跨文档了 |
| 7 | 版本对与指纹齐全 | 复现不了 |
| 8 | **没有整窗失败**：这一窗该跑的 视角×遍 **都解析成功**（⛔ 判据**不是**"出了节点"） | 有窗没跑完 |

★ 1–3 是"**尺子**"（M11：核验器自己要先对）；4–7 是**硬约束**。

★★ **第 8 条的口径必须是"解析完整"，不能是"出了节点"**：**空集是合法标签**（§23.4-2）——
这两条材料本来就**没有一处值得记的位置**时，正确答案就是**空图**。拿"没节点"当失败，等于把"确实没得记"这一整类
**负样本**判成窗失败并且不存档，而那恰恰是这批数据里最该有的东西。

> ⚠️ **加注**：**原理由出自 v15，已作废**——那版把这一类窗写成"主人不在场的窗"，而 `<主人>` 装置**已在 v16 整个移除**（`99_归档/标注提示词-2026-10-16/标注提示词-更改.md` v16 行），**该类窗不再产生**。
> ★ 本加注**只换理由，结论一字不动**（空集仍是合法标签、空窗数仍必须报出来）。
⇒ 代价要写明：模型偷懒交空图也会被收下 ⇒ 所以第 8 条**必须把空窗数报出来**（`空图 N 个：章号`），
让它是个看得见的数，而不是一个默认值。见 [`99_归档/标注提示词-2026-10-16/标注提示词-试跑.md`](99_归档/标注提示词-2026-10-16/标注提示词-试跑.md) 试跑 17。

### 23.9 跑批已踩出来的细节（2026-10-10 首次跑通归档管线）

★ **一次归档 ≠ 只能标一个组。** 实测一次归档标出 **3 个组**（成员 22 / 9 / 4）。
⚠️ 但那次只产出 **1 条材料**（`样本 id = …-g0`）⇒ **"组数"与"材料条数"是两件事**：
3 个组起码该造出 3 条以上。这是**造材料**那一步的欠账，不是标注只能标一个组。

★ **多视角必须分多次请求，一次只用一个视角**——⛔ 不是"一次请求里又标事情又标情绪"。

| 依据 | 内容 |
|---|---|
| **实测** | v4 把三种混在一次里 ⇒ 模型立刻用"同一类事"去装属性桶（把出生日期＋出生地＋祖籍＋职称＋别名合成一组）；v5 拆成三视角、一次一个 ⇒ 修好 |
| 设计 §3.5.1 | 各视角**各自降噪、不跨视角取一致** ⇒ 混着给会造出一张**不存在的第四张图** |
| 设计 §3.5 ＋ 试跑 6 | **换视角连节点本身都会换**（六组对照全部同向）⇒ 节点那一层也不共用 |

⇒ 成本就是那个乘法：**视角数 × 遍数 × 窗数**。

★ **判据不写成"可判的一句话" ⇒ 模型会倒向极端**（实测）：

> v0"一个具体的事、一个明确的观点、一种情绪**都值得记**" ⇒ **13 节点 / 13 轮（全标）**
> v1"**不是每处都要标**，大部分话只是承接、招呼、语气" ⇒ **0 个节点（全不标）**
> ⇒ **两次都严格照做。**

⇒ 所以判据要**可判**，并**明说两个方向都会错**。改完实测：支持者轮覆盖率 **33% → 100%**、
漏标 **21/30 → 0/30**、行均节点 0.33 → 1.00（**没泛滥**）。

★ **"一章 ＝ 一次归档"的三点注意**：

- ⚠️ **窗边界**：正好切在章边界会把一句话切两半 ⇒ 留少量重叠，或按自然段收尾；
- ✅ **组事实上限于一个窗**（一次标注只看一窗）⇒ **跨章的"同一件事"只能靠关联**，⛔ 不能靠组
  ——这与 §25"跨材料的关联只有训练能建"**完全对齐**；
- ★ **归档每章一次，但重训要解耦**：重训按"**可学关联增了多少**"批量触发（§24），⛔ 不是每章都重训。

★ **出题那一步会撞上下文窗口**：实测前三次跑都报
`HTTP 400 input exceeds the context window`（最后一次跑通）⇒ **喂给它的范围要写清：是本窗**，
⛔ 不是整本书。

★ **两个"视角"别混**：

| | 是什么 |
|---|---|
| **叙述视角** | 谁在看（主人公 / 全知）——**文本性质**，与标注无关 |
| **标注视角** | 按什么标准分组（设计 §3.1 的三种）——**设计里的"多视角"** |

⛔ **"关于主人公的资料"不是第四个标注视角**——那是**话题**，而实测"话题不是类"（会变成筐）。
它该是**题目要问的内容**（§20.1），不是分组标准。

★ **每次判断都要说出"具体是什么"**（落在 `组说明`，**只进记录、不进图**）：
说不清就不许合——"同一种 X"里的 X 必须能被指认出来，否则它不是判据，是个筐。
★ 而 `组说明` 同时是**出题的素材**（§20.1）。

★ **小修**：`读法版本` 现在写的是 `null`。第 0 步的读法 ＝ 提示词 ＋ 模型 ＋ thinking
⇒ 应由提示词指纹 ＋ 模型/路由 ＋ thinking 显式值拼出来，别留空（设计 §6.4.1 的版本对）。

## 24. 重训

**两个时钟**（设计 §3.5）：**重提取**（图）可以局部、频繁；**重训**（读法）要**少而批量**。
两者频率不同，其间读法滞后于图。

★ **按现在的架构，重提取的爆炸半径小了**：关系靠算、不落库 ⇒ **库里只有节点与组** ⇒
设计 §3.5 那个触发量"**被替换节点的比例**"现在只反映地址与组的变化（原来还要算边）。
⇒ 重提取可以更频繁，重训阈值可以更松。

★ **不增量，整套重来**（设计 §7.4）：⛔ 不从上一轮的结果接着训。
⇒ 每轮重训都要**从当时的节点与组与原文重建训练集**。
⇒ ★★ 所以"整套重来"负担得起，**只因为数据集是可重建的**——它是归档的产物（§23），
而归档可重跑。这也是 §23 那个"唯一约束"换来的实际收益。

★ **若用需要参考模型的那类目标**（如 DPO 形状，见 §15.3 编写，⛔ 尚未定）：
**参考模型 = 这一轮的起点**（初始读法版本），⛔ 不是上一轮训练的结果。

★ **不对齐程度**不触发重训，但要**登记**（设计 §3.5）：同一批检验在图变化前后各跑一次，记下差值。

★★ **连续性不由读法承担，由材料与图承担。** 次次全重训会得到**截然不同的解**——这是正常的
（非凸 ＋ 随机初始化）：确定性只保证"同一份数据 ⇒ 同一个解"，
**不保证"数据变一点 ⇒ 解变一点"**。
⇒ 所以"内部状态的连续过渡"（设计 §1.3）**不能挂在读法上**；它的载体是
**材料与图**（累积、从不重来）＋ 调制。
⇒ ★★ 这也解释了"整套重来"为什么在这里无害：**被重来的只是读法，而经历一直累积。**

★ **"增量重训"这笔交易（目前不做）**：设计 §7.4 禁增量，理由不是洁癖，是**可归因**——
只有每次从头，行为的差异才**只能来自数据（经历）**，而不是来自上一轮的路径。
⇒ 若以后要走增量，必须**同时放弃"可归因"**；那要按 `文档规范` 进 `决策记录`
（决定 / 理由 / **被否掉的方案** / 能否回退）。

★★ **触发量是两个，不是一个——但不按"材料增长 / 重标注"分。**

先把两个词指清楚（本文后面全按这个口径）：

| 词 | 指什么 | 落不落库 |
|---|---|---|
| **节点与组**（旧称"图"） | **缓存**：cell（锚点区间）· 依赖簇 · 待观察池 · ＋ 地址 | ⛔ **缓存**（＝ 原文 ＋ 读法版本的函数，可重算） |
| **训练产的关联**（＝设计 §3.6 表里"训练"那一类） | **读的时候算出来的关系** | ⛔ 不落，★ **只存档**（每次现算的判断） |

★ 落点分三类：**存储**（原文 · 参数 · 记录）/ **缓存**（库）/ **一次性**（设计 §3 开篇）。

★ 还要分清"之内"说的是哪一层：**组在一份原文（一个文档）之内**，
⛔ **不是在一个归档批次之内**——归档会把一段时期内的**多份**原文并起来处理（设计 §6.4），
但**组不跨文档**。

⇒ 由此一个关键推论：**组不跨文档 ⇒ 新材料改不了旧材料的组。**
所以设计 §3.5 的前半句"**材料增长 ⇒ 图只增不改**"**在"图"这个意义上是对的**。

⚠️ **错的是它的后半句："⇒ 训练仍然对准（不需要重训）。"** 因为——**图没变，但要学的东西变了**：
新材料带来了新的**可学关联**（"他后来是不是又提到了"），而关联**只有训练能建**（归档 §3.9(4)）。

⇒ 于是两个触发量各管一件事：

| 触发量 | 量什么 | 由什么引起 |
|---|---|---|
| **节点与组变了多少** | 节点与组的分布变动比例（新增 ＋ 被替换） | 主要是**重判噪声**——同一份原文重判也会变（实测同组对 Jaccard **0.37**，试跑 7）；混着重新标注的改动 |
| ★ **可学关联增了多少** | 新材料带来多少新的"他后来是不是又提到了"（⚠️ **计数口径待标定**，进 `参数账`） | ★ **材料增长** ⇒ **这才是"材料增长要触发重训"的理由** |

★ 而"**旧连接断开**"据此重新落位：关联不落库 ⇒ 断开发生在**参数**里 ⇒
它**不是图的变化，是读法的变化**（没有任何对象要删）。

⚠️ 一条副产物：**重训频率 = min（可学关联攒到阈值，偏好攒够）**——前者是新材料给的，后者是裁判给的。

★ **"重判抖动"是一条必须立的基线**（数据侧）：既然重提取是"重判一遍"，而重判本身有抖动，
那么"行为变了"可能是**经历**，也可能只是**重判了一次** ⇒ 与"重训抖动"（参数侧）一起，
构成"变化必须超过的噪声底"（见 §16.1 那三对比较）。

⚠️ 重训频率还有一个上限：**调制与 编写 只吃偏好数据**（§23.6）⇒
**偏好攒得多快，重训就有多快**；而偏好要裁判 ⇒ 它是这条链上最慢的一环。

## 25. 强调：三条回路

对方在对话里的**强调**是一份特殊材料——它同时喂三条回路，而三条回路的时间尺度差很多：

| 回路 | 什么时候生效 | 靠什么 | 要训练吗 |
|---|---|---|---|
| **调制**（当下） | 本轮对话内 | 输入流（**图不变**） | 不要 |
| ★ **跨材料的关联** | **归档 ＋ 重训之后** | **组与组之间的相关——学出来的** | ★ **要** |
| **读法改良**（出题） | 更晚 | 归档时出题 | 要 |

★ **两条要训练的，是同一个来源喂出来的**：这里的"强调"正就是归档 §3.9(4) 说的那个
**唯一弱标签来源**——"**他后来是不是又提到了**"。
⇒ 一句话：**关系演化的燃料，就是对方一次次的重提。**

⚠️ **一处容易搞错的（本文一度写错，记在这里）**：跨材料的关联**不是"归到同一组"**。
组在**一份原文（一个文档）之内**；跨材料的那个东西是**关联**（设计 §3.6 的"边"），
而**关联只有训练能建**（归档 §3.9(4)）。
⇒ ❌ 不能用"组内软加成"去解释它——那是把跨材料的事塞进材料内的机制里。

⚠️ **慢约束**："归档后下一轮就能带出来"**只在重训发生过之后成立**。两次重训之间，
同样的输入**还是带不出来**——因为通路在参数里，不在**节点与组**里。

⚠️ **边界**：**不带内容的强调**（"你忘了""我说过的"）本身**不含那件事的内容**
⇒ 它连"可供关联的新材料"都没提供（新节点得由内容产生）。要让它有用，只能靠归档时的模型
**从上下文判出它指的是什么**——那是判断，而且不可靠。⇒ **记成假设，别当机制。**
