## 八、「多归属」那一层（2026-10-17 · 作者定 A · 已做）

**问题**：真对话第 2 场里归档 0 次"归进" —— **不是模型乱判**，而是它判得**窄**：
"年糕踩键盘" 和 "年糕拍肩求抱" 被它判成**不是同一件事**（它只看得到候选件的**代表**，看不到全部成员）。

⇒ ★★ **于是有一个自我强化**：**件窄 ⇒ 判"不是同一件事" ⇒ 新建 ⇒ 件永远窄** ——
**和"盲区自我固化"是同一个病，换了个位置。**

**作者给的解法（A）**：**⛔ 别把"件"当唯一定语** —— 三种"关系"可以同时挂在同一个件上：

| v16 的视角 | 结构 |
|---|---|
| **同一件事** | **件** |
| **同一类事 · 同一种情绪 · 别的什么** | ★ **块**（**关系名由模型自己起**） |

⇒ **一个件可以同时落在多个块里**（多归属）；**同名 ⇒ 同一个块（连通块）**。

**已做**（最终形态 —— 块的**关系名是自由文本**）：
- `graph.py`：`块 = {id, 关系, 成员, 说法}` ＋ `加块`（同名 ⇒ 复用）/ `并块`（同名 ⇒ 同一个块）/ `件的块`
- `⑤` 的提示词从**一问**变**两问**（【一】同一件事 · 【二】**因为什么连在一起** ＋ 给个短名字）
- `完成()`：按关系名 **并块**
- `recall.py`：**块内边**（`块内边权重 = 1.0`）· **同场共现按轮距衰减**（`base/(1+轮距)`）

⚠️ **中途改过一次**：先做成"视角写死 ∈ {类, 情绪}"，作者否掉了 ——
「**得能自己增加块才行**，两个槽太粗」。⇒ 改成**关系名由模型自己起**。

**验证**（自由关系名 · 重跑两场）：6 个块，名字都是具体的：

```
块-0001「工作硬撑」      件-0005, 件-0001
块-0002「打开编辑器」    件-0005, 件-0002
块-0003「记忆系统的事」  件-0006, 件-0004
块-0004「怎么串起来」    件-0006, 件-0004
块-0005「猫的事」        件-0007, 件-0003   ← ★ 年糕那两件
```

★ **多归属真的是多**：件-0005 同时属于「工作硬撑」和「打开编辑器」；
件-0002 同时属于「打开编辑器」和「自己那摊东西」。
⚠️ **名字粒度不齐**：「猫的事」像一个类，「打开编辑器」更像一件具体的事 —— 模型判断的差。

**✅ 边权那个问题（已解）**：原来「同场共现」是"同场就全连、权 1.0" ⇒ 图**全连通** ⇒

## 九、把「块」改成「边」（2026-10-17 · 作者定 · 已做）

**问题**：块是模型起名 + 模型判成员的 ⇒ 三次重跑出 **13 / 6 / 5** 个块，名字还漂
（「没人等的活」/「没人等着要的活」；「那套系统」/「徒手挖墙的耗」**是同一对件起了两个名**）。
我一度加了两道补丁：**让 prompt 复用已有名字**（13→6）、**按 Jaccard 去重**（→5）——
★ 但**两次都只是压数**，根子没动。

**作者那句话是钥匙**：「**合并也行、不合并也行**」——
⇒ **如果"选哪边都行"，那它就不是存储该有的东西，它是视图。**

**改法**（`流程框架 §3.1.4`）：

```
存：边 = {a: 件id, b: 件id, 关系: 自由文本, 说法}    ← 原子，pairwise
派生：块 = 某关系名下的连通块（并查集）              ← 随时算，⛔ 存
[R] 传播沿边，⛔ 沿块
```

⇒ ★★ **"同一对件起了两个名字"不再是冲突** —— 那是**两条不同关系的边** ✓
⇒ ★★★ **而这也正是作者最初那句**：「一个节点-组可以归在**不同的边**里」——
**边才是原子，⛔ 组**。我把它实现成了"组"，绕了一圈又回来了。
⇒ **「块去重」整段删掉**（不需要了）。

**验证**（同一批底片，从零重跑三次）：

| | 三次 | |
|---|---|---|
| **件** | **13 / 13 / 13** | ✅ |
| **边** | **18 / 18 / 16** | ✅ |
| **块（派生）** | **5 / 6 / 4** | ❌ |

⇒ ★★★ **稳的是件和边；抖的是块** —— 一条边的差别就能把两块并掉或拆开。
