# 标注提示词 · 设计

**这份放"为什么这么写"**：判据从哪来、为什么这么落地、以及还没定的事。
提示词本体在 [`标注提示词.md`](标注提示词.md)，逐版改动在 [`标注提示词-更改.md`](标注提示词-更改.md)，
跑出来的结果在 [`标注提示词-试跑.md`](标注提示词-试跑.md)。

---

## 1. 一次标注 = 一个视角

`设计 3.1` 给组列了**三种**情况：**同一件事 · 同一类事 · 同一种情绪**。
它们**是三个不同的分组标准，不是一次判断里的三个选项**。

依据是 `设计 3.5.1`：

> **多视角**：不同的标准 ⇒ 本来就应该不同 ⇒ **每个视角各自降噪，不跨视角取一致**。

**混着给的后果是实测出来的**：v4 把三种混在一次里，模型立刻用"同一类事"去装属性桶——
同一条 KdConv 上把「出生日期 + 出生地 + 祖籍 + 职称 + 别名」合成一组。
而**按"同一类事"这个标准，那一组是对的**；它之所以看着别扭，是因为它和
"同一件事"那张图混在了一起。混出来的东西**既不是这张图，也不是那张图**，
而 `设计 3.5` 说图不是唯一的、每张图带版本标识。

**怎么落地**：三个视角**共用同一份"节点"判据、硬要求与输出格式**，
只有"组的判据"和"例子"两段不同。所以本体里写成：

| 块名 | 内容 |
|---|---|
| `公共` | 节点判据 + `<组判据>` + `<例子>` + 硬要求 + 输入 + 输出 |
| `组-<视角>` | 这个视角的分组判据 |
| `例子-<视角>` | 这个视角的例子（**各自一份材料，只为这个视角服务**） |

拼装由 `tools/标注/annotate.py` 的 `load_prompt(视角)` 做，**缺哪一块就报错**
（不许静默少一段——这是本项目栽过三次的坑）。

**一条操作约束**：三个视角的结果**各自成图**，**不得跨视角投票**（`3.5.1`）——
那会造出一张不存在的第四张图，而且会把各视角特有的关系投票掉。

## 2. 每条判据的来源

### 2.1 "值得记"必须给判据，不能给形容词

v0 写"一个具体的事、一个明确的观点、一种情绪**都值得记**" ⇒ **13 个节点 / 13 轮**，全标。
v1 写"**不是每处都要标**，大部分话只是承接、招呼、语气" ⇒ **0 个节点**。
**它两次都严格照做。**

⇒ 所以判据要**说成一句可以判的话**（"这段文字是不是在说一件具体的事"），
并且**明说两个方向都会错**——只在一侧加力，它就会往那一侧倒。

### 2.2 禁令不取消行为，只让它换个名字出现

v1/v2 明说"只说得出来谁接在谁后面的，不要写边"。实测：模型**没写"顺序"，
它把顺序改名叫了"起因"**——一条 KdConv 上 7 条"起因"边**同一端全是同一个节点**。

⇒ 处置不是把禁令写得更狠，是**把这件事从这一步的任务里拿掉**（v4 删掉边整节），
以及**一次只让它做一个判断**（v5 拆视角）。
⇒ 由此得到一条通用写法：**"不行"清单替代不了"这件事该归到哪里"。**

### 2.3 判据的"糙"与"细"不是文风问题

"同一种情绪"糙在**它不需要说出是哪一种**——说一句"都有情绪"就能把任何几处装进去。
v6 改成"**同一种具体情绪**"：**要能说出名字**（自我否定 / 委屈 / 强撑…），
**说不清就不许合**，并且写明"方向相反的两种情绪不能合一""都是负面的不算"。

⇒ **一般形式**：**判据里凡是出现"同一种 X"，就要问 X 能不能被指认出来。**
指认不出来的（"有点复杂""不太好受""都是负面"），就不是判据，是个筐。

### 2.4 `组说明` 只进记录、不进图

依据 `设计 3.2`：标注记录装"模型写下的理由与概念名"。
名字落进记录有三个用处：**能复核**（凭什么合的）、**能统计**（哪几种判据反复被用到）、
**能回看**（下次标注时知道上一次怎么分的）。
而它**不进图**的理由是 `3.3`：含义只作标注，进去会变成几何。

⚠️ **它会改变行为**——要求说理，模型会更斟酌。所以带 `组说明` 的版本
（v6 起）**不能与不带它的版本混着比**。

### 2.5 为什么用"引文"而不是"起止位置"

模型数不准字符位置。给它"起止位置"，它会编一个看起来合理的数字，**编错了看不出来**。
改成交出原文片段，**定位由机械做**：查不到就报错，查出多处就报歧义。
⇒ 于是"锚在原文区间上"这条约束**由机械保证**，不靠模型的自觉（`3.1` 的准入约束）。

### 2.6 为什么组不带类型、不带名字

组说的是"这些属于一起"。给它取名字，等于把一次判断变成一次命名，
而名字会被下一次读到（`3.2`：记录里的措辞会带偏下一次标注）。
⚠️ 三个视角的**块名**（`组-同一件事` 等）是**我们这边的档位名**，不进产出、不进图。

### 2.7 为什么标注不产出关系（v4 起）

一句话：**"该不该连"是判断，"连起来叫什么"是另一次判断，
而后者要等前者定了再做——对是给定的，它就编不出来。**
（对着 `设计 3.6` 的表格：标注只给出组。）
关系挪到"给定成对位置再问"的那一步，即裁决者（`待决 5`）。

### 2.8 例子必须自洽，否则比没有例子更坏

v7 之前的三段例子里有三处**自相矛盾**，其中一处直接教出坏行为：

| 毛病 | 后果 |
|---|---|
| 例子里写了 `组 1：[3]`（**单成员组**），同一段的说明又说"节点 3 **不属于任何组**"，而公共块说单成员组等于没分 | **三处互斥**。实测模型就是爱写单成员组（强撑两处各写一个、某格单成员组占比 50%）——它是在照例子学 |
| 说明说"那正好，让她看看你新搬的地方"只是承接、不标；可判据是"在说一件具体的事、**一个明确的观点**" | 例子在教少标，判据说要标 ⇒ 模型挑省事的那边 |
| 说明说"把 [0,1,2] 合成一组**过宽**"，但"这个人的基本资料"到底含不含"他是演员"，读不出来 | **给了反例却没给可操作的界** |

⇒ **规矩**：例子里的每一个"不标 / 不合"都要能**指着判据那一句**说通；
  说不太通的，宁可改材料，也不要在说明里硬解释。

### 2.9 例子说明不要长过例子本体

v7 之前三段例子的说明部分 **279–369 字，比例子本体还长**，而且大半是"不许…"。
⇒ 那是**用禁令代替判据**的形态，属于过度约束。
⇒ v7 收短了，并把"不写单成员组"从暗示改成**一句显式约束**
（`⛔ 那就不要为它写组`）——**该给的约束要给够，但不能靠禁令堆**。

### 2.10 判据之间会打架，而且模型会说出来

**做法**：标完之后**在同一个上下文里**（把它刚交的产出接在中间）问它四个具体问题。
另起一次问答没用——它没做过那份活，只能泛泛猜（实测那种问法思考量为 0）。

**三次追问查出来的三处打架**（都有原话，见 `标注提示词-试跑.md` 试跑 9）：

| 打架的两句 | 为什么打架 |
|---|---|
| 「整句摘，不许截断」 × 「承接 / 招呼 / 语气不标」 | `算了，说出来好受点，谢谢你听我说完。` 里"谢谢你听我说完"像招呼；不标它就得截断，截断就违反硬要求 |
| 「一轮通常一个节点」 × 「确实说了两件事就分成两个」 × 「标少标多都会错」 | **三句互相顶**：同一处按一句该拆、按另一句该合，而两边都被写成"错" |
| 「只有它自己的组等于没分」 × 「想给某种情绪留个位置」 | 模型知道不该写单成员组，**还是写了**，并自认"这是我自己造出来的组" |

⇒ ★ **规矩**：**每加一条约束，都要回头问"它跟已有的哪一条打架"。**
  这些冲突不是模型看错，是三句话放在一起确实可以推出相反的结论。

### 2.11 举例会被当成判据清单

**实测**：视角三原本写了一句举例——
`自我否定 · 委屈 · 松了一口气 · 不甘心 · 被冷落 · 期待 · 强撑`。
模型的原话是：

> 「加上"**强撑**"这个词在提示词的样例情绪列表里出现过，我就**顺手拿它当判据**了。」

⇒ 它在材料里凑不出足够的"同一种情绪"时，**从清单里挑一个来贴**，还写了单成员组来安置它。
⇒ ★ **举例与判据写在同一行，举例就会被当成判据**（尤其是材料里恰好找不到的时候）。
  ⇒ 要么不给清单，要么**明说这些只是例子、不是必须凑齐的东西、清单里没有的也算**。
⇒ 这条与 §2.3 是同一条：**"同一种 X"必须能被指认出来，否则它不是判据，是个筐**；
  而给一个现成的清单，等于给了一个现成的筐。

### 2.12 "怕散着"是硬给的主要动机

三次追问、三次自认"凑答案"，动机**完全一致**：

> 「如果不放进任何组，就会**散着**…会**没有着落**，所以硬把它们放在了一起。」
> 「不划到一起，**像少了点什么**。」

而**行为对得上**：那一次产出 **18/18 个节点全被划进组**，一个都没散着；
另一次明知不该写，还是造了两个单成员组。

⇒ 公共块现在只写"不属于任何组…是正常情况，不是遗漏"，**显然不够**。
⇒ 处置方向：**把"散着"给一个正面身份**（写明这段材料里可能有相当一部分节点都散着，
  而且"散着"与"成组"同样是正常产出），而不是只在否定句里提一句。

### 2.13 "是谁说的、是不是在回应"不该影响取舍（真语料查出来的）

**实测**（HCoT 6 份材料，支持者轮覆盖率）：**两极分化**——两份 93% / 100%，四份 **0% / 7%**。
⇒ 整段材料只做一个"要标哪一边"的决定，**全标或全不标**。

**根因在提示词自己**：判据写着「重复对方的话……就不标」，
例子里更明写着「它们是承接与安慰，**说的不是说话人自己的事**」。
⇒ **是我们在教它跳过一边。**

**改法**：判据补上"或者给出一句解释、建议、判断"；写明
「**是谁说的、是不是在回应上一句，都不影响**」；排除项收成
"招呼、语气词、纯附和、没说出任何东西的重复"。
⇒ 效果：覆盖率 **33% → 100%**，取舍侧漏标 **21/30 → 0/30**，行均节点 0.33 → 1.00（未泛滥）。

### 2.14 "类"的粒度必须给可判标准

**实测**：分组侧命中率（同策略的轮有没有被划到一起）改前 **20%**。
两段追问都点着同一句：

> 「**"类"的粗细没有边界**……"多具体才算具体"没有可判断的标准，**只能自己猜一个粒度**。」

**改法**：① 类可以是**在干什么**（安慰 / 建议 / 重述 / 给信息 / 解释），
"在讲哪一段往事""都在说这个困扰"是**话题**；
② 粒度判据：用一个说法讲出来，看它**套到别的几处上还成立吗**——
太粗（装进大半节点）是话题、太细（只套一处）那处就不成组。
⇒ 效果：分组侧 **20% → 53%**。

⇒ ★ **一般形式**：**凡是"同一类 / 同一种"的判据，都要给粒度判据**，
  否则模型只能猜，而猜出来的边界**每次都不一样**（这正是重复性差的来源之一）。

### 2.15 一处的动机：产出形状被当成了成绩

追问里"硬给"的自认，动机有**四个说法**，其实是同一件事：

> 「**怕散着**，会没有着落」·「不给它们归一组，好像这一遍**显得不完整**」
> 「出现了却没有组，**感觉"浪费了"**」·「单拎出来**是为了显得"有层次"**」
> 「**为了和另一组形成对称**才写的」

⇒ 公共块现在只写"不属于任何组…是正常情况，不是遗漏"——**四次追问、四次都感到这个压力**，
  **显然不够**。⇒ 处置方向：**把"散着"给一个正面身份**，
  而不是只在否定句里提一句（见试跑 11 §四）。

### 2.16 示例会被当成清单（第二次）

第一次是样例情绪列表（§2.11）；第二次是**例子本身**：

> 「**前面示例里也有明确的重述类节点，所以我有一种"应该也把这边的重述归出来"的压力**」

⇒ ★ **例子里的每一处，都可能被读成"材料里也该找出一处对应的"。**
  ⇒ 这跟 §2.8（例子必须自洽）是一条线的：**例子不只是示范，它是一种预期**。
  ⇒ 写例子时要问：**这一处会不会被当成"必须凑出来"的清单项？**

### 2.17 一个位置可以有多个功能——"只按一个标准"不等于"只能挑一个类"

模型点的冲突（原话）：

> 「材料里**同一个支持者回应往往同时有多个功能**——既是重述，又是解释，又是安慰，
>  又可能是建议。按"一个标准"分组时，我很难判断该归到哪一类。」

⇒ 输出说明里其实写了「一个节点可以同时属于多个组」，**但它没读出来**，
  于是把"只按一个标准"读成了"只能挑一个类"。
⇒ **待改（下一步的单改）**：把"每条候选的类各自独立判一次"写进 `组` 那一段。

## 3. 还没定的

| # | 事 | 现在怎么处理 |
|---|---|---|
| **1** | **每段材料标出多少个节点 / 多少组** | 不设数。实测节点密度随语料差 2.3 倍（Douban 10.4 / KdConv 24.4 每千字），**那是材料的性质，不是取舍的松紧**（`参数账` Z2） |
| **2** | **材料怎么喂** | 整段给。⚠️ **只喂正文，不喂旁注**——材料文件顶部的出处说明里有标题，标题常带主题人名 |
| **3** | **位置怎么定** | 由外部给：模型产引文，定位在仓库一侧做 |
| **4** | **降噪要跑几遍** | `3.5.1` 要求同一视角多遍取一致。★ 已测（试跑 7）：节点 Jaccard **0.85**、同组对 Jaccard **0.37**。⇒ **不能按"组"取一致**（一个节点漏了整组就废，多数格子交集为空），要**按节点对投票再重组**。剩：**票数阈值取几**。总调用数 = 3 视角 × 遍数 × 材料数 |
| **5** | **关系什么时候问** | v4 起不标。挪到"给定成对位置再问"的那一步（裁决者，`待决 5`） |
| **6** | **三个视角的结果怎么用** | 各自成图（`3.5`）。⚠️ **不得跨视角投票**（`3.5.1`） |
| **7** | **"同一类"跨材料怎么成立** | 视角二只解决"同一类事"，**跨材料、字面上无关的那种"同一类"仍归训练**（`设计 3.6`）。见 `待决 8` |
| **8** | **`组说明` 会不会改变行为** | 会（见 2.4）。⚠️ 实测模型会把提示词措辞抄进说明里（"凭的是：凭的是……"）；v7 已要求"写清那一条本身，不要复述题面的话"，**待验** |
| **9** | **提示词对照要重做** | ⛔ **要**。实测思考量在同一任务上从 **0 波动到 24934 字**（正文才 963 字），而试跑 4/6/7 **都没记思考字数** ⇒ "A 版标出的节点比 B 版多"这类结论**分不清是提示词的功劳还是它这次想得多**。⇒ 以后每个格子都要记思考字数 |
| **10** | **怎么给提示词瘦身** | ⚠️ **只能逐句实测**，不能凭读感。实测：`★ 全部标完后，回头把每一条再审一遍…` 看着像重复，**删掉它节点数就翻倍**（9 → 17）。而 v7 那轮我**一次改了四处**，**归因不了**是哪一处 ⇒ **一次只删一句，每句都跑** |
| **11** | **任务描述与判据要不要再校一遍** | v7 校了一遍（两样→三样、"关系图"→不产出关系、显式堵单成员组）。⇒ 以后每加一条约束，都要回头问：**它跟已有的哪一条打架？** |
| **12** | **样例清单要不要留** | ⛔ 实测被当成判据用（§2.11）。⇒ 倾向删掉；但"离谱的近义词"与"给答案"之间的界要试过才知道 |
| **13** | **"散着"要不要给正面身份** | ⛔ 三次追问三次都因"怕散着"而硬给（§2.12）。⇒ 待改，**单句改动、逐条测** |
| **16** | **瘦身怎么判** | ⛔ **不能用分组命中率逐句判生死**：实测同一提示词两遍差 **±10–13 点**（153 个可判点分布在 30 份材料里，**有效样本量是材料数**，不是点数）⇒ 噪声比要判的效应还大。见 [`标注提示词-试跑.md`](标注提示词-试跑.md) 试跑 12 |
| **17** | **靶子还要不要做大** | 要判 10 点量级的差异，得**每条件 5–10 遍取均值**，或把材料数抬到 200+。⇒ 待定：值得为"提示词瘦身"付这个代价吗 |
| **18** | ★ **怎么让"偷懒的类"写不出来** | ⛔ 实测：判据（"对调成员内容还成立吗"）**写进去了，生成时不执行**；被追问时自认 **10/15 个组是"只靠动作或语气"**（试跑 15 §四）。⇒ 候选：**`组说明` 必须原样引用一个成员的片段当凭据**——偷懒的类拿不出凭据，且**机械可查** |
