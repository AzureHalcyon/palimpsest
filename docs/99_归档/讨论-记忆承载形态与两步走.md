## §1 目标 vs 手段（**专防混淆**）

> ## ★★★ 总纲原则（2026-10-08 定 · 已并入 `中介层-设计 §3` 开头）
>
> `[原话]` 用户：**"做这个项目，一旦做成机械的，那就真的机械了。模型的事情，最终还是得归于模型啊。"**
> 定稿提法：**"机械的归机械，模型的归模型。"**
>
> | 这件事在干什么 | 归谁 |
> |---|---|
> | **记 · 存 · 查**（存储 / 索引 / 记账 / 核验） | ★ **机械**（写死、要快、可复算） |
> | **判**（选什么 / 看哪里 / 该不该说） | ★★ **模型**（学习、可变、**留痕**） |
>
> ⚠️ **拿不准 ⇒ 归模型**。
> ★★ **它解掉了四次同形的老矛盾**（切分 / 标注网络 / 判同一性 / 该想起什么）——
> **每次都判给模型，理由一样：规则能保证的只是"一致"，而我们要的是"对"。**
> ★★ **可核的正当形态只有三种**：**留痕 · 可重做 · 可撤销**；
> ⛔ **不正当的是"用规则替代判断"**。

| 是目标 | 是手段 / 是妥协 |
|---|---|
| 真正的长期人格 / 情绪 / 记忆 | ★ **"读法"（平替）** |
| 行为随经历变 | 文本投影 · `B_p` · 渲染形式 · 上下文预算 |
| 状态连续，能影响读取与表现 | 手工余弦 + `τ`/`mass`/`clip` |
| 编码器（能输出、能模拟） | 心跳（第一步的替身） |
| 底片永不改写 | `read_z`（临时的"补一次扩散"） |
| 一个空间、靠指称区分 | 四层分区（当前位置标记） |

⇒ ⚠️ **判别问句（供以后自检）**：
> **"这一条是为终极目标服务的，还是只为第一步好用的？"**
> **只为第一步好用的，刻意做浅，并在文档里标注"第一步专属"。**
> 已确认属于 **"第一步专属"** 的：`B_p`（文字长度预算）、渲染的文字形式、`τ`/`mass`/`clip` 的标定值。

## §3 讨论定下来的机制

### 3.1 密度是主角

- 条目 = embedding 编码的 **d 维向量**（自带属性）；读取命中**激活半径内的全部条目**；
- ★ **同一情境，池子密度升高 ⇒ 读出的条目变多** ⇒ **新经历改变读取** = 读法漂移的载体；
- **激活半径可控；密度不可控（涌现）**；
- 三种行为**自然涌现、且都已实现** `[实测/本人确认]`：
  **同域新增** ⇒ 邻域变厚；**跨域但语义靠近** ⇒ **联想**；**单条被强化** ⇒ 该处重量变。

### 3.2 ★ 强度改判

| | |
|---|---|
| 旧 | `w = 1 + n_d + n_p`（计数式）+ `κ·log w` 只改顺序 |
| ★ 新方向 | **结构量**："**这条离得近不近 / 周围有多少同伴**" |
| 为什么改 | 计数式让强度**变成密度的替身** ⇒ 两套分数打到同一个位置 ⇒ 互斗 |
| ★ 一条算三用 | ① 读取打分 ② **关系发展的量具**（聚落有没有长大）③ **崩坏报警**（塌成一团 / 碎成渣） |

### 3.3 岛 / 聚落

| 形态 | 状态 |
|---|---|
| **硬划分 + `argmax` 判归属** | ⛔ `§3.7` 已实测否掉（平均每条属 36.6 个方向），**不许回流** |
| ★ **"岛" = 局部密度超过阈值的描述**（没有明确范围） | ✅ **只进仪表盘，不参与读取** |

### 3.4 ★★ 编码器（**当前头号阻塞**）

> ★★★ **2026-10-08 第 2 次改判 —— 目标改写成"浮现"**（`[原话]`）
> 用户：**"编码器的目标，再直白一些，就是代替记忆，实现'听到什么话，脑海里浮现出什么'
> 这个事情（一次回答其实可以浮现好几次，因为 CoT 很长，可能会想很多事情）。
> 编码器自身，我估计可能还是会读一些原文。当然也可能有不读原文的方案，
> 但模型最终大概只能拿到编码器输出的这一段。"**
>
> ⇒ ★ **它代替的不是"记忆仓库"，是"浮现"。** 载体（文字 / 激活）因此退居次要。
>
> **★★ 为什么这次改判是关键 —— 它把判据从"反事实"变成了"有内容的事件"**：
>
> | | 前一版目标 | ★ **浮现版** |
> |---|---|---|
> | 目标 | 让行为朝"这段经历**应该**造成的改变"这个方向变 | ★ **"听到什么话，浮现出什么"** |
> | 判据 | ❌ **反事实**（"如果没记住，会有什么不同"）—— **不可直接测** | ✅ **"该不该浮现"**——**浮现是有内容的**，可问对错 |
>
> ⇒ ★★ **它与"dreaming 模型自己出卷子"天然合流**：
> **出卷 = 写一道浮现题；答题 = 看它浮现得对不对。**
>
> **★★ 自带"不该提"的判据（白捡）**：
> **浮现是内部的，说出来才是行为** ⇒
> ⛔ 把浮现**直接念出来** = 炫耀知识（撞 `§8.3`）；✅ 让浮现**影响怎么说** = 正确用法。
> ⇒ **"该不该提" = "浮现与说出口之间那一层过滤有没有生效"**——而那一层（投影/分寸）**已经有了**。

**编码器的处境**：

```
输入：情境 s + 状态/池子 +（内层可选：相关的那批原文片段）
      ↓ 编码器   ← 可读原文（内层）
输出：定长表示（第一步 = 文字；第二步 = 激活）
      ↓
用途：★ 进入底座，让底座"带着这段浮现"回应
```

**★ 四条判据**（**四条各自报警，人读裁决；⛔ 不许合成一个分数** —— 那是 `§8.3` 最忌讳的"塞进一个旋钮"）：

| # | 约束 | 反面（要防的） | 谁管 |
|---|---|---|---|
| **1** | **产生了增量** | 复读他的话（"让下一句更可能"是**代理**，会把渲染推向"像他"⇒ 收窄） | 边际增益 |
| **2** | ★★ **该想起来时想得起来** | 该用没用上 ⇒ 等于没记 | 采样+排序 · 卷子 |
| **3** | ★★ **不该提的时候不冒出来** | 硬提、说教、炫耀知识（`§8.3`） | 采样+排序 · 人读 |
| **4** | **不许越界** | 提到"他不该被知道"的（`§8.1`）；把"它推的"说成"他说过"（`§8.4`） | 机械核 · 卷子 |

⇒ ⚠️ **两个偏差方向相反**（**过度表达**被 3/4 挡；**表达不足**被 1/2 挡）⇒ **不能压成一个分**。

**★★ 形态：不是"一段定长文本"，是"一轮里的**一串**"** `[原话]`

```
一轮对话
  ├─ 浮现 1（触发：他刚说的那句）
  ├─ 浮现 2（触发：浮现 1 带出来的）
  ├─ 浮现 3（触发：模型自己想到的）
  └─ …（不定次）
        ↓ 最后才生成回应
```
⇒ ★★ **这就是"连续状态回路"在第一步的对应物**：
**第一步做不到"模型一直醒着"，但能做到"一轮里浮现好几次"** = **用第一步模拟第二步**。
⇒ ★ **`实现规范 §5.3`「读取分两轮」是它的粗糙版**，现在它有了**认知层面的解释**，不再是工程技巧。

**★ 两层读法（必须分开）** `[原话]`：**"编码器自身可能还是会读一些原文……但模型最终只能拿到编码器输出的这一段。"**

| 层 | 读什么 | 谁看得到 |
|---|---|---|
| ★ **内层（浮现）** | **可以读原文**——那是"想起来"的过程 | ⛔ 只有编码器自己 |
| ★ **外层（交付）** | **只有编码器输出的那一段** | ✅ 模型看这个 |

⇒ ⛔ **红线：内层读到的原文，不许绕过编码器直接进交付**（否则就变回"把原文碎片塞给它"，§0.4-12）。

**★ 编码器的真实目标（一句话）**

> **代替记忆，实现"听到什么话，脑海里浮现出什么"；**
> **而那个浮现必须是：该用的时候用得上、不该用的时候不冒出来、不越界、有增量。**

**★ 其余属性**（沿用第 1 版判断，未被推翻）：

| 项 | 内容 |
|---|---|
| **为什么必须换 `read_z`** | 三个毛病：**太机械**（手工余弦）· **接口是文字往返** · **时序是"事后问"** |
| **职责** | ★ **选子空间**（这次该从关系网里取哪一块）+ ★ **表述**（同一件事在不同情境有不同表述） |
| **输出** | **定长**；★ **第一步文字、第二步激活 = 同一个映射的两副面孔**（所以它不是消耗品） |
| **安全性** | ★ **用完即弃**：输出**不进池子** ⇒ **误差不累积**（最坏是"这次渲染得不好"） |
| **⚠️ 判据要多维** | ⛔ 不许用"接得上下一句"当唯一标准（那是**代理指标**，会犯 `§8.3`"用错尺子"）⇒ 用上面那四条 |

### 3.5 信息流硬规矩

1. ★ **没真正发生过的不得进池子**——但 **它自己说的话要录**（`§8.6`：那是行为）；
2. ★ **从它的话里提取的东西，不得成为"关于他的"条目**（堵伪造知识 + 堵"应该→必须"）；
3. ★ **压缩器只许吃原文，不许吃压缩产物**（重新摘要必须从原文出发，不许在上次摘要上改）；
4. ★ **分流**：**情绪 / 氛围 / 印象**可有损摘要；**事实 / 数据 / 承诺 / 时间**只走 **指针 + 原文**；
5. ★ **时间线按类型带权重**（他说的 > 它说的 > 它渲染的）——**兜底/诊断，不当主力**；
6. **组织是网不是树**（一句话可进多个组）。

### 3.6 dreaming：**必要，但要拆**

| 拆成 | 为谁存在 | 第二步 |
|---|---|---|
| **压缩** | 上下文有限 | ★ **换形态但没消失**（压的是"激活怎么组织"） |
| **选择**（= `§6` 的"筛选"） | 参数更新 | ✅ 要 |
| **核对** | 防编、防漂 | ✅ 要，且可更频繁 |
| ★ **核验再交付** | 复用已有的 JSON 修补回路，从"格式合格"扩到"内容合格" | |
| ★★ **并行多轮** | 降噪；**每轮必须独立从原文出发**（串联迭代 = 放大） | 与第十八轮"多初始化对照"同一手法 |

### 3.7 卷子（量具）

**出发点** `[原话]`：**"只能靠探针——连我自己也说不清某个知识我还记不记得，只有给一张卷子才知道。"**
⇒ ★ **推论**：条目级的"可审"其实是**符号层的特权**，不是它更可审。

**两个出题来源**（测的不是同一件事）：

| 出题者 | 怎么出 | 测什么 |
|---|---|---|
| **底片采样** | 从归档那一刻的底片机械抽样，**答案是逐字原文** | ★ **有没有丢**（假阴性）· **有没有编**（假阳性） |
| ★ **dreaming 时的模型** | ★ **它自己出题**——因为**它最清楚当时到底想总结什么** | ★★ **它记下的东西，是不是它当时想表达的那个意思** |

⇒ ★ **第二种补的正是第一种测不到的那一格**：
> **"记录"与"当时的意图"之间的偏离** —— 也就是那个实测的病（**应该 → 必须**）。
> 底片采样的卷子**只知道原文，不知道它当时想抓什么**。

**三条纪律**（否则模型出的题会自利、不可判）：
1. ★ **答案必须落在底片上**（不许出"你觉得你懂他吗"这种没答案的题）；
2. ★ **题目要能证伪**（有明确判据，不能是"有没有进步"这类）；
3. ★ **出题时的意图留档**（否则以后没法判"这题当年想问什么"）。

**★ 配套工程件：留档 dreaming 的对话窗口**

> `[原话]` **"可以留档 dreaming 时的对话窗口（至少第一阶段这很简单），这样核对时其实可以 fork 一个来直接问问。"**

- **为什么值钱**：模型出的题**只有它自己答得了**（要它当时的语境）；
  ★ **fork 那个窗口 = 回到当时的语境答题**，而不是让一个新模型去猜；
- **成本**：第一期**几乎为零**——dreaming 本来就是一段消息列表，**存下来即可**；
- ★ **纪律**：**fork 是只读的**——**不许把 fork 的结论写回池子**（同 §3.4"用完即弃"）。
- ⇒ ★ **出题、留档、fork 追问，是同一件事的三步**，而且它和 §3.6 的"核验再交付"共用一条回路。

**定位**：**不是静态文件，是随归档增长的机制**。
⇒ ⭐ **建议重裁** `Neuro-sama-调研 §11.1` 那条"探针作废"：
**作废的是"手写探针 + 人工预设正解"**；**底片/模型出题的卷子进主线**。

⚠️ **反面**：**"越追求可审 ⇒ 越往离散漂"** ——
★ **风险具体是**：只为"可测"优化 ⇒ **表示被推向离散**。

### 3.8 ★★ 训练：材料可以"生成"，但范围要限定（2026-10-08 新增）

> `[原话]` 用户的突破：**"我一开始想，能不能写一个示例输入和输出，来展示理想效果？
> 接着就想到，如果能写出示例，那这不就是我们需要的材料吗？完全可以生成啊。"**
>
> ⇒ ★ **这把当前瓶颈（监督信号从哪来）整个绕开了**：从"只能标日志"变成"**可以造材料**"。

**材料 = `(情境, 该浮现什么)` 对**：

| 部分 | 从哪来 | 能不能生成 |
|---|---|---|
| **情境** | 从底片采样真实触发 / 半合成改写 | ★ **可以生成** |
| ★ **该浮现什么** | **多份候选**（采样 N 个）⇒ **两两排序** | ★ **可以生成** |
| ⛔ **底片本身** | —— | ⛔ **不许生成**（事实源不能造） |
| ⛔ **进池子的东西** | —— | ⛔ **不许是生成的**（红线 13） |

⇒ ★ **一句话**：**情境可以造，浮现可以多造；但"底片"和"进池子的东西"必须是真实发生过的。**

**三个信号源，各管一段（互不替代）**：

| 信号源 | 管哪条判据 | 成本 |
|---|---|---|
| **边际增益**（有 / 无这段浮现，下游差多少） | 判据 **1**（有增量） | 🟢 自监督 |
| ★ **采样 + 两两排序**（同一情境多份候选，比较） | 判据 **2 / 3** | 🟡 要能重放 + 采样 |
| **dreaming 模型自己出卷子**（+ 留档窗口，fork 只读追问） | 判据 **4** + **表达偏离意图** | 🟢 零 |

**★ 主训练形态：采样 + 排序（"可以不断往'更正确'努力"）** `[原话]`

```
同一情境 ⇒ 采样 N 个候选浮现
   → 两两比较排序
   → 取靠前的继续采样、继续比
```
⇒ ★ **这一步把训练从"只能标日志"变成"可以造日志"**：
**没有对照就没有训练，有了采样就有了。**
⛔ **硬约束：候选一个都不许进池子**（它们只是候选表述，只在 shadow 路里比较）。

**★ 三条防护**（否则会绕回"越来越像他"）：

| # | 防护 | 做法 |
|---|---|---|
| **1** | ★ **别用"预测"，用"边际增益"** | 判据 = **有这段浮现 vs 没有它**，下一句概率差多少；⛔ 不是"下一句概率高"本身（那会推向"像他"⇒ PRISK 那条"偏好收窄"） |
| **2** | **方差过滤** | 只在两个候选**差得明显**时取这一对 |
| **3** | ★★ **监视"代理 ↔ 目标"的偏离** | 定期看：**浮现是不是越来越像他的原话**（相似度 / 措辞重合）⇒ 一起就往回拉 |

**★ 下游模型可以做裁判，但约束必须提前讲清** `[原话]`（"约束就得做好，提前就把约束讲清楚"）：

1. ⛔ **不许用"流畅 / 通顺 / 像话"当理由**；
2. ⛔ **不许奖励"更顺着他说"**（谄媚）；
3. ✅ **按"这段经历有没有被正确表达"判**，判据是**能不能指回原文片段**；
4. ⚠️ **判不出时，必须允许它输出"判不了"**（否则它会硬给一个）。

**★ 防过拟合底座**：偏好对里的"下游"要**跨模型采样**
（同一候选用两个不同底座各跑一遍）⇒ 学"表述本身好不好"，而不是"某个模型喜不喜欢"。

**★ 主路 / shadow 路**（架构上的一个发现）：

```
主路（真实）  ：当前编码器 → 浮现 → 真的说出去 → 进底片       （不打扰）
shadow 路（离线）：同一情境 ⇒ 采样 N 个候选浮现 ⇒ 只存档，不发出
                  ⇒ 事后再比较 / 重放 ⇒ 得到偏好对
```
⇒ ★★ **这条 shadow 路同时就是"卷子"要的基础设施**：
**同一个机制，既产训练数据，又产量具读数。**
⇒ **这就解决了 `§11.2`「量具必须早于训练」那个先后矛盾——如果它俩是同一条路，就没有先后问题。**

| 项 | 内容 |
|---|---|
| 为什么必须换 | `read_z` 三个毛病：**太机械**（手工余弦）· **接口是文字往返** · **时序是"事后问"** |
| 职责 | ★ **选子空间**（这次该从关系网里取哪一块）+ ★ **表述**（同一件事在不同情境有不同表述） |
| 输出 | **定长**；★ **第一步文字、第二步激活 = 同一个映射的两副面孔**（所以它不是消耗品） |
| 安全性 | ★ **用完即弃**：输出**不进池子** ⇒ **误差不累积**（最坏是"这次渲染得不好"） |
| 训练信号 | 自监督：**情境 + 当轮池子状态 → 他真实说的下一句**（⚠️ 需补记**每轮状态**，见 §4-4） |
| ⚠️ 判据要多维 | "接得上下一句"只是**代理指标**（犯 `§8.3`"用错尺子"）⇒ 还需 **没编（卷子）/ 负向判据 / 人读** |

### 3.9 ★★★ 网络形态定案（2026-10-08 第三轮 · 已确认）

> 起点原话：**"原文是一个整体。然后我们拿到的是模型对原文提炼出的关系网络。"**
> ⇒ ★ **池子不是"条目表"，是"原文上的网络"**：**节点锚在原文的位置上，边是它们之间的关系。**
> ⇒ 这一个形态**同时解决三件**：可归因（节点就是原文位置，指回去是结构性的）·
>   读出是子集（网络只是原文的一种组织）· 原文不碎（碎片化从来不是"存在哪"，是"怎么取"）。

**(1) ★★ 池子 = 原文（整体）+ 网络（节点 + 边）+ 元数据**；⛔ **不存模型写的解释句（③）**

**(2) ★★ τ 是「谱」，不是值** `[原话]`：**"τ 没什么，我们可以有很多不同的 τ。"**
- ⇒ **每个节点 / 边自带时间尺度** ⇒ **天然是一条谱**；
- ⇒ ★ **`中介层-设计 §6 第 1 条`那条"不同衰减曲线形状暂缓"可以取消暂缓**：
  **它不需要"多条曲线"，它需要的是"多个 τ"，而那是网络的自然属性**；
- ⇒ **`TAG_MULT` 那套分档从"参数"降为"初始取值规则"**；
- ⇒ **长期池 / 临时池两个容器取消**，改成 **边上的 τ**（"升迁" = `τ` 变大，**连续量，不是搬家**）。
  ⚠️ 代价：**存活判定变复杂**——一条原文位置只要**还有一条边没淡**，它就还在。

**(3) ★★ 节点有类型（异质图，不是平面网络）** `[原话]`：**"节点不一定就是正面的，我们可以有负面节点。甚至更多其他节点。"**
- ⇒ **`情境负面` 那一层 = 一类负面节点**（不再是独立容器）；
- ⇒ ★ **底色 / 情境负面 / 记忆 / 临时的"四层分区"改成"类型标记"**，
  **这才真正符合 `§3.2`「空间只有一个，靠指称区分，不靠分区」**（以前其实是四层，已经在分区）；
- ⇒ ⚠️ **纪律不变**：**类型是元数据，进读取时起作用（过滤 / 调制），⛔ 不参与几何**
  （编进向量会撞 `§3.1` 那条失效面："不难过"和"很难过"余弦重合）。

**(4) ★★★ 跨对话窗口的原文也建边 —— 而长距离边「只有训练能建」** `[原话]`
：**"往远看，不同对话窗口之间的原文，都可以建立网络。这也正是训练才做得到的。"**

| 边的类型 | 距离 | 谁能建 | 现状 |
|---|---|---|---|
| **短距** | 同窗口相邻 | 机械 / 几何（余弦就近） | ✅ 已有（密度机制） |
| **显式** | 跨窗口、话题明显相关 | 模型在归档时标 | ⚠️ 薄 |
| ★★ **长距** | **跨窗口、跨月、话题不重合** | ★★ **只有训练** | ❌ **完全没有** |

⇒ ★★ **这是"为什么要训练"唯一不可替代的理由**：
**不是"训练更准"，是"有整类边，除了训练没有别的办法建"**
（余弦建不出来——话题不重合；规则建不出来——没有共同词；模型手标不可靠——它不会主动翻半年前）。
⇒ ★ **三个后果**：
1. **弱标签从哪来**：只能用"**他后来是不是又提到了**" ⇒ ★ **这正是 `§7.1(2)`"强化只能来自真实重复"的网络版**；
2. **必须能看全量原文** ⇒ **离线 / 批次的事**（同 `§7.3` 便宜的线上、贵的离线）；
3. ⚠️ 规模问题 —— **由下一节解决**。

**(5) ★★★ 规模由「参数化的读法」吸收** `[原话]`：**"训练是可以解决的，就像编码器要输出定长一样。"**

| 层 | 规模 | 会不会炸 |
|---|---|---|
| **原文（底片）** | 线性增长 | ✅ **不炸**——存是廉价的（`§6 第 2 条`） |
| **边的数量** | 组合爆炸 | ★ **参数化之后不炸**：**由读法吸收，不由存储承担** |
| ★ **读取成本** | —— | ★ **定长**（编码器输出定长）⇒ **也不炸** |

⇒ ★★ **这是"记忆 = 组织方式"的字面实现**：
**记忆的量不随内容线性增长，而由"组织方式的参数量"决定。**
⇒ ★ 而 **Fusi 那条"容量 ↔ 寿命"因此从"工程瓶颈"退回"理论背景"**——
**容量瓶颈不在存储，在读法。**

**(6) ★ 锚不住的节点不落库**（防"库被措辞污染"的最后一道闸）
网络是模型提炼的 ⇒ 它能造出"原文里没有对应位置"的概念（"他在回避某个话题"）。
⇒ **"他推出来的概念"不落库，它是浮现的产物**；**库只存"锚得住的东西"**。
⇒ 与红线 13 的分工：**13 管"没发生过的"，这条管"锚不住的"。**

### 3.10 ★★ 表示格式与图计算（2026-10-08 第五轮 · 已确认）

**(1) ★★ 锚 = 原文区间**（不是切片 id、不是哈希）

| 候选 | 稳定性 | 判定 |
|---|---|---|
| 切片 id | ❌ 跟着切分规则变 | ⛔ |
| **哈希** | ⚠️ **只答"完全同一段"；差一个字就从 1 掉到 0** | ⛔ 不当身份 |
| ★ **原文区间**（doc + start + end） | ✅ 不依赖任何分段规则；**节点可以是任意长度** | ★ **定为身份** |

⇒ ★ **"切片"是"读的单位"，不是"锚的单位"**——按切片读时，由区间算出它落在哪个切片里。

**(2) ★★ 位置共享、节点每网络自切** `[原话]`：**"不同网络可以有完全不同的切分。原文并非只能切一种粒度/分词方式。"**

| | 谁定 | 能不能变 |
|---|---|---|
| **位置** | 原文（共享坐标系） | ⛔ 不变 |
| ★ **节点** | **每张网络自己切** | ✅ **可以完全不同粒度** |
| **边** | 每张网络自己建 | ✅ |
| **网络身份** | `(原文范围 + 切分方式 + 提取方式)` 的标识 | 每次重提取 = **新网络** |

⇒ ★ 所以不存在"重切分让全网失效"——**重切分只是重造那一张网络**，别的网络不受影响。
⇒ ⚠️ **"不存网络历史版本"要精确化**：**不存内容快照，但要存版本标识**（否则激发记录指向不明）。

**(3) ★★ 比较：机械层用 IoU，含义层用判官**

| 层 | 要判什么 | 靠什么 |
|---|---|---|
| **区间层** | "这两段是不是同一段文本" | ★ **IoU（机械、可复算、连续量）** |
| ★★ **含义层** | "这两张网络说的是不是同一件事" | ★★ **判官 + 人工抽查** |

⚠️ **IoU 的边界（本人指出）**：**"说法不同但意义完全相同"它测不出来**；
**一件事可能散在多处、各有各的说法** ⇒ ★★ **说明"同一性"这个问法本身有问题**。

**(4) ★★★ 改判：同一性不是一个属性，是「一组边」**

| 情况 | 靠什么 | 结果 |
|---|---|---|
| 两处文本**重合** | IoU（机械） | 我们知道它们重合 |
| 两处文本**不重合但同一件事** | 判官 | 我们**判**它们相关 |
| ★ 一件事**散在多处** | ★★ **多点之间的一组边** | ★ **"是同一件事" = "两两之间有边 / 连通"** |

⇒ ★★ **所以"同一件事"不进库** —— **它是边结构的一个连通块**（与"岛"同一待遇：**描述，不是实体**）。
⇒ ★ 它**退化成"哪些边存在"**——**那正是训练要学的东西**。
⇒ ★ **"读法变了没有"的判据也随之换**：
**不问"节点是不是同一个"，问"同一个刺激下，亮起来的边结构是不是同一套"**。

**(5) ★★ 判官也适用「并行降噪」** `[原话]`：**"判官也适用并行降噪的设计"**
⇒ ★★ **"并行 + 取一致"因此成了三个环节的共用机制**：

| 环节 | 判什么 |
|---|---|
| **dreaming 抽取** | 哪些算一类、留哪些 |
| ★ **判官** | 两处文本是不是同一件事 |
| **编码器（浮现）** | 该浮现什么 |

⇒ ★ **判官不必一次就准**——**多次独立判断后一致的才算**。
⛔ **两条纪律**：**每轮必须独立**（不许迭代，否则是放大）；**判官结论不许直接落库**——
**多轮一致的"边"才落库**，不一致的悬置或丢弃。

**(6) ★★ 图能算，且算在"激发小块"上**

| 要算什么 | 复杂度 | 可行性 |
|---|---|---|
| **连通块** | O(N+E) 线性（并查集 / BFS） | ✅ |
| **岛 / 局部密度** | O(N+E) | ✅ |
| ★ **两张网络像不像** | 激发节点集 Jaccard O(k)；诱导子图谱距离 O(k³)，**k = 激发数（十几个）** | ✅ |

⇒ ★★ **因为激发稀疏，所有图计算都在小块上做；全局只有线性操作** ⇒ 规模问题不回来。
⛔ **不做**：整图同构（NP）；全图矩阵。

**(7) ★★ 巨型连通块 → 先按来源切，最后才拓扑二分**

| 步骤 | 做法 |
|---|---|
| ① **先按【边的来源】切** | ★ **机械边（IoU）构成的结构 vs 判官边构成的结构**——★ **机械那部分无判官偏置** |
| ② 再按【类型】切 | 显式 / 长距 / 不同 `τ` |
| ③ **都切不动才拓扑二分** | 谱二分 / 最大割近似；★ **必须报告"分得干不干净"**，⛔ **切不开就如实说"这团本来就连着"** |

⇒ ★★ **为什么"先按来源切"**：**分裂只能切、不能连** ⇒
**"不该分到一起"这件事在上游就已经发生**（是某条边连的）⇒ **要治的是边，不是分裂**。
⇒ ★ **三条真失败模式**：**① 伪边**（判官误判 ⇒ 上游治：并行取一致）·
**② 伪分裂**（数据本来连续、算法硬切一刀 ⇒ 切不动就报告）·
**③ 度量偏置**（切法不唯一 ⇒ 要写清用的什么度量）。
⇒ ★ 而 **"它只是指标"是最强的安全垫**：**判错 = 仪表盘被误导一次，⛔ 不是"把两件事记成一件"**。

**(8) ★★ 分层激发**（本人指出：稀疏激发暗示它可以分层）

```
第 0 层：整张网络（几乎全暗）
第 1 层：被照亮的一大片（几十个节点）   ← ★ 范围
第 2 层：其中最亮的几个（几个节点）      ← ★ 焦点
第 3 层：围绕它们的边
```
⇒ ★ **它解决的麻烦**：单层形态下，"照亮十几个"和"细看某一个"**只能靠调半径区分**
—— 那是**一个旋钮管两件事**。分层之后 **范围与焦点分开**。
⇒ ★ **`实现规范 §5.3`「两轮读取」是它的一个特例**（宽候选 → 精排 = 第 1 层 → 第 2 层）。

**(9) ★★ 两条建议立成原则**（在多个地方反复出现，不是个案）

| 原则 | 出现之处 |
|---|---|
| ★★ **"并行 + 取一致"是共用降噪机制** | **3 处**：dreaming 抽取 · 判官 · 浮现采样 |
| ★★ **"派生物只当指标，不进读取路径"** | **3 处**：方向（`§3.7`）· 岛 · **图计算** |

⇒ ★ 第二条**解释了为什么我们敢算这些东西**：**算了也不怕，因为它们影响不了行为**——
**它们只影响我们怎么看它。**

### 3.11 ★ 每轮状态 = 训练数据的格式（第六轮 · 已确认）

```
每轮一行：
  刺激   ：位置（原文坐标，与网络无关）/ tick / 自己想到的
  网络   ：网络 id（原文范围 + 切分方式 + 提取方式）
  期望   ：一组位置 + 关系类型        ← ★ 它是卷子的题面
  激发   ：节点（区间 + 强度）+ 边（id + 强度）
  参数   ：τ / 半径 / 上限
  成本   ：实际花了多少               ← ★ 它取代 `B_p`，是新的"第一步成本上限"
```
⇒ ★★ **这一张表同时是**：状态轨迹 · 训练样本 · 卷子 · 长距边的统计原料。**一处记，四处用。**
⇒ ★ **"期望"的形态定为"一组位置 + 关系类型"**（⛔ 不用自然语言——那会含措辞、又会漂）。

### 3.12 ★★★ 合成体与失效信息（第七轮 · 已确认）

#### (A) 读取器 + 编码器 = 一个黑箱

`[原话]` 用户：**"编码器的输出就是要代替原来 read_z 的输出的。然后我们可以把它总结成一个黑箱，
扔进去输入对话（或者 AI 想知道的、AI 的 CoT 等等），拿出来给 AI 看的东西。"**

```
黑箱(输入) → ★ 给 AI 看的东西
   输入：当前对话 / AI 明确想知道的 / ★ AI 自己的 CoT
   输出：★ 取代 `read_z` 的输出（⛔ 不是新增一层 ⇒ read_z 从设计里划掉）
```
- ★★ **为什么不能拆成"选取器 + 渲染器"两个模块**：**"取哪一块"与"怎么说"是同一件事的两面**；
  拆开的话第二个只能"给已选好的东西润色"——**那正是被否掉的"把碎片交给 API"**；
- 内部两个部件一条链：**① 选取**（→ 激发子图）· **② 渲染**（→ 交付）；
  ⛔ **② 只吃 ① 的输出，不许另外去读原文**；
- ★ **接口按终态定**（交付类型可换：文字 / 激活），**训练按资源分阶段**。

**★★★ 四层：三层可重建，一层一次性**

```
① 源  层：原文（永不改写）                    ← 根，唯一不可重建
② 网络层：网络（派生视图，可整套重提取）        ← 可重建（从①）
③ 读取层：激发子图（★ 读法，可训练）            ← 可重建（从①+②）+ 可训练
④ 交付层：文字 / 激活（用完即弃）              ← 一次性，⛔ 不落库
```
⇒ ★★ **判据只有一句**：**"这一层能不能从原文重算出来？"**
**能 ⇒ 不该当事实源；不能 ⇒ 必须一次性。**
⇒ 这一句**解释了前面七八条规矩**。

#### (B) ★★★ 更正：可锚的是「网络」，不是「交付」

`[原话]` 用户：**"输出是编码器给的，能不能具体指向某个锚点，并不好说。"**

| 层 | 要不要可锚 |
|---|---|
| 原文 / 网络 / 激发子图 | ✅ **必须**（网络锚不住就不落库） |
| ★ **交付**（给 AI 看的文字 / 激活） | ⛔ **不可能、也不需要** |

⇒ ★★ **交付天生不可锚**：它要**改写、合并、省略**——
"同一件事在不同情况下有不同表述"**就是在说它必然改写**。
⇒ ⚠️ **"逐句对锚"是过强要求**：会把**改写**误判成**编造**。

**★ 改后的判据：**

> ## **交付的内容，必须来自激发子图。激发子图里没有的，不该出现在交付里。**

⇒ 这是**集合包含**检查（允许改写 / 合并 / 省略）；⚠️ **判它需要判官**（语义问题）
⇒ **属于"并行 + 取一致"那一路，不是机械可得**。
⇒ ★ **两步的检查是对称的**：第一步（文字）更依赖判官；
★ **第二步（激活）反而更机械**（**交付向量的支撑集 vs 激发子图**可直接算）
⇒ ★ 印证"可审计是约束不是目标"：**第二步某些方面反而更好审。**

**★ 最实用的推论：标注必须做到「网络层」**
⇒ **交付不可锚 ⇒ 可查点只能在网络上** ⇒
**节点 / 边必须标来源类型**（来自"他的原话" vs 来自"它渲染的"）
—— ★ **这就是"标注"这条硬要求存在的确切理由。**

#### (C) ★★ 失效的信息：标失效 ≠ 丢掉

`[原话]` 用户：**"失效的信息本身也有价值，也值得被激活，但这个似乎难度更高一点。"**

| | 处置 |
|---|---|
| 底片 | ⛔ 永不改写 |
| 网络里的节点 / 边 | ★ **也不删**——只加 `invalid_at` |
| 读取时 | ⚠️ **默认不给"当现在的事实"用**；★ **但可以按"历史"取出来** |

⇒ ★★ **最该钉住的一条**：**一旦失效，永远不许再以"现在时"激活，只许以"曾经"出现。**
⚠️ 否则是最糟的失败：**同时知道"他戒烟了"和"他抽烟"，在某刻说出"你抽烟"** —— **比不知道更糟**。

⇒ ★ **机制 = 双时态**（`valid_at` / `invalid_at`，Graphiti 那套）：
**"现在"是一个参数** ⇒ 同一份网络，问"现在"一个答案、问"那时候"另一个答案。
⇒ ★ **难度分三层**：**存**（🟢 两个字段）· **取**（🟢 带时间参数）·
★★ **判"这次该用过去还是现在"**（🔴 是判断，不是查表）· ★★★ **"变化"该不该浮出来**（🔴 说早了像翻旧账，说晚了像没记住）。
⇒ ★★ **而最后一层恰好是"浮现"该干的活** ⇒ **不需要新机制**。

**★★★ 最有价值的一层：失效信息的价值不在"它曾是真的"，在"它变了"**

⇒ ★ **"他戒烟了"比"他不抽烟"信息量大得多**——前者告诉你**他在改**。
⇒ ★ 这给"旧的不删、只标失效"一个**比"可回溯"更强的理由**：
**那条失效的记录，是"变化"这条事实的材料。**
⇒ ★★ 所以 **`valid_to` 的触发应产生一条"变化"的边 / 记录**（`抽烟 → 戒烟`），
**锚在两段原文上**（旧的那句 + 新的那句）⇒ ✅ **过得了"锚得住才落库"那道闸**。

**★ "定期整理"是正解，不是权宜之计**：**整理 = 发现冲突 + 标 `valid_to`**（⛔ 不改写、不删）。
⚠️ **"它变了"只能由新的原文证明**（他自己说出来）；**⛔ 系统不许从旧的两段之间推测变化**——那是反刍。

#### (D) ★ 成本：现在是"防跑飞的护栏"

`[原话]` 用户：**"成本现在可以放的很宽，等做成了再看收紧的事情。"**
⇒ ★ 有结构性理由：**激发稀疏 ⇒ 记账本来就不随池子规模增长**。
⇒ ⚠️ 护栏仍要有（否则某天照亮整库，一次浮现就崩）。

### 3.14-2 ★★★ 读的机制：稀疏激活 + 分层下钻（第九轮 · 已确认）

> ⚠️ 编号说明：本节按**话题**紧接 §3.12 之后，**不按时间顺序**；
> §3.13（并行与多视角）是同日更早的一轮，排在后面。

#### (A) ★★ 不是"切"，是"标"

`[原话]` 用户：**"之前不让切是因为切完就完了。现在与其说是切，不如说是连，是连网络而不是切词条。"**
以及 **"锚点得靠模型切。"**

| | 切（旧） | ★ 标（新） |
|---|---|---|
| 原文 | 切出来的**就是全部** ⇒ 没切到的等于丢了 | ★ **全文始终在**（信息完整） |
| 产物 | 一个**划分**（互斥、覆盖） | ★ **一层标记**（**可重叠、可不覆盖、可多套并存**） |
| 所以 | 切完粒度定死 | ★ 标记可加、可重做、可多视角 |

⇒ ★★ **禁令收窄**：**⛔ 不许用模型做"准入裁量"**；**切/标可交模型，但它只许输出【区间】**。

#### (B) ★★★ 编码器看不到全部 ⇒ 稀疏激活 + 分层下钻

`[原话]` 用户：**"编码器肯定不可能直接看到所有内容。还是做稀疏激活，
先激活某一个整体，再激活整体里的某一轮 / 某一段原文，
至于激活尺度，给编码器看的尺度，这就是网络的作用之一了。"**

```
第 0 层：原文（完整保存 —— ★ 保真在这里）        ← ⛔ 不需要模型看它
   ↓ 激活某一个"整体"（文档 / 一场对话 / 一个话题）
第 1 层：那个整体
   ↓ 激活整体里的某一轮 / 某一段
第 2 层：那一段
   ↓ 再往下一层（句 / 片）
```
⇒ ★★ **两个约束同时满足**：**信息完整**归**存储**；**编码器看有限**归**稀疏激活 + 下钻**。
⇒ ⚠️ **更正**：早先"**编码器看得见完整的原文**"**作废**。

#### (C) ★★ 网络的身份升一档：**下钻的路径**

| 身份 | 说明 |
|---|---|
| 结构 | 节点 + 边 |
| 注意力 | 哪些位置被点亮 |
| ★★ **尺度 / 路径** | ★ **激活尺度多少、从哪儿钻进去、下钻到哪停** |

⇒ ★★ **"激活尺度"因此有了落点**：不是读法的参数，**是网络给出的一层**。
⇒ 与 `§3.8d(7)` 分层激发合上：**不是"亮度分层"，是"尺度分层"**。
⇒ ★ **"边"同时是下钻通路** ⇒ **长距边的价值多一条：让"跨窗口下钻"成为可能**。
⇒ ★ **`成本` = 下钻层数 × 每层点亮规模** ⇒ 天然有界，护栏够用。

#### (D) ★★★ 下钻路径是【核验记录】，不是训练特征

`[原话]` 用户：**"第四条也注意，依然是核验手段。"**

⇒ ★ 与"**软标记只给核验看**"**是同一条纪律**：
> ★★ **凡是"记录给人看"的东西，都不许变成"喂给模型"的东西。**
⇒ ★ 落点：**"激发"那一格展开**（`§3.11`）= "亮了哪些节点" + "从哪层钻进去、经过哪些层、停在哪"。

### 3.13 ★★★ 并行与多视角 · 编码器的变化 · 来源只是软标记（第八轮 · 已确认）

#### (A) ★★ 降噪与多视角是【两个正交机制】，⛔ 不要混

`[原话]` 用户：**"要分清，降噪是同一标准，不同输出，而不同视角，本就是不同标准。
是每一个视角，都要分别降噪。"**

| | 标准 | 多份之间 | 处理 |
|---|---|---|---|
| **降噪** | ★ **同一个标准** | **不同输出** | ★ **取一致** |
| ★★ **多视角** | ★★ **不同标准** | 各自不同 | ★★ **每个视角分别降噪**；⛔ **不跨视角取一致** |

```
视角 A（标准 A）→ 跑 N 遍 → 取一致
视角 B（标准 B）→ 跑 N 遍 → 取一致
    ⛔ A 与 B 之间不做一致性比较
```
⇒ ⚠️ **更正**：早先"**孤例 → 弱**"是错的 ——
**跨视角的差异不是"低置信度"，是"另一个视角"**，**不该进那个对比**。
⇒ ★ `[原话]` **"除了降噪，也起到从多个角度采样增强完整性的作用。"**
⇒ ★ 所以多视角的意义是 **"从不同角度采样、补全"**，⛔ **不是"互相投票"**。

#### (B) ★★ "标很多不同的网络" = 并行落在"标网络"上，一次拿两个收益

```
原文（任何来源）→ ★ 并行标 N 张网络（每张 = 一种切分 + 一组关系）
                   ├─ 同标准多遍 ⇒ ★ 降噪
                   └─ 不同标准   ⇒ ★ 多视角（补全）
```
⛔ 纪律：**每一遍必须独立**（不许在上一遍的网络上再标）。

#### (C) ★★★ 编码器：统一、且本身随经历变

`[原话]` 用户：**"我说的通用编码器指的是，套上哪个数据库都能用的。
这边的设计则是编码器本身也在不断变化。"**

| | 通用编码器 | ★ 本项目的编码器 |
|---|---|---|
| 换数据库 | ✅ 照样用 | ⛔ **不能**——它是在**这个空间里长出来的** |
| 随时间 | 不变 | ★★ **一直在变** |

⇒ ★ **⛔ 不为来源分叉**（早先"按来源分编码器"的说法作废）。

#### (D) ★★ 来源 = 软标记（一条管线）

`[原话]` 用户：**"三种来源没必要做硬区分，区分反而不合理。"**

| | ⛔ 硬区分 | ✅ 软标记 |
|---|---|---|
| 形态 | 不同管道 / 编码器 / 存储 | 记录上的一个**来源标记** |
| 后果 | 流程分叉、通用性没了 | **流程统一** |

#### (E) ★★★ 补一句（把软标记的用途钉死）

`[原话]` 用户：**"软标记是给核验看的，不是训练用的。"**

⇒ ★★ 所以：
- ✅ **写进记录，用于核验**；
- ⛔ **不进黑箱的输入、不作路由、不作训练特征**（否则就是变相按来源分叉）。
- ⚠️ 连带更正：早先"**来源标记同时是审计与路由**"**作废** —— **它只是审计**。

#### (F) ★★ 三种来源的能力分工（材料性质，不是管道分叉）

| 来源 | 能得到 | ⛔ 做不到 |
|---|---|---|
| **旧对话** | ★ **真实信息**（关于他） | "我们之间的事" · 人设/守则 |
| **生成材料** | ★ **人设 / 守则** | ⛔ **真实信息** |
| ★★ **新对话** | ★★ **两者都可以** | —— |

⇒ ★ 与 `§3.5` 三个认知方向对上：**材料性质决定它能喂哪个方向**。
⛔ 纪律不变：**从旧对话里提取的东西，不得长出"我"的边**；
⚠️ **软标记只给核验看** ⇒ **这条规则必须进核验清单**。

## §4 待决 / 待补（**记录者不替本人定**）

> ★ **2026-10-08 第二轮已定（编码器那条闭环）**：
> · ★★ **编码器目标 = "听见什么话，浮现出什么"**（代替的是**浮现**，不是记忆仓库）——载体退居次要
> · ★★ **形态 = 一轮里浮现好几次**（CoT 很长）⇒ 这就是"连续状态回路"在第一步的对应物
> · ★ **两层读法**：内层（浮现）可读原文；外层（交付）只给编码器输出；⛔ 内层不许绕过编码器
> · ★★ **判据四条**（增量 / 该想起来 / 不该提 / 不越界），**各自报警、人读裁决，⛔ 不许合成一个分数**
> · ★★ **训练材料可以生成**（情境可造、浮现可多造；⛔ 底片与进池子的东西不许生成）
> · ★★ **主训练形态 = 采样 + 两两排序**（没对照就没训练）
> · ★ **三个信号源各管一段**：边际增益（判据 1）· 采样排序（判据 2/3）· dreaming 出卷子（判据 4）
