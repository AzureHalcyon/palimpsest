# 风格层 · 已归档（2026-10-16）

**归档理由一句话：风格层作为独立的一层站不住。**

它原来要解决的问题是"记忆稀疏时，模型默认 persona 盖过记忆"。后来发现——
**一个好的起点（开场那段设定）就解决了，而且解决得更彻底**；
再往后（作者：酒馆经验）**只要代入发生，CoT 自己就转成内心 os，每轮根本不需要插手**。

⇒ 于是"风格层"这个独立层没有非它不可的活。**改做在记忆里**（见 `../../草稿-常驻记忆与翻译器.md`）。

## 做过什么（可复用的实测）

## 死了的

- 「风格层是一个**独立的层**、外挂在 LLM 上」（这是被归档的东西本身）
- **多尺度跨会话状态 `s`**（快区/慢区/旁路注入）—— 作者：**记忆本来就是跨对话存在的**，
  跨对话留存由记忆层承担，⛔ 不需要另设一个跨会话状态模块。"记忆层的动力学之前考虑过"。
- **prefix 作为主通道** —— 它在抢一个本来就在自转的位置。
- **"一次生成、机械切成 prefix ＋ 输入段"** —— 切的是标点，不是角色；两段本来就不同源。

## 活下来的

- **CoT prefill 的接口配方**（将来若要"微调某几轮"还用得上）
- **两条硬约束**（翻译器的输出同样不许有转折/指称）
- ★ **"喂实例，⛔ 不喂描述"** —— 这条现在换了个说法：**记忆的出口必须是第一人称**
  （`她当时有点沉` 不合格，`我有点闷` 合格）
- ★ **"常驻 / 按需"就是原来"无条件 / 按需"那一格** —— 位置保住了，只是内容改成记忆
- **段内冻结 ＋ 段末重训**那套（现在对应"常驻记忆的重算"）
