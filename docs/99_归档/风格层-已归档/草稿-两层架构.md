# 一、为什么会有两层（来龙去脉）

1. 起点：**只有记忆层。**
2. 撞到的问题：**记忆稀疏时，模型默认的 persona 会盖过记忆。**
   —— 刚攒下的一点点记忆，压不住模型自带的那套"助手"人格。
3. **记忆确实能涌现风格，但一开始太稀疏，不够强。**
4. ⇒ 于是加一层**风格层**，变成两层。★ **风格层是骨架，记忆层把它填丰满**（这就是"骨架"这个名字的来处）。
5. 风格层 ＝ **类似 LoRA / adapter 的可重训物**，作用是**把人格等稳定下来**。
6. 然后才是技术细节：
   - 风格层与大模型之间**需要一个转换** ⇒ 考虑加一个**端侧小模型**干**翻译**的活；
   - 状态怎么进 ⇒ **旁路注入小模型**；
   - 落点怎么选 ⇒ **测 prefix**。

⚠️ 一条纪律：**上面第 6 条里那些都只是风格层的一部分，风格层 ≠ prefix。**
而且 **⛔ 大模型不只拿小模型的输出**——它拿到的是**整个上下文**，风格层只占其中一块。

# 二、全景

```
 用户 ──话──▶ ┌──────────┐ ──回应──▶ 用户        ← 全程只有这一条对话
              │  大模型   │
              └──────────┘
                ▲   ▲   ▲   ▲
                │   │   │   └── 用户这一句
                │   │   └────── 历史（含★她自己说过的近处回应）
                │   └────────── 系统消息 · 记忆层返回值
                │
        ┌───────┴──────── 风格层的产出：prefix · 输入段
        │
     ┌──────┐
     │ 小模型 │◀── 情境（文字，修剪整理过的上下文）
     └──────┘
        ▲
        └── 旁路注入 ◀── 状态 s（情绪 · 气氛 · 分寸 · 时间尺度）
                          ▲
                          └── 只吃真实发生过的：用户的话 · 她的回应
```

# 三、两层各是什么

| | **风格层** | **记忆层** |
|---|---|---|
| 是什么 | 可重训的外挂（LoRA / adapter 式） | 关系图 ＋ 读取 |
| 什么时候用 | ★ **无条件**（全程套在大模型上，每次 I/O 都过） | ★ **按需**（第一阶段＝tool 接口） |
| 管什么 | 风格 · 人格 · 情绪 · 分寸 · 气氛 · 时间尺度 | 内容 · 事实 · 经历 |
| 目标是 | **把人格稳定下来** | **把风格填丰满** |

- `[作者定]` ★ 两层的区别就是**"什么时候使用"**。
- `[作者定]` ★ **分配规则：不需要具体记忆的 → 风格层；需要具体记忆的 → 记忆层。**
  例：情绪 · 分寸 · 气氛 · 时间尺度 · "怎么比" → **风格**；事实 · 经历 → **记忆**。
  ★ **"连接"被这条规则自动切两半**："怎么算同一件事"（形状）→ 风格；"这两处是不是同一件事"（判定）→ 记忆。
- 记忆返回值 ＝ 浮现的输出，⛔ **不是原文片段**。
- `[作者定]` **偏好两层都不单独训，是涌现的**；记忆靠连接能涌现风格，但**不够** ⇒ 才要风格层。
- `[作者定]` ★★ **材料 ≠ 整个上下文**。材料是**修剪整理之后的上下文** ⇒ 风格层的补充段 · CoT 都属于上下文，⛔ 都不是材料（**CoT 不进材料**）。

# 四、风格层内部

## 4.1 两条路，一个层

★ **情绪 / 状态属于风格层**（分配规则）；**但它的载体是旁路，⛔ 不是文字。**
⇒ 「旁路」是**载体**，⛔ **不是归属**。（我曾把这两件事混掉，写成"风格层不承担状态"——错。）

| 路 | 载什么 | 怎么走 | 到哪 |
|---|---|---|---|
| **文字路** | 风格 · 开口姿态 · 这一刻的框 | 小模型**产出的文字** | prefix · 输入段 → **大模型** |
| **状态路（旁路）** | 情绪 · 气氛 · 分寸 · 时间尺度 | **注入小模型自己的中间层**（薄注入点 · 每 4 层 · 低秩 · **零初始化** · 可拔 · 独立版本） | 小模型 |

- ★★ **用户全程只和大模型对话。** 小模型 ⛔ **不对用户说话**，它是**中转/翻译**：
  把"情境（文字）＋ 状态（注入）"**说成给大模型的输入** —— 用户看不到，⛔ 也不是"她的回答"。
- ★★ **状态 ⛔ 不走文字。** 起念里不该出现"她今天很累""她这么高兴"这类**内容**——那是**把状态当内容做**。
  状态改的是"**怎么说**"，⛔ 不是"说什么"。**状态不走文字，但它体现在文字里**（经小模型写出来之后）。
- ⚠️ **两个"碰不到"要分清**：**碰不到基座内部**说的是**大模型**（API，黑盒）⇒ 风格层对大模型只能靠文字；
  **旁路注入发生在小模型自己**的层里（小模型是我们的）。两条不冲突。
- ⚠️ **别拿旧文档的「调制」或调研里的"情绪是调制器"来讲这条**：前者是**旧设计**（读取模型那一路），后者是**调研记录**，⛔ 都不是这里的东西。

## 4.2 小模型这一侧

- 职责：**只维护风格**（翻译）。⛔ 不产生状态、⛔ 不产生内容、⛔ 不决定要不要查记忆。
- 输入：**情境**（文字，修剪整理过的）＋ **状态**（旁路注入）。
- 输出：**给大模型的文字**，按用途落到两个通道上。
- ★ 训练目标的排序：**"跟历史里的她是同一个人"排第一**，贴情境、好不好听都排在后面。

## 4.3 通道分工（按用途分，⛔ 不按内容分）

| 通道 | 留给 | 为什么 |
|---|---|---|
| **system message** | 对话初始化 · 工具调用等**底层** | 底层管道，⛔ 不塞风格 |
| ★ **prefix（落在 CoT 内）** | **风格 · 开口的姿态** | **最强位置**（字面意义"开口之前"）＋ **不暴露**（CoT 不给用户看）＋ **不进材料** |
| **用户的话之前/之后** | **较长的限制 · 约束**等 | 需要在回答时显式遵守的东西；位置灵活、可长 |

- ★ **约束要显式遵守 ⇒ 放输入段；风格要渗透 ⇒ 放生成起点。** prefill 占的是生成的开头，**不宜长**。
- `[作者定]` ★★ **CoT 不进材料** ⇒ 风格层写进 CoT 的东西**不回材料** ⇒ **风格层不会自己教自己**，⛔ 不用另立纪律。

## 4.4 风格层本身

- `[作者定]` 有**种子**（初值），随每次归档**重训演化**。
- `[作者定]` ★ **收敛回种子没关系**：看的是"**动没动、动得跟经历相不相称**"，⛔ 不是"离种子多远"。
- `[作者定]` "快区/慢区"**只是指代**：使用时**整个风格层按需激活**，⛔ 不预设分区。
- `[作者定]` 跨归档**可以有模糊地带**（昨天的情绪今天还有一点）⇒ 用**衰减**，⛔ 不用硬边界。
- `[作者定]` ⛔ **不手列结构量**：情绪**不预设低维、不列分量**（不可辨识 · 方向可能反 · 放大噪声）。
- `[作者定]` 介入点定在**输入侧**（出口不在主路，先不做）。通道**按用途分** ⇒"固定槽 vs 自由路由"这个问题不存在：路由只决定**这次写什么内容**，⛔ 不决定放哪儿。

# 五、状态 s（2026-10-16 修正）

- `[作者定]` ★★ **多尺度**：`s = { s_fast · s_mid · s_slow }`，各自 λ **差几个数量级**（分钟/几轮 · 一小时级 · 跨天）。
  ⇒ **一个 λ 管不了差几个数量级的时间尺度**：取快了跨天的不留，取慢了这次对话里她纹丝不动。
- `[作者定]` ★★ **每轮两次更新**（⛔ 都不在轮的中间）：

  ```
  ① 生成前：s ← step(s, 用户这一句)     ← 即时（被刺激驱动）
  ② 生成时：输入 = 这一句 ＋ s
  ③ 生成后：s ← step(s, 她的回应)       ← 持续（被自己的输出带动）
  ```

  ⇒ **"即时"与"持续"不是两个机制，是同一条递推上的两个更新步。**
- `[作者定]` **一轮之内冻结**；loop 的多跳共享同一份 `s` ⇒ ⛔ 不会自我引燃。**轮内的情绪演变由生成过程（大模型）承担。**
- `[作者定]` 只吃**真实发生过的交互**：用户的话 · 她的回应。
  ⛔ 不吃：风格层自己写的 prefill（是条件，没发生）· CoT（无状态）。
- ⚠️ **守一条**：`s` 不提供内容、不决定"想起什么"（只给倾向与连续性）⇒ 没有替记忆层干活。

# 六、大模型到底拿到什么（⛔ 不只拿小模型的输出）

| 大模型拿到 | 谁给的 | 风格层的角色 |
|---|---|---|
| **系统消息** | 底层（初始化 · 工具） | ⛔ 不塞风格（作者定） |
| **历史** | 真实发生过（**修剪整理过**） | ★ 里面**她自己说过的近处回应**是"她一贯怎么说话"**最强的证据** |
| **记忆层的返回值** | 记忆层（按需 tool） | 内容；⛔ 不是风格 |
| **用户这一句** | 用户 | —— |
| **风格层的产出** | 小模型 | prefix ＋ 输入段（风格 · 姿态 · 框） |

⇒ ★ **"让大模型进入状态"不能只靠 prefix**，是**这五块加起来的合力**。
而其中**最有力的一块是历史里的她自己**——它既是"她说的"，又是大模型认得出"是我说的"的唯一东西。

## 6.1 从实验拿到的三条（`实验-01-prefix通道/结论.md`）

1. **通道可用**：起念落 CoT prefill，48/48 条件被接住，0 空输出；且顶掉模型自己要写的 80–90% 思考。
2. **思考跟着走 ≠ 输出跟着走** ⇒ 读数必须读**可见输出**。
3. ★ **一致性 > 强度**：给错方向的起念会被**情境压平、被历史拉回**。
   ⇒ 大模型有自洽性检查；上下文互相矛盾时它选**证据多的一边**（历史 > prefix）。

# 七、要解决的问题：大模型自己的状态能不能和风格层对齐

★ 大模型自己聊天时**自带一个状态**（它自己的 persona 惯性 · 它对这段对话口气的累积）。这条**不是风格层给的**。

**能不能对齐——这是两层架构的成败处：**

- 对不上 ⇒ 风格层的产出被它的默认 persona 吃掉。
  ⚠️ **这正是最开始那个问题**（"模型默认 persona 覆盖记忆"）**的同一种失败**，只是换了个对手。
- 对得上 ⇒ 风格层才算真的立住。

对黑盒大模型，**能用的手段只有上下文里那五块**（第六节）。由此两条设计结论：

1. **她刚才那句话必须原样在上下文里。** 那是"真实发生过、且它认得出是自己"的唯一东西。
   对照"材料是修剪整理之后的上下文"——修剪规则要开一个例外：
   ★ **属于她近处回应的那几轮，⛔ 不许修剪、⛔ 不许摘要**，否则连续状态断掉，表现为**情绪跳变**。
2. **气氛的载体是措辞，不是说明。** ⛔ 不能对它说"气氛有点冷"（那是内容）；要让它**读到一句冷的话**。

7. ★ **记忆返回值要不要进 `s`** —— 这是情绪与记忆层唯一的重叠处（想起来的事会影响情绪）。
   `[作者定]` 这条**比较复杂，得看情况**。支持：想起来的事会影响情绪。顾虑：它来自**库**，⛔ 不是"发生过的交互"。
8. ★★ **风格层的输入形态**（三种，未定）：

   | 方案 | 情境怎么进 | 状态怎么进 | 延迟 |
   |---|---|---|---|
   | **A 文本** | 情境 tokenize 进模型 | 中间层注入 | 随句子长短变 |
   | ★ **B 全注入** | 情境压成向量（软提示/注入） | 中间层注入 | ✅ **恒定** |
   | **C 混合** | 情境给文本 | 只注"底色" | 随句子长短变 |

   - `[推断]` 倾向先试 **B**，留 **A** 作对照。B 的好处：**延迟与用户话的长短无关** · **自动实现"无指称"** · **"注入被忽略"这个失败模式没了**。
   - ⚠️ B 的风险：**模式化退化**（同一状态 → 固定那几句）⇒ 判据：**同状态换情境，输出要有变化**。

9. ★★ **小模型一次产出一段还是两段**（prefix ＋ 输入段）：
   - `[推断]` 倾向**一次生成、机械切开**：两段都出自同一个 `s`，分开生成会产出**互相矛盾的两段**（框说"别追问"、姿态却在追问）；而且延迟只付一次。
10. ★★ **对齐怎么做**（第七节）：除"保住她的近处回应"之外还有什么手段。
