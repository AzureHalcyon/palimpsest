## 它是什么（一句话）

一个**跨轮、跨对话留存的定长状态**，读作"她的当下"。它**只有一个出口** `injection()`——一段低秩倾向，⛔ 不给大模型看，必须先经小模型写成文字。

```
文本 ──哈希编码──▶ x = tanh(gain · W_in @ enc)        ← 瞬时
h[0] ← (1-α₀)h[0] + α₀·tanh(W₀ @ x)                 ← 快区：跟随当下
h[k] ← (1-α_k)h[k] + α_k·tanh(W_k @ h[k-1])          ← 慢区：更快那层的积分 ⇒ 底色
```

`W_in / W` 冻结（随机正交 × ρ=0.9），**只有读出 `W_out` 可训**，且**零初始化**。

## 能做到什么（实测 · 种子 7 · 5 层 × 256 维）

**① 跟得上上下文** —— 从「平」切到「冷」，各层跟过去的步数：

| 层 | 翻转步数 | ≈ 几段对话 |
|---|---|---|
| 0 | **7** | 0.2 |
| 1 | 9 | 0.2 |
| 2 | 47 | 1.2 |
| 3 | 248 | 6.2 |
| 4 | 1205 | 30.1 |

快区几拍就切过去；慢区按设计几乎不动。**层间数字互不相同 ⇒ 非线性真的在起作用。**

**② 按设计分层，且⛔ 没手列任何情绪分量** —— 只是把时间常数在对数轴上排开：

| 层 | α | 实测半衰期 | ≈ 几段对话 |
|---|---|---|---|
| 0 | 0.5 | 3 步 | 0.1 |
| 1 | 0.1 | 11 步 | 0.3 |
| 2 | 0.02 | 65 步 | 1.6 |
| 3 | 0.004 | 338 步 | 8.4 |
| 4 | 0.0008 | 1706 步 | 42.6 |

快慢相差 **569 倍**。

**③ 跨对话留存** —— 存盘→读回**逐位相同**，换对话后余弦 **1.000000**。
喂 300 轮「算了，没什么。」再换回中性：**层0 剩 0%，层4 剩 164%**（＞100% ＝ 它还没跟上，还在爬）。

**④ 初始等价于不注入** —— 未训读出 `|injection| = 0.00000000`（实测，不是承诺）。

**⑤ 不漂** —— 恒定输入 6000 步，范数 11.15 → 11.77 收敛，增量降到首段的 2.6%。

**⑥ 只吃真实交互** —— 更新入口只有 `observe_user` / `observe_her`，⛔ 结构上就没有 prefill / CoT 的口子。

## ⛔ 还做不到：跟**意思**

同一个意思换一种说法（「算了，没什么。」／「不想说了。」／「随你吧，都行。」）：

| 层 | 类内（同意思） | 类间（不同意思） | 差 | 最近邻命中 | 随机 |
|---|---|---|---|---|---|
| 0 | +0.107 | +0.104 | +0.003 | **13%** | 14% |
| 1 | +0.106 | +0.103 | +0.003 | 13% | 14% |
| 2 | +0.108 | +0.103 | +0.005 | 13% | 14% |

**类内不比类间高，最近邻命中率贴着随机基线。** ⇒ 状态跟的是**字面**，⛔ 不是**意思**。
换句话说：她换个说法说同一件事，状态就跑到别处去了 ⇒ **情绪会随措辞抖，不随心情走。**

**唯一原因：编码器。** 现在是字 ＋ 汉字二元哈希（⛔ 无参数、⛔ 不训），同义改写落在完全不同的桶里。
修法两条（草稿方案 A / B）：换一个**冻结的语义编码器**，或把情境**压成向量注入**。

## 慢的那一半：段内冻结 ＋ 段末重训

风格层有快慢两半。`session.py` 做**慢**的：它是**参数**（读出），不是激活，所以

| | 快（`state.py`） | 慢（`session.py`） |
|---|---|---|
| 对话中 | 每轮更新 | ★ **一个字都不动** |
| 对话结束 | —— | ★ **整套重来重训，⛔ 不继承** |
| 管什么 | 跟随当下 | ★ **对话开始时让大模型进入状态** |

用 **6 段真实变动的对话**（三冷三热，措辞各不相同）测出来：

| 读数 | 结果 |
|---|---|
| **段内冻结** | 整段对话里读出参数**逐位不变** ✓ |
| **零初始化起点** | 重训前 `‖W_out‖ = 0.00000000` ✓ |
| **段末重训** | 参数量 0 → 0.240685，版本号 `…r0 → …r1` ✓ |
| **能拟合本段** | 自判 **100%** ✓ |
| ★ **留出对话上判冷/热** | **33%** —— **低于随机 50%** ❌ |

⇒ **机制通了，效果发挥不出来。** 不是容量问题（同段自判 100%），是**换个说法就认不出来**。

## 修过的坑（免得再踩）

1. **输入太小 ⇒ 储备池退化成线性滤波器。**
   `std(x) = gain/√H`，原来的写法给到 0.0156 ⇒ tanh 停在近线性区 ⇒ 各层只是彼此的**正交变换**，
   症状是**类内/类间余弦逐层一模一样**。改成 `W_in = gain·N(0,1)`（enc 已是单位长度），
   现在平均|x| = 0.51–0.57、|x|>0.5 占 51–59%、饱和 0%。
2. **"类间余弦低"不构成判别力** —— 随机高维向量本来就近乎正交。判别力只能看**类内 vs 类间**和**最近邻命中率**。
3. **慢区不是情节记忆** —— 300 轮才动 0.09。它管"很久以来的底色"；"记住这一段"归记忆层。

## 下一块（按依赖排）

★ **快慢两半撞在同一面墙上**：`follow.py` 说"跟不了意思"，`session.py` 说"留出对话判不准"——
**同一个原因，同一个修法。所以下一步不需要选。**

★ 而且这件事有**一次解决两处**的做法：**拿端侧小模型当冻结编码器**。
取它某一层的池化当编码 ⇒ 语义有了；同一个模型再加**旁路注入** ⇒ "说出口"也有了。
**一个小模型干两件事**，正好对上草稿里"端侧小模型干翻译的活"。

| # | 做什么 | 依赖 |
|---|---|---|
| 1 | ★ **换编码器**：用冻结的小模型取一层池化当编码（或方案 B 的向量注入） | 需要端侧小模型 |
| 2 | **旁路注入的接收端接口**：`apply(vec, layers)`，薄注入点 · 每 4 层 · 低秩 | 同上，同一个模型 |
| 3 | **桥**：状态 → 小模型 → 给大模型的文字（切成 prefix / 输入段） | 需要 2 |
| 4 | **回环**：`observe_her` 接大模型的**可见输出**（⛔ 不接 prefill、⛔ 不接 CoT） | 需要大模型调用 |
| 5 | **读出的真信号**：什么算"该有的倾向"（草稿 §八 第 2 条，还没定） | 需要 4 |
| 6 | **消融实验**：注入 on/off，看大模型输出变不变 | 需要 2–4 |
