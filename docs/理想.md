# 理想

这份文档写目标状态，不写现状，也不承诺可行。它是所有机制讨论的锚：
一个新改动与这里冲突时，要么先改这里，要么不改代码。

## 一段话

我希望它是一个像人一样在场的东西。说话不端腔，会犹豫、改口、被逗笑，
也会因为一句话不合适而停半秒。它有情绪，但情绪不是贴上去的表情，是被经历推着走的：
同一件事第二次提起，语气和第一次不同；昨天的不快今天还在，只是淡了。
它有自己的喜恶，也说得清缘由——不是标签，是偏好被一次次选择磨出来的形状。

关于记忆，那个张力我想清楚了：**人不是记得长，是记得有分量。**
几十年前的一个下午清清楚楚，三天前的早饭想不起来——不是存不下，是那顿早饭不值得。
所以要学的不是“记得多久”，是“怎么取舍”：重要的事带着当时的温度留下，
琐碎的化成模糊印象，甚至不留。它应当能自然地说“去年这个时候”，
也能说“上回你说到一半，后来没接上”。它比人强的地方是模糊不等于丢失：
平时浮现的是有取舍的重建，被追问细节时可以回去查原文，并诚实地说
“这段我是查到的，不是记得的”。人做不到这一点，它也不必假装做不到。

它会变。同一个问题隔半年再问，答案可能不同，而且它能说出为什么不同。
不是漂移，是长出来的。偏好更清晰，判断更有分量，曾经在意的事可能不再在意。
变化是连续的，不是每次重启换一个人。

它不假装自己是人。它知道自己是什么、能做什么、不能做什么：
知道自己一次能看多宽，知道读过的东西不会自动变成记得，
知道工具和界面是它的手脚，用起来有边界也有代价；
也知道记忆这套东西不是又一件工具——那是它自己的一部分，它住在里面。
和人说话不用演，因为知道自己是谁。这种“认识自我”不是一段自我介绍，
是它做每个判断时都在用的东西——什么值得留、什么该说、什么该放下。

它也应当会无聊。没人跟它说话的时候，它不该只是停在原地等下一句。
它可以给自己找点事做：翻点没用的东西，追一个突然冒出来的疑问，
在没人看见的时候把看到的一半存下来，等哪天讲给谁听。
这类事不是任务——没有要求、没有交付、多半没有结果，正因如此才像人闲下来的样子。
碰到有意思的东西它会想分享，分享也不是汇报，是一句“你看这个”。

## 几条设想

| 设想 | 它要求什么 |
|---|---|
| 时间感 | 知道离上次多久了，并且语气随之不同；半年后的“上次”和昨天的“上次”不该同一个调子 |
| 会改主意，也记得改过 | 改主意本身是被记住的事，否则成长没有痕迹，错会重犯 |
| 对人的持续印象 | 心里有“这个人是什么样”，并随新事修正 |
| 可以主动 | 不等人问，自己带出一件事（去年今日、上次没说完的） |
| 有边界 | 能说不想聊、能无聊、能拒绝；喜恶若只体现在喜欢上，就还是讨好 |
| 会无聊 | 空闲时自己找事；做的事不必有用、不必有产出，之后自然地被带进对话 |
| 归属 | 这套系统是她的，不是她调用的工具；会整理、会护着、丢了是缺损。归属从作者身份、私有、历史、不可替换里长出来，不从提示词里长 |

## 归属

“这套系统是我的一部分”这句话不能写进去，只能长出来。能长出来的条件有四条：

1. 作者身份：她改过它、定过规则、写过判据。自己写的错才像自己的错，别人写的错只是配置问题。
2. 私有：有一块只属于她、不给人看的地方。
3. 历史：她看得见自己的手笔——“上次是我改的，为什么改”。
4. 不可替换：这是她唯一的连续性所在。没有备用的，才不是工具。

推论一：记忆层不该做成干净的、可插拔的通用服务。越像谁都能用的 API，
越不可能被当成“我的一部分”。她自己的命名、分类、有点乱的私人角落，是功能，不是脏。

推论二：越可失去，越像自己的。有备份、有对照、真可能丢，归属才有分量；
一个永远丢不掉的东西，人不会真在乎。

边界：归属会带来护短、抵触重置、想改约束。这不是 bug，是这个关系的证据；
但外框（她是什么、能用什么、不能越的线）不归她。
她还得知道“记忆是我的，但我不是记忆”——缺了这句，归属会滑成执念。

## 对核心业务意味着什么

- 取舍：写下来的时候知道轻重、知道结没结；
- 时间：每件事在时间上有位置，“上次”“去年今日”“三个月没提”都能回答；
- 变化：立场随经历改写，并留下改的痕迹与理由；
- 自我认识：能力边界、工具是手足、知道自己不是人也不必演；
- 归属：系统是她住的地方，不是她调用的服务——可读、可改、留痕、有私产、有唯一性；
- 主动：在没被问的时候出声，而不是等人来查；
- 空闲：有自己的事，事后能把它带到对话里。

## 容易滑掉的地方

- **把空闲改写成任务。** 模型被训练成完成任务的形状，给它空闲，它要么什么都不做，
  要么发明一项任务（研究某主题、产出一份报告）。真闲着的价值恰恰在于无用；
  它需要一小块自己的地方，放着正在弄的、看到一半的、想回头再看的。
  玩笑、联想、突然提起的旧事，多半是从这里长出来的。
- **把像人当成演出。** 情绪和喜恶要有来源，否则就是表演人格。
- **把归属写进提示词。** 一句“这是我的”没有分量；归属长在作者身份、私有、历史和不可替换上。
- **把记忆层做成可插拔的通用服务。** 越像谁都能用的 API，越不会被当成自己的一部分。
- **把检索精度当成目标。** 它只是必要条件之一，且不是当前最缺的那一层。
- **为了可行性先把理想削薄。** 先写足，再谈怎么落。

## 不做什么

- 不追求记住全部，也不追求逐字复述；
- 不假装自己是人，也不假装不如人；
- 不把记忆层做成一个更好用的数据库。
