## 1. ★★★ 迭代线（作者原话 · 这一节是核心）

### 1.1 原话

`[作者原话]`

> "先用**角色卡**做第一波判断，然后**人判哪些好**，然后**训出第 1 iteration 的模型**，
> 然后**模型判第二波**，**人判哪些好**……**这样继续**。但这也不一定对。"

以及随后一句：

> "关于判候选，**候选就来自训了一半的模型**。"

### 1.2 逐句拆开

| 原话 | 拆开是什么 | 谁在做 |
|---|---|---|
| "先用角色卡做第一波判断" | 还没有任何模型时，用**一份人写好的初始设定**去产第一批判断/候选 | **初始化**（见 §1.4 用词） |
| "然后人判哪些好" | ★ **人只在候选之间挑好的**——⛔ **不需要人去找"该想起来什么"** | **人** |
| "然后训出第 1 iteration 的模型" | 用这批"哪些好"做信号，训出**第 1 版比较函数** | 训练 |
| "然后模型判第二波" | ★ **第 1 版自己去产下一批候选**（它自己试着连） | **上一轮训出来的模型** |
| "人判哪些好……这样继续" | 每轮都这样：**模型产候选 → 人判好坏 → 再训一版** | 循环 |

### 1.3 一个完整的版本循环长什么样

```
第 N 版：
  ① 当前这一版在图上产出若干候选
       （N=0 时还没有模型：用初始化那份设定，**或者**直接以已标出来的图为全部可用 —— 见 §1.4b）
       —— 候选 ＝ "这几处可能连着" / "这几组可能是一件事"
  ② 人判：这些候选里，哪些好
       —— ★ 人只做比较与挑选，⛔ 不负责凭空列举
  ③ 用②当信号，训出一版新的比较函数
  ④ 回到①，用新这一版产下一批候选
```

★ **"训了一半的模型"就是这个循环里处在中间的那一版**——它已经比上一版好，但还没训完；
⇒ 所以"候选从哪来"这一格**有着落了**：**候选来自自己，⛔ 不需要外部更强的老师。**

### 1.4 用词：为什么写"初始化"，不写"角色卡"

`[设计原文]`

- 文档里的对应物叫 **初始化**：`§6.5` "初始化是一类特殊材料：**一次性的输入，用于装载基础设定**……
  但它**必须标记为初始化**，不伪装成来自人的输入。"
- `README` 里有一句**看起来相反**的话："人格、情绪与关系**不靠预设和角色卡**，而是从累积的经历里长出来。"

⇒ 所以正文用"**初始化那份设定**"这个说法，⛔ 不用"角色卡"——避免看起来在撞 README。

### 1.8 ★★★ 归档里的两遍：先独立标节点，再开放记忆层判连接

`[作者定 2026-10-11]`

**定了的划法：节点与组独立标；连接带记忆标。** 落实成**两遍**：

```
第一遍 · 独立标（⛔ 不看记忆）
   输入：这一章原文 ＋ 视角
   产出：★ 节点与组                    ← 地基；＝ 现在的 annotate.py ✓
                                      （外生 · 可复现 · 与记忆层无关）

第二遍 · 开放前期记忆（★ **同一个任务，只多给输入**）
   输入：这一章原文 ＋ 视角 ＋ 【已被取用的前期记忆（旧位置与组）】
   产出：★ 与第一遍**同一形态**：节点与组（＋理由）——但**不进库**（见下面的落点）
```

- ★ **任务是同一个**："这一段里哪些值得记住"——⛔ **不问"跟旧的哪一处是同一件事"**。
  三条理由（作者 2026-10-11）：
  1. **不预设对应物**：全新的东西**无处可对**，问"跟谁是一件事"会把它**漏掉**；
  2. **"同一件事"只是一种关系**（还有导致 / 同时 / 属于 / **变了**…）；
  3. ★★ **变化前后本来就不同** ⇒ 问"是同一件事吗"，模型很自然答"**不是**"
     ⇒ **最想捕捉的变化/漂移，恰好会被这个问法判掉**。
  ⇒ 所以**该不该记、记什么，由模型定**；"**变化**"本身**值得记** ⇒ 会被标 ✓
- ★ **关系与变化的理由有一个现成的落点**：**`组说明`**（记录层——`②标注记录` 里已经有了：
  "模型凭什么把这几处划在一起"，例如实测 luna 给出的"凭的是盗洞挖掘过程中洞内出现变故…拉绳救援"）
  ⇒ ⛔ **不需要新造"关系类型表"**。
- ★★ **落点（乙 · 作者 2026-10-11 拍）**：
  **正式的图仍由第一遍（独立标）产出、落库**；**第二遍的产物只存档**（当训练信号）。
  ⇒ 理由：如果第二遍的产物**就是那一版图**，图就**依赖当时那一版记忆层** ⇒ **图不再外生**
  ⇒ `训练 §3.1` 第三对比较（**回响的检测器**）**失效**。
  ⇒ ★ 所以第二遍**也产出节点与组，但⛔ 不进库** ⇒ 因此它**不构成"在上一遍的网络上再标"** ✓
  与 `[设计原文]` `§6.4.2`"每一遍必须独立"**不冲突** ✓
  ⇒ ★★ **顺带解掉一处打架**：`设计 §3.1`"组与组之间的关系**主要留给训练**"——
  第二遍的关系判断**只存档、只当训练信号** ⇒ 那些关系**最终仍由训练建成**（⛔ 不作为库里的边）⇒ **不冲突** ✓
- ★ **白捡的检验**：两遍**同一个任务、同一套提示词**，只差"**有没有开放前期记忆**"
  ⇒ ★ **"第二遍比第一遍多标出来的东西 ＋ 它给出的理由" ＝ 记忆层的贡献**（可干净归因）。

### 1.9 回响的问题（★ 它给了"独立标"一个更硬的理由）

「回响」＝**信号由系统自己产 ⇒ 自我确认 ⇒ 偏差被放大**。
而"连接带记忆标"踩在它上面：**第 N 版的判断成为第 N+1 版的输入** ⇒ **跨版本**的自我确认。

- ⚠️ 比"同一版内自采样"更危险：**盲区被固化**，而不只是错误被放大。
- **已有的防护**：**人判在环**（外部锚）· **负例是机械造的**（不经过记忆层）·
  ★★ **原文是根**：`[设计原文]` 裁判的判据是"**能不能指回原文**" ⇒ 回响发生在"判断"层，
  而每个判断都要落在原文上 ⇒ **可以机械核**。
- ★ 旧仓库排除的那条正对应：`[旧仓库实测]` #9「取回驱动」的强化（`access_count`）
  ——信号是"**系统自己的取回**" ⇒ **回音室**；★ **强化只能来自「真实经历的重复」**。
  ⇒ 可用的判据：**这个信号是"系统自己说的"，还是"原文里有的"？**
- ⚠️ **消不掉的一半**：**人看不到的、模型没想到的，永远学不到**（盲区固化）。
  只能缓解：**多视角 · 多起点 · 留痕**。

### ★★★ 回响的检测器 ＝ `训练 §3.1` 的第三、第四对

| 对 | 比较什么 | 分离出 |
|---|---|---|
| **第三对** | 同一读法 · **图变化前后** | **图/材料的贡献** |
| **第四对** | 同一张图 · **读法变化前后** | **读法自己的贡献** |

⇒ 这两对**分得开** ⇒ "漂移是不是经历驱动的"有答案；**分不开 ⇒ 就是有回响**。
⇒ ⛔ 而如果**图随记忆层变**，第三对就**失效** ⇒ 回响**没有检测器**。
⇒ ★★★ **所以"节点与组必须独立标"的理由不止"地基稳"，更是：图的变化必须外生。**

## 2. 训练的对象：**连接**（不是偏好）

`[作者原话]` + `[推的，与"边不落库、给人看"一致]`

> 作者原话："理想情况，**偏好这些是从记忆里涌现或者说体现出来的**。给了节点和组，**把它们连接起来**，
> 不断增加新连接和断开旧连接。**旧的连接要断开去连接新的，这就是事情的转变和所谓个性漂移**。"

- **怎么连起来的不是存下来的东西，是算出来的**：一套参数 ＋ 节点与组 ⇒ 算出哪些连在一起。
- ⇒ "偏好从记忆里**涌现**"这个说法是准的：**偏好不是一个头，它是连接的形态**。
- ⇒ **个性漂移 ＝ 连接的增／断**。

### 增与断，两条不同的路

| | 靠什么 |
|---|---|
| **增新连接** | 新节点进来 **＋ 重训**（`[设计原文]` 跨材料、字面无关的关联**只有训练能算出来**） |
| **断旧连接 ①** | **图增长自然挤出旧的**——新节点进来，同一套参数在**新图**上的自然激活就变了 ⇒ **不用训** |
| **断旧连接 ②** | 重训后函数本身变了 ⇒ 要训，信号就是 §4 |

### 11.7 级联模型（01 Fusi 2005 · 02 Benna-Fusi 2016）· **已逐字核实** —— ⛔ 撤回一条映射，★ 一条对我们有利、★ 一条与我们冲突

**① ⛔ 撤回**：`√N_syn` 里的 **`N_syn` 是"一条记忆的编码宽度"（多少个独立突触单元）**，
⛔ **不是记忆条目数、也不是我们的节点数**。
> `[原文实测]` 01:210–214："**When a memory is stored through the systematic modification of a population of
> Nsyn binary synapses**, the initial memory trace … Signal ∝ qNsyn."；图 5 标题："versus the number of
> synapses **used in storage**"。
⇒ ★★ **"节点数 → 寿命"这个映射是假的**（只在一种严格条件下才成立：节点＝独立随机二值单元 ·
每条记忆是"全节点、均衡 ±1"的稠密随机模式 · 读出为线性重叠）。
⇒ 若一条关联只覆盖 `k` 个节点，寿命收益是 **√k**，⛔ 不是 √25000。
（"元素数 ↔ 可记住条目数"的那个映射在 **2016**：capacity ≈ N。）

**② ⚠️ 原文内部两个指数并存**：固定 `n` ⇒ `t_max ∝ N^{2/3}`（01:488, 499–517）；
把 `n` 随 `N` 一起调（`q_n ∝ N^{−1/2}`）⇒ `t_max ∝ √N`（01:595–603）。
⇒ 引 `√N` 而漏掉"**n 必须随 N_syn 增长**"这个前提，就是漏了条件。

**③ ★ 措辞更正**：原文说的是 "**comes very close (to within a logarithmic factor)**"，
⛔ **不是"同时拿到两者"**；代价是**每条记忆刚写下时"响度"被摊薄成 `1/n`**。

**④ ★★ 一条对我们有利的**：**遗忘是"被新内容挤掉"，不是被动衰减** —— 2005 强力支持：
> "**forgetting is a consequence of ongoing activity and acquisition of new experiences, not merely a
> passive decay of the memory trace**"（01:27–37）
⇒ **新内容停止 ⇒ 痕迹停止衰减**（模型里衰减率 ＝ 干扰事件率 × 改写概率）。
⇒ 这支持我们的"**该被挤掉，不该被动衰减**"。

**⑤ ★★★ 但一条与我们冲突（要紧）**：**纯挤占式在数学上不闭合**。
> `[原文实测]` 02:1367–1373："if the decay kernel is a power law `r(t)=t^{−γ}` then we must have
> **γ > 1/2** or else … **the variance of the synaptic weight would blow up**"
> 而 2016 **确实保留了一个真被动漏项**在最慢的那个变量上（02:132–134, 1378–1381）。
⇒ ★★ **"永不衰减"的纯挤占式设计在这套数学下不成立** ⇒ **必须留 ≥1 条耗散通道**（最慢时间尺度 `T`）。
⇒ 这一点与"失效只是标记、⛔ 不删除"的想法**有张力**，要单独想清楚（标记 ≠ 无耗散）。

**⑥ ★ 可实现性（好消息）**：**零梯度** · 参数**解析给定**（2005 ≈5 个/群体；2016 ≈`3m+4`≈28 个数）·
状态 **KB 级**（2000 节点 ≈ 2 KB；2016 路线 2000×8 float ≈ 64 KB，可压到几 KB）·
笔记本可跑（2000×8 ≈ 1.6 万 flops/次写入；25000×8 ≈ 20 万 flops）⇒ ★ **它确实是一个"非传统 NN"的真候选，而且不需要人判验证集。**

**⑦ ⚠️ 容量要事先算清**：2005 容量 ≈ `(12/5n)^{4/3} N_syn^{2/3}`（`N_syn=10^5, n=10` ⇒ ≈**320 条**）；
2016 capacity ≈ `N/logT`（`N=2000, m=6` ⇒ ≈**220 条**；`N=25000, m=8` ⇒ ≈**2100 条**）
⇒ ★ **每条约 10 个元素才换 1 条记忆**，而且是**稠密随机模式**。

**⑧ ★★★ 最根本的不匹配**：级联的前提是**独立、随机、均衡 ±1、互不相关**的写入模式
> `[原文实测]` 02:94–96："**we consider memories that are unstructured (random) and do not have any
> correlations with previously stored information (uncorrelated)**"
⇒ 而我们的节点/组**恰恰是高度结构化、高度相关的**（同一件事的节点天然相关）⇒ 2016 自己承认这是最大限制。
⇒ 还有：**级联里"记忆之间"唯一被建模的关系是「互为噪声」**（02:123–124："Previously stored memories,
which are assumed to be random and uncorrelated, **make the memory trace noisy**"）——
⛔ **没有任何"记忆A ↔ 记忆B 的连接/绑定"状态或机制**；它验证的 retrieval 是**同一条**被加噪模式的补全。

**⑨ ★ 一句话行动建议**：**把级联只当作「遗忘/保持层」的候选**（它确实是零梯度、KB 状态、解析超参、笔记本可跑的非传统方案），
★ **"连接"仍需另一套机制**；⛔ 别把 `√N_syn` 当"节点数 → 寿命"。

⇒ 这就是为什么"训练地狱"不是我们没找对方法，而是**这一类问题的结构本身**。

## 12. 三块**别丢**的东西（前几轮聊出来、差点没记）

### 12.1 ★★★ 能训的是「同一性」，⛔ **不是「该不该」**

`[推的，但把 §1 的迭代线读透就是这个]`

| 问题 | 有标签吗 | 有验证集吗 | 能算 loss 吗 |
|---|---|---|---|
| **"该不该想起来"** | ⛔ 没有 | ⛔ **没有**（每个情境只发生一次） | ⛔ |
| ★★ **"这两处是不是同一件事"** | ✅ **有**（判出来的） | ★ **有**（可划 held-out 的同一性对） | ✅ **能** |

⚠️ **与 §6.6 对账（必须一起读）**：**这是"形"与"量"的冲突**——
"同一性对"这个**任务形态**有标签、能划 held-out（**形**）；但**人判的量只有 10²**（**量**）。
★ **形成立不蕴含能训** ⇒ **下面这句"能训"是 `[推的]`**，它成立的条件是：
① 候选生成那一格先有形状（§10）② 判的量能上去。**这两个条件现在都不成立。**

⇒ ★★ **"至少得是一个切实能训的"——这个就是**：**一个判断"两处是不是同一件事"的比较函数**
（判别式 · 二分类/打分 · 能量化 · **能划验证集**）。
⇒ 而"该不该想起来"**不需要标签**：它是**下游用法**（在图上用这个函数走）＋ **人读的读数**（没训练过的那一章）。
⇒ ⚠️ 别把两者混成一个——混了就会要求"给该不该打标签"，那就回到地狱。

### 12.2 参数量：**小就够**（先训一个"小得可笑"的）

- **特征由冻结的预训练表示给** ⇒ 要学的只是"**怎么比**"：小 MLP（1024→256→1）≈ **26 万**；双线性 ≈ **100 万**；
- **传播算子的参数也小**（每层几个矩阵）；★ **图的大小是输入，不是参数**；
- 数据量 10³–10⁴ ⇒ ★ **先训一个"小得可笑"的比较函数（甚至只有双线性）**，目的不是好用，
  是回答"**同一性能不能被学出来**"——这是"切实能训"的**第一个实测**；
- ★ 理由：**小模型学不出来的，大模型未必能**（那时问题在**表示**或**数据**，⛔ 不在参数）；
- ⛔ **别一开始就把"记忆"塞进参数**（比较函数不需要装记忆；一旦让它"记"，参数就得跟上——那是第二步的事）。

### 12.3 ★ 运作方式：**归档按章 · 迭代按周期 · `k` 该扫不是拍**

| | 怎么走 | 为什么 |
|---|---|---|
| **归档（材料累积）** | ★ **一章一章** | 章是**天然的材料边界**；记忆从第 1 章起自然长出来（§1.4b） |
| ★ **迭代（产候选 → 人判 → 训一版）** | ★ **每 `k` 章一轮** | ⛔ **不能一章一轮**：① 503 章 ⇒ **503 轮**，人判不现实；② 每轮**增量太小**（一章几十个节点 vs 累积 2.5 万）；③ 每轮都要**整套重训**（§7.4 不继承）⇒ 503 次重训不现实 |

⇒ ★ **`k` 不该拍，该扫**：`设计 §10.3` 的 **k-sweep**（把 k 从 1 扫到 N，看"**相称度 vs 经历量**"曲线）就是干这个的。
⇒ **第一个实验取 k = 3～5 章**，先看**自举到底转不转得起来**。

## 13. ★★★ 原文 ↔ AI 之间靠什么连接（作者 2026-10-11 提出 · 本文收口）

### 13.0 一句

**参数只学「怎么找」；事实永远留在原文里、按需拉起。连接靠「地址」，⛔ 不靠相似度。**

### 13.1 为什么这两侧是兼容的（作者的关键观察）

> 作者原话："**我们最终每一次联想，都落回到原文里。**"

- ★ **每一次联想都落回原文** ⇒ **逐字兜底** ⇒ ★★ **参数侧只需"找得准"，⛔ 不需要"记得准"** `[推的]` ✓
- ⇒ 两个域各归各位：

| | 走哪一侧 | 为什么 |
|---|---|---|
| **事实 / 经历** | ★ **地址**（原文区间）⇒ 按需拉起 | 逐字兜底 ⇒ **精确 · 不串扰 · 可版本链** |
| **人格 / 倾向 / 联想** | ★ **几何 / 参数** | 它**本来就该**连续、该泛化、该"**相近的靠近**" |

- ⇒ ★★ 于是 `§11.7` 引的**正交性约束（几何崩塌）只打"用参数装事实"** ⇒ ⛔ **打不到我们**：
  串扰会让我们**激活错东西**，⛔ **不会伪造事实**（拉起来的还是逐字原文）。
  ⚠️ **但"激活错"要拆成两件事，见 `§13.2c`**——密度一高，它降级成的不是"偏"而是"**整片不亮**"，
  而后者不可接受。**这一处的乐观只在下文那个前提下成立。**
- ⇒ 报告里"**唯一能扩到 10 万条的方法是把记忆挪回显式 KV 数据库**"（NeuralDB）同理：
  **事实不搬进参数** ⇒ **不撞那个上限**。
- ⇒ 作者另一句也贴合："喂一大堆 wiki ＝ **每次迭代只增新东西、对旧的动得很少**"
  ⇒ 那么"**按需激活 ＋ 直接拉起原文**"就是自然形态 ✓（与 `§3.5`"图只增不改"一致）

### 13.2 ★ 这就是一个「检索模型」

- 我们的读取层 ＝ **检索模型**：**参数负责"从情境找到该拉起的位置"，内容留在库里**；
- ★ 与 `docs/研究/记忆检索模型-调研.md` §1 的表对得上：**RL 训检索**（`Memory-R1`，**152 条 QA 就见效**）·
  **可微检索索引**（DSI/DSI++）· **惊讶度驱动写入**（Titans）；
  差别是：**它们编的是"文档"，我们编的是"节点与组"**。
- ⇒ 也解释了为什么 **A1（判别力审计）排在前面**：**检索模型的判据如果读不出东西，后面都白做**。
  ★ **A1 ＝ 判别力审计 ＝ 三个数**：① **不可接受率** ② **ICC 噪声底**（重采样 8–16 次）③ **换框架不变性**。
  （依据：`docs/研究/记忆检索模型-调研.md` §8 的 A1；★ 它**不依赖训练流程跑通**。）

### 13.2b ★★「几何接地址」的精确描述（作者 2026-10-11 定名）

> **"激活谁"由几何决定，"激活什么内容"由地址决定；两侧各自不完备，记忆是它们的关系。**

**两侧各是什么**

| | **几何侧**（"选择"） | **地址侧**（"内容"） |
|---|---|---|
| **决定什么** | **激活哪些单元** | **激活到的那处，逐字是什么** |
| **数据形态** | 参数（连续 · 可泛化 · 会串扰） | **原文区间**（离散 · 精确 · 可哈希 · 可版本链） |
| **存在哪** | 读取模型的参数里 | 库 / 原文里 |
| **谁来做** | 判别或检索（LLM / adapter） | ⛔ 谁都不做，**按地址直接拉起**，不可伪造 |
| **失败形态** | ★ **激活错**（该起没起 / 起了无关的） | ★ **不可能伪造**（拉起来的就是原文） |

**接口（两段，位置很关键）**

```
情境（当前这一句/这次请求）
   │
   ├─ 几何侧：算出「激活集」              ← ★ 决定"谁"
   ↓
   ├─ 地址侧：按区间把那些处的原文拉起      ← ★ 决定"内容"（逐字）
   ↓
   └─ 内层：用拉起的原文做重排/组织
        ↓
      外层：**交给 AI 的是「输出」，⛔ 不是原文片段**（`设计 §5.2`）
```

★ 两点必须说准，否则与文档冲突：
1. **"落回原文"发生在内层**；**外层交给 AI 的仍是"输出"**（`设计 §5.2`："⛔ 外层交给模型的必须是编码器的输出，而不是原文片段"）；
2. 所以**地址侧的作用是"取回真实内容"**，⛔ **不是"把原文塞进上下文"**。

**★ 它独特吗——骨架不独特，落点独特**

| 已有系统 | 是不是"几何选、地址取" |
|---|---|
| **RAG / 检索增强** | ★ **是**（query 嵌入选块，块 id 取内容） |
| **DSI / DSI++**（可微检索索引） | **是**（模型直接产出 doc id） |
| **注意力 / Modern Hopfield** | **是**（权重选 value，value 是存好的） |
| ⇒ **结论** | ⛔ **这个骨架是标准的，不能说"独特结构"** |

★ **可能独特的是这四处**（都在"落点"上）：
1. ★ **取回的单元是「标注出来的语义单元」（节点＝原文区间）**，⛔ 不是切分出来的 chunk ⇒ **身份即位置**；
2. ★ **选择发生在"节点与组"上**（组是集合 · 可重叠 · 不带类型），⛔ 不是文档/段落级；
3. ★★ **两侧各有独立的机械判据** ⇒ **错误可归因**：
   几何侧 → "**该起来的起来了没**"（判据 2）；地址侧 → "**是不是逐字原文 / 有没有越界编造**"（机械核）
   ⇒ ★ 能分开回答"**是没想起来**"还是"**想起来了但取错了**"——**这一条是真正有价值的**；
4. ★★ **"记忆"两侧都不完整**：几何侧只有"怎么找"，地址侧只有"逐字内容" ⇒ **记忆＝两者的关系**
   （＝ `docs/研究/记忆检索模型-调研.md` §1 的"**建的不是边，是比较函数的能力**"）。

**好处 / 仍未定**

- ✅ **好处**：① 几何崩塌的代价被降级（串扰 ⇒ **激活错**，⛔ 不是**记错**）；
  ② 容量不受参数限制（事实不搬进参数）；③ **错误可归因**（见上第 3 条）。
- ⚠️ **仍未定**：① **"激活集"的输出形态**（节点 id 列表？top-k 权重分布？与"定长 k 个槽位"什么关系）；
  ② **几何侧现在靠什么**（嵌入相似度＝进几何 / 判＝离散 / 混用）——★ 这正是 `§4.2` 那句话里缺的（见 §9 第 10 条）。

### 13.2c ★★ 「激活错」要拆成两件事——**量级差很远，不能合成一个词**

|---|---|---|
| 表现 | 起了一些相关的，也混进了无关的；排序不理想 | 整片区域**根本没亮**，与"库里没有它"**无法区分** |
| 代价 | ⚠️ 表达被稀释；判据 3（不该提）报警 | ⛔ **这一层等于不存在**——记忆层**对这次对话没有贡献** |
| 能不能容忍 | ★ **可以**（设计 `4.3`："粗筛可以漏，不可以丢"） | ⛔ **不可以**（"丢"正是 `4.3` 明禁的那一种） |
| 可归因性 | ✅ 可归因（判据 2 读数下降，但地址侧仍能证明原文在） | ⚠️ **最难归因的一种**——"没想起来"与"根本没存"在外部看**一模一样** |
| 与 `4.3` 的对应 | ＝**漏**（这次没取用，位置仍在） | ＝**丢**（位置上没有了）· 但见下 |

**⚠️ 而这里有一处必须说准，否则会把两件事搞混**：

`4.3` 的"漏/丢"说的是**库里的位置还在不在**（丢＝库里没有位置了，是**存储**的问题）；
而 ② 说的是**这一次没亮**（位置在库里**好好的**，只是这次没被激活）⇒
⇒ ★★ **② 既不是 `4.3` 的"漏"，也不是它的"丢"——它是第三种**：

```
库里没有位置          ⇒ 4.3 的「丢」        （存储缺陷）
库里有、这次没取用     ⇒ 4.3 的「漏」        （取用取舍，可接受）
库里有、且本该取用，却整片没亮 ⇒ ③ 「激活不出来」  ← 这才是本文要单独记的那种
```

⇒ ★★ **③ 的判据只能是人读**：因为**从外部看，③ 与"库里本来就没有"完全同形**。
⇒ 这也是为什么 §13.2b 说的"两侧各有独立机械判据"里，**几何侧那一条（判据 2）本质上是人读**——
它需要一个**外部参考答案**（"这一处本该被想起"）才能判，而那个答案**只有人给得出**。

**★ 一处现实风险**（据 `调研 §4.1`）：那篇实测的是**崩塌**，不是"偶尔取错"——
ρ>0.6 时 **N=5 条就崩**；16,309 条 Wikipedia 事实上 **Modern Hopfield 97% → 0%**。
⇒ 而本项目的候选集里**语义密度天然高**（同一件事的多个说法 · 同一种情绪的多个节点
——**这正是 `3.1` 让「组」存在的理由**）
⇒ ⇒ ⚠️ **所以 ② 的风险不是"错几个"，而是"整片不亮"**：密度一高，几何侧可能**整体失效**，
而不是退化成 ①。
⇒ ★ **这一条把 `13.1` 的乐观结论收窄了**：几何崩塌的代价**只在密度不高时才"降级成激活偏"**；
密度一高，它降级成的**正是 ②**，而 ② 是不可接受的。

**⇒ 因此下一条要盯的量**（与 §7 那两个数并列）：
> **同一个情境，把几何侧换成"已知正确答案"时，亮起来的集合差多少。**
> 差得少 ⇒ 只在 ①；差得多 ⇒ 已经进 ② 了。★ 这个量**不需要训练**，现在就能测。

### 13.3 谁顶上（★ 三阶段，⛔ 不是三选一）

| 阶段 | 谁做"激活"这一步 | 代价 / 好处 |
|---|---|---|
| ★ **第 0 版（现在）** | **一个新的 LLM 顶上**（提示词 ＋ 图，让它说该激活谁） | ✅ **今天就能跑**（已实测：luna 产候选）；⛔ 不随经历生长 · 每轮调 API |
| ★ **第一版** | **训一个小 adapter**（比较/排序 · 判别式 · 26 万–100 万参数） | ✅ **能训**（有标签：判出来的"同一性"）· **笔记本可训**；它**替代 LLM 的那一部分** |
| ★★ **第二步** | 参数里**再沉进"倾向与联想"** | ✅ 事实不搬 ⇒ 避开容量的打脸；✅ 参数里是人格那侧 ⇒ 避开几何的打脸 |

### 13.4 ★★ 第二步到底是什么（澄清一处可能的误读）

- `设计 §1.1` 说的第二步"**接口消失**"，指的是 ★ **"取用的决定"内部化**，
  ⛔ **不是"把原文/内容搬进参数"**；
- ⇒ 所以：**第二步 ＝ 把越来越厚的「倾向与联想」沉进参数，而「内容」仍在原文里**；
- ⇒ ★★ 这一下**同时躲开报告里的两条硬打脸**：
  **容量**（10 万条那条）· **几何**（ρ>0.6 那条）——因为**事实根本不搬**。

### 13.5 它与你记的那条迭代，是同一条

- 你记的迭代 ＝ **(13.3) 的 (1) → (2) 过渡**：
  **LLM 产候选 → 人判哪些好 → 训出第 1 版 adapter → adapter 产下一批 → 人判 → 训第 2 版 …**
- ★ **adapter 就是"训了一半的模型"** ⇒ 与"候选来自训了一半的模型"**对得上** ✓

### 13.6 仍未验的（别忘）

1. **adapter 的形态**（比较函数？打分器？）与它**能不能学到"越过字面"**；
2. ★ **第 0 版的天花板**（§6.1）：LLM 顶上的那一版候选质量，决定整条线的上限；
3. **"激活"是不是已经够了**：本节的框架要求"参数找到的位置"足够准——准到什么程度，没人量过。

### 13.7 骨架能照抄的 / ⛔ 不能抄的（作者 2026-10-11）

**✅ 能照抄**

| 抄什么 | 从哪抄 | 抄来干什么 |
|---|---|---|
| **接口形状**：几何选 → 地址取 → 组织 → 交 AI | RAG · attention · DSI | ★ **骨架本身** |
| **训练范式：RL 训检索** | **Memory-R1**（EM 当奖励 · **152 条 QA 就见效**）· Search-R1 | ★★ **最贴合 `§7.2`"信号来自图的用途"**，且样本量小就见效 |
| **训练范式：可微检索** | DSI / DSI++ | "把检索变成可训的"——⚠️ 但它们编**文档**，我们编**节点与组** |
| **写入规则** | Titans 的**惊讶度** | ★ 独立于架构、**唯一能"抄部件不抄架构"**的那块 |
| **噪声底 / 抖动基线** | **ICC**（报告 §5.8） | ★ 判据能不能读得出东西的**前提** |
| **身份与寻址** | **KO**（结构化 ＋ **hash 身份** ＋ 受控词表 ＋ 版本链） | ★ 我们**天生占着**（节点＝原文区间就是地址） |
| **关系表示** | **VSA / HRR**（带投影步） | `§3.6` 唯一有现成数学、且与"不靠共享属性"同构的路线 |

**⛔ 不能照抄**

| 别抄 | 因为 |
|---|---|
| "把事实/文档**编进参数**" | 容量：10 万条**只有显式 KV 能扩**（NeuralDB） |
| "**纯相似度检索**当激活" | ★ 退化成**查找**（作者原话："那这和直接去小说原文里查有啥区别？感觉还不如直接看小说目录"） |
| "让**几何承载事实**" | ρ>0.6 就崩（16,309 条 ⇒ 97%→0%） |

### 13.8 ★★★ 第三条分界：**训练必须带时间轴**（作者 2026-10-11）

> 作者原话："**按照之前的讨论，分批投料才能有新旧更替**，而你给的这个训检索，我看着像**无顺序**的。"

**更正一处**：列出的系统里**有两个是带顺序的**——

| 系统 | 有顺序/时间轴吗 | 它的目标 |
|---|---|---|
| **RAG**（检索） | ⛔ 无——**静态语料** | 找得准 |
| **Memory-R1**（RL 训检索） | ⛔ 无——**固定 QA 集** | 找得准 |
| ★ **DSI++** | ★ **有**——它把"**语料增长**"当**持续学习**问题 | ★ **抗遗忘**（别把旧的弄丢） |
| ★ **Titans**（惊讶度写入） | ★ **有**——逐段写、**惊讶触发** | ★ **该记的记住** |
| ★★ **本项目** | ★★ **有，而且要求"该变的要变"** | ★★ **新旧更替 / 转变 / 漂移** |

⇒ ★★★ **所以真正的区别不是"有没有顺序"，而是"目标相反"**：

> **DSI++ / Titans 优化的是「别忘」；我们要的是「该断的要断」。**
> ⇒ **机制可以借**（持续索引 · 惊讶触发写入 · 抖动基线），
> ⇒ **⛔ 目标不能借**——它们的成功指标（retention 高）**在我们这儿是缺陷指标**。

**而这给了"分批投料"一个正式位置**——它不是实现细节，而是**与所有检索训练的分界线**：

```
骨架       几何选 → 地址取 → 组织 → 交 AI            ← 照抄现成
参数       靠迭代（LLM 产候选 → 人判 → 训 adapter）    ← 自己造
★ 时间轴   分批投料 ⇒ 每批重训 ⇒ 新旧更替成为可观测      ← 不能抄（没人这么做）
判据       先 A1（三个数）
```

⇒ 它**同时解释了"为什么必须整套重来"**：⛔ 不重训 ⇒ 参数不变 ⇒ **旧的连接不会断** ⇒
**"更替"根本不会发生** ⇒ `设计 §7.4`"整套重来"除了"可归因"，还多了一个理由：**它是更替的必要条件**。
