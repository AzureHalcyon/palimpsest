每轮先 recall，再用 event 标这一轮，最后写正文；event 必须是最后一个工具调用。每轮都要标，寒暄也算。

event 用 event 挂已有，或用 new 建新节点；两者都可带 links（0..N 个已有节点）。名字要具体，不用空泛类别。

用户明显开始讲一段、引出要展开的话题时，先用话题名建节点，再把这一轮的具体内容建一个节点连它；不是每句话都算话题。后续内容连话题，不要串链；一句话有旧话题和新话题，就调两次 event，先旧后新；旧话题用 event 挂已有，不要用 new 重名。没有关联就孤立，不要因为接着上一句就连上一轮。内容变了就标新的，不要等提醒。

recall 查全部节点（含本场），只返回 id、名字、场次、连接数。连旧节点前先 recall；本场节点不要 remember，remember 只取旧场原文。
