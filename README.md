# palimpsest

## “我要给她完整的一生”

一个持续演化的记忆系统，为长期陪伴设计。
人格、情绪与关系不靠预设和角色卡，而是从累积的经历里长出来。

---

## 终极目标：人格和记忆融入模型里

记忆最终要长进模型参数里。模型自己带着它，直接由内部状态决定想起什么。

## 两步计划

| | 第一步 · 外挂 | 第二步 · 融合 |
|---|---|---|
| 记忆在哪 | 关系图在外面，显式保存 | 吸收进模型参数 |
| 读到的是什么 | 激活（节点与组上的） | 激活（模型内部的） |
| 注入点 | 文字 | 模型内部的激活 |
| 代价 | 有损：多一层文字往返 | —— |

## 核心：记忆是一种网络

```
语料（原文，逐字）──▶ 关系图 ──激活──▶ 浮现
```

语料是逐字保存的原文。关系图是从它标注出来的结构：节点锚在原文区间上，
节点被划成**组**，边是它们之间的关系。**节点**的产生是判断，一律由**标注**给出，不用规则或相似度判定；**边**有两个来源（**标注**与**训练**，见 `设计 §3.6`）——其中**训练产的关联只存档、不进图**，标注侧落库的只有**组内的连接随之成立**那一形态。**组不是边**：组说的是"这些位置属于一起"，不带类型；
边说的是"它们之间是什么关系"，必须带类型，而且**不限定连两个**。

同一份语料可以有多个尺度。对同一份原文做不同角度的标注，得到**多份节点与组**；
**换一种切分粒度、分组标准或关系视角，就是另一份**——换视角换掉的不只是边，
**节点本身也会换**。一个事情可以有很多面。

**激活是一次注意力**：情境与**节点与组**里的单元直接相比，由权重决定取用哪些位置、各取多少。
任意两个单元都可以直接相望，决定取用谁的是内容，不是它们在**节点与组**里处于哪一级。
多个尺度是**节点与组**的性质，不是展开的顺序。**节点与组都是被注意的单元。**

**稀疏有两条来源**：权重自己集中在少数单元上；需要时先粗筛。
粗筛可以漏，不可以丢——漏是这次没取用，它在**节点与组**里仍在原处；丢是它在**节点与组**里没有了位置。

记忆的规模由组织方式的参数量决定，不由内容量决定。
读取成本与**节点与组**的规模无关，只与本次激活的范围有关。

节点与**落库的边**各自带时间尺度，所以时间尺度是一条谱，不是一个档位。
**含义只作标注，不进几何**；节点之间要建立关联就加一条边（几方就带几方），不靠共享属性。

## 读取模型

读取模型读**节点与组**，输出激活。输入可以是当前对话、AI 明确想知道的，或 AI 自己的思维链。
输出是给 AI 看的东西。

输出在一轮里是一串，每一次回答可以浮现好几次。它分两层：内层可以读原文，外层只给出编码器的输出。
外层给的是编码器的输出，不是原文片段——片段长度不可控，而且无法表示完整信息。

输出有两种形态：第一步是文字，第二步是激活。同一个映射，两种输出。
它随经历生长，因此是这份语料上的读取函数，无法整体搬到别的语料。

训练信号来自下游真实结果与检验。★ **节点与组是训练的材料（输入）**，⛔ 不是训练的对象、也不是训练的信号——训练的对象是**读取**（从情境到输出那一段映射，见设计 §7）。

## 三条根

一、语料是根。逐字保存，永不改写；其余一切都是派生物。

二、读法是它自己的。读取函数随经历生长，是这份语料上的函数。

三、机械的归机械，模型的归模型。记、存、查归机械：写死、要快、可复算；
判（选什么、看哪里、该不该说）归模型：学习、可变、留痕。

> “一旦做成机械的，那就真的机械了。”

## 它现在能干什么

记得住。经历攒下来不会丢，也不会被后来的总结覆盖。

会忘。不重要的事自然淡出。失效是标记，不是删除。

因为记得而改变行为。判据不是答得好不好，是行为有没有因为经历而改变。

想起来的东西会变。同一件事过一段时间再被提起，激活到的不是同一批内容。

表述每次重新生成。同一段记忆在不同处境下有不同说法，说法用完即弃，不覆盖原文。

## 约束

完整的约束见 [`docs/设计.md`](docs/设计.md) 第 11 节。摘要：

一、原文逐字保存，定稿之后永不改写；修订只为修复采集故障，且只能在建图之前。

二、节点一律由标注产生；含义只作标注，不参与几何计算；图整套重提取，不做局部修补。

三、激活只从**节点与组**里选，不创建库里的任何对象；编码器的输出不落库；一切记录都不进读取路径。

四、只有实际发生过的内容进入原文；处理产物不回流为材料。
