# palimpsest

<u>*我要给她完整的一生！——图恒宇*</u>

大模型每次对话都从零开始。把聊天记录塞回上下文，模型只是“查文本”；把角色卡交给大模型，角色卡很快会过时；把语义检索接入 AI 的记忆文档，这些文档也会很快腐化。

本项目尝试解决 AI 记忆难以长期维护的问题。最终目标是构建一个有连续人格和记忆的 AI 个体，人格与记忆随经历不断演化。

## 两步计划

1. 外挂（现在）：记忆作为模型外部的一层。事件网络、读取与归档都在模型外完成，先验证 AI 记得住、想得起来。读法暂时冻结，不训练，只积累材料。
2. 融合（以后）：把记忆与读法一起放进模型中作为特殊的一层，让人格和记忆随经历演化。人格的演化需要参数级变化，不能只靠提示词。

## 目前的工作方式简述

1. 在聊天中，模型维护一个“事件网络”，这个事件网络会将整个对话划分为不同的事件。一件事可以包含另一件，也可以和别的事有关。

2. 在回忆时，模型给出关键词作为回忆线索；线索先落到几个事件上成为种子，再沿“属于/相关”和内容相似度扩散；几件事竞争，选出一件。

3. 回忆重建完成后，把选中的事按一定顺序拼回来，交给编写模型写成一段第一人称回忆；只有这段回忆进上下文，原文和候选都不进。编写目前是一次模型调用，是暂时的办法。

4. 在归档时，跑一次 REM 式重放加 SWS 式衰减：先按当天标记和旧事件抽样选一批起点，不均匀地点亮它们；被多个起点走到的连接加强，所有非结构连接整体乘一个衰减系数，太弱的剪掉。原文不删。

5. 对于旧记忆，归档重放时不仅沿已有的边走，还会按内容重合感应：一件新事被点亮，内容相近的旧事也会被带亮。被一起点亮够多次的跨场事件，会形成新的“相关”连接。

原文不改，而记忆的变化发生在连接和写法上。

## 一轮里都发生什么

### 测试时

```
用户消息
  ↓
event：这一轮在说哪件事
  ↓
recall：从线索出发，在事件网里激活，选出最像的一件事
  ↓
recollect：按顺序重建，写成一段第一人称回忆
  ↓
回复：上下文里只有这段回忆
```

### 归档时

- 跑一次重放：像睡眠一样，不均匀地点亮当天的事；常走的连接加强，所有非结构连接整体衰减，
  太弱的剪掉；
- 原文、状态记录、事件图、编写日志分别落盘；
- 归档把 live 图写成下一版冻结；下一场开场从冻结副本读，不读本场 live 图；
- 未归档的场续聊时恢复本场 frozen 和完整 messages，和第一次完全一样。

## 为什么不直接塞记忆条目/历史记录？

| 常见做法         | palimpsest               |
| ------------ | ------------------------ |
| 按消息或按轮存      | 按事件存；一件事可以跨很多轮，也可以只在一句话里 |
| 向量检索最相似的几段   | 线索在事件网里扩散，几件事竞争，选一件      |
| 把检索到的原文塞回上下文 | 把选中的事重建成一段回忆，只把回忆放进去     |
| 忘了就是删数据      | 忘的是连接强度；原文一直保留           |

它记住的不是“哪些句子和问题像”，而是“我们经历过哪几件事，它们怎么连在一起”。

## 快速开始

需要 Python 3.13，以及一个对话模型和一个嵌入模型的调用方式。

```powershell
pip install pyyaml
```

凭证放在一个 YAML 里：

```yaml
refs:
  DEEPSEEK_API_KEY: "你的 key"
  ALIYUN_MAAS_BASE_URL: "https://你的嵌入服务地址"
  ALIYUN_MAAS_API_KEY: "你的嵌入 key"
```

聊一场：

```powershell
python -m memory_v2 chat --credentials .local/credentials.yaml --data .local/memory --session first
```

聊完让它巩固这一场，加 `--replay-on-exit`。也可以事后单独跑：

```powershell
python -m memory_v2 replay --session first --credentials .local/credentials.yaml
```

不调模型、只验逻辑：

```powershell
python memory_v2/tests/check.py
```

给外部程序用，一句一发：

```powershell
python -m memory_v2.serve --data .local/memory --session first --credentials .local/credentials.yaml --port 8765
```

然后向 `http://127.0.0.1:8765/send` POST `{"text": "..."}`，拿回复和这一轮的事件状态。
