# palimpsest

**一个为长期陪伴设计的记忆系统。** 记忆和人格从累积的经历里长出来——
不靠角色卡，也不靠每轮重新贴一遍人设。

## 方向

两条根不动：

1. **原文是根本**：逐字保存，定稿后永不改写；其余一切都是派生物。
2. **记忆的读法是它自己的**：读取函数随经历生长，是这份语料上的函数，搬不到别的语料上。

第三条是分工：**记、存、查归机械**（写死、要快、可复算）；**判归模型**（选什么、看哪里、
该不该说），而且留痕。

### 第一步 · 外挂（现在）

把记忆做成**模型外面的一张图**：格（原文的一段）、件（跨场的一处落点）、组（依赖簇）、
边（连与改口）、标记集、势。每一场归档都会让它变——**这一步要验证的是：她记得住，也想得起来。**

读法（怎么找、怎么写）**暂时冻结**：不训练，只把材料攒着。

### 第二步 · 融合（以后）

把记忆和读法一起放进**模型参数**里，让她自己带着记忆、由内部状态决定想起什么。
**人格的演化跟着这一步走**——它需要参数级的东西（类 adapter/LoRA），不是提示词。

> `docs/记忆层.md` 把这条路拆得更细（第 0/1/2 步）：第 0 步＝现在（不训，只攒料）·
> 第 1 步＝训读法 · 第 2 步＝压进参数（即这里的第二步）。
> 两个东西都会变，所以**不能同时放开**：读法先冻着，记忆先演化。
> 为什么这么定、以后怎么归因，见 [`docs/决策记录.md`](docs/决策记录.md) 2026-10-19「演化与归因」那条。

## 进展

| 已经能跑          | 说明                                                         |
| ------------- | ---------------------------------------------------------- |
| 归档（①–⑤）        | 切格 → 误差（**占位**：读她自己的 logprobs，只作观测）→ 候选 → 判（归进/新建/连/改口）→ 层1 强化 / 层2 衰减 |
| 格 / 件 / 组 / 势 | 每场所有格都有向量；件是跨场的落点；组是依赖簇（按场）与相似聚类（可跨场）；势是读取路径的 EMA，只引导传播    |
| 每轮自查          | 她自己调 `recall`；取到的件经“编写”融成一段再给她，原文不出读取层                     |
| 常驻记忆          | 开场只给一次：手写设定；另有一条会话级补充位（默认写「和谁的私聊」，之后一直在上下文里） |
| Android 宿主    | Chaquopy 把 `memory/` 嵌进 APK；对话 / 归档 / 旧场 / 记忆页都能用（构建见 [`app/README.md`](app/README.md)） |
| 可改的东西         | 提示词九段、参数账（以 `knobs.参数账()` 为准）、模型与端点；改过的存覆盖，不碰仓库默认 |

**还没做**：

- **事件级误差**（② 现在只有 token 级的 logprobs 读数，噪声大，只作观测）；
- **SWS 剪候选**（④ 里"该剪哪一条"至今没有判据，见 [`docs/待决.md`](docs/待决.md) §27）；
- **材料与卷子**（评估和训练的前提，还没产出）；
- **训练读法**；
- **人格的专门系统**（类 adapter/LoRA，见 [`docs/决策记录.md`](docs/决策记录.md) 2026-10-19「人格需要专门系统」那条）；
- **联网与唤醒工具**（暂不接入，见 [`docs/待决.md`](docs/待决.md) §29）。

> 这是**研究原型**，不是可以直接拿来用的产品；能跑的是上面那张表。

跑测试（不需要网络与凭证，模型调用走脚本桩）：

```powershell
python memory/tests/smoke.py
python memory/tests/p1.py ; python memory/tests/p2.py ; python memory/tests/p3.py
python tools/文档/check_docs.py      # 文档自查：编号顺序、重复、冲突标记、相对链接
```
