# palimpsest

## “我要给她完整的一生”

一个持续演化的记忆系统，为长期陪伴设计。
人格、情绪与关系不靠预设和角色卡，而是从累积的经历里长出来。

---

## 终极目标：人格和记忆融入模型里

记忆最终要长进模型参数里。模型自己带着它，直接由内部状态决定想起什么。

## 两步计划

| | 第一步 · 外挂 | 第二步 · 融合 |
|---|---|---|
| 记忆在哪 | 关系图在外面，显式保存 | 吸收进模型参数 |
| 读到的是什么 | 激活（图上的激活） | 激活（模型内部的） |
| 注入点 | 文字 | 模型内部的激活 |
| 代价 | 有损：多一层文字往返 | —— |

## 核心：记忆是一种网络

```
语料（原文，逐字）──▶ 关系图 ──激活──▶ 浮现
```

语料是逐字保存的原文。关系图是从它标注出来的结构：节点锚在原文区间上，
边是它们之间的关系。

一张图上有多个尺度。对同一份语料做不同角度的语义标注，得到多张图；
换一种切分粒度或关系视角，就是另一张。一个事情可以有很多面。

编码器每次只读图上的一小片。读取在多尺度上稀疏激活：
先激活一个整体（一份文档、一场对话、一个话题），再激活里面的一段，再到句或片。
原文的完整由存储保证。

记忆的规模由组织方式的参数量决定，不由内容量决定。激活是稀疏的，一次只涉及少量单元；
读取成本是定长的，因为编码器输出定长。

每个节点和边自带时间尺度，所以时间尺度是一条谱，不是一个档位。
节点有类型，可以有负面节点，也可以有其他类型；类型是元数据，参与过滤与调制，不参与几何。

训练要学的是：什么情境下，图上哪些地方激活。

## 编码器

编码器读图，输出激活。输入可以是当前对话、AI 明确想知道的，或 AI 自己的思维链。
输出是给 AI 看的东西。

输出在一轮里是一串，每一次回答可以浮现好几次。它分两层：内层可以读原文，外层只给出编码器的输出。
输出不进库，所以出错不会累积。

输出有两种形态：第一步是文字，第二步是激活。同一个映射，两种输出。
它随经历生长，因此是这份语料上的读取函数，无法整体搬到别的语料。

训练信号来自下游真实结果与探针集。关系图是被训练的对象。

## 三条根

一、语料是根。逐字保存，永不改写；其余一切都是派生物。

二、读法是它自己的。读取函数随经历生长，是这份语料上的函数。

三、机械的归机械，模型的归模型。记、存、查归机械：写死、要快、可复算；
判（选什么、看哪里、该不该说）归模型：学习、可变、留痕。

> “一旦做成机械的，那就真的机械了。”

## 它现在能干什么

记得住。经历攒下来不会丢，也不会被后来的总结覆盖。

会忘。不重要的事自然淡出。失效是标记，不是删除。

因为记得而改变行为。判据不是答得好不好，是行为有没有因为经历而改变。

想起来的东西会变。同一件事过一段时间再被提起，激活到的不是同一批内容。

表述每次重新生成。同一段记忆在不同处境下有不同说法，说法用完即弃，不覆盖原文。

## 约束

一、语料永不改写。

二、不在派生物上再加工：关系图全量重提取，不打补丁。

三、输出可重算，所以不落库；失效是标记，不是删除。
