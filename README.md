# palimpsest

**一个为长期陪伴设计的记忆系统。** 记忆和人格从累积的经历里长出来——
不靠角色卡，也不靠每轮重新贴一遍人设。

## 方向

两条根不动：

1. **原文是根本**：逐字保存，定稿后永不改写；其余一切都是派生物。
2. **记忆的读法是它自己的**：读取函数随经历生长，是这份语料上的函数，搬不到别的语料上。

第三条是分工：**记、存、查归机械**（写死、要快、可复算）；**判归模型**（选什么、看哪里、
该不该说），而且留痕。

### 第一步 · 外挂（现在）

记忆是模型外面的一张**事件网**：事件由对话中维护的状态给出（`event` 工具，六种模式），
边只有 `属于` / `相关`；一个父可以挂很多子，一个子也可以连别的根。
读取是「线索 → 种子 → 沿网和内容扩散 → 竞争 → 重建 → 编写」；
归档不再让模型判，只剩每轮落盘 ＋ 一场结束跑一次重放（REM-SWS：不均匀激活、加强、全局衰减、剪枝）。
**只有编写出来的那段进上下文**，原文和候选都不进。

这一代在 [`memory_v2/`](memory_v2/README.md)；上一代（格 / 件 / 组 / 势）整体归档在
[`archive/v1/memory/`](archive/v1/memory/README.md)，保留可运行。**这一步要验证的是：她记得住，也想得起来。**

读法（怎么找、怎么写）**暂时冻结**：不训练，只把材料攒着。

### 第二步 · 融合（以后）

把记忆和读法一起放进**模型参数**里，让她自己带着记忆、由内部状态决定想起什么。
**人格的演化跟着这一步走**——它需要参数级的东西（类 adapter/LoRA），不是提示词。

> `docs/记忆层.md` 把这条路拆得更细（第 0/1/2 步）：第 0 步＝现在（不训，只攒料）·
> 第 1 步＝训读法 · 第 2 步＝压进参数（即这里的第二步）。
> 两个东西都会变，所以**不能同时放开**：读法先冻着，记忆先演化。
> 为什么这么定、以后怎么归因，见 [`docs/决策记录.md`](docs/决策记录.md) 2026-10-19「演化与归因」那条。

## 进展

### memory_v2（当前）

| 已经能跑 | 说明 |
|---|---|
| 事件状态 | `继续` / `子事` / `回` / `换事` / `接旧` / `关联`；栈、多父、状态快照 |
| 读取 | 关键词 ＋ 向量种子、沿网和内容扩散、网络赢家、竞争、日期过滤 |
| 编写 | 按线索选段、日期 ＋ 注意力强度、最新说法赢；原文只读，不补、不猜 |
| 归档 | 每轮落盘、手动 `replay`、加强 / 衰减 / 剪、`ingest` 回灌 |
| 实时入口 | [`memory_v2/serve.py`](memory_v2/serve.py)，HTTP 一句一发 |
| 自检 | `python memory_v2/tests/check.py`（无需网络与凭证） |

**已经验过**：两场实聊（38 轮装修、32 轮工作/生活），都是读一句回一句，不是脚本；
跨会话各问 10 题，都是 10/10，0 编造；假前提、未定项、具体日期都守住了。

### memory（上一代，保留作对照）

| 已经能跑 | 说明 |
|---|---|
| 归档（①–⑤） | 切格 → 误差 → 候选 → 判 → 层1 强化 / 层2 衰减 |
| 格 / 件 / 组 / 势 | 件是跨场的落点；组是依赖簇；势是读取路径的 EMA |
| Android 宿主 | Chaquopy 把 `archive/v1/memory/` 嵌进 APK（构建见 [`archive/v1/app/README.md`](archive/v1/app/README.md)） |

**还没做**：

- **App 接入 `memory_v2`**：Android 宿主还接在 `archive/v1/memory/` 上；
- **跨多天的长期验证**：现在两场是同一天跑的，纵向的遗忘与再认还没验；
- **读取标定 / 消融**：网络赢家门槛、扩散权重还是探针上定的；
- **规模**：事件上千后的读取与重放耗时；
- **人格的专门系统**（类 adapter/LoRA，见 [`docs/决策记录.md`](docs/决策记录.md) 2026-10-19「人格需要专门系统」那条）。

> 这是**研究原型**，不是可以直接拿来用的产品；能跑的是上面那张表。

跑测试（不需要网络与凭证，模型调用走脚本桩）：

```powershell
python memory_v2/tests/check.py       # 当前链路
python tools/文档/check_docs.py       # 文档自查：编号顺序、重复、冲突标记、相对链接
```

旧链路的测试在 `archive/v1/memory/tests/`，能直接跑：

```powershell
python archive/v1/memory/tests/smoke.py
python archive/v1/memory/tests/p1.py ; python archive/v1/memory/tests/p2.py ; python archive/v1/memory/tests/p3.py
```
