## 搬迁带来的两条纪律

1. **一个仓库一份源码**：`app/app/src/main/python/memory` 是指向本目录的**目录 junction**。
   ⛔ 别在 `app/` 里改 Python —— 改这里。
2. **自检是新写的**，⛔ 不搬旧仓那 539 条断言（`分支声明 §4`：那些守的是旧形状，
   混进来会变成"为了让断言过而改设计"）。现在只有搬迁冒烟：

```powershell
python memory/tests/smoke.py
```

## 与旧仓的关系

旧仓 `companion-ai/companion`（`companion` 包）**冻结只读**，只当对照基线与 A/B 用。
要复用它的 `llm` / `embedder` / `pending` / `budgets` 就**按依赖 import**，⛔ 不要 copy-paste：
那段 `DREAM_SYS` 里"条目要独立包含完整意思"的旧信念正好是新方向（锚回原文）要推翻的，
复制会把这条信念顺带带过来，而且它**不会报错**。

## 目录约定

- 数据落盘走 `cache_dir`：`<cache>/底片/<场id>.json`、`<cache>/逐轮记录/<场id>.jsonl`
  （放在 `cache/` 下是**故意的** —— 手机上的 `backup.ps1` 捞的就是 `files/cache`）。
- 凡是**模型生成过**的东西（`判` / `说` / `常驻`）都必须落盘：温度 >0 ⇒ 重跑拿不到同一份。
