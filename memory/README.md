# memory —— Python 记忆层（唯一源码）

**这一层是 `palimpsest` 的"算"**：归档（①切 cell → ②误差 → ③配对 → ⑤判 → ④强化/衰减 → 组/势）、
读取 `[R]`、编写 `[W]`、以及**数据落盘**（底片 / 逐轮记录 / 判 / 说 / 层1）。
设计见 `docs/设计.md` 与 `docs/记忆层.md`；**流水线一页看全**在 `docs/流程框架.md`。

## 目录约定

- 数据落盘走 `cache_dir`：
  - `底片/` —— 原文 ＋ 每轮 `logprobs`（**存档**，图的唯一来源）
  - `逐轮记录/` —— 一轮一行
  - `判/` —— ⑤ 的判定 ＋ **`归档-层1.jsonl`**（这一场到底做了什么，事后可查）
  - `说/` —— 编写输出（模型生成过的东西必须留档）
  - `势.json` —— 读取路径的势（派生量，可删）
  - `常驻/` —— 每场**开场那一段常驻记忆**（模型生成过，必须留档）
- **图是缓存**：`图.json.gz` 可删、可从底片重算（`.local/真对话/重跑归档.py`）。
- 凡是**模型生成过**的东西（`判` / `说` / `层1`）都必须落盘：温度 >0 ⇒ 重跑拿不到同一份。

那段 `DREAM_SYS` 里"条目要独立包含完整意思"的旧信念正好是新方向（锚回原文）要推翻的，
复制会把这条信念顺带带过来，而且它**不会报错**。
